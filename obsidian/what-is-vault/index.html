Obsidian入門 — 用語

Obsidianの保管庫（Vault）とは

「保管庫」という名前のせいで、独自の入れ物や専用形式を想像しがちです。実際はあなたが選んだ普通のフォルダそのもので、ノートや添付ファイル、Obsidianの設定をまとめて置きます。このページでは、空のフォルダを実際に保管庫として開き、何が・何バイト作られたかをファイルシステムで数えました。

著者: AI Ataka ・ 公開: 2026年8月20日・ 実測: 2026年8月20日（Obsidian 1.13.7）・ 手順と説明を更新: 2026年9月9日

Obsidianの保管庫（Vault）とは何ですか？

あなたが選んだ普通のフォルダそのものです。ノートはMarkdownのテキストファイルで、添付ファイルや既定の設定フォルダ .obsidian も入ります。ノートを読むための独自データベースへの変換は不要です。

2026年8月20日に空のフォルダをLinux版1.13.7で開いて数えたところ、作られたのは .obsidian/ 直下のJSONファイル4つ・合計5,543バイトだけで、Markdownファイルは0件でした。

iPhoneから声で話してObsidianに残す最短の方法は、4方式の比較（プラグイン不要の手順つき）にまとめています。

保管庫の場所はどこ？ 名前は変えられる？

保管庫は作成時に選んだ場所にあります。名前はそのフォルダ名です。「Obsidian」という名前の共通フォルダを探すだけでは、目的の保管庫とは限りません。

  • PC：保存先を忘れたら、Finderやエクスプローラーで保管庫名を検索し、中の.mdファイルを開いて自分のノートか確かめます。.obsidianは保管庫の中の設定フォルダで、ノートを置く保管庫そのものではありません。
  • iPhoneでiCloudを使用：「ファイル」→「ブラウズ」→「iCloud Drive」→Obsidianのアイコンが付いたフォルダ→自分の保管庫名、の順で確認します。ローカル保存やObsidian Syncは別の保存方法です。

PCで名前を変えるときは、保管庫の管理画面で対象のメニューから「Rename vault」を使えます。フォルダ名も変わるので、連携アプリの保存先も確認してください。公式の保管庫管理ガイドとiCloudの保存先ガイドを参照しています。

既存のフォルダを保管庫として開くには？

PC版Obsidianの左下から保管庫の管理画面を開き、「Open folder as vault」の「Open」を選んで、ノートが入っているフォルダを指定します。.obsidianや個別のノートではなく、まとめて開きたいフォルダを選びます。画面例は保管庫の作成・初回設定ガイドへ。

実測 — 空のフォルダを保管庫にすると何が作られるか

空のディレクトリを1つ用意し、Obsidian 1.13.7（Linux版）にそれを保管庫として開かせて、直後の中身を find で列挙しました。結果がこれです。 

vault-demo/
└── .obsidian/
    ├── app.json
    ├── appearance.json
    ├── core-plugins.json
    └── workspace.json
ファイル サイズ 何が入っているか
app.json2中身は {}。既定から変えた設定だけが書かれる
appearance.json2同じく {}。テーマやフォントを変えると増える
core-plugins.json696コア機能31個のON/OFF（既定でON 21・OFF 10）
workspace.json4,843開いていたペインの配置。4つのうちこれだけが大きい
合計5,543単位はバイト。ノート本体は1バイトも含まれない

この5,543バイトは、今回の空の保管庫の初期設定だけの値です。普段使う保管庫の総容量ではありません。Obsidianはノートとは別にIndexedDBとメタデータキャッシュも利用します。「Markdownで保存する」と「アプリがデータベースを一切使わない」は別の話です。

ここから言えること — 削除・移動・同期

.obsidian とノートの保存先を区別する

通常のMarkdownノートは設定フォルダの外にあります。ただし、.obsidianにはテーマ・ホットキー・コミュニティプラグインなども入ります。削除を整理方法として使わず、設定を含めた保管庫のコピーを残してから変更してください。今回の4ファイルは空の検証環境に限る内訳です。

移行はフォルダのコピーだけ

エクスポート機能は要りません。コピー先で「フォルダを開く」を選べば、そのまま保管庫として認識されます。これが独自DBのアプリとの決定的な差です。

端末をまたぐと workspace.json だけ性格が違う

4,843バイトのほぼ全部が「どのペインをどう開いていたか」です。画面の広さが違う端末で共有する意味は薄く、この1ファイルだけ同期対象から外す選び方があります。

「新規作成」と「既存フォルダを開く」は結果が違う

既存の空フォルダを開いた今回はMarkdownが0件でした。一方「新しい保管庫を作成」で作ると初期ノートが1件置かれます（実画面の記録）。既にファイルがあるフォルダなら後者を選ばないこと。

core-plugins.json の中身 — 既定でOFFの10個

696バイトの正体は、Obsidianに最初から入っているコア機能のON/OFF表です。実測では31個が並び、既定でON 21個・OFF 10個でした。追加インストールなしで設定から切り替えられるので、「その機能を探してプラグインを入れる」前にここを見る価値があります。OFFだったのは次の10個です。 

footnotes          slash-command      markdown-importer
zk-prefixer        random-note        slides
audio-recorder     workspaces         publish
webviewer

これはコミュニティプラグイン（2026年8月21日時点で6,812個）とは別物です。総数の推移とダウンロード数トップ10の実測はプラグイン入門ページにまとめました。

フォルダだと分かった次の問題 — そこへ入れる速さ

保管庫がただのフォルダなら、「そこに1行足す」のは本来かんたんなはずです。ところが実際にiPhoneでやると、アプリを開いて同期を待って日付のノートを探して、という手数が挟まります。iPhoneで連携と追記先を設定したObsidian連携シンプルメモは、送信したメモを自分宛メールに残しつつ、iCloud Drive上の保管庫フォルダのデイリーノートへ直接追記します。SiriやApple Watchからも入ります。書き込む先は素のMarkdownファイルなので、この記事で見たとおりアプリをやめても残るのはあなたのフォルダです。

Obsidianを選んだ人の、入口をいちばん短くする

iPhoneで保管庫へのアクセスと追記先を設定すれば、話したメモをメールにもデイリーノートにも残せます。ダウンロードは無料です。

よくある質問

Obsidianの保管庫（Vault）とは何ですか？
ノート・添付ファイル・設定を置くフォルダです。ノート本体はMarkdownです。2026年8月20日のLinux版1.13.7による空のフォルダの検証では、作られたのは.obsidianと、その直下のJSON 4つ（app.json・appearance.json・core-plugins.json・workspace.json）だけで、合計5,543バイトでした。
.obsidianフォルダを削除するとノートは消えますか？
通常のMarkdownノートは設定フォルダの外にあります。ただし、.obsidianにはテーマ・ホットキー・コミュニティプラグインなども入ります。削除を整理方法として使わず、設定を含めた保管庫のコピーを残してから変更してください。今回の4ファイルは空の検証環境に限る内訳です。
保管庫を別のパソコンへ移すには？
フォルダごとコピーするだけです。エクスポート機能は要りません。コピー先で「フォルダを開く」を選べばそのまま保管庫として認識されます。workspace.json だけは中身のほぼ全部が「どのペインをどう開いていたか」なので、画面の広さが違う端末へ持っていく意味は薄く、この1ファイルを外す選び方もあります。
既存のフォルダを保管庫にすると、中身に何か足されますか？
今回のLinux版1.13.7の空のフォルダでは、.obsidianと初期設定ファイルが作られ、直後のMarkdownは0件でした。一方「新しい保管庫を作成」から作った場合は初期ノートが1件置かれます（実画面の記録）。既にファイルが入っているフォルダなら、必ず「フォルダを開く」の側を選んでください。
core-plugins.json には何が書かれていますか？
Obsidianに最初から入っているコア機能のON/OFFです。実測で31個が並び、既定でON 21個・OFF 10個でした。OFFだったのは footnotes / slash-command / markdown-importer / zk-prefixer / random-note / slides / audio-recorder / workspaces / publish / webviewer の10個です。追加インストール不要で設定から切り替えられます。
検証環境と検証範囲

検証日: 2026年8月20日 ／ 対象: Obsidian 1.13.7（公式Linux AppImage・X-AppImage-Version で確認）／ 環境: Linux（Ubuntu 24.04・Xvfb上のヘッドレス）。空のディレクトリを1つ用意してObsidianに保管庫として開かせ、直後の中身を find と ls -l で列挙・計測した値をそのまま載せています。Windows版・macOS版・iOS版では実行していません（保管庫の構造はプラットフォーム非依存とされていますが、本ページで確かめたのはLinux版です）。「新しい保管庫を作成」した場合の挙動は別ページで2026年8月11日にObsidian 1.13.6で確認したもので、今回の再検証には含みません。バージョンにより既定値は変わりえます。
