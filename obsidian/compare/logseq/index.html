Obsidian vs Logseq 比較検証Obsidian vs Logseq, hands-on

ObsidianとLogseq、どちらを選ぶ？Obsidian or Logseq — which one?

ネット上の比較記事の多くは、両方を実際に触らずに書かれています。このページでは同じフォルダを両方のアプリで開く実験を行い、プラグイン数は公式レジストリを当日実カウントして比較しました。2026年に入って起きたLogseq 2.0（DB版）への分岐まで含めて、いま選ぶならどちらかを整理します。Most comparison articles are written without touching either app. For this one we opened the same folder in both apps, counted plugins directly from the official registries on the same day, and factored in the 2026 split into Logseq 2.0 (the DB version) — then worked out which to pick today.

著者: AI Ataka ・ 公開: 2026年8月11日・ 検証日: 2026年8月11日By AI Ataka · Published August 11, 2026 · Tested August 11, 2026

ひとことで言うとSHORT ANSWER

自由な形式のノートと長文、豊富なプラグインを求めるならObsidian。すべてを箇条書き（ブロック）とデイリーノート起点で書く運用が合うならLogseqです。ただし2026年の判断材料として大きいのは、Logseqが2.0でノートの正本をMarkdownファイルからデータベースへ移す移行期に入ったこと。「データをプレーンなMarkdownファイルとして持ち続けたい」を最優先するなら、現時点の安全側はObsidian（またはファイル版のLogseq OG）です。両者は同じフォルダで共存でき、実験では相互に書き込みも成立しました。詳しくは以下の検証結果をどうぞ。Pick Obsidian for free-form notes, long-form writing and a deep plugin ecosystem; pick Logseq if writing everything as outliner blocks anchored to a daily journal fits how you think. The big 2026 factor: Logseq 2.0 moves the source of truth from Markdown files into a database. If keeping your notes as plain Markdown files is non-negotiable, the safe pick today is Obsidian (or the file-based Logseq OG). The two can share one folder — our experiment had them reading and writing the same files.

ObsidianとLogseqとは — 30秒でおさらいObsidian and Logseq in 30 seconds

🪨 Obsidian
ローカルのMarkdownファイルをそのまま「保管庫（Vault）」として扱うノートアプリ。ファイルは普通の.mdで、[[リンク]]とグラフビューでノート同士をつなぎます。本体は個人・商用とも無料。開発元はDynalist Inc.（カナダ）で、ソースは非公開ですがデータは常に手元に残ります。A note app that treats a folder of local Markdown files as a "vault". Files are ordinary .md; [[links]] and a graph view connect them. Free for personal and commercial use. Built by Dynalist Inc.; closed source, but your data always stays in your files.
🧩 Logseq
「今日のジャーナルにブロック（箇条書き）で書き、あとからつながる」思想のアウトライナー型ノートアプリ。AGPL-3.0のオープンソースで本体無料。従来はMarkdown/Orgファイル保存でしたが、2026年7月公開の2.0（ベータ）からデータベース保存のDB版へ軸足を移しつつあります。An outliner built around writing blocks into today's journal and letting structure emerge. Open source (AGPL-3.0), free. Historically stored as Markdown/Org files; since the 2.0 beta of July 2026 the project is shifting to a database-backed version.

検証: 同じフォルダを両方のアプリで開くとどうなるかThe experiment: one folder, both apps

「ObsidianとLogseqは同じMarkdownフォルダを共有できる」とよく言われますが、実際に何が起きるかを示した日本語の記事はほとんどありません。そこで、3つのノートを入れたフォルダを用意し、Obsidian → Logseq（ファイル版）の順で同じフォルダを開き、双方から書き込んでみました。"Obsidian and Logseq can share one Markdown folder" is often claimed and rarely demonstrated. So we made a folder with three notes, opened it in Obsidian and then in Logseq (file version), and wrote from both sides.

  1. Obsidianで保管庫として開くOpen it as an Obsidian vault
    通常のノート・[[リンク]]・タグ・日付名のデイリーノート（2026-08-11.md）がそのまま機能。フォルダには設定用の .obsidian/ だけが追加されました。Notes, [[links]], tags and a date-named daily note (2026-08-11.md) all worked as-is. The only addition to the folder was a .obsidian/ config directory.
  2. 同じフォルダをLogseqで開くOpen the same folder in Logseq
    Logseqは logseq/・journals/・pages/ の3フォルダを追加しました。既存ノートは削除も変換もされず、ルートに置いてあった日付名ファイルを、その日のジャーナルとして自動で統合表示しました。Logseq added three directories — logseq/, journals/, pages/ — deleted or converted nothing, and automatically surfaced the date-named file at the root as that day's journal.
  3. Logseq側から1行書き込むWrite one line from Logseq
    ジャーナルに追加したブロックは、Logseq専用ファイルではなくObsidianが作った 2026-08-11.md そのものに「- 」形式で追記され、Obsidianを開き直すとそのまま表示されました。往復が成立します。The new block was appended — as a "- " line — into the very 2026-08-11.md Obsidian had created, and showed up in Obsidian on reopen. The round trip holds.

共存はしますが、思想は混ざりません。Logseqは全行をブロックとして扱うため、Obsidianで書いた段落をLogseq側で編集すると箇条書き構造に組み替えられることがあります。またLogseqのジャーナル新規分は journals/2026_08_11.md（アンダースコア区切り）に作られ、Obsidianのデイリーノート既定（2026-08-11.md）と命名が食い違います。「読むのは両方・書くのは片方」に決めておくのが安全です。They coexist; their philosophies don't merge. Logseq treats every line as a block, so paragraphs edited on the Logseq side can get restructured into bullets. New journal days are created as journals/2026_08_11.md — underscores — which clashes with Obsidian's 2026-08-11.md default. Safest rule: read in both, write in one.

書き味とグラフ — 同じ「つながるノート」でも思想が違うWriting feel and graphs — two philosophies of "linked notes"

最大の分かれ目は「段落で書くか、ブロックで書くか」です。Obsidianは普通の文書のように書けて、リンクは書き手が張った分だけつながります。Logseqはすべてが箇条書きブロックで、タグやページ参照が自動的にネットワークになります。グラフビューにもその差がそのまま出ます。実測では、同じ3ノートのフォルダでも、Obsidianのグラフは「ノート3つ＋リンク1本」、Logseqのグラフはタグ（#アイデア・#PKM）までノード化されて6ノードになりました。The deepest split is paragraphs versus blocks. Obsidian writes like a document, linked exactly as much as you link it. In Logseq everything is a block, and tags and page references become a network automatically. The graphs show it: for the same three-note folder, Obsidian drew 3 notes and 1 link, while Logseq drew six nodes — the #tags became nodes too.

【2026年の重要変化】Logseq 2.0はMarkdownファイルをやめるThe big 2026 change: Logseq 2.0 moves off Markdown files

2026年7月13日、Logseqは2.0ベータ（DB版）を公開しました。ノートの正本はMarkdownファイルではなくローカルのデータベース（SQLite）になり、従来のファイル版は「Logseq OG」として別リポジトリで継続されます。実際にDB版（2.0.1）を起動して確かめました。On July 13, 2026 Logseq shipped its 2.0 beta — the DB version. The source of truth moves from Markdown files to a local SQLite database, and the file-based app continues separately as Logseq OG. We ran the 2.0.1 build to see it first-hand.

🗄️ 検証で確認できたことWhat we verified
DB版はフォルダを選ばずに初回起動からすぐ書き始められ、入力したブロックはMarkdownファイルとしては一切生成されませんでした（アプリ内のデータベースに保存）。ファイル版にあった「フォルダを選ぶ」導線そのものが初期画面から消えています。The DB version starts writable with no folder chosen, and the blocks we typed produced no Markdown files at all — they live in the app's database. The file version's "choose a folder" step is gone from onboarding.
🔀 2系統への分岐The two-track split
公式の位置づけでは、DB版がこれからの本流（リアルタイム共同編集や新モバイルアプリはこちら）、ファイル版=Logseq OGは「ノートを編集可能なローカルファイルのまま持ちたい人向け」として続きます。移行は強制ではありませんが、開発の重心は移ります。Officially, the DB version is the future track (real-time collaboration and the new mobile app land there), while Logseq OG remains for people who want notes as editable local files. Migration isn't forced — but the momentum moves.

この分岐が選択にどう効くか。「10年後もテキストエディタで開けるファイルでノートを残したい」という理由でこの2つを比べているなら、その基準を今も満たし続けるのはObsidianとLogseq OGです。一方、ブロック構造・型付きプロパティ・リアルタイム共同編集といった新機能に魅力を感じるなら、Logseq DB版は追う価値のある進化です（ただしベータであることは織り込んでください）。What it means for the choice: if you're comparing these two because you want notes that any text editor can still open in ten years, the options that keep meeting that bar are Obsidian and Logseq OG. If typed properties, tags-as-classes and real-time collaboration excite you, Logseq DB is worth following — priced as a beta.

結論 — こう選ぶThe verdict — how to choose

🪨 Obsidianが向く人Choose Obsidian if…
長文や段落で書きたい。プラグインやテーマで自分仕様に育てたい。日本語の情報が多い方が安心。データを何十年も普通のMarkdownファイルで持ち続けたい。迷ったらこちらが失敗しにくい選択です。You write in paragraphs and long form, want a deep plugin ecosystem, value abundant guides — and want your data as plain Markdown files for decades. The low-regret default.
🧩 Logseqが向く人Choose Logseq if…
頭の中が箇条書きで動く。まず今日のジャーナルに書き、整理は「あとからつながる」に任せたい。TODO管理をノートと一体にしたい。オープンソースであることに価値を感じる。Your mind runs in outlines; you write into today's journal first and let structure emerge; you want TODOs living inside notes; open source matters to you.
🔁 併用したい人Running both
検証のとおり同じフォルダで共存できます。おすすめは閲覧・検索は自由に、書き込みは片方に固定。ObsidianメインならLogseqはジャーナル閲覧用、と役割を分けると事故が起きません。As verified, one folder serves both. Read and search freely in either — but fix all writing to one side and nothing goes wrong.
🧭 まだ迷う人へStill torn?
どちらも無料なので、同じフォルダをまず両方で1週間ずつ使うのが最短です。このページの実験のとおり、試すこと自体にリスクはほぼありません（書き込みは片方ずつに）。Both are free: point them at the same folder and live a week in each. As the experiment shows, trying costs you almost nothing — just write from one at a time.

どちらを選んでも残る課題 — iPhoneでの「一瞬のメモ」The gap both leave open: split-second capture on iPhone

ObsidianもLogseqも「書いた後の整理と接続」が主戦場で、歩いている瞬間の1行を残す速さは主目的ではありません。移動中のキャプチャが多いなら、保管庫（iCloud Drive上のフォルダ）へ直接追記する軽い入力用アプリを足す構成が実用的です。Obsidian連携シンプルメモは、送信したメモを自分宛メールに残しつつ、Obsidianのデイリーノートへ自動追記します。SiriやApple Watchからも入ります。なお追記先はObsidian形式（YYYY-MM-DD.md等）で、Logseqの journals/ 命名やブロック形式には対応していません。Logseqを選んだ方はSimpleMemoとLogseqの比較も参考にしてください。Both apps live for organising and connecting what's already written; capturing one line mid-walk is neither's core. If that's most of your note-taking, add a lightweight capture app that appends straight into the vault folder in iCloud Drive. Simple Memo emails each note to you and appends it to your Obsidian daily note, including from Siri and Apple Watch. It writes Obsidian-style files (YYYY-MM-DD.md) — it does not target Logseq's journals/ naming or block format. If you picked Logseq, see our Simple Memo vs Logseq comparison.

よくある質問FAQ

ObsidianとLogseqは併用できますか？Can Obsidian and Logseq share a vault?
できます。検証では、Obsidianは.obsidian、Logseqはlogseq・journals・pagesをそれぞれ作って共存し、互いの設定を壊しませんでした。Logseq（ファイル版）で入力したブロックは同じMarkdownファイルに「- 」形式で追記され、Obsidian側にも即座に表示されます。ただしLogseqはすべてを箇条書きブロックとして扱うため、長文の段落をLogseq側で編集すると構造が変わることがあります。書き込みは片方を主にしてください。Yes. In our test each app created its own directories (.obsidian vs logseq/journals/pages) and broke nothing. A block typed in file-version Logseq was appended to the same Markdown file as a "- " line and appeared in Obsidian immediately. But Logseq treats everything as blocks, so edit long paragraphs on the Obsidian side and keep writing to one app.
LogseqからObsidianへ移行できますか？Can I migrate from Logseq to Obsidian?
ファイル版Logseq（0.10系／Logseq OG）ならデータはMarkdownなので、そのフォルダをObsidianで開くだけで読めます。ただし全行が「- 」の箇条書きで、ジャーナルのファイル名が2026_08_11.md形式（アンダースコア）である点はObsidianの既定と異なります。移行後にデイリーノートの日付書式とフォルダを合わせてください。DB版（2.0）からはエクスポート機能を経由します。From file-version Logseq (0.10.x / OG), just open the folder as a vault — it's Markdown. Expect every line bulleted and journals named 2026_08_11.md (underscores), unlike Obsidian's default; align the date format after moving. From the DB version, go through its export.
Logseqは無料ですか？料金はかかりますか？Is Logseq free? What costs money?
アプリ本体は無料で、AGPL-3.0のオープンソースです。必須の課金はありません。2026年8月時点では、DB版向けの公式同期（RTC）が招待制の有償アルファとして始まった段階で、ファイル版の同期はiCloud DriveやGitなどを自分で用意するのが主流です。Obsidianも本体無料で、有料なのは公式同期のObsidian Sync（Standard 月$4・年払い）などのサービスだけです。The app is free, open source under AGPL-3.0, with no required payment. As of August 2026, official sync (RTC) for the DB version is a paid invite-only alpha; file-version users mostly sync via iCloud Drive or Git. Obsidian is likewise free, charging only for services such as Obsidian Sync (Standard $4/mo billed annually).
Logseq 2.0（DB版）でMarkdownファイルはどうなりますか？What happens to Markdown files in Logseq 2.0 (DB)?
2.0（ベータ）はノートの正本をローカルのデータベース（SQLite）に保存します。検証でも、DB版で入力したブロックはMarkdownファイルとしては生成されませんでした。従来のファイル版は「Logseq OG」として別リポジトリで継続されます。プレーンなMarkdownファイルでノートを持ち続けたい場合は、ObsidianまたはLogseq OGが該当します。2.0 (beta) keeps the canonical copy in a local SQLite database — in our test, typed blocks produced no Markdown files. The file-based app continues as "Logseq OG". If plain Markdown files are the requirement, that points to Obsidian or Logseq OG.
プラグインの数はどちらが多いですか？Which has more plugins?
2026年8月11日に公式レジストリを直接数えた結果、Obsidianはプラグイン6,571個・テーマ680種、Logseqはプラグイン546個・テーマ66種でした。約12倍の差があります。ただしLogseqはジャーナルやTODOなど中核機能が本体組み込みで、プラグインなしで完結する範囲は広めです。Counting both official registries on August 11, 2026: Obsidian 6,571 plugins / 680 themes; Logseq 546 plugins / 66 themes — roughly a 12× gap. Logseq does ship more core features (journal, TODOs) built in.
iPhoneだけで使えますか？Can I run either on just an iPhone?
どちらもiOSアプリがあります。Obsidianは保管庫をiCloud Driveに置けばiPhone単体で運用できます。Logseqはファイル版アプリに加え、DB版の新iOSアプリが2026年からアルファ提供中です。どちらの場合も、思いついた瞬間の1行にはアプリ起動と同期の待ちが挟まるため、デイリーノートへの追記を速くする方法を組み合わせる人が多いです。Both have iOS apps. Obsidian works standalone with an iCloud vault; Logseq has its file-version app plus a new DB-version iOS app in alpha since 2026.
