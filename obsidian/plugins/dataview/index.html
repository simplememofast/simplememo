Dataviewは何をするプラグインですか？

保管庫（Vault）をデータベースのように検索できるようにするプラグインです。ノートのfrontmatterやインラインフィールドに書いたメタデータを、DQL・インライン式・DataviewJS・インラインJS式という4つの書き方で扱えます。DQLの出力形式はLIST・TABLE・TASK・CALENDARで、DataviewJSと同じ分類ではありません。公式ダウンロード数データ（2026年8月22日取得）では480万5,635件で3位でした（レジストリの登録総数は6,840個ですが、順位はこれとは別ファイルのダウンロード数データの中での順位です）。

ダウンロード統計の更新日時だけで、開発の継続・停止や現在の動作を判定することはできません。下の数値とバージョンは2026年8月22日の取得記録で、現在値ではありません。

Obsidian公式の配布元（GitHub: obsidianmd/obsidian-releases）が公開する community-plugin-stats.json と、Dataview自身のリポジトリ（GitHub: blacksmithgu/obsidian-dataview）の manifest.json を、raw.githubusercontent.com 経由でこの環境に直接取得しました。

4つのクエリモード — 公式READMEのサンプルより

公式READMEはDQL・インライン式・DataviewJS・インラインJS式の4つの書き方を区別しています。DQL内の出力形式はLIST（一覧）、TABLE（表）、TASK（タスク）、CALENDAR（日付のカレンダー）です。以下のREADME例は今回も実機で実行していません。

1. DQL（Dataview Query Language）

SQLに似た専用の記法。基本的な用途に向く。

```dataview
TABLE file.name AS "File", rating AS "Rating" FROM #book
```
2. インライン式

本文中に埋め込み、プレビューで評価される。

We are on page `= this.file.name`.
3. DataviewJS

JavaScript APIをフル活用できる、最も強力なモード。

```dataviewjs
dv.taskList(dv.pages().file.tasks.where(t => !t.completed));
```
4. インラインJS式

インライン式のJavaScript版。任意のJSをその場で実行できる。

This page was last modified at `$= dv.current().file.mtime`.

データの入力側は2種類です。ノート先頭のYAML frontmatter（---で囲む）か、本文中にフィールド名:: 値と書くインラインフィールドで、どちらもDataviewが読み取ってクエリの対象にします。 入力UIと保存YAMLから実クエリへつなぐ例は、プロパティを変更し、Dataviewの一覧が変わる実機例で確認できます。 

---
alias: "document"
last-reviewed: 2021-08-17
thoughts:
  rating: 8
  reviewable: false
---
Basic Field:: Value
**Bold Field**:: Nice!
You can also write [field:: inline fields]; multiple [field2:: on the same line].

DataviewJSのセキュリティに関する注意

公式READMEより

DataviewJSは強力な分、他のObsidianプラグインと同じ権限で動きます。つまりファイルの書き換え・作成・削除や、ネットワーク通信も可能です。自分で書いたコードか、内容を理解している・信頼できる配布元のスクリプトだけを使うことが公式に推奨されています。一方、通常のDataviewクエリ（DQL）はサンドボックス化されており、保管庫に変更を加えることはできません（その分できることは限られます）。

クエリを書く前に、まず1行を残す場所を決める

Dataviewは保管庫にあるノートやメタデータを検索・集計します。入力したメモをシンプルメモから残す場合は、連携をオンにし、アクセスできるフォルダと保存先を設定して書き込みテストを確認します。日付ノートか固定のInboxを選べます。メールの到着とノートの保存は別に確認し、Dataview用のフィールドを自動生成する機能とは区別してください。

クエリの対象になる1行を、まず作る

入力したメモの保存先と連携条件を確認してから使えます。ダウンロードは無料です。

よくある質問

Dataviewは何をするプラグインですか？
保管庫（Vault）をデータベースのように検索できるようにするプラグインです。ノートのfrontmatterやインラインフィールドに書いたメタデータを、DQL・インライン式・DataviewJS・インラインJS式という4つの書き方で扱えます。DQLの出力形式はLIST・TABLE・TASK・CALENDARで、DataviewJSと同じ分類ではありません。
Dataviewはどれくらい使われていますか？
Obsidian公式のダウンロード数データを2026年8月22日に直接取得したところ、480万5,635件で、そのデータの中で3位でした（1位Excalidraw・2位Templater）。なお「登録プラグイン6,840個」はレジストリ一覧の件数で、順位を計算したダウンロード数データとは別ファイルです。
Dataviewは今も開発されていますか？
このページの2026年8月22日の統計・版の取得記録だけでは、現在の開発状況は判定できません。統計の更新日時はコードの更新日時とは別です。公式リリースと変更履歴を確認し、利用するObsidianの版で試してください。今回の訂正では現行版をインストールして動作を確認していません。
Dataviewの基本的な書き方は？
ノートのfrontmatter（YAML）か、本文中に「フィールド名:: 値」の形で書くインラインフィールドでメタデータを付けます。そのうえでdataviewコードブロックに表示形式と条件を書きます。例えばLIST・TABLEではノート、TASKではノート内のタスクを表示できます。
DataviewJSは安全に使えますか？
公式READMEによれば、DataviewJSは他のObsidianプラグインと同じ権限で動くため、ファイルの書き換え・削除やネットワーク通信が可能です。自分で書いたコードか、信頼できる配布元のスクリプトだけを使うことが推奨されています。通常のDQLクエリはサンドボックス化されており、保管庫に書き込みはできません。
