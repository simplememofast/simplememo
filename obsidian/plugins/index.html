Obsidianのプラグイン、まず何を入れる？Obsidian plugins: where to start

「プラグインが多い」だけでは選べません。このページでは、Obsidian公式のプラグインレジストリと公式が公開しているダウンロード数データをこちらで直接取得し、総数と実際に最も使われている10個を実カウントしました。あわせて、プラグインを入れなくても済む範囲も正直に書きます。"There are thousands of plugins" does not tell you which to pick. For this page we pulled Obsidian's official plugin registry and its official download-count data directly and counted the total and the 10 most-downloaded plugins ourselves. We also cover, honestly, what you can do without installing anything at all.

著者: AI Ataka ・ 公開: 2026年8月21日・ 検証日: 2026年8月21日（公式レジストリ実カウント）・更新: 2026年8月27日（キーワード分析を追加）By AI Ataka · Published August 21, 2026 · Counted August 21, 2026 (official registry) · Updated August 27, 2026 (added keyword analysis)

Obsidianのプラグインは何個ありますか？最初に入れるべきは？How many Obsidian plugins are there, and which to install first?

2026年8月21日に公式レジストリを直接数えたところ6,812個（テーマは701種）でした。公式が公開するダウンロード数データで並べ替えると、1位はExcalidraw（手書き図解・736万件）、2位はTemplater（テンプレート・533万件）、3位はDataview（ノート検索・480万件）です。

ただし数の多さは「入れるべき」の理由にはなりません。Obsidian本体には最初からコア機能が31個入っており、そこで足りる用途も少なくありません。下の実測データと、プラグインなしで足りる範囲の両方を見てから決めてください。

Counting the official registry directly on August 21, 2026 gave 6,812 plugins (701 themes). Sorted by the official download-count data, #1 is Excalidraw (hand-drawn diagrams, 7.36M downloads), #2 is Templater (templating, 5.34M), #3 is Dataview (querying your notes, 4.81M).

A big number is not itself a reason to install anything. Obsidian ships with 31 core features already on, and many needs stop there. See both the counts below and what the core app covers before deciding.

実測 — 名前・説明文にキャプチャ系キーワードを含むプラグインの数Measured: plugins whose name or description mentions capture-related keywords

2026年8月27日、同じcommunity-plugins.json（この日時点で6,982件）を取得し、各プラグインのname・descriptionフィールドに対して英語キーワードの部分一致（大文字小文字を区別しない）を数えました。1個のプラグインが複数キーワードに一致することもあるため、内訳の合計は総数と一致しません。On August 27, 2026, we fetched the same community-plugins.json (6,982 entries as of that date) and counted case-insensitive substring matches against each plugin's name and description fields. A single plugin can match more than one keyword, so the rows below do not sum to the total.

6,982個のうち、名前や説明文で「capture」を名指しするプラグインは82個（1.2%）にとどまりました。最も多いのは「daily note」関連の133個（1.9%）で、キャプチャそのものより「捕まえた後どこに書くか」を扱うプラグインの方が多い、という分布です。この数え方は文字列の部分一致であり、機能の実態を厳密に分類したものではありません（説明文に「capture」とあっても中身が別機能のプラグインや、逆にキャプチャ機能を持ちながら別の語で説明しているプラグインは、どちらもこの表には正しく反映されません）。規模感の目安として扱ってください。Out of 6,982 plugins, only 82 (1.2%) explicitly name "capture" in their name or description. The largest group is "daily note"-related at 133 (1.9%) — more plugins address where a captured thought ends up than address the act of capturing it. This is a substring match, not a rigorous functional classification (a plugin can mention "capture" while doing something else, or offer real capture features under different wording, and neither case is caught correctly here). Treat it as a rough order of magnitude, not a precise count.

入れる前に — プラグインなしで足りる範囲Before you install anything: what core Obsidian covers

Obsidianはコミュニティプラグインを1つも入れなくても、かなりの部分が動きます。空の保管庫を実測した別ページで確認したとおり、本体にはコア機能が31個入っており、既定でON 21個・OFF 10個です。デイリーノート・グラフビュー・Markdown書式変換など中核部分はここに含まれます。Obsidian works for a lot of workflows with zero community plugins installed. As measured on a separate page, the app ships with 31 core features, 21 on and 10 off by default — daily notes, the graph view and Markdown formatting are all in there already.

デイリーノート・カレンダー的な使い方Daily notes & calendar-style use

コア機能の「デイリーノート」だけで日付ファイルの自動作成は動きます。7位のCalendarプラグインはそこに月表示のUIを足すもので、無くても運用は成立します。The core "Daily notes" feature already creates a date-named file each day. The #7 Calendar plugin adds a month-grid UI on top — the workflow works without it.

表の編集Editing tables

Markdownの表は素の記法でも書けます。5位のAdvanced Tablesは移動・整形を速くするもので、表そのものを可能にしているわけではありません。Plain Markdown tables work without any plugin. #5 Advanced Tables speeds up navigating and formatting them — it does not make tables possible in the first place.

バックアップBackups

保管庫はただのフォルダなので、OS標準のバックアップやiCloud Driveの版履歴でも保護できます。6位のGitプラグインは差分管理という別の価値を足すものです。A vault is just a folder, so OS-level backup or iCloud Drive's version history already protects it. The #6 Git plugin adds diff-based version control, a different value on top.

見た目の調整Tweaking the look

テーマの切り替え自体はコア機能で完結します。8位のStyle Settingsは、テーマ側が対応していればCSS変数をGUIで調整できるようにするもので、必須ではありません。Switching themes is itself a core feature. #8 Style Settings gives you a GUI for a theme's CSS variables when that theme supports it — it is not required to use a theme at all.

一方で、手描き図解（Excalidraw）・テンプレート自動化（Templater）・横断検索（Dataview）・タスク集計（Tasks）・カンバン（Kanban）・ファイルアイコン（Iconize）はコアにない機能で、上位に来ているのはそれだけの理由があります。On the other hand, hand-drawn diagrams (Excalidraw), template automation (Templater), cross-note queries (Dataview), task rollups (Tasks), Kanban boards (Kanban) and file icons (Iconize) are not in core — there is a real reason each ranks where it does.

プラグインを探す前に、まず1行を残す場所を決めるBefore you go plugin-hunting, decide where the first line lands

プラグインは「保管庫の中でできること」を増やしますが、「保管庫にたどり着くまでの手間」は減らしません。Obsidian連携シンプルメモは、送信したメモを自分宛メールに残しつつ、iCloud Drive上の保管庫フォルダのデイリーノートへ直接追記します。SiriやApple Watchからも入り、書き込む先はただのMarkdownファイルです。Plugins expand what you can do inside a vault; they do not shorten the walk to get there. Simple Memo emails each note to you and appends it straight into the daily note inside your vault folder on iCloud Drive, including from Siri and Apple Watch, and it writes plain Markdown.

Obsidianのプラグインは何個ありますか？How many Obsidian plugins are there?
2026年8月21日に公式レジストリ（GitHub上のcommunity-plugins.json）を直接取得して数えたところ6,812個でした。テーマは同じ日にcommunity-css-themes.jsonを数えて701種です。2026年8月11日の初回計測（6,571個）から10日で241個増えています。Counting the official registry (community-plugins.json on GitHub) directly on August 21, 2026 gave 6,812. Themes, counted the same day from community-css-themes.json, came to 701. That is 241 more plugins than the first count of 6,571 on August 11, 2026 — 10 days earlier.
最初に入れるべきプラグインはどれですか？Which plugin should I install first?
公式が公開するダウンロード数データ（community-plugin-stats.json）で並べ替えると、1位はExcalidraw（手書き図解・736万件）、2位はTemplater（テンプレート・533万件）、3位はDataview（横断検索・480万件）でした。ダウンロード数は人気の目安であり、自分の使い方に合うかは別に確認してください。Sorted by the official download-count data (community-plugin-stats.json), #1 is Excalidraw (hand-drawn diagrams, 7.36M), #2 is Templater (templating, 5.34M), #3 is Dataview (cross-note queries, 4.81M). Downloads are a popularity signal, not a guarantee it fits your workflow — check that separately.
プラグインを入れなくても使える機能はありますか？What works without installing any plugin?
あります。実測では、Obsidian本体に最初から入っているコア機能が31個あり、既定でON 21個・OFF 10個でした（詳細は保管庫の実測ページ）。デイリーノートやグラフビューなど中核機能はコミュニティプラグインなしで動きます。Yes. As measured, Obsidian ships with 31 core features, 21 on and 10 off by default (details on our vault measurement page). Daily notes, the graph view and other core functions all work with zero community plugins installed.
プラグインの登録数と実際の使われ方は一致しますか？Does the registry count match how plugins are actually used?
一致しません。登録数（6,812個）とダウンロード数データに実績がある件数（6,780個）はほぼ重なりますが、上位を独占しているのはごく一部です。1位のExcalidraw（736万件）は10位のIconize（218万件）の3倍以上で、分布は先頭に大きく偏っています。No. The registered count (6,812) and the number with recorded download stats (6,780) nearly match, but a small handful dominate. #1 Excalidraw (7.36M) has more than 3x #10 Iconize's downloads (2.18M) — the distribution is heavily front-loaded.
プラグインはどこから入れますか？Where do I install plugins from?
設定の「コミュニティプラグイン」から検索して入れるのが公式の経路で、このページで数えたレジストリがその一覧の実体です。GitHubリポジトリを直接指定する手動インストールもできますが、公式レジストリの審査を経ていないため、素性が分かっているもの以外は避けるのが安全です。The official path is searching from Settings → Community plugins — the registry we counted here is exactly that list. Manually pointing at a GitHub repo also works but skips the official registry's review, so it is safer to stick to known sources.
Obsidianで「キャプチャ」に関係するプラグインはどれくらいありますか？How many Obsidian plugins are about "capture"?
2026年8月27日に公式レジストリ6,982件の名前・説明文をキーワードで数えたところ、「capture」を名指しするものは82個（1.2%）でした。最多は「daily note」関連の133個（1.9%）です。文字列の部分一致による概算のため、正確な機能分類ではありません。Counting keywords in the names and descriptions of all 6,982 registry entries on August 27, 2026, plugins explicitly naming "capture" came to 82 (1.2%). The largest group was "daily note"-related at 133 (1.9%). This is a substring-match estimate, not a precise functional classification.
