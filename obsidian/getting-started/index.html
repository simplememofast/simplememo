Obsidianのダウンロードとインストール

まずは公式サイトから、お使いのOS用のObsidianをダウンロードします。Windows・Macの導入手順を下にまとめました。起動後は日本語を選び、保管庫を作って最初のノートへ進みます。以降の実画面6枚は、2026年8月12日にLinux版1.13.6を操作した記録です。

著者: AI ATAKA ・ 公開: 2026年8月12日・ 実画面の検証日: 2026年8月12日 ・ 補足更新: 2026年9月22日

公式ダウンロード先とOS別の手順

Obsidian公式ダウンロードページを開く → お使いのOSを選びます。

  • Windows：「Windows」の「Universal」からインストーラを取得し、開いて画面の案内に沿ってインストールします。
  • Mac：「macOS」の「Universal」を取得して開き、Obsidianを「Applications」フォルダへドラッグします。
  • Linux：公式ページで配布形式を選びます。形式ごとの操作は公式インストール手順を参照してください。本記事の実画面はAppImage版です。
  • iPhone・iPad / Android：公式ダウンロードページ内のApp Store / Google Playへのリンクから入手できます。以下の実画面ガイドはデスクトップ版を対象としています。

上の案内は2026年9月22日に確認した公式資料に基づきます。Windows・Mac・モバイル版を今回実機検証した記録ではありません。

インストールできたら日本語の設定と初回起動へ。すでにノートのフォルダがある場合は既存の保管庫を開く手順を確認できます。

Obsidianはどうやって始めればいいですか？

公式サイトから自分のOS用のObsidianを無料でインストールし、初回起動画面で保管庫（Vault）を1つ作れば、その場でノートを書き始められます。アカウント登録は不要です。実機検証では、インストールから最初のノート・リンク・グラフビューの表示まで15分かからず、その間メールアドレスの入力は一度も求められませんでした。

以下、この検証で撮影した実画面のスクリーンショットで、同じ手順を1ステップずつたどります。

公式ダウンロード新規か既存か選ぶインストール保管庫を作るノートを書くリンクを作る保存を確認コピーを確認

始める前に：新しく作るか、既存の保管庫を開くか

初めて使うなら、この先の手順で新しい保管庫を作れます。既存のMarkdownフォルダがある場合は、保管庫の管理画面で「保管庫としてフォルダを開く」を選び、そのフォルダを指定します。保管庫の中に別の保管庫を作るとリンクの扱いに問題が起きるため、入れ子にしないようにします。

保存先は、後からファイル管理画面で開ける場所を選び、フォルダ名と場所を控えます。別端末にも同じ保管庫を使いたい場合は、同期方法と対応端末を先に確認してください。メモをただローカルに作ることと、同期を設定することは別の作業です。

この補足と下の保存・コピー確認は、2026年9月9日に確認した保管庫の公式管理ガイドなどを基にした案内です。掲載の実画面は2026年8月12日のLinux版1.13.6の記録で、現在の画面と細部が異なる場合があります。

Step 1: インストール — 対応OSと配布形式

Obsidianは公式サイトのダウンロードページから無料で入手します。2026年8月12日に公式リリース（v1.13.6）の配布ファイルを直接確認したところ、次の形式が提供されていました。

OS 配布形式（v1.13.6で確認） 本記事での検証
Windows インストーラ（.exe） 配布の存在のみ確認（実行は未検証）
macOS ディスクイメージ（.dmg） 配布の存在のみ確認（実行は未検証）
Linux AppImage（x64/arm64）・.deb・.tar.gz AppImageを実際にインストール・起動（本記事の全スクショ）
iOS / Android App Store / Google Playの公式アプリ 未検証（公式情報のみ）

※ 配布形式は公式GitHubリリース（obsidianmd/obsidian-releases v1.13.6）の配布ファイルを当日確認した実測です。ダウンロードしたら、Windowsは.exeを実行、Macは.dmgを開いてアプリをApplicationsへドラッグ、というOS標準の手順でインストールします。

Step 2: 初回起動 — 日本語を選び、保管庫を作る画面へ

初めて起動すると、ノート画面ではなく「保管庫（Vault）をどうするか」を決める画面が開きます。ここで戸惑う人が多いのですが、やることは1つだけ——「保管庫を新規作成する」の作成を押すだけです。画面下の言語メニューで日本語を選べば、UIごと日本語になります（本記事の検証もすべて日本語UIです）。サインインのボタンもありますが、これは有料の公式同期（Obsidian Sync）用で、始めるのにアカウントは要りません。

Step 3: 保管庫（Vault）を作る — 名前と場所を決めるだけ

決めるのは名称とロケーション（作成場所）の2つだけです。検証では名称を「メモ」、場所をホーム内のVaultsフォルダにしました。名称には日本語がそのまま使えます。ここで作られる保管庫の実体は、指定した場所に作られる普通のフォルダです——このことはこの後、フォルダの中身を開いて実物で確認します。

「作成」を押すと、日本語の「ようこそ」ノートが開いた状態で保管庫が立ち上がりました。右側には早くもグラフビューが見えています。

保管庫の実体はただのフォルダ

作成直後の保管庫フォルダをファイルマネージャ（ターミナル）で開くと、中身は設定用の隠しフォルダ.obsidianと「ようこそ.md」の2つだけでした。ノートの本文は.mdファイルで、Obsidian以外のテキストエディタでも読めます。一方、アプリは同期状態やメタデータのためにIndexedDBも利用します。本文の保存形式とアプリ内部の保存処理は区別してください。公式のデータ保存の説明。

# 作成直後の保管庫の中身（実測・2026-08-12）
Vaults/メモ/
├─ .obsidian/     ← 設定フォルダ（app.json, appearance.json など5ファイル）
└─ ようこそ.md    ← 最初から入っている案内ノート（普通のMarkdown）

Step 4: 最初のノートを書く — Ctrl+N（Macは⌘N）

Ctrl+N（Macは⌘N）で新規ノートを作り、タイトルに「はじめてのノート」と入力して、本文を書きました。- で始めた行が自動で箇条書きになる、いわゆるMarkdown記法がそのまま使えますが、記法を覚えていなくても普通の文章を書くだけで問題ありません。

保存ボタンはありません。書いた内容は自動で.mdファイルに保存されます。実際に、このノートをテキストエディタで開くと中身はこうなっていました。画面で見たままのMarkdownです。 

# はじめてのノート.md の実際の中身（テキストエディタで開いた実物）

今日からObsidianを使い始めた。

このノートは普通のMarkdownファイルとして保存されている。

- 覚えたいこと
- 思いついたこと
- あとで調べたいこと

をここに書いていく。

Step 5: リンクを張る — [[ ]]がObsidianの核心

ノートの中で[[と入力すると、リンク先を選ぶ候補がその場に出ます。ここがObsidianの一番の特徴で、リンク先のノートはまだ存在していなくて構いません。検証では、まだ無い「買い物リスト」という名前を[[買い物リスト]]と書きました。候補には「一致するものが見つかりません」と表示されますが、これで正常です。

書いたリンクをCtrlを押しながらクリック（Macは⌘+クリック）すると、その瞬間に「買い物リスト.md」が作られて開きました。中身を書くと、右のグラフビューには「はじめてのノート → 買い物リスト」のつながりが線として現れ、画面下には「1 バックリンク」——つまり「このノートは、はじめてのノートからリンクされている」という逆方向の情報も自動で記録されています。

ここまでで身についたこと

①保管庫＝ただのフォルダを作る ②ノート＝ただのMarkdownファイルを書く ③[[リンク]]でノート同士をつなぐ（先に張って、後から作れる）。Obsidianの入門はこの3つで完了です。タグ・プラグイン・同期などはすべて、この土台の上に必要になってから足すもので、最初の日に設定する必要はありません。

最初のノートが使える状態か、5点を確認する

本文を書けたら、次の確認を一度行うと、明日も同じ場所から続けられます。これは読者が自分の環境で試すチェックリストです。

  1. 名前：「はじめてのノート」など、見つけやすい名前にする。
  2. 再表示：別のノートを開いてから戻り、書いた一文が残っているか確認する。
  3. 実ファイル：保管庫フォルダ内で該当する.mdを探し、コピーをテキストエディタで開いて本文を読む。
  4. リンク：作ったリンクを開き、意図したノートへ移動するか確認する。
  5. 再開：アプリを閉じて開き直し、同じ保管庫とノートを見つけられるか確認する。

アプリでメモが見つからないときは、まず現在開いている保管庫の名前と場所を確認します。別の空の保管庫を開いているだけなら、元フォルダを開くことで続けられます。場所の調べ方は保管庫の実体と保存先を参照してください。

グラフに線が出ない場合は、先にリンク先が開けるかを確認し、グラフの表示範囲やフィルターを見ます。線を出すためにプラグインを増やす必要はありません。画面の見た目より、必要なノートを開けることを最初の確認にします。

同期とは別に、コピーから読めるか試す

同期は変更を別端末へ反映する仕組みで、誤削除も伝わる場合があります。Obsidian公式のバックアップ案内は、同期とは別のコピーを勧めています。ノートだけでなく添付や保管庫設定も戻したいなら、.obsidianを含めたフォルダの内容を確認します。

  1. 編集を終え、保存された保管庫フォルダを別のバックアップ先へコピーする。
  2. コピーから検証用の別フォルダへ必要なノートと添付を取り出す。元の保管庫には上書きしない。
  3. テキストエディタや画像ビューアで開き、本文と必要な添付が読めるか確認する。

1回コピーしても、その後の更新分は含まれません。自分の利用頻度に合うバックアップ方法を選びます。.obsidianは設定を含む隠しフォルダで、不要ファイルと決めつけて消さないようにしてください。

始めた後の課題 — iPhoneからの「一瞬のメモ」をどうするか

ObsidianにはiOSアプリもあり、保管庫をiCloud Driveに置いてiPhoneと共有する方法があります（本記事ではiOS版は未検証です。iPhone側の選択肢はiPhoneからObsidianに送る方法6選で比較しています）。外出中の短いメモも同じ保管庫へ集めたいときは、入力の入口を決めておくと便利です。Obsidian連携シンプルメモは、iPhoneから自分宛てにメモをメール送信し、連携を設定したObsidianのデイリーノートにも追記できるアプリです。SiriやApple Watchも入力の入口にできます。

SimpleMemoで最初の1件を残す前に：メールを併用する場合は、アプリで宛先の設定・認証を済ませます。「予約」の段階では宛先認証を続け、完了後に受信箱を確認してください。Obsidianへの追記は、連携をオンにして保管庫内の保存先と必要なフォルダアクセスを設定し、デイリーノートにも同じ1件が残ったか確認します。音声入力にはiOS 26以降の対応端末・言語と、マイク・音声認識の権限が必要です。

今日作った保管庫に、明日から1行ずつ貯まっていく

メールの宛先とObsidianの保存先を設定して、短いメモから試せます。ダウンロードは無料。Freeのメール送信枠は1日3通です。

よくある質問

Obsidianはどこからダウンロードできますか？
公式サイト（obsidian.md/download）から無料でダウンロードできます。2026年8月12日の確認時点でWindows用インストーラ（.exe）、macOS用ディスクイメージ（.dmg）、Linux用AppImage/.deb/.tar.gz、iOS/Android向けの公式アプリが配布されており、本記事ではLinux版AppImageを実際にダウンロード・インストールして検証しました。
Obsidianは無料で使えますか？
アプリ本体は個人利用・商用利用とも無料です。有料なのは公式同期のObsidian Sync（Standard 月4ドル・年払い）や公開サービスのObsidian Publishなど、追加サービスだけです。この記事の検証（インストール〜ノート作成〜リンク〜グラフビュー）も、すべて無料の範囲で完結しました。
アカウント登録は必要ですか？
不要です。2026年8月12日の実機検証では、インストールから保管庫の作成、ノートの作成・リンク・グラフビューの表示まで、メールアドレスの入力やアカウント登録を一度も求められませんでした。アカウントが必要になるのは、有料の公式同期（Obsidian Sync）などを使う場合だけです。
日本語で使えますか？
使えます。初回起動画面の言語メニューで日本語を選択でき、メニューや設定も日本語表示になります。この記事の検証（Obsidian 1.13.6）もすべて日本語UIで行いました。保管庫名やノート名にも「メモ」「はじめてのノート」のような日本語がそのまま使えることを確認しています。
保管庫（Vault）とは何ですか？
ノートを保存するフォルダのことです。実体は普通のフォルダで、検証で作成した直後の保管庫の中身は、設定用の.obsidianフォルダと「ようこそ.md」の2つだけでした。ノートはすべて普通のMarkdownファイル（.md）として保存されるため、Obsidianを使わなくてもテキストエディタで開けます。
WindowsやMacでも同じ手順ですか？
公式リリースにWindows用インストーラ（.exe）とmacOS用ディスクイメージ（.dmg）があることを2026年8月12日に確認しています（Linux用はAppImage・deb・tar.gz）。本記事のスクリーンショットはLinux版のもので、Windows版・Mac版の画面は検証していませんが、インストール後の保管庫作成からの流れは同じObsidianアプリの操作になります。
iPhoneだけで始められますか？
ObsidianにはiOS版アプリがあり、App Storeから無料で入手できます（本記事ではiOS版の動作は検証していません）。iPhoneで思いついた1行をObsidianに残す方法はデイリーノートへ追記する方法とiPhoneからObsidianに送る方法6選で詳しく解説しています。
既存のMarkdownフォルダを使えますか？
保管庫の管理画面で「保管庫としてフォルダを開く」を選び、既存フォルダを指定できます。別の保管庫の内部に新しい保管庫を作ることは避け、開いた場所とノートの内容を確認してください。
Obsidian Syncを使えばバックアップは不要ですか？
同期とバックアップは別です。誤削除や上書きが同期先にも反映される場合があるため、別のコピーを用意し、必要なノートと添付を開けるか確認してください。
検証環境と検証範囲

検証日: 2026年8月12日 ／ 対象: Obsidian 1.13.6（公式AppImage・日本語UI）／ 環境: Linuxデスクトップ（Ubuntu 24.04）。掲載スクリーンショットは、上記環境でインストール〜保管庫作成〜ノート作成〜リンク〜グラフビューを実際に操作して撮影したものです。配布形式（.exe/.dmg/AppImage/deb/tar.gz）は同日に公式GitHubリリースを直接確認した実測です。Windows版・macOS版・iOS版の実行は検証していません（それらに関する記述は公式配布物・公式情報の確認に基づきます）。仕様・料金は変わる可能性があるため、最新情報は公式サイトでご確認ください。
