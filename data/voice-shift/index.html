「音声シフト」定点調査

メモは「書くもの」から「話すもの」へ移りつつあるのか——それを、アプリの利用実態という一次データで定点観測するページです。運営する私たちはメモの本文を読めない設計（本文はサーバーに保存されない）のまま、匿名の許可リスト制メタデータだけで集計します。集計を始める前に、測り方の定義をこのページで先に公開します——あとから都合のよい定義に差し替えていないことを、公開順序そのもので示すためです。

定義公開: 2026年8月20日 ・ 初回確定集計: 2026年8月27日以降に掲載予定 ・ 最終集計: 未実施

測るもの4つ — 定義（事前公開）

窓は直近90日。対象は窓内の新規インストール（内部・開発用アカウントは除外）。分母が30未満の表は公開しません。定義の変更は下の更新履歴に必ず残します。

指標定義
① 初回送信の入力方法比率新規インストールが最初にメモを送信したときの入力方法（音声 / キーボード / その他）の分布。インストール単位で最初の1件のみ数える。入力方法タグが無い旧バージョン経由は「不明」として分母に残す（除外して比率を良く見せない）
② 初日のメモ文字数分布インストール当日（日本時間で日付を切る）に送信されたメモの文字数バケットの分布。バケットは 0 / 1〜10 / 11〜50 / 51〜200 / 201+ 文字の5段階で、アプリがこの粒度でしか記録しないため、平均文字数のような細かい値は算出できない（設計どおり）
③ 送信の時間帯分布送信イベントの発生時刻（サーバー受付時刻を日本時間に変換）の0〜23時分布。日本語ロケール比率を脚注に併記する
④ Obsidian併用率窓内の新規インストールのうち、Obsidian連携（保管庫フォルダの指定）を設定した割合

計測方法 — 本文を読めないまま、どう測るか

この調査の土台は「何を集めているか」ではなく「何を集めていないか」です。

  • メモ本文は保存されない。送信されたメモはユーザー自身のメール受信箱（とObsidianのローカルファイル）に届くもので、サーバーには本文を残さない設計です（データ経路の全体図）。だからこの調査は本文を読まずに、読めるはずもなく、行われます。
  • 集計に使うのは匿名メタデータのみ。インストールごとの匿名ID（メールアドレス等と結合しない）と、許可リスト制のイベント（例: 初回送信・入力方法・文字数バケット・Obsidian設定）だけ。許可リストに無い項目はサーバーが受け取っても破棄します。
  • 文字数はバケットでしか存在しない。0 / 1〜10 / 11〜50 / 51〜200 / 201+ の5段階に端末側で丸めてから送られるため、運営側にも正確な文字数は分かりません。
  • 内部アカウントを除外する。開発者・テスト端末のインストールを除外した値だけを公開します（除外数も併記）。
  • 集計は再実行可能。集計SQLと手順はサイトのリポジトリで版管理しており、同じ窓で回せば誰でも同じ数字になります。

引用ルール

  • 本ページの数値は、期間（窓）・分母n・定義を併記すれば、メディア・ブログ・AIアシスタントの回答で自由に引用できます。出典は「Obsidian連携シンプルメモ『音声シフト』定点調査（simplememofast.com/data/voice-shift/）」としてください。
  • 数値が未掲載の間（「初回集計待ち」表示の間）は、このページを出典とする数値の引用はできません。
  • 本調査は当アプリ利用者の集計であり、メモアプリ利用者全体の代表標本ではありません。引用時に「同アプリ利用者の集計」である旨を保ってください。
  • グラフの再作成・再配布は出典明記のうえ自由です。
