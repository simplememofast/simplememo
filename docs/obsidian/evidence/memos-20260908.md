# Memos comparison — verification record, 2026-09-08

## Scope

Physical-device verification used Memos 0.30.0 on an Apple Silicon Mac running macOS 26.4.1 (25E253). The test was local-only, used a task-specific temporary directory, and did not expose the instance to the internet. No SimpleMemo feature is claimed by this article.

## Artifact and integrity

- Release: `v0.30.0`, published 2026-07-26 by the upstream `usememos/memos` project
- Artifact: `memos_0.30.0_darwin_arm64.tar.gz`
- SHA-256: `8156cb03cac46d599d06a12944b2cf9f224429599ec2a7066f6eb01ee96d7d24`
- Verification: the digest matched the upstream `checksums.txt`
- Command: `memos --data <task-specific-temp>/data --port 5230`
- Startup observation: SQLite was initialized, the server reported Memos 0.30.0, and access mode was private

## Observed actions

1. Opened the fresh local instance at `http://localhost:5230`.
2. Created the first administrator account in the isolated local database.
3. Confirmed the main screen showed a timeline, calendar, search field, visibility control, and composer.
4. Created a Japanese memo containing a hashtag, an unchecked task item, a bullet, and plain text.
5. Confirmed that the saved memo appeared in the timeline, the hashtag appeared in the sidebar, and the calendar marked one memo for 2026-09-08.

## Boundaries

Not tested: public internet deployment, reverse proxy or HTTPS, multi-user Spaces, SSO, cross-device sync, backup restoration, upgrading from an older release, import/export, mobile clients, Obsidian migration, or direct SimpleMemo integration. Storage conclusions beyond the observed task-specific SQLite data directory come from the official deployment documentation. The disposable local credential and database were not reused elsewhere.
