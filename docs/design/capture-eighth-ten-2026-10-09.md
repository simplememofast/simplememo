## Design

The opt-in stylesheet carries the Obsidian page's dark palette, typography and quiet borders through the entire guide. Eight introductions reuse an original application screenshot as a decorative preview; the full-size source, accessible description and verification caveats remain in the article. Each existing screenshot is 32–77 KB. No simulated application UI or new claim is introduced.

Reading routes sit below the image-led introductions. Chapters distinguish prose, numbered instructions, comparison tables, raw code, original screenshots, downloadable files and reference cards. The Markdown catalogue keeps its disclosure and copy controls. Source cards, FAQs, related-reading links and footer typography receive the same treatment. Existing image links still open the original evidence. Shared chrome remains generator-managed. Nine legacy headers had hidden navigation links but no matching menu control; the standard menu ID and button are restored, with a mobile download link retaining the original campaign and tracking attributes. The existing first three routes also form the standard desktop shortcuts. Scoped styles improve small footer text.

Original article text, H1, metadata, JSON-LD, scripts, links, anchors, CTA attributes and campaign destinations are preserved. The nine other language editions are rebuilt from their existing complete translation catalogs. The change introduces no new article prose and no new JavaScript; the restored menu uses existing shared interface translations. An invariant comparison of all 100 editions confirms unchanged article text, headings, metadata, structured data, original image references, article links, anchors and existing CTA destinations.

## Review and verification

The first review found inherited article styles overriding the intended layout and pale text inside Siri's light speech bubbles. These were corrected. An adversarial source review identified duplicated step numbering and physical padding that conflicted with right-to-left placement. Numbering now has one source and uses logical spacing; related-reading arrows reserve space on the correct side. FAQ open/closed indicators override the legacy always-plus rule. Small footer text is enlarged. Print emulation verifies dark step numbers. A follow-up review caught the missing mobile CTA after restoring the menu; that route is restored with the exact existing destination and tracking. A final Arabic visual review found an inherited physical arrow offset; it is now cleared before logical positioning. No major or moderate source-review findings remain.

Local browser checks cover all 100 language/page combinations at 375, 430 and 1440 pixels (300 layouts), with no document overflow or clipped main components, one working menu, ten language choices and a mobile download route on every page. All ten Japanese pages also pass fragment destination and keyboard disclosure open/close checks with visible focus. Arabic step numbering and related-reading spacing, Siri speech contrast, Markdown disclosures, and the lower reference sections receive visual review. Translation, SEO and production results are recorded in the PR completion comment. No award or design-contest result is claimed.
