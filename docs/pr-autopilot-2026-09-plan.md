## 1. 配信日 — **9月上旬ではなく、条件で決める**

外部レビューの「配信前の最低条件」に **30日程度の連続運転** がある。
自律運用の開始は **2026-08-11** なので、

```
  8/11 + 21日 = 9/01   ← 「30日程度」とは言えない
  8/11 + 28日 = 9/08   ← ここから「約30日」と言える
  8/11 + 30日 = 9/10
```

同時に、9月上旬〜中旬は **Appleウィーク**で、`trend-radar-prompt.md` は
「**Appleイベント週に無関係弾を出さない**」と定めている。

### 配信日の条件（この2つの交差）

```
  配信日 ≥ 2026-09-08                      （運転28日以上）
  かつ  配信日 ≤ Appleイベント日 − 2日      （発表前の静かな窓）
  または 配信日 ≥ Appleイベント日 + 7日     （余韻を外す）
  かつ  平日の朝（G4）
```

| 候補 | 運転日数 | 評価 |
|---|---:|---|
| **9/08（月）・9/09（火）** | 28〜29日 | **Appleイベントが9/10以降なら第一候補。**「約30日」と言える下限 |
| 9/10（水） | 30日 | 条件はちょうど満たす。イベント日と重なるリスクが最も高い帯 |
| 9/16〜9/19 | 36〜39日 | イベント直後。**余韻の混雑に埋もれる**（避けたい） |
| **9/24〜9/26** | 44〜46日 | **混雑を完全に外す。**運転日数も余裕。上旬ではない |

> **【オーナー判断・8/23】Appleイベントの日程を確認して、上の条件式に当てる。**
> 日程が9/8より前なら9/08〜09、9/10前後なら9/24週へ倒すのが安全。
