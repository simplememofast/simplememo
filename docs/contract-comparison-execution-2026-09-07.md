# 定型規約の条件比較・横断リスク抽出

2026-09-07。個別の条項検査に加え、保存済みの原文分析11件から、責任上限・知財・個人情報・準拠法の条件差と横断リスクをAIが比較した。実行記録は `contract_review.ai_comparisons` の `vendor-terms-four-clause-comparison-20260907`。

`node scripts/compare-vendor-clauses.mjs --json` とテキスト出力を実データで実行した。結果は比較1件・元分析11件・4観点。各観点に条件差、リスク、対応方針があり、比較元の個別結論、原文URL・版・指紋・根拠節・位置へたどれる。FirebaseのGCP共通本文は既存の明示参照を使用し、原文分析を増やさない。

## 比較により取り出した論点

- 責任上限：支払額連動でも対象期間・最低額・除外損害・例外が異なる。月数や固定額だけの順位は作れず、上限を停止損失の補填見込みとみなせない。
- 知財：帰属と利用許諾は別。公開コンテンツ・サービス提供・フィードバック・集計データ・ドメイン移管は権利対象が異なる。
- 個人情報：DPAの名称が共通でも製品経路・対象データ・同意義務が異なる。API向けの学習禁止をConsumer経路へ広げられない。
- 準拠法：法域の一致だけでは仲裁・裁判所・地域例外・事前通知の条件が一致しない。

これらはAIが原文分析を比較して導いた評価であり、検証器が法律上の正しさを判断した結果ではない。AnthropicのCommercial/Consumer原文も再確認した。比較の基礎は台帳に保存された取得時点・契約主体の版であり、地域別応答を混ぜない。

## 検証と残る条件

比較記録はすべての登録分析を明示的に参照する。原文指紋変更、参照欠落・重複、4観点の条件差・リスク・対応の不足、契約承認への誤変換を検出する。比較元が増えた場合も、既存の比較が対象を黙って落とさないよう再確認を要求する。既存の条項ワークシートのCI検査に接続した。

比較元の個社分析をもう一度実行したとは数えない。実際の受諾版・個別契約・地域適用、DPA審査全体、契約締結・支払い・事業者の切替は未確認又は未実行のまま。個人情報や非公開請求データは使用していない。
