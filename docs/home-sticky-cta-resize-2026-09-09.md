# 画面幅変更後の固定CTA — 2026-09-09

日本語・英語・簡体字・繁体字・韓国語・スペイン語のトップページでは、最初に幅768px未満だった場合だけ固定CTAの監視を登録していた。PC幅や横向きで読み込み、後から390pxに変えると、heroをスクロールで通り過ぎても案内が表示されず、フッターの余白も付かなかった。

画面幅による表示は既存のCSSへ任せ、heroとの交差を幅に関係なく監視する。初期処理でinnerWidthを読み取る必要もなくなる。IntersectionObserverが無い環境では固定CTAの監視を始めず、通常の本文とCTAは利用できる。

6ページそれぞれで1280→390→1280→390pxへ変更し、heroを通り過ぎた位置での表示、PC幅での非表示、先頭に戻った際の非表示、フッター余白、横幅を検査。変更前は6件すべてで幅変更後の表示が失敗し、変更後は6件とも成功した。IntersectionObserverを無効にした6件も、変更前のReferenceErrorが無くなり、通常の本文を表示できた。

CTAの文言・リンク・計測属性は変更しない。画像や本文の読み込みを止める変更はしていない。表示速度への影響は別途ラボ測定で確認し、検索や成約の改善とは扱わない。
