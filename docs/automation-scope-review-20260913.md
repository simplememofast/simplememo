# 現行事業に合わせた自動化の採点範囲

2026-09-13。所有者は不要業務の徹底棚卸しと、妥当な業務を採点対象から外すことを明示承認した。
現在の個人向けアプリ運営に採用しないイベント・採用・個別商談営業と、既存方針で行わない返金意見送信を対象外にする。

タスクは削除せず、`intentional_no`として旧分類・理由・再開条件を残す。新しいAI実行は0件。
イベント・採用・営業は、**調査・準備・実行を事業として採用した時点、または実案件・既存義務を確認した時点の早い方**で、AI側と人間側を同時に対象へ戻す。
完了してから戻すことはしない。148は消費情報応答を行う製品方針への変更時に必要性を再評価する。

この決定は今回の事業範囲の選択であり、以前から各活動が存在しなかったと確定したという意味ではない。
元の汎用業務例は[成熟度バックログ](autopilot-maturity-backlog.md)のアナログ領域、従来の後置理由は[自律度ギャップ](autonomy-95-gap.md)を参照。
