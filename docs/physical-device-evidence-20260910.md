# 接続した実機の確認と残る購入・復元証拠

2026-09-10。配布済みTestFlight 5.8.54（1342）、ソース
`a1cb757ba4a5f5730f50030c9d7b75704de2cb13`をiPhone 13とApple Watchで確認した。
正式な確認は同じ配布版で5/6項目であり、AI実行率は156/179のまま。
配布内容は[iOS PR #467](https://github.com/simplememofast/simplememo-ios/pull/467)。
旧5.8.53（1316）の購入成功を今回の確認には転用しない。
以下は2026-09-10 13:30 UTCに非公開の実機記録とCI結果を読み戻した時点の状態。

## 委任された操作

ユーザーはiPhoneの接続・信頼を済ませて実機利用を指示し、WatchのDeveloperモードと
iPhoneのUIオートメーションを有効にしたうえで、残る実機確認の続行を依頼した。
これに基づきCodexが接続済み端末のUIを操作し、実際の結果を観測している。
「実機確認は機械には代われない」という旧分類は、この実行経路を反映していなかった。

委任の範囲は、ユーザーが利用を指示し接続・信頼した端末の実機テストと証拠の記録。
ユーザーは1Passwordの通常利用も指示した。保存項目と利用先を照合し、秘密値をチャットや
公開記録へ出さず、端末内のコピー・ペーストを使用する。Face ID、端末のロック解除、
サイドボタン認証など本人の操作が必要な箇所はユーザーが行う。
利用者本人の収集同意や、無関係な端末・アカウントには範囲を広げない。

## 復元の反復を停止した理由

既存Premium状態から復元を5回開始し、うち2回は認証情報未入力のままキャンセルした。
残る3回は保存済み認証情報を端末内で使用したが、復元成功は確認できなかった。
一度はAppleの認証成功後にStoreKitのアカウント解決エラーが記録され、別の一度は
Sandbox認証のHTTP 502が記録された。最後の試行はアプリの一般エラーのみであり、
同じ502が原因だったとは判定していない。これらを購入・復元の合格に数えない。

ユーザーから「既にPremiumの状態で繰り返しても復元の確認にならない」と指摘を受け、
この経路を停止した。非公開の実機実行ラッパーは旧復元メソッドとクラス一括実行を拒否する。
時間の経過や認証の解除だけを理由に、その復元を再開しない。

## 専用Sandboxで追加確認できたこと

無料状態かつ購入履歴のない専用Sandboxで、新規購入の完了を1件確認した。
購入画面は4回開始し、最初の3回は認証情報を送信する前に閉じたかキャンセルした。
認証情報の送信は1回で、TestFlightの購入完了表示、アプリの購入成功表示、
対象時間の`FinishTransaction_SK2`ログを照合した。取引IDは実機側から取得していない。
購入直後の設定はFreeのままだったが、アプリを前面へ戻した後にPremium表示を確認した。
証拠は非公開の`dedicated-sandbox-new-purchase.json`に保持する。

購入前の権利なし状態では復元操作を2回開始し、1回は認証前にキャンセル、1回は認証した。
処理終了後もFreeだったが、最終の購入なし案内は取得できておらず、結果検証は未完了。
この試行は有効な権利の再取得を証明しない。`dedicated-sandbox-free-baseline.json`に
記録した本日の実使用回数も未観測であり、無料枠4回目からの課金導線は未検証。
購入成功をその導線の実適用や全実機確認の完了へ置き換えない。

購入後の設定表示を更新する[iOS PR #468](https://github.com/simplememofast/simplememo-ios/pull/468)は、
ローカル643件と最終コミットのCloud CIを通過し、mainへマージした。
マージSHA `5840e61653638b39d15d1e6de672e8368a6f2340`のMain Validationも成功。
この修正のTestFlight配布や実機確認は実施しておらず、実機1342の証拠には含めない。

## 残る条件と加点

新規購入は確認済みなので繰り返さない。有効な購入権利の再取得は別の未完了項目として保持する。
2026-09-11、元のMedia & PurchasesアカウントとXCTestの本人認証は完了した。
同日09:41・09:42 JSTに、CodexがiPhone 13の同じ配布版5.8.54(1342)で購読表示の確認と
元の下書きの照合を実行し、各1件成功・失敗0を確認した。認証画面が消えただけで完了とはしていない。
下書きは保持されている。証拠は非公開の`xctest-authentication-success.json`と各実行結果に保持する。
本人認証待ちは解消しているが、Premium表示だけを独立した購入権利の再取得の証拠にはしない。
この確認に新規購入・復元の開始は含まず、停止した既存Premiumからの反復復元も再開していない。
権利の再取得を検証する場合は、有効な購入権利が存在する前提とStoreKitからの結果を照合する。
表示用キャッシュの書き換えで無料状態を作らない。
期限切れや購入履歴の削除で権利をなくした場合に、Premiumへ戻ることを期待しない。

同日10:14 JSTの限定された起動観測では、StoreKitが現在の権利1件・購読状態1件を返した。
ただし購読観測の送信・保存は確認できず、署名検証や取得後の条件のどこで止まったかは未特定である。
この結果も購入復元の完了には数えない。限定収集設定は解除済みで、詳細は
[購読観測の実行証拠](subscription-observation-evidence-20260910.md)に記録する。
各条件を個人情報なしで端末ログへ残す[iOS PR #469](https://github.com/simplememofast/simplememo-ios/pull/469)は、
最終版のローカル39件・Cloudの事前検証・マージ後のMain Validationを通過して取り込み済み。
次回のまとめ配布用の修正であり、実機1342の結果や新しいTestFlight配布の証拠には含めない。

StoreKit 2は通常、起動や再インストール時に取引を自動で取得するため、復元の全ケースで
無料表示を経由するとは限らない。既存Premium表示を成功の根拠にせず、新規購入・自動取得・
明示的な復元のどれを確認したかを記録する。
[Appleのsync仕様](https://developer.apple.com/documentation/storekit/appstore/sync())、
[現在の権利の取得仕様](https://developer.apple.com/documentation/storekit/transaction/currententitlements)。

専用Sandboxの準備や1Passwordの解除は購入・復元の完了ではない。
全6項目が同じ配布版で揃ってから、実行者・時刻・SHA・版・ビルドと証拠の種類を
`simplememo-ios/data/appstore/device-verification.json`へ記録する。
Codexの実機操作をオーナーの申告に置き換えず、本人が行った認証も区別する。
現在その提出用記録は更新していない。

今回変更するのは実機結果と残る条件の記録のみ。実行者の実績は`human_only`、
ブロッカーは`verification_pending`を維持し、全実機確認の完遂前には加点しない。
提出時の同一SHA、CI、TestFlight 24時間、日英ノート、提出枠、日次上限、段階公開の条件も維持する。
今回のTestFlight配布記録は2026-09-10 05:09:32 UTCであり、24時間経過は
2026-09-11 14:09:32 JST以降となる。
