## 2. 新データが確定させた6つの事実

### 2-1. 製品はカテゴリ上位25%。獲得の下流価値は高い

D1 40.28%・D7 8.33%はともにAppleピアセット（仕事効率化×サブスク型）の**75パーセンタイル超**。
「作れば残る」状態が実証されたので、**獲得（表示→install）への投資は下流で減衰しない**。
逆に言うと、CVR 2.45%（中央値未満）と$2.63（下位25%未満）が、上流で稼いだ表示を捨てている。

> **含意:** v3が守備範囲にしなかった「ストアの中」が、いま最も安い改善面。
> なお **Appleベンチマーク数値（上位25%等）は対外訴求に使わない**（Apple提供の内部比較情報。§8参照）。

### 2-2. Obsidianコホートは黄金——ただし逆因果に注意して読む

- 設定済み新規41人の活性 **97.6%**（未設定 30.5%）。設定は**全員day0**。
- 窓内全installでも sender率 48.9% vs 19.9%（**2.5倍**）
- サブスク源泉でも「参照元アプリ」17/49 ——Obsidian文脈の流入が課金までつながっている
- paywall CVR: obsidian_only 33%（3→1） vs daily_limit_3rd 8.3%（12→1）

注記: 活性40人中36人は**送信→設定の順**（config_first は4人のみ）。「設定が活性を作った」ではなく
「**Obsidian目的で来た人はほぼ確実に活きる**」と読む。どちらにせよ獲得すべき人物像は同じ。
v3の「Obsidianクラスタ深掘り」（サイト側CTR 6.52%）と、アプリ側の最良コホートが**同一人物**だと確定した。

first send の**77%が音声**（48/62）。memo_text_started も音声60 vs キーボード17。

### 2-5. AI経由の来訪は「もう来ている」——そして最も濃い

## 3. ボトルネック診断——制約理論で1つずつ

```
表示(82.5千/3M)は足りている ─ v3どおり勝ち筋の面だけ伸ばす
クリック→サイト(1,912/月)も v3施策が進行中（mid-CTA・次の1歩）
サイト→ストア(87/月)は改善中（+36%）
★ストア→install（CVR 2.45%）← いまの主制約。全ソースに掛かる乗数
★install→課金の単価（$2.63）← 第二制約。年額比率29%が低い
install→活性(58%)・D1(40%)・D7(8.3%)は上位25% ── 触らなくてよい（製品が既に仕事をしている）
```

CVRを中央値3.46%へ戻すだけで、**同じ表示のまま install +41%（約+310/月）**。
サイトのクリックを+41%増やすのに必要な労力と比べれば、これが最も安い。

## 4. 施策ROIランキング

> 各施策: **根拠 → 作業 → 工数 → 期待効果（式つき）→ 確度 → 測定**。
> 期待効果は月次・保守側。確度は「実測あり=高 / 外挿=中 / 仮説=低」。

### 🥇 R1. CPP配線 — 作成済み34本のカスタムプロダクトページをサイトCTAに接続する

- **根拠:** CPP34本が**配線ゼロ**（ASCプロダクトページ一覧で全行「-」）。唯一露出した mail-to-self は
  **CVR 5.42% = デフォルト2.45%の2.2倍**（n=15、小標本）。サイトのCTAは既に `pt=128498560&ct=<page>__<placement>` 完備で、
  `ppid=` だけが無い。
- **作業:** ページクラスタ→CPPの対応表を作り、CTA hrefに `ppid=<uuid>` を付与
  （例: `/vs/notion*` → vs-notion、`/blog/line-keep-alternative` → LINE Keep Alternative、`/obsidian/*` → obsidian-vault、
  `/siri/`・`/hands-free/` → feat-siri-shortcuts、`/apple-watch*` → watch-capture、`/note-to-email/` → mail-to-self）。
  `scripts/tag-cta-placements.js` の隣に生成ロジックを足すのが素直。CPP側の中身（スクショ1枚目）が
  ページの検索意図と一致しているかを配線前に1本ずつ確認。
- **工数:** 0.5〜1日（サイト側のみ・ストア審査不要。CPP自体は承認済み資産）
- **期待効果:** Web参照PPV 17/日×30=510/月。ブレンドCVR 2.45%→4%で **+8 install/月**。
  それ自体は小さいが、**真の価値は計測解像度**——以後「どのページが何install生むか」がASCで直接読める。
  R2/R9（広告）/PR の判定精度が全部これに乗る。
- **確度:** 中（実測1点あり）／計測価値は確実
- **測定:** ASC プロダクトページ別 閲覧数・DL数・CVR（週次でgrowthレポートに1表追加）

## 5. ブランディング考察（徹底版）

### 5-1. 名乗りは統一済み。次は「文法」を統一する

エンティティ統合（Obsidian連携シンプルメモ / Simple Memo - for Obsidian）はv3で完了（8/11・§11-5）。

これをPR・ASO・X・サイトコピーの共通文法として固定する。「AIが賢い」を先頭に置いた瞬間に
PV1/26の面に立つことが自社データで分かっている（VISION §0の実証）。

### 5-2. トップページがまだAI前面である（本書で唯一のサイトコピー指摘）
