## ⑦ 法人経営

**全項目 ⬜。**3リポジトリに証跡ゼロ（evidence §7）。

レビューの原則をそのまま採る：
**「法人責任や士業判断まで無人化するのではなく、権限と承認境界を明確にする」**。

仕訳/請求/領収書/銀行/カード/月次締めの統合 ・ 税務/給与/社会保険/法定期限の管理 ・
定型/非定型契約の分類 ・ 責任上限/知財/個人情報/準拠法の条項検査 ・
取引先/送金先/利用サービスの許可リスト ・ 支出上限と重要支出の二者承認 ・
契約/請求/納品/支払いの照合 ・ AI事業者のDPA/データ利用/SLA/撤退計画の審査 ・
エージェントごとの権限/認証情報/失効手順 ・ 董事会/株主/規制/契約記録の保存 ・
法務/税務/労務/事故時の専門家エスカレーション ・ 物理業務発注後の写真/受領/品質/成果確認 ・
倫理/評判/長期影響を評価する独立監査

> **`HaaS` を書くときは Human-as-a-Service か Hardware-as-a-Service かを必ず明記する。**
> 曖昧なまま外に出さない。

## アナログ領域 — AIと人間の分担

**「できない」ではなく「どこまでAIがやり、どこから人間か」**で整理する。

| 領域 | AIが担う | 人間が担う |
|---|---|---|
| **イベント** | 候補選定・見積比較・発注・在庫・配送・リード集計 | 現地設営・接客・物理的な実施 |
| **人事** | 募集・候補抽出・日程調整・書類作成 | 採用・解雇・評価・健康情報に関する判断 |
| **公的資金** | 制度探索・期限管理・申請書下書き・証憑収集 | 表明・提出・面談・法的責任 |
| **契約** | 定型契約・条項比較・リスク抽出 | 非定型・高額・海外・知財関連の承認 |
| **R&D** | 調査・仮説・プロトタイプ・実験 | 安全性・知財・投資継続判断 |
| **営業** | リード選定・メール・日程調整・提案書 | 交渉・信頼形成・重要契約 |
| **危機対応** | — | **個人情報事故・法的請求・重大障害・炎上は自動停止して経営者へ移管** |

> **この表がそのままプレスリリースの本文になる**（原稿 §3 の担当分担表はこの縮約）。
> 「AIにできないこと」を並べるより、「境界を設計してある」ほうが強い。
