## 継続実行への適用

`node scripts/execution-priorities.mjs` で、各行の直接効果と作業見積もり、現在の待ちを出す。
未評価を短時間作業とみなさず、待機・権限境界・実需のない作業を分ける。
評価の有効期間は24時間。期限切れ後は再調査へ戻す。
この仕組み自体、調査完了、包括承認の再記録ではAI実行率を上げない。
