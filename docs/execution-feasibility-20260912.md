## 上限の算数

現在の未移管実施中21件のうち4件を残すため、最大17件の移管となる。
未着手20件のうちn件を新たにAIが完遂した場合の、十分に緩い上限は
`(158 + 17 + n) / (179 + n)`、`0 <= n <= 20`。
これはnに対して増加するので、最も有利な場合でも195/199 = 97.989949748…%。
小数1桁表示で98.0%になっても、厳密な98%超条件には不合格である。
配信後なら196/199になり得るという仮定も、配信前条件を満たしたことにはならない。

これは現在の能力・業務定義・未実行状態に依存する条件付き上限で、将来永遠に不可能という主張ではない。
他の全件が完遂できるとも主張していない。現行分類に基づく上限178/192はさらに低い。
棚卸しの削除・分割、human_onlyの一括変更、丸め、閾値変更によって届かせない。
