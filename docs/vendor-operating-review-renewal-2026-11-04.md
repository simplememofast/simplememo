## オーナーに残すこと

1. **Anthropic の AUP（2026-11-12 発効）**：「consumer subscription を経由させるサービス」の禁止が、
   CI の Claude Code の OAuth 経路（本人の契約を本人のリポジトリで使う）に当たらないか。
   この審査は当たらないと読むが、法的な判断ではない。
2. **Postiz の鍵の失効とアカウントの扱い**：鍵2つがリポジトリの secret に残り、発行元での失効の記録が無い。
   失効・secret の削除・アカウントの解約やデータの削除の依頼は、オーナーだけができる。
3. **Bing Webmaster の再同意**：10-14 から毎日失敗している。再同意するなら、元の読み取りの権限だけで行う。
4. **Cloudflare のメール移行の保留**：日次上限が 1,000/日になり、再開の合図の1つに当たった。再開するかはオーナーが決める。
   この審査は再開を許していない。
5. **Resend の Contact ID の再利用**：残っている2件は解除の手段が無い。修正 #483 は draft のままである。
6. **D1 で止まった送信1件**：解除はオーナーだけができ、期限は 11-13 22:31Z。済んだかは確かめていない。
7. **Codex の週次観測**：9-30 から止まっている。Mac 側の定期実行の確認が要る。
8. 前回から残っているもの（GA4 の BigQuery の写しの保存期限、GA のデータ処理規約の受諾と共有の設定、
   Ahrefs のプラン、ライブドアの運営会社の変更）は、そのまま残っている。

## 限界

- これは運用上のリスクの判断で、法的な判断ではない。法的に依拠するなら、資格のある専門家の確認が要る。
- 規約の指紋はこの環境から取った回で、CI の週次とは別。OpenAI は Web アーカイブの写しで読んだ。
- 管理画面は見ていない（Cloudflare のメール送信の上限だけは API で読んだ）。各社の受諾版・設定・請求は確かめていない。
- 9/8・10/2・10/4 の判断の根拠（各社の原文の読み）は引き継いでいる。今回は全文を読み直していない。
- 調査の一部（各社の改定の読み、TDnet の走査）はこのセッションの調査役が行い、影響の大きい4点だけを原本で確かめ直した。
