# 価格変更の委任と実行条件（2026-09-28）

オーナーは、将来の価格変更を AI が担当することを認め、人へのエスカレーションを求めた。これは具体的な価格、対象地域、実施日、既存購読者への適用方法を決めた指示ではない。自律変更の数値幅も未設定である。したがって、**すべての実価格変更について案件ごとの事前承認を受ける**。AI は原資料の照合、影響分析、変更案の作成と、承認された内容の実設定・読戻しを担当できる。プラン構造と無料枠の変更、契約や課金同意の判断は別の承認を要する。

## 変更前に揃える一枚の承認票

| 項目 | 記録する内容 |
| --- | --- |
| 対象 | アプリと購読 SKU、変更する国・地域、通貨 |
| 原状態 | App Store Connect で読み取った現価格、読取時刻、現在の予定価格、既存購読者の状態 |
| 提案 | 新価格、開始日と時刻、地域ごとの差、変更理由と収益・顧客影響の試算 |
| 購読者 | 既存購読者の価格を維持するか、変更を適用するか、その対象と根拠 |
| 通知 | Apple による通知・同意の要否と予定、アプリ・サイト・ペイウォール・サポート表示の整合 |
| 実行 | 実行者、案件の承認者と承認時刻、実施可能な範囲、停止条件、読戻しの担当 |

`data/site-constants.json` は公開表示の入力であり、実際の App Store 価格の証明ではない。承認票は App Store Connect の実状態に基づいて作る。Apple は既存購読者の価格維持・適用、値上げ時の通知・同意、発効後の変更制限を案内している。実行時に[Apple の現行手順](https://developer.apple.com/help/app-store-connect/manage-subscriptions/manage-pricing-for-auto-renewable-subscriptions)を確認する。

## AI が実行できる範囲

1. 実 ASC 価格と公開表示を読み、変更範囲・既存購読者・通知の影響を整理する。承認票に不明点を明示して人へ渡す。
2. 人が対象 SKU、国・地域、新旧価格、開始日、既存購読者の扱い、通知方針を案件ごとに承認したら、指定された変更だけを既存の正規経路で行う。追加の課金、権限拡大、認証方法の変更、別の SKU や無料枠の変更は含まれない。
3. 変更後に ASC の実価格・予定・既存購読者設定、アプリ・サイト・ペイウォールの本番表示を読み戻し、承認票との差分と時刻を記録する。必要な CI や配布確認を省略しない。
4. 不一致、403、認証・権限・Apple の保留、通知や同意の不明点、読戻し不能、想定外の顧客影響があれば作業を止め、人へエスカレーションする。停止解除や別価格への修正は推測で行わない。

この文書と権限台帳の更新は、将来の実行を安全にするための準備である。具体的な価格変更、承認票、本番読戻しはまだない。正式な AI 実行率では #150 を引き続き未受入とし、方針変更や CI 成功だけで加点しない。元の受入条件を変更する場合は、変更前の台帳を残し、適用日を明示した別版で判断する。
