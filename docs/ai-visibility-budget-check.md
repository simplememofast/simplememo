# AI露出観測で見つかった予算検査の誤検知

2026-09-06の初回クラウド観測は5問成功、実費0.238017ドル。実費をanalysisとして記録したPR #997で、L1検査が全19候補のbudget=passを理由に停止した。初めてanalysisの実測が入ったことで中央値を使えるようになったためで、予算超過や月次枠切れではない。

全候補で同じ結果になる事実は引き続きログに出す。その上で同じ実判定関数に、設定済み6種別それぞれの「上限ちょうど」「上限超過」「予測不明」を渡し、pass/fail/unknownを区別できる場合だけ、今回の同質なサンプルを検査故障と扱わない。対照は診断用の入力であり、候補や実行台帳には追加しない。他の同値基準は従来どおり停止する。

定数pass/fail/unknownの判定器と上限なしの状態は回帰検査で拒否した。予算上限、L4方針、実候補の判定、執行条件は変更していない。1回の実費が同種別の他業務を精密に予測する保証はなく、既存中央値予測の限界は残る。
