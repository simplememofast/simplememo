# Editorial resources

The public resources added in September 2026 are generated by `scripts/build-citation-assets.py`:

- `/en/autopilot/`: an English report about the historical August 11–September 2 window.
- `/press/` and `/en/press/`: descriptions, product facts, existing setup screens, explanatory animations, and original research sources.
- `/resources/obsidian-inbox/` and its English counterpart: a browser-local Markdown example generator, starter files, and an unfilled measurement worksheet.

Run `python3 scripts/build-citation-assets.py` after editing its content, source assets, or site constants. Run it with `--check` to verify committed output. SEO Validation runs that check. The generated HTML uses the existing i18n normalizer, and image/CSS/JS queries use the same content hashes as the cache check.

The historical JSON at `data/autopilot-research-2026-09-02.json` is an extract of an explicitly identified public Git revision. It contains 41 rows: 28 attempted runs, 19 shipments, and 7 attempted runs with a recorded intervention. Do not replace this dated input with the live ledger or silently move its observation window. A future report needs a separately dated snapshot and descriptions that agree with it.

The site's existing videos were made by `scripts/build-videos.py`. The media kit therefore labels them explanatory animations, not device recordings or benchmark evidence. The comparison CSV contains empty measurements. Device measurements and editorial reviews cannot be inferred from these assets.

The Markdown tool neither accesses a vault nor sends note content. It uses textContent for the preview, a Blob for download, and an explicit clipboard action with a selectable-text fallback. These tool pages omit the analytics bootstrap. Manual import should preserve existing files; the tool does not configure app append templates.

Browser verification requires the existing Playwright dependency and its Chromium installation:

    python3 -m http.server 8769 --bind 127.0.0.1
    node scripts/verify-citation-assets.cjs http://127.0.0.1:8769 /tmp/citation-evidence

The check covers five mobile pages, canonical/language metadata, CSV counts, an empty worksheet, both tool languages, literal markup input, generated download bytes, no input-triggered network requests, denied clipboard access, and non-JavaScript download access. Screenshots can be written outside the public tree with the optional second argument.

Public pages are connected from the Japanese and English homepages, Obsidian pages, existing templates, the Captio article, and the Second Brain guide. The sitemap and llms.txt list the appropriate original resources. This is preparation for earned coverage; publication of these pages does not itself prove a new referring domain or a higher DR.
