# 規約監視で配信文字コードを扱う

2026-09-07。ムームードメインの規約HTMLはmetaタグでEUC-JPを宣言していた。従来の `Response.text()` はUTF-8で復号するため日本語が文字化けしていた。指紋があることだけでは、本文を正しく取得できた証明にならない。

取得バイト列をHTTPのcharset、HTMLのmeta宣言、既定UTF-8の順に復号する。未知の文字コードや不正なバイト列は失敗として扱い、既存の `unknown` 経路で台帳を保持する。

自己検査はEUC-JPのHTTP宣言とmeta宣言、UTF-8、HTTP優先、不正な応答の拒否を確認する。実URLへの取得で24,124文字、置換文字0、条文の日本語を確認した。注入した不正応答でも `fetchError` を返し、本文はnullとなった。

今回は指紋や人の判定を手動更新しない。次回の監視では復号方法の修正により指紋が変わり、従来の読み直しゲートが作動しうる。それは契約改定の証明ではない。旧指紋との比較には取得方法の差を考慮して再読する。業務executorとスコアの追加変更はない。
