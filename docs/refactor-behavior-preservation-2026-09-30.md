# 振る舞いを維持する内部整理（2026-09-30）

SEO 検査と運用アクションの大きな関数を責務ごとに分け、重複した HTML
ファイル列挙を共通化した。検査ルールの修正や運用判断の変更は含めない。

## 変更範囲

- `scripts/seo-check.js`: CLI、ファイル読み取り、レポート集約を残し、ページ単位の
  検査を `lib/seo-page.js`、サイト全体の検査を `lib/seo-site.js` へ分離した。
  検査順序、エラー・警告の本文、noindex の既存判定、JSON-LD の走査、
  事実確認日の 30 日・180 日の閾値を維持する。
- `scripts/autopilot-act.mjs`: アクション導出を順序付きの内部関数に分割し、
  失敗した実行の診断を内部関数にまとめた。出力の順序、所有者、再試行・
  保留・エスカレーションの条件と、既存の exported API を維持する。
- `scripts/lib/site-files.js`: 配列を返す既存関数と、遅延列挙する関数を同じ
  実装にまとめた。`sync_constants.js`、`add-internal-links.js`、
  `check-viewport-overflow.mjs` は、各呼び出し元の除外名・隠しファイル・
  読み取りエラー・並び順・読み取りタイミングを保って使用する。
- `scripts/lib/refactor-behavior.test.mjs`: 観測可能な境界条件の回帰検査を追加し、
  既存の `scripts/refactor.test.mjs` から実行する。

配信する HTML・CSS・ブラウザ JavaScript・画像・Functions、
ワークフロー、ガード式・ピンの台帳には変更を加えていない。既存の CLI
パスとフラグも維持した。

既存エラーの解消に伴い、`data/revenue-series.json` の観測元の生成日時と
観測期間だけを既存の生成器で更新した。確定観測日数 20 日、未観測 8 日、
`monthly_ready: false` は維持され、金額や個票は運んでいない。
`data/financial-policy.json` に差分はない。

回帰検査と一括検証は Node 20.20.2 で実行した。
変更前との比較基準は main の `13936212`。

一括検証の失敗は、`check-generators.mjs --run` が収益データの日別 v2 から
旧スパンへの巻き戻しを拒否することと、`automation-rate.mjs --check` が
隣接リポジトリの古い作業ツリーに必要な根拠ファイルを見つけられないこと。
失敗箇所と診断内容は変更前と一致した（実行時間表示のみ異なる）。
最新の main を持つ3リポジトリを、既存の作業中の変更とは別の検証環境に揃えた。
根拠ファイルの検査はそのまま成功した。収益側も日別 v2 の実測を正しく読めるように
なり、古い公開側の写しを `growth/scripts/revenue-series.mjs --write` で再生成した。
その後の一括検証は Node 20.20.2 で 217 本すべて成功した。
検証を通すための根拠の削除や保護条件の緩和は行っていない。
新旧比較 8,395 ケースも再実行し、一致した。

完成したコードへの独立レビューでも、導出順序、検査本文、ファイル列挙の
互換性に問題は見つからなかった。比較は確認した入力・環境に対する結果であり、
一括検証が導出対象外とする CI ステップや本番環境での実行結果は含まない。
当初は Draft PR として提出した。出荷は既存の SEO Validation が成功した
HEAD だけをマージし、Cloudflare Pages の Git 連携で本番へ反映する。
