# 記録されたベンダープランの期限

2026-09-07。AppsFlyerの認証済み管理画面で、利用中のWelcome Planに2026-04-24〜2027-04-23の期間が表示されていた。従来の「無料プラン。有料化の予定なし」だけでは、この期間を日次運転が読めなかった。

`data/vendor-register.json` の `plan_dates` に、プラン名・表示期間・観測日・確認元を記録する。新規契約の同意や購入は行っていない。請求書・カード・アカウント識別子・利用者データは公開台帳に入れない。AppsFlyerの取引先承認とDPAレビュー履歴は変更しない。

日次のSEOワークフローが `node scripts/check-vendors.mjs --plan-dates` を実行し、ログとサマリーに結果を残す。記録された終了日の90日前から警告し、終了後は `recorded_term_elapsed` と表示する。警告だけで出荷やメモ配信を停止しない。担当の自律運転は、管理画面で最新プランと継続条件を読み直し、確認できた内容を新しい観測として記録する。

この機能が自動取得するのは現在日付だけである。ベンダー管理画面へのログイン、更新後の契約取得、契約同意、支払い、サービスの稼働確認は含まない。記録の期限が過ぎても、サービス停止や有料移行と断定しない。期限未観測の他社も無期限・無料と扱わない。

AppsFlyerの今回の記録では2027-01-23から再確認を求める。期間の逆転、実在しない日付、将来日の観測、確認元欠落、自動更新済みへの偽装を自己テストで拒否する。CIは観測記録の形式と日付による判定を検査し、契約解釈や管理画面の現在状態は証明しない。
