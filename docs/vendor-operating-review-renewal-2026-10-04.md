## 新しく足した3件

台帳では `discovered_dependencies`（追加依存先）に足した。支払の許可リストを兼ねる `vendors` には入れない。
契約の承認と支払の許可は false。いずれも実アカウントの契約主体・受諾版・管理画面の設定は見ていない。

### Google アナリティクス（GA4、サイトのタグ）

- **範囲**：サイトの大半のページが `gtag.js`（測定 ID `G-EPZVZKCVQG`）を読み込み、閲覧・リンクの表示とクリックの
  イベントを送る。日次の書き出しは google_cloud（BigQuery、asia-northeast1）に入る。
- **DPA**：[GA の利用規約](https://marketingplatform.google.com/about/analytics/terms/jp/)（2023-05-15 更新、
  契約先は Google LLC）は、範囲内の利用に [Google 広告のデータ処理規約](https://business.safety.google/adsprocessorterms/)
  （v8.0）が及ぶとする。一方、EEA・英国・スイスの外の既存のアカウントは管理画面で受諾が要ると Google のヘルプは説明している。
  **当社の受諾は未確認**。
- **データ利用**：Cookie（`_ga`）のランダムな識別子、ページ、参照元、おおよその地域、端末。Google は GA4 では IP アドレスを
  記録・保存しないと説明している。**データ共有の設定（Google のサービスの改善への利用など）と、GA の保持期間の設定は未確認**。
  BigQuery の写しは保存期限が無い（上記）。
- **SLA**：無償版の GA に SLA は見つからない（SLA は 360 の対象）。
- **撤退**：タグを外せば新しい収集は止まる。プロパティの削除はゴミ箱で35日後に確定する。BigQuery の写しは別に残る。
- **条件**：今の測定の範囲を広げない（新しいイベント・ユーザー ID・広告機能・Google シグナルを足さない）。
  受諾・共有の設定・保持期間を確かめる前に用途を広げない。GA4 の写しを行の単位でアプリやメールの記録と結び付けない。

### Ahrefs（Web Analytics と Ahrefs のアカウント）

- **範囲**：サイトの大半のページが `analytics.ahrefs.com` の計測を読み込み、閲覧数を数える。
  Ahrefs のアカウントは SEO の観測（Site Explorer などの手動のエクスポート）にも使っている。アカウントの持ち主・プランは未確認
  （有料のプランなら、支払の許可リストの `vendors` に無い支払先になる）。
- **DPA**：[利用規約](https://ahrefs.com/legal/terms)（2026-09-14 更新、Ahrefs Pte. Ltd.・シンガポール）は、
  利用によって [DPA](https://ahrefs.com/legal/data-processing-addendum)（2025-09-15 更新）にも同意するとする。
  Web Analytics が DPA の対象と明記されているかは確かめていない。
- **データ利用**：Ahrefs は Web Analytics について、Cookie を使わず、生の IP アドレスを保存しない
  （IP と利用者のブラウザ情報を毎日替わるソルトでハッシュする）と[説明している](https://help.ahrefs.com/en/articles/10247870-about-ahrefs-web-analytics)。
  保存期間の記載は見つからない。
- **SLA**：規約は "as is" で、稼働の約束は見つからない。
- **撤退**：計測のスクリプトを外せば新しい収集は止まる。アカウントの削除はサポートへの依頼による。
- **条件**：今の閲覧数の計測と SEO の観測の範囲を広げない。秘密・顧客の情報を入れない。

### ライブドアブログ（AtomPub）

- **範囲**：自社のブログ（captio.livedoor.blog）へ、開発記録の公開記事（AI が書き、開示文を付ける）を AtomPub で投稿する。
  HTTPS の Basic 認証で、鍵（AtomPub 用パスワード）はリポジトリの secret にだけ置く。運営会社は株式会社ライブドア。
  プラン（無料か有料か）は未確認。
- **DPA**：DPA は見つからない。[プライバシーポリシー](https://www.livedoor.com/privacy/index.html)は 2025-07-31 改訂。
- **データ利用**：[利用規約](https://www.livedoor.com/rules/index.html)（2025-02-04 更新）§1.3.1 は、投稿内容の利用
  （複製・公衆送信・翻案などを含む）を運営会社に非独占的に許し、運営会社が指定する第三者への許諾の権限も与え、
  著作者人格権を行使しないとする。公開してよい記事だけを扱う。
- **SLA**：規約は事前の通知なしの中断（§1.7.1）を定め、設備での保管を保証しない（§1.5.3）。SLA は見つからない。
- **撤退**：[エクスポート](https://support.livedoor.info/hc/ja/articles/9583743096847)は MT 形式で記事・コメントを書き出すが、
  画像は含まない。ブログの削除は元に戻せず、同じサブドメインは取り直せない。運営会社の株式譲渡が予定されている（上記）。
- **条件**：元の門・周期・投稿の検証・STOP と、鍵を書き手のモデルに渡さない分離を保つ。原稿・記事 ID・画像を手元に保つ。
  運営会社の変更が完了したら、規約・プライバシーの変更を読み直す。
