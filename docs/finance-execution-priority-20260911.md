# 会計・予算・AI原価の実行優先度

2026-09-11。オーナーは、直接加点につながり、業務全体の実行証拠を
短時間で揃えられる施策を優先するよう指定している。カード明細の
個別精査についても、直接加点との関係を確認した。

会計の一部記帳と銀行明細の残高照合は進んだが、以下の3業務は未完了。
部分作業の件数をAI実行率へ加点しない。非公開の金額・口座・請求原本は
この公開リポジトリへ転記しない。

- **月次予算の決定**：全社費用、共有費用の配賦、未払分の精算と支払時期、
  収入・残高との関係、実際の予算適用が残る。既存の月次予算の適用処理は
  AI実費用であり、その判断は別業務で計上済み。全社予算表の作成や同じ
  AI費用上限の再適用だけでは完了にしない。月次締め自体を予算決定の
  必須条件として追加するものではない。
- **仕訳・請求・領収書・月次締めの統合**：既存の原本と記帳結果を再利用し、
  会社帰属・利用期間・総額と手数料・税区分・期首残高・未処理分を含む
  対象月全体を完了させる。明細の追加取得や個別記帳だけでは加点しない。
- **AI費用に対する粗利**：同じ比較期間の受取額と開発・運用AI費用、
  共有プランの配賦が必要。未観測の副系費用や未配賦をゼロとせず、
  部分月を月次実績へ外挿して完了にしない。

3件の完遂までの時間は現在見積もれないため、見積もりを未評価にする。
不足資料を反復探索すること自体を継続作業にせず、次の状態変化があった時に
再評価する。

1. 会社負担・利用期間・精算時期などを確定できる新しい原本が得られた。
2. 既存の必須支出を継続しながら、全社の配分を実際の支出経路へ適用できる
   具体的な手段と結果確認方法が揃った。
3. 同期間の事業別収入・AI費用・配賦が揃い、実際の原価回収評価ができる。

これは会計業務を不要とする判断でも、既存の支払いや運転中のサービスを
停止する指示でもない。現在の包括承認は維持し、追加確認を要求しない。
この優先度の更新は採点台帳・分母・配信条件を変更しない。
