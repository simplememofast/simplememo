# 検証コピーを作れない場合の実行停止 — 2026-09-09

新規worktreeの依存をディレクトリへのシンボリックリンクで接続したところ、preflightの検証コピー作成が失敗した。コピーが無い場合にも実行ディレクトリが元の作業ツリーのままで、check-generators --runへ進んでいた。今回は生成器自身のdirty-tree検査が拒否し、本文の上書きは起きなかった。

コピー作成に失敗した検査を1件の失敗として記録し、その生成器を実行しない。後続の独立した検査は続ける。成功やskipとして数えず、preflight全体は非0で終了する。

実CLIの回帰検査は、一時フォルダーに「起動した場所へファイルを書く生成器」を置く。Gitが無い場合と、コピー不能なディレクトリへのリンクがある場合の両方で、元フォルダーに生成器のファイルが作られないことを確認する。コピーを作れる場合は生成器がコピー内だけで動作し、通常の後続検査も実行されることを確認する。

旧実装ではこの回帰検査が失敗し、修正後の自己テスト23件は成功した。ユーザーの元のリポジトリへ故意に書き込む試験はしていない。
