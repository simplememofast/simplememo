**Images −2.** Alt/dimensions/lazy posture is clean site-wide (822 `<img>`, 0 missing alt and 0 missing width/height on public pages), and the four PNGs named in 07-07 #15 were recompressed — but the class regressed: **22 `og/*.png` now exceed 300 KB** (was 1), including the site-default `og/index.png` (506,644 B, used by 7 pages) and `og/index-en.png` (510,691 B).
