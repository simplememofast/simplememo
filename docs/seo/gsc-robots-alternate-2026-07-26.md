## 3. なぜ「robots.txtによりブロック」に79件も残っていたのか

**77件（`?lang=`）はすでに解除済みのルールの残像。** 決定的証跡:

```
docs/seo/gsc-index-triage-2026-07-02.md:16
  robots.txtに`?lang=`ブロックなし(PR #270で解除済み)
```

該当URLの「前回のクロール」は**ほぼ全件が 2026-05-14〜05-22 に集中**しており、PR #270 以前にあたる。
GSCはURLを再クロールするまで前回判定を表示し続けるため、低優先度のパラメータURLは
数ヶ月バケットに居座る。**解除済み＝Googleが取得できる状態なので、再クロール時に301を見て消える。**

**残り2件は PR #412 の対象そのもの**:

```
/?from=AppAgg.com&utm_campaign=…   （クロール 07-24 = PR #412マージの前日）
/?ref=producthunt                   （クロール 06-21）
```

PR #412 で `Disallow: /*?ref=` 等6行を撤去し、`ref`/`from`/`source`/`q` は301で剥がすようにした。
`?ref=producthunt` のようなローンチ系被リンクは今後も増えるが、パラメータ非依存の処理なので
新しい値が来ても自動的に正規URLへ統合される。

## 4. 本PRの実装 — `seo-check.js` に回帰ガードを追加

07-02・07-07・07-16・07-19・07-25 の5回、同じ不変条件を人手で確認してきた。
**この確認をCIに移す**（`errors` = exit 2 でCI失敗）。

### 4-1. `[ROBOTS]` パラメータDisallowの禁止

`Disallow:` にクエリパターン（`?`）を含む行があればエラー。

robotsでブロックすると Googlebot はURLを取得できず、**canonicalも301も永遠に見られない** —
URLはインデックスから消えず「ブロック済み」として滞留する。これがこのバケット79件を作った
regression そのもの（`?lang=` は PR #270、`utm_*`/`ref`/`from`/`source` は PR #412 で解除）。
パラメータURLの処理は `functions/_middleware.js` の責務であって robots.txt の仕事ではない、
という設計をコードで固定する。

### 4-2. `[URL]` 内部リンクの正規形強制

全HTMLの `href` を走査（**実測 10,569本**）し、自サイト向けリンクが非正規形なら即エラー:

| 検出 | 理由 |
|---|---|
| `?lang=` | 301で剥がされる = 不要な1ホップ |
| `.html` | 正規形は拡張子なし |
| `http://` / `www.` | どちらもリダイレクト |
| 二重スラッシュ | `/en/vs/*//` を作った形 |
| `ref`/`from`/`source`/`utm_*`/`fbclid`/`gclid` | 内部リンクに付ける理由がない |

### 4-3. `[EDGE]` sitemapとエッジ規則の整合

- `functions/_middleware.js` の `RETIRED`（9パス）と `GONE`（6スラッグ）を実際にパースし、
  **sitemapがそれらのURLを載せていないこと**を検証。301/410すると決めたURLを
  sitemapで「クロールしに来い」と宣言する矛盾を防ぐ
- **`RETIRED` が `_redirects` に完全にカバーされていること**を検証。Middlewareが
  高速パス・`_redirects` がFunctionsデプロイ失敗時のフォールバックという二重化は
  PR #412 で導入したもので、放置すれば必ずドリフトする

### 4-4. ガードが実際に発火することの検証

「鳴らない警報」を避けるため、8パターンすべてを注入して発火を実測した:

|---|---|
| robots.txt に `Disallow: /*?utm_*` | ✅ `[ROBOTS]` |

| 内部リンクに `.html` | ✅ `[URL]` |
| 内部リンクに `/en//faq` | ✅ `[URL]` 二重スラッシュ |
| 内部リンクに `http://www.simplememofast.com/faq` | ✅ `[URL]` ×2（http と www 両方） |
