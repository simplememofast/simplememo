# Claude検索付き回答の観測と再集計

`claude-sonnet-web-v1` は、リポジトリや前の回答を渡さない独立セッションで5問を観測する系列です。既存のPerplexity・Gemini等の画面観測とは、取得方法・モデル・繰り返し数が異なるため混ぜません。各回のCLI版、実際に報告されたモデル名、取得日時、検索の成功確認、費用を保持します。`sonnet` は別名指定なので、将来も同じモデルになることを保証しません。

## 言及と引用を分ける

`mention_metrics_version: answer-prose-v2.1` では次の定義です。

| 項目 | 定義 |
|---|---|
| `mention` | 回答本文に製品名がある。出典一覧・URL・コードブロック・画像・参照定義の文字は除く。本文内のリンクやインラインコードで装飾された製品名は表示名を判定する |
| `own_site_citation` | 回答・出典のHTTP(S)リンクに、自社の正確なホスト名が1つ以上ある。コード例や画像のURLは除く |
| `unaided_mention_rate` | 非指名Q1〜Q4の有効回答のうち、本文に製品名がある割合 |
| `unaided_own_site_citation_rate` | 同じ分母で、自社リンクを含む回答の割合 |

Q5は質問にブランド名を含むため、非指名の分母に入れません。検索未確認・失敗は`null`として除外し、言及0・引用0に置換しません。有効回答がない場合は割合も`null`です。リンクの存在は、ページが現在閲覧できること、回答の事実が正しいこと、推薦・導入・売上につながったことを証明しません。引用タイトルと本文の名称も区別して確認してください。

旧版は回答全文への正規表現で判定していたため、出典URL内の`simplememofast.com`も製品言及になっていました。2026-09-06の実行34016914073では、Q2・Q3の本文に製品名がなくても言及扱いとなり、非指名言及率が50%と出力されていました。本文言及は0/4、自社リンクを含む回答は2/4です。これは集計訂正であり、露出が50%から0%へ低下したという意味ではありません。

v2.1では、本文の製品名がバッククォートで装飾されていても言及として残します。v2はこれも除外していました。コードブロック内の例と、インラインコード内のURLは引き続き除外します。保存済みの2026-09-06の5回答にはこの差はなく、0/4・2/4は変わりません。

## 既存回答を再集計する

```sh
python3 scripts/ai-visibility-probe.py --recalculate
python3 scripts/ai-visibility-probe.py --check-report
python3 scripts/ai-visibility-probe.test.py
```

これらはモデルを呼び出しません。`--recalculate`は保存済みの回答から派生指標だけを更新し、取得日時・質問・回答原文・検索確認・モデル・費用を保持します。訂正前の指標と旧定義は`measurement_correction`に記録します。同じデータの再実行では変化しません。別の保存ファイルには`--report /path/to/report.json`を付けます。

引数なしの実行は新規のモデル観測です。集計の誤りを直すだけなら使いません。CIは既存のテスト実行を通じて、保存済み指標が回答原文と現在の定義に一致することも検査します。

週次の比較では観測日・モデル・定義版・有効回答数を併記してください。1問1回答の小さな観測から、施策の因果効果や全AIサービスでの言及率を推定しません。
