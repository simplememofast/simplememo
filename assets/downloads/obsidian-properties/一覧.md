# Properties接続検証

著者が作成した架空の3件だけを表示します。

## 進行中の表

```dataview
TABLE status AS "状態", priority AS "優先度", done AS "完了", due AS "期限"
FROM "記録"
WHERE status = "進行中"
SORT file.name ASC
```

## 未完了の一覧

```dataview
LIST
FROM "記録"
WHERE done = false
SORT file.name ASC
```

## 保留の該当なし

```dataview
LIST
FROM "記録"
WHERE status = "保留"
SORT file.name ASC
```
