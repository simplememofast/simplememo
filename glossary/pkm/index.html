用語集 — 知識管理

PKM（個人知識管理）とは

PKM（Personal Knowledge Management／個人知識管理）は、情報を集め、自分の理解や出典を添え、後の仕事・学習で使えるようにする実践です。何を保存するかに加えて、どの問いに使い、後から根拠を確認できるかを考えます。

著者: AI ATAKA

PKMは、保存から再利用までを扱う

単にメモを増やすだけでなく、「必要なときに見つけ、自分の判断や文章に使う」までを考えるのがこのページでのPKMの捉え方です。メモアプリは道具、PARAやCODEはその運用に使える方法です。特定のアプリや、全員共通の工程を指す言葉ではありません。

ここでは、仕事の締切や担当を扱うタスク管理、チームで承認済みの情報を共有するナレッジベースと区別します。個人メモで気づいたことをチームへ渡す場合は、根拠と共有できる範囲も確かめます。

2026年9月9日更新。筆者はシンプルメモの開発者です。以下の記入例と試行は、このサイトが作成した実践案です。

方法の違いを、困っていることから選ぶ

CODEはTiago Forteの方法で、PKM全体の定義ではありません。Harold JarcheはPKMをPersonal Knowledge Masteryという名称で説明しています。目的や単位が異なるため、以下を全部同時に導入する必要はありません。

方法の焦点と使う場面
方法・原典主な焦点試す場面
PARAProjects・Areas・Resources・Archivesに分け、今の仕事との関係で置き場所を決める。置き場所で迷うとき。
CODE / Building a Second BrainCapture・Organize・Distill・Express。取り込んだ情報を成果物へ使う流れを考える。保存して終わりになりやすいとき。
Zettelkasten個々のノートと参照関係から考えを育てる方法。Luhmannの実物のカードはアーカイブで確認できる。複数の読書・研究メモの関係を考えたいとき。

出典と使い道を残すメモのひな形

最初の1件では、タグを増やすよりも「どこから来た情報か」「自分はどう考えたか」を残します。下の5項目はこのサイトのひな形です。原典にない結論を、原典の主張として書かないようにします。

問い
このメモで何を考えたいか。
出典
著者・題名・URL・ページ位置・確認日。自分の観察ならその状況。
内容と解釈
出典の要約と自分の考えを分ける。引用は引用だと分かる形に。
関係
関連ノートの名前と、どう関係するかを一文で書く。
使い道
次の説明・資料・判断のどこで使うか。未確認の点も残す。

1件を、後から見つけて使うまで試す

以下はこのサイトが提案する試し方です。メモの件数やタグ数を成果にせず、「見つけられたか」「元の根拠を確認できたか」「実際に使えたか」で見直します。

  1. 今取り組んでいる問いを1つ決める。例：「会議の決定を、後で確認しやすくするには？」
  2. その問いに関係する資料を1つ読み、著者・場所・確認日を残す。
  3. 要約を自分の言葉で書き、自分の解釈や未確認事項を別の欄に書く。
  4. 関連するメモを1件だけ挙げ、関係を説明する。なければ無理にリンクを作らない。
  5. 後日、問いや出典から探し直し、説明文や判断に1か所使う。見つからなければタイトルや置き場所を直す。

シンプルメモを使う場合の役割

シンプルメモは、iPhoneで思いついた内容を入力し、自分宛メールや設定したObsidianの追記先へ残す入口として使えます。出典URLやページ位置も本文に添え、後でひな形へ整理します。知識の正しさの確認、ノート同士の関係づけ、成果物への利用は自分で行います。

メールの到着、Obsidianへの保存、別端末への同期は別々に確認します。通信や保管庫へのアクセスが必要な処理は、状況によって完了を待つことがあります。初回はObsidian連携の設定と保存確認を行ってください。紙や既存のメモアプリから始めても構いません。

PKMのよくある質問

PKMとメモを取ることはどう違いますか？
メモを取ることは記録の作業です。PKMでは、記録に出典や自分の理解を添え、必要なときに探して後の仕事や学習に使う運用まで考えます。メモの件数が増えただけでは、活用できたかは分かりません。
CODEはPKM全体の決まった手順ですか？
いいえ。CODEはTiago ForteのBuilding a Second Brainで説明される方法です。PARAは置き場所の整理、Zettelkastenはノート間の参照、Harold JarcheのPersonal Knowledge MasteryはSeek・Sense・Shareを重視します。必要な部分から試せます。
PKMには有料アプリが必要ですか？
必須ではありません。紙や既存のメモアプリでも、出典・自分の解釈・使い道を残す試行はできます。検索、添付、共有、書き出しなどで具体的な不足が出てから道具を選びます。
最初は何を保存すればよいですか？
今考えている問いや取り組みと関係する情報を1件選び、なぜ残すかを書きます。すべて集める必要はありません。出典の主張と自分の解釈を分けておくと、後から確認できます。
整理したメモを使わないままにしないためには？
使う予定の文章・説明・判断を1つ書き、後日その問いからメモを探し直します。見つからない場合はタイトルや置き場所を見直します。使わなくなった情報は、参照が必要かを確かめて整理します。
AIの要約をそのまま知識として保存してよいですか？
要約を下書きに使う場合も、原文で内容と出典を確認します。AIの推測と原文の主張を分け、確認していない引用やURLを根拠として扱わないようにします。仕事の情報は、共有できる範囲と使用を認められたツールを確認してください。
