メモアプリ用語集

メモアプリや生産性ツールに関する重要な用語を解説します。暗号化技術、生産性メソッド、メールプロトコルまで、メモアプリを深く理解するための10の用語をわかりやすく紹介します。

セキュリティ・技術用語

🔐
AES-GCM暗号化
Galois/Counter Mode認証付き暗号化。TLS 1.3と同じ方式ファミリーで、シンプルメモのOutboxストレージにも使用。AES-CBCとの違いも解説。

E2E暗号化
エンドツーエンド暗号化の仕組みと、シンプルメモのオンデバイスAES-GCMアプローチとの比較。

📤
Outboxアーキテクチャ
ローカルにキューイングし接続時に送信するパターン。シンプルメモのコア技術革新。
詳しく見る →
📡
SMTP/IMAP
メールの送受信プロトコルの仕組みと、シンプルメモがSMTP設定不要な理由。

Inbox Zero

GTD

知識管理・学習用語

📝
Markdown
プレーンテキストで書式を表現する軽量マークアップ言語。多くのメモアプリが対応するデファクトスタンダード。
詳しく見る →
🧠
PKM（個人知識管理）
個人が知識を収集・整理・活用するための体系的なアプローチ。セカンドブレインやZettelkastenの上位概念。
詳しく見る →
🔁
スペースド・リペティション
間隔を空けて繰り返し学習する記憶術。忘却曲線に基づき最適なタイミングで復習することで記憶を定着させる。
詳しく見る →
🗺️
マインドマップ
中心テーマから放射状にアイデアを広げる思考整理法。Tony Buzanが体系化した視覚的なノートテイキング手法。
詳しく見る →
📓
コーネル式ノート
コーネル大学で開発されたノートテイキングシステム。ノート・キュー・サマリーの3分割で効果的な学習を実現。

集中力・生産性用語

📵
デジタルデトックス
デジタルデバイスやSNSから意図的に距離を置くこと。注意力の回復と深い思考を取り戻すための実践法。
詳しく見る →
🎯
ディープワーク
Cal Newportが提唱した、集中した状態で認知的に要求の高い作業を行う能力。シャローワークとの対比で理解する。
詳しく見る →
📊
アイゼンハワー・マトリクス
緊急度と重要度の2軸でタスクを4象限に分類する優先順位フレームワーク。第2象限（重要だが緊急でない）に集中する方法。
詳しく見る →
📌
カンバン
トヨタ生産方式から生まれた視覚的なワークフロー管理手法。「To Do」「Doing」「Done」のボード形式でタスクを可視化。
詳しく見る →
⏱️
タイムボクシング
タスクに固定の時間枠を割り当てる時間管理テクニック。締め切り効果を活用して集中力と完了率を高める。
