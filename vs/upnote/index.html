シンプルメモ vs UpNote
どちらを選ぶべきか

UpNoteは、ノートをアプリ内で編集・整理し、複数端末で同期したい人の候補です。シンプルメモは、短い記録を自分のメールや設定済みのObsidianへ残したいときに検討できます。入力の入口、保存先、持ち出し方を同じ1件で確かめて選びましょう。

シンプルメモの料金と無料枠

UpNoteも新規ノートへ直接進める

UpNoteのモバイル版では一覧下部の青い新規ノートボタンから書けます。本文の1行目がタイトルになるため、タイトルを別欄へ入力する必要はありません。PCではCmd/Ctrl + N、別アプリからはMacのCmd + Option + N、Windows/LinuxのCtrl + Alt + Nで新しいウィンドウを開けます。

毎回ノートブックを選ぶことが必須という前提で速度差を計算することはできません。自分が使う入口から短いメモを1件書き、後で探せるかを確認します。受信箱で処理したい場合は、シンプルメモから届いた本文を読むところまでを比較します。

UpNote公式：新規ノートとタイトル

50ノート、買い切り、解約後を確認する

無料版は最大50ノートです。添付、ロック、インポート、PDF・Markdownへの書き出しなどはPremiumの条件を確認してください。月額とLifetimeのどちらを買う場合も、地域のストアで表示される金額を優先します。Windows/Linuxから直接購入する機能はなく、Mac・iOS・Androidで購入後、同じUpNoteアカウントへサインインして反映します。

月額を解約しても既存ノートは閲覧できますが、50件を超えている場合は新規作成できず、一部の書き出し機能も使えなくなります。移行を予定している場合は、契約が有効な間に必要な形式で試しに書き出しておきます。

UpNote公式：Premiumと解約後の制約

Evernote移行は、少量でリンクと添付を確かめる

PC版でEvernoteのENEXファイルを取り込めます。元のノートブック単位でENEXを分け、「Use file name as notebook」を有効にすると分類を作れます。階層化は取り込み後に行います。タグをハッシュタグへ変換すると、特殊文字がハイフンへ変わる場合があります。

Evernote内部リンクはUpNote内のリンクへ変換されず、元のEvernoteを開きます。20MBを超える添付や30万文字を超えるノートは取り込めない場合があります。色やレイアウトも確認し、元のENEXを残してください。2万ノートまたは添付10GBを超える一括取り込みには、1回50件までの制約があります。

UpNote公式：ENEX取り込みと制限

同期と、取り戻せるコピーを分けて考える

UpNoteの自動バックアップはMac・Windows・Linuxで端末内に保存されます。既定は1日1回・最大50日分で、設定から間隔・保存先・添付の扱いを確認できます。スマホ中心で使う場合も、PCへ同期した上でバックアップが作られたかを確認します。バックアップ用フォルダの管理ファイルは編集しません。

UpNote公式：自動バックアップ

別アプリへ移すには、少量をMarkdownやHTMLなどで書き出し、本文・画像・リンクを実際に開きます。バックアップを持つことと、他アプリで同じ状態を再現できることは別です。シンプルメモの受信メールも、メール側の容量・保持設定・バックアップに従います。

UpNote公式：書き出し形式と操作

UpNoteは、サインインしなければノートを端末内に保持し、同期を使うと米国のFirebaseサーバーにも保存します。通信・保存時の暗号化やアプリロックを、運営者が内容を復号できないE2EEと同一視しないでください。

UpNote公式：データ保存とプライバシー

無料枠から本格移行までの5手順

  1. よく書く短いメモを1件決め、普段使う端末と入口から入力する。
  2. 翌日のつもりで検索し、本文を追記して保存先を確かめる。
  3. 必要なノートを開いてから圏外で読み書きし、再接続後に別端末の内容を確認する。
  4. 取り込みが必要ならPremiumの機能と購入条件を先に確認。利用できる状態になったら、画像・添付・内部リンクを含む少量を取り込み、元データと見比べる。
  5. 契約で利用できる形式で書き出し、ファイルとバックアップの保存先を確認してから、本格移行を判断する。

アプリ内で書き続けるならUpNoteを単独で試すのが出発点です。メールを日々処理するならシンプルメモも候補になります。併用で受信メールをUpNoteへ移す場合は、コピーや対応形式の取り込みが別途必要で、自動連携が設定済みとは限りません。

よくある質問

UpNoteの現在の料金はいくらですか？
公式サイトは月額US$1.99、LifetimeはUS$39.99と案内しています。地域と税で異なるため、日本で購入するときはアプリ内の最終金額を確認してください。
無料版の50ノートを超えるとどうなりますか？
新しいノートを増やすにはPremiumが必要です。月額契約が終わっても既存ノートは閲覧できますが、50件を超えていると新規作成できず、一部のPremium機能も使えなくなります。
新規ノートの前にノートブック選択は必須ですか？
必須ではありません。モバイルの新規ノートボタンやPCのショートカットから書けます。1行目がタイトルになるため、タイトルの別入力も不要です。
UpNoteはオフラインで使えますか？
読み書きできます。サインインして同期を使う場合、再接続後に変更が他の端末へ反映されます。必要なノートや添付は移動前に実機で開いて確認してください。
ノートロックはE2EEですか？
いいえ。UpNoteは通信中と保存時の暗号化を説明していますが、E2EEには対応していないと明記しています。アプリやノートのロックは、その区別を変えません。
Evernoteの内部リンクも移せますか？
UpNote内のリンクへは変換されず、元のEvernoteを開くリンクとして残ります。添付サイズ、長いノート、タグ変換や書式にも制約があるため、少量で試してから移行します。
受信箱でメモを処理したい方へ
まずは1件、書いて送って、届いた本文を確認。無料枠は1日3通です。
