이동 중인 핸즈프리 음성 메모

이동 중에도 열기만 하면 됩니다.

아래 음성 명령은 일본어 설정의 예시입니다. Siri의 언어 설정과 기기에 등록된 단축어를 확인하세요.

손이 막히는 출퇴근·사이클링·드라이브에서도 설정해 두면열면 녹음이 시작됩니다(iOS 26 이후 지원 단말기), 온디바이스 음성 인식으로 말하기만 하면 됩니다. 쓰기 중은초저에 자동 저장하고, 전송하면 Obsidian에 로컬 저장으로——전파가 없어도 단말기에 남습니다. 앱을 열 때와 보낼 때는 화면 조작이 필요합니다. 화면에 접촉하지 않고 전송하고 싶을 때는 Siri의 “シンプルメモで残す”를 사용합니다(잠겨 있는 설정에 따라 해제가 필요합니다).

한 마디로 말하면

설정의 “시작 시 음성 입력 자동 켜기”를 켜면, 앱을 열었을 때 음성 입력이 자동으로 시작됩니다 따라서 마이크를 찾아 탭하지 않아도 말을 시작할 수 있습니다（iOS 26 이후 지원 단말기. 시작 표시를 확인한 후에 말씀드리겠습니다. 대화한 내용은 초안으로 단말기 내에 자동으로 저장됩니다. 전송하면 Obsidian에 로컬 파일로 추가되며, 메일은 오프라인인 경우 대기열에 저장되고, 온라인 복귀 시 자동으로 전송됩니다. 그래서전파가 없는 이동 중에도 메모는 단말기에 남습니다.

이동 중에 효과가 있는 4개의 메커니즘

🎙️ 열기만 하면 자동 녹음
설정의「시작 시 음성 입력을 자동으로 켭니다에서 열면 녹음이 시작됩니다. 마이크를 찾아 탭하는 번거로움이 없습니다.
🎯 온디바이스 음성 인식
Apple의 온디바이스 음성 인식(iOS 26 이후)을 사용하여, 문자 전사를 위해 음성을 외부에 전송하지 않으며, 추가 요금도 발생하지 않습니다. 첫 번째에 언어 모델을 넣으면오프라인에서도 인식합니다.
💾 초고 자동 저장
말한 내용은, 변경된 후 약 0.4초 후에 단말기 내부로 AES-GCM 암호화로자동 저장。 앱이 멈추거나 중단되더라도, 다음에 열면 마지막으로 저장한 지점부터 계속할 수 있습니다.
🟣 Obsidian 로컬 저장(통신 범위 외 OK)
Obsidian 연동는 폴더 직접 쓰기입니다.네트워크 연결이 없어도, 그 자리에서 로컬 노트에 추가되며, iCloud 동기화는 복귀 후에 수행됩니다. AirPods에서 Siri에게 말을 걸어 데일리 노트에 전달하는 절차(잠금 중인 조건 포함)는AirPods→Obsidian핸즈프리 실천에 정리했습니다.

통신 범위 밖이라도 단말기에 남겨 두세요

터널·산길·지하 등 전파가 없는 장소에서도, 아직 쓰지 않은 부분은 초안으로 단말기에 남아 전송하면 메모가 Outbox에 들어갑니다(Obsidian 연동을 폴더 직접 기록으로 설정하면 그 자리에서 로컬 노트에도 추가합니다). 초안은 전송과 동시에 사라집니다. 나중에 온라인에 다시 접속하면 메일이 자동으로 전송되고, Obsidian의 내용도 iCloud로 동기화됩니다.

🗣️ 말하기(신역 외) → 💾 초안(전송까지는 단말기 내에서) → 📤 전송 시 Outbox에 큐 ＋ 🟣 Obsidian 로컬 추가
프라이버시

음성 전사는 기기 내에서 완료되어, 전사를 위해 음성이나 텍스트를 외부로 전송하지 않습니다. 초안·오프라인 큐·전송 기록은 단말기 내에서 AES-GCM으로 암호화됩니다. 메일 본문은 전송 시 통과만 가능하며, 당사 서버에 영구적으로 저장되지 않습니다.

설정

  • iPhone（iOS 26 이후·음성 입력 지원 기종）
  • Obsidian의 보관함이 iCloud Drive 또는 “이 iPhone 내”에 있습니다(로컬 저장에 사용)
  • 초회만 온라인(언어 모델 획득)
  1. 시작 시 음성 입력 자동 켜기
    설정 →「음성 입력 및 사운드」→「시작 시 음성 입력 자동 켜기」를 켭니다. 이후에는 열면 녹음이 시작됩니다.
  2. Obsidian 폴더를 선택합니다
    설정의 “Obsidian”란에서 “Obsidian 연동”을 켜고, 보관함 폴더(iCloud Drive 또는 “이 iPhone 내”)를 선택합니다. 파일을 직접 기록하기 때문에 범위 밖에서도 로컬에 저장됩니다.
  3. 음성 모델을 준비합니다(초회만)
    한 번 온라인에서 마이크를 탭하여 언어 모델을 가져옵니다. 이후에는 음성 인식도 오프라인으로 작동합니다.
  4. 홈 화면/위젯에 배치
    누르기 쉬운 위치나 위젯에 배치하여 가장 빠르게 시작할 수 있도록 합니다.
  5. 열기 → 말하기 → 전송
    안전한 상황에서 열어 말하기만 하면 됩니다. 전송하면 메모가 Outbox에 들어갑니다(Obsidian 연동을 켜두면 로컬 노트에도 추가됩니다), 초안은 사라집니다.

자주 묻는 질문

운전 중이나 자전거 주행 중에 사용해도 될까요?

운전 중·주행 중에 스마트폰을 손에 들기·통화·화면을 주시하는 행위는 일본 도로교통법에서 금지되어 있으며 위험합니다(자전거도 2024년 11부터 “하면서 스마트폰”이 벌칙 대상입니다). 앱에서 녹음하여 전송하려면, 열 때와 전송할 때 화면 조작이 필요합니다. 안전을 위해, 1 안전한 장소에 정차한 후, 2 또는 핸즈프리로 Siri와 같이 음성만으로 조작하는 것에 한합니다(화면을 보지 않거나 조작하지 마십시오). 해제나 화면 조작을 요구받은 경우 정차한 뒤에, 3동승자는 반드시 조작을 지켜 주시기 바랍니다. 전방에 대한 주의가 최우선입니다.

전파가 없는 장소(터널·산·지하)에서도 사용할 수 있나요?

사용할 수 있습니다. 통화 범위 밖이라도, 대화한 내용은 (1) 단말기 내 초안으로 자동 저장됩니다. 전송하면 (2) 메일은 오프라인 큐(Outbox)에 암호화되어 저장되고 복구 시 자동으로 전송되며, (3)Obsidian 연동을 폴더에 직접 기록해 두면 그 자리에서 로컬 노트에 추가됩니다. 음성 인식도 처음에 언어 모델을 가져오면 오프라인으로 작동합니다.

열기만 하면 녹음이 시작되도록 어떻게 설정합니까?

설정의 “음성 입력 및 사운드”에 있는 “시작 시 음성 입력 자동 켜기”를 켭니다. 이후에는 앱을 열면 녹음이 시작되므로 마이크를 찾아 탭할 필요가 없습니다(iOS 26 이후 지원 기기). 시작 표시를 확인한 후에 말씀드리겠습니다.

음성의 정확도는? 추가 요금이 발생합니까?

Apple의 온디바이스 음성 인식(iOS 26 이후)을 사용하여, 문자 전사는 단말기 내에서 수행합니다. 정확도는 측정하지 않았으며, 말투·주변 소리·언어에 따라 달라지므로, 보내기 전에 문자를 확인해 주세요. 문자 전사를 위해 음성도 텍스트도 외부로 전송하지 않으며, 사용량 기반 외부 API도 사용하지 않으므로 추가 요금이 발생하지 않습니다.

말을 잘못하거나 중간에 중단해도 괜찮습니까?

괜찮습니다. 입력 중인 내용은 변경된 후 약 0.4초 후에 단말기에 AES-GCM 암호화로 자동 저장되므로, 앱이 닫히거나 종료되더라도 다음에 열면 마지막으로 저장한 지점부터 편집을 계속할 수 있습니다. 전송하면 초안이 폐기됩니다.

손이 막혀 있어도, 그 자리에서 바로 떠오른다
다운로드는 무료입니다. 음성 입력은 iOS, 26 이후 지원 단말기에서. 안전 운용으로 사용해 주세요.
