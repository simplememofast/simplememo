이 가이드에 대하여저자는 Simple Memo를 개발합니다. 이것은 Apple 단축키와 메일을 사용한 수동 빌드 지침이며, 이 페이지에는 사전 제작된 iCloud 다운로드가 없습니다. 동작 이름과 프롬프트는 iOS 버전에 따라 달라질 수 있습니다. 지침은 Apple의 문서와 비교하여 확인되었으며, 직접 만든 바로가기를 테스트해 보시기 바랍니다.

“Show Compose Sheet”는 단축키에서 무엇을 합니까?

Apple 메일의 Send Email 작업에서, 작성 시트 표시가 전송을 누르기 전에 검토할 메시지를 표시합니다. 작업 옵션을 확장하여 찾으세요. 해당 컴포즈 미리보기 없이 요청 전송을 끄면, 권한, 계정 설정, 잠긴 장치 또는 자동화 자체 확인 설정이 실행을 방해할 수 있습니다.

첫 번째 테스트에서는 켜 두세요. 보낸 사람, 수신자 주소, 제목 및 본문을 확인하십시오. 무해한 테스트 메모를 한 통 보낸 후, 대상 받은 편지함을 확인하십시오. 단축어 마무리는 이메일이 도착했음을 증명하는 것이 아닙니다. 나중에 미리보기를 비활성화하면, 실행하려는 방식으로 다시 테스트하십시오.

Apple은 일부 작업을 단축어 앱을 열어야 함을 설명하고, 트리거 확인 및 개별 작업 설정은 별개입니다. 하나의 설정을 비활성화해도 무인 워크플로가 보장되는 것은 아닙니다.

시작하기 전에

Apple 메일을 열고 전송 계정이 구성되어 정상적으로 작동하는지 확인하십시오. 귀하의 목적지인 Gmail 또는 Outlook 주소를 아는 것만으로는 충분하지 않습니다: 여기에서 사용되는 이메일 전송 작업은 Apple 메일에 속합니다. 수신인으로 귀하의 주소를 사용하십시오.

단축키에서 + 버튼을 사용하여 새 단축키를 만들고, 이름을 지정한 뒤, 순서대로 추가할 작업을 검색하십시오. Apple의 custom shortcut guide는 단축키를 만들고 테스트하는 방법을 다룹니다. 아래 예시들은 초기 설정을 단순하게 유지하기 위해 고정된 주제를 사용합니다. 나중에 날짜 및 형식 지정 작업을 추가할 수 있습니다.

잃을 여유가 없는 메모의 경우, 이메일 작업 전에 사본을 저장해 두십시오. 예를 들어, Apple Notes' Create Note 액션을 삽입하고 동일한 텍스트를 전달하십시오. 이 추가 단계에 의존하기 전에 저장된 메모가 열리는지 확인하십시오. 이 레시피에는 사용자 지정 재시도 대기열이 포함되어 있지 않습니다.

받은 편지함이 유용한 목적지일 때

이미 받은 편지함을 검토하는 것이 이미 하루의 일부분이라면, 스스로에게 이메일을 보내는 것이 타당합니다. “Memo”와 같은 예측 가능한 주제는 포착된 생각을 더 쉽게 찾을 수 있게 합니다. 지식 라이브러리의 경우, 정보가 정리되는 위치로 Apple Notes, Notion, 또는 Obsidian을 선호하실 수 있습니다. 실제로 다시 방문할 목적지를 선택하십시오.

레시피 1: 이메일로 메모 문자

  1. “Email a Memo”라는 바로가기를 생성하십시오. Ask for Input을 추가하고, 입력 유형을 Text로 설정한 뒤, “What do you want to remember?”를 사용하십시오. 프롬프트처럼.
  2. Apple 메일의 이메일 보내기 작업을 아래에 추가하십시오. 수신자에 주소를 입력하고 Subject에 “Memo”를 입력하십시오.
  3. 변수 선택기를 사용해 메시지 본문을 Ask for Input의 출력값으로 설정하세요. “Provided Input”이라는 단어 자체를 메시지 본문에 입력하지 마세요.
  4. 보내기 이메일을 확장하고 표시 작성 시트를 켜는를 유지하십시오. 바로 가기를 실행하고, 짧은 테스트 노트를 입력한 뒤, 전송하기 전에 초안을 확인하십시오. 받은 편지함에서 수신을 확인해 주세요.
  5. 한 번 작동하면, 편리한 실행기를 원한다면 바로가기 메뉴를 사용하여 홈 화면에 추가하십시오. 한 번 탭으로 실행해도 텍스트 입력 및 모든 확인 단계가 그대로 남습니다.

Apple의 Ask for Input guide는 작업이 입력된 값을 다음 작업으로 전달하는 방법을 설명합니다.

레시피 2: 이메일 음성 전사

  1. 텍스트 레시피를 복제하고 이름을 “Email a Voice Note”로 지정하십시오. 입력 요청을 Dictate Text로 교체하십시오.
  2. 기기에서 제공되는 언어와 중지 옵션을 선택하십시오. 마이크 또는 음성 권한에 작업 요청을 부여하십시오.
  3. 이메일 보내기에서, 이전 본문 변수를 텍스트 출력으로 교체하십시오. “Voice memo”를 주제로 사용하고, 컴포즈 미리보기를 켜 두세요.
  4. 정지 상태에서 실행하고, 짧은 문장을 말한 뒤, 전송하기 전에 전사본을 검토하십시오. 이름, 숫자 및 구두점은 수정이 필요할 수 있습니다.

이 레시피는 오디오 녹음이 아니라 전사본을 전송합니다. 특정 iPhone 세대에서 오프라인으로 작동한다고 가정하지 마십시오: Apple says Dictation availability and features vary by language and region 그 일반적인 받아쓰기 안내는 모든 구성에서 단축어 동작을 테스트하는 것이 아닙니다. 이메일 전송에도 연결이 필요합니다.

레시피 3: 스크린샷 텍스트를 이메일로 전송

  1. 사진 선택으로 바로가기를 생성하십시오. 실행될 때 단일 스크린샷을 선택하여 어떤 이미지가 처리될지 확인하십시오.
  2. 추가 이미지에서 텍스트 추출 선택한 사진을 전달하십시오. 기기에서 해당 작업을 검색하십시오; 사용 가능 여부와 인식되는 언어는 설치된 시스템에 따라 달라집니다.
  3. 추가 전송 이메일. 수신자 주소를 직접 사용하고, 제목은 “Screenshot text”이며, 본문은 Extract Text from Image를 사용하십시오.
  4. 표시 작성 시트를 켜 두세요. 몇 줄의 명확한 선이 포함된 스크린샷을 선택한 다음, 전송하기 전에 초안을 이미지와 비교하십시오. 추출된 텍스트가 비어 있거나 부정확한 경우 소스를 취소하고 수정하십시오.

이 레시피에는 스크린샷이 첨부되지 않았으며, 추출된 텍스트만 메일에 전달됩니다. 이미지를 명시적으로 선택하면 관련 없는 “latest screenshot”을 실수로 사용하는 것을 방지할 수 있습니다. 추출 작업을 사용할 수 없는 경우, 기기가 지원하는 기능을 사용하여 이미지에서 텍스트를 복사하고 Recipe 1을 사용하십시오.

레시피 4: 일일 저널 프롬프트

  1. 복제 레시피 1. 입력 프롬프트를 “오늘 기억하고 싶은 한 가지는 무엇인가요?” 로 변경하십시오. 그리고 그것은 “Journal”의 적용을 받습니다.
  2. 일정을 추가하기 전에 바로가기를 수동으로 테스트하십시오.
  3. Shortcuts에서 Automation을 열고 Time of Day 자동화를 생성하십시오. 시간을 선택하고 날짜를 반복한 다음, 저널 바로가기를 선택하거나 Run Shortcut을 추가하여 호출하십시오.
  4. 제공될 때 자동화를 실행하도록 요청하는 옵션을 선택하십시오. Run After Confirmation이 있는 버전에서는 해당 설정을 사용하십시오; 다른 버전에서는 Ask Before Running을 노출합니다. 이메일 미리보기를 켜 두세요.
  5. 다음 예정 시간에 알림에 응답하고, 항목을 작성한 뒤 검토 후에 보내십시오. 일정을 정상적으로 처리하기 전에 이메일을 확인하십시오.

Apple은 event triggers 아래의 일정 옵션을 문서화합니다. 예약된 트리거는 귀하를 위해 저널 항목을 작성하지 않습니다: 입력 요청은 여전히 귀하의 응답을 필요로 합니다.

레시피 5: 도착 알림

  1. 복제 레시피 1. “What should I remember here?”를 사용하십시오. 프롬프트 및 “Office memo”와 같은 고정된 주제로서. 수동으로 테스트하십시오.
  2. Arrive 트리거를 사용하여 자동화를 생성하십시오. 위치를 선택하고 지도에서 경계를 조정하십시오.
  3. 단축키를 선택하거나 실행 단축키를 추가하여 호출하십시오. 제안될 때 트리거 확인을 활성화한 상태로 유지하고, 이메일 미리보기도 함께 표시하십시오.
  4. 실질 도착 시 프롬프트를 확인하십시오, 멈추어 글을 쓸 준비가 되었을 때. 결과 메시지가 받은 편지함에 도착했는지 확인하십시오.

Apple의 여행 트리거 가이드는 위치 경계와 시간 범위를 설명합니다. 이 레시피는 위치를 사용하여 프롬프트를 트리거합니다; 이메일에 GPS 좌표를 추가하지 않습니다. 위치 타이밍은 변동될 수 있으므로, 도착 알림이 신뢰할 수 없을 경우 시간 기반 또는 수동 단축키를 사용하십시오.

포집 목적지 선택

DIY 단축키는 사용자가 맞춤 설정하고 유지하고자 하는 워크플로에 적합합니다. 트리거를 추가하거나 미리보기를 숨기기 전에 첫 번째 성공적인 버전을 간단하게 유지하십시오.

Simple Memo는 iPhone의 텍스트를 구성된 이메일 인박스로 캡처하는 또 다른 방법이며, 선택적인 Obsidian integration을 포함합니다. 무료 등급은 하루에 3을 보낼 수 있도록 허용합니다. 보류 중인 전송은 온디바이스 Outbox에 보관되며, 실제 메일 전달은 연결 및 성공적인 전송을 기다립니다. 보류 중이거나 실패한 항목을 확인하고, 메모를 저장하는 것이 배송을 증명한다고 가정하지 마십시오.

Outbox 및 전송 기록은 장치 내 암호화를 사용하며, 이메일은 전달 인프라를 통해 전송됩니다. 이것은 종단 간 암호화된 이메일이 아닙니다; 개인정보 처리방침을 참조하십시오. 이는 작업 흐름 차이이며, Simple Memo 및 단축키의 측정된 속도 순위가 아닙니다.

이메일이 도착하지 않을 경우

  • 먼저 메일 격리: 동일한 구성된 계정에서 수동으로 짧은 메시지를 전송하십시오. 그것이 실패하면 먼저 계정 또는 연결 문제를 해결하십시오.
  • 동을 검사하십시오: Show Compose Sheet를 켜고 발신자, 수신자 및 실제 출력 변수를 확인하십시오. 본문에 비어 있거나 리터럴인 변수 이름이 입력 연결 문제를 가리킵니다.
  • 레시피에서 트리거를 분리하십시오: Shortcuts 앱에서 바로 가기를 실행하십시오. 그곳에서 작동한다면, 자동화의 활성화된 상태와 확인 설정을 확인하십시오.
  • 재시도하기 전에 배송을 확인하십시오: 수신자 인박스와 스팸 폴더를 확인하고, 가능한 경우 Mail's Sent 및 Outbox도 확인하십시오. 보낸 항목은 제출을 기록하고, 수신함은 도착을 확인합니다. 상태가 불확실한 경우 메모를 반복해서 재전송하지 마십시오.
  • 보내지 않은 텍스트를 유지하십시오: 오류를 닫기 전에 복사하거나 메모에 저장하십시오. 메일의 오프라인 처리는 계정 및 작업에 따라 달라지며, 이러한 레시피는 자체적인 지속적인 재시도 로직을 구현하지 않습니다.
  • 변경 후 다시 확인하십시오: 계정, 권한 또는 iOS 변경은 기존 바로가기에 영향을 줄 수 있습니다. 일반적인 발사 방법의 짧은 테스트를 반복하십시오.
이미 검토 중인 인박스로 캡처
Simple Memo는 iPhone에서 텍스트 캡처를 위한 것으로, 하루에 3개의 무료 전송이 있으며, 보류 중인 메시지에는 Outbox이 있습니다. 위의 Simple Memo를 설치하지 않고도 Apple 단축키 레시피를 만들 수 있습니다.
