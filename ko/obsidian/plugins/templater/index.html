Templater 사용법
실행 방법 및 데일리 노트 설정

Templater는 노트 내의 변수와 함수를 실행하여 그 결과를 본문에 삽입하는 플러그인입니다. 먼저 1장을 수동으로 삽입하고, 다음으로 데일리 노트를 생성할 때 설정으로 진행합니다. 여기에서는 변수가 남아 있는 상태와 설정 후 결과를 동일한 템플릿으로 확인했습니다.

준비와 표기수동으로 삽입데일리 노트 설정적용되지 않을 때자주 묻는 질문검증 및 출처

Templater를 준비하고, 표기법을 구분합니다

공식 도입 안내에서는 Obsidian의 Community plugins에서 “Templater”를 검색하여 설치합니다. 이번 검증에서는 공식 2.25.1의 배포 파일을 Vault에 격리하고, 설정 화면에서 플러그인을 활성화했습니다. 사용 중인 Obsidian이나 Templateer 버전이 다를 경우, 화면 이름 및 동작도 자신의 환경에서 확인해 주세요.

Templater의 Template folder location에, 예에서는 Templates을 지정합니다. 명령은 <%로 시작하고 %>로 끝납니다. tp.file.title은 대상 노트의 제목이며, tp.date.now("YYYY-MM-DD HH:mm")는 실행 시 날짜와 시간을 사용하는 예시입니다. 손으로 날짜를 쓰는 저널링 템플릿이나 core Templates의 {{date}} 표기법과 혼동하지 않도록 합니다.

코어 Templates의 제목·날짜 교체 및 저장 결과를 확인하고자 하는 경우, 전체 10종을 실제로 삽입하여 다시 표시한 Markdown 템플릿집도 참고하십시오.

Templater는 JavaScript 및 시스템 명령도 실행할 수 있는 플러그인입니다. 공식 README는 이해할 수 있는 코드를 신뢰할 수 있는 출처에서 사용하도록 안내하고 있습니다. 이 문서의 짧은 예에서는 외부 통신·사용자 스크립트·시스템 명령을 사용하지 않습니다.

먼저, 템플릿을 현재 노트에 삽입합니다

검증에 사용한 Templates/Simple.md의 원문은 다음과 같습니다. 영어 메모 부분은 개인 정보를 포함하지 않는 검증용 허구의 내용입니다.

# <% tp.file.title %>

created: <% tp.date.now("YYYY-MM-DD HH:mm") %>
result: templater-simple-expanded

## Capture

  1. Templates/Simple.md을 준비하고, 삽입된 노트를 엽니다.
  2. 명령 팔레트에서 Templater: Open insert template modal을 선택하고, 목록에서 Simple을 선택합니다.
  3. 삽입된 헤드라인과 날짜를 확인합니다. 이번 Normal 노트에서는 tp.file.title이 Normal로, 시각 식이 2026-09-30 10:46으로 전개되었습니다.

result: templater-simple-expanded은 원문에 있는 고정 문자입니다. 이 행이 보이는 것을 성공 판정에 사용하지 않습니다. <% … %>이 실제 값으로 교체된 것을 확인합니다. 날짜와 시간은 이 Linux 환경의 UTC이며, 일본 시간으로는 19:46입니다.

이미 본문에 붙여넣은 Templater 명령을 확장하는Replace templates in the active file은 별도의 작업입니다. 데일리 노트에서의 복구 예는 후의 절에 표시됩니다.

새로운 일일 노트에서 Templater를 실행합니다

먼저 core Daily notes가 템플릿 본문을 삽입하고, 그 본문에 있는 Templater 명령을 처리하는 구성을 시도했습니다. 사용한 Templates/Daily.md은 다음 원문입니다.

# Daily <% tp.date.now("YYYY-MM-DD") %>

note-title: <% tp.file.title %>
result: templater-daily-expanded

## Inbox
- Sample daily capture.

이번 설정값은 다음과 같습니다. Core Daily notes와 Templater 설정을 구분하여 확인합니다.

설정할 위치표시되는 항목이번 값
코어 일일 노트일자 형식YYYY-MM-DD
코어 일일 노트새 파일 위치Daily
코어 일일 노트템플릿 파일 위치Templates/Daily.md
템플레이터템플릿 폴더 위치Templates
템플레이터새 파일 생성 시 Templater 트리거OFF와 ON을 비교
템플레이터템플릿 매칭 모드None

Trigger를 ON으로 하고, Template matching mode를 None으로 설정한 설정 화면입니다. None은 템플릿을 자동으로 할당하지 않는 설정이지만, 새로운 노트 본문에 이미 있는 Templater 명령은 처리합니다. 이 예에서는 Daily notes 측에서 템플릿을 지정하고 있기 때문에 Folder templates 및 File regex templates를 추가하지 않았습니다.

같은 템플릿, 날짜 형식, Daily/2026-09-30.md이라는 저장 대상에서 새로 만든 노트를 비교했습니다.

Trigger OFF：식이 남아 있습니다

# Daily <% tp.date.now("YYYY-MM-DD") %>

note-title: <% tp.file.title %>
result: templater-daily-expanded

## Inbox
- Sample daily capture.

Trigger ON+None：값으로 전개되었습니다

# Daily 2026-09-30

note-title: 2026-09-30
result: templater-daily-expanded

## Inbox
- Sample daily capture.

여기에서도 result: templater-daily-expanded은 양쪽에 있는 고정 문자입니다. 차이는 헤드라인의 tp.date.now과 note-title의 tp.file.title이 값으로 바뀐 것입니다.

비교 방법:ON의 신규 생성을 확인하기 위해, 격리된 Vault의 가상 시험 노트만 삭제하고 동일한 이름으로 다시 만들었습니다. 독자의 기록된 일일 노트를 삭제하는 절차가 아닙니다. 직접 시험할 때는 검증용 Vault이나 복사본을 사용하고, 기존 기록을 남겨 주세요.

템플릿이 적용되지 않을 때, 무엇을 확인합니까?

노트 본문이 포함되지 않은 경우와 본문에 Templater 식만 남는 경우를 구분합니다. 이번 OFF 노트에서는 본문 자체를 포함했습니다. Trigger를 ON으로 한 뒤 Daily notes 명령으로 동일한 기존 노트를 다시 열어도, 저장된 내용인 SHA256이 앞뒤로 일치하고 식이 남아 있었습니다.

그 기존 노트를 연 상태에서 Templater: Replace templates in the active file을 실행하면 날짜와 제목의 식을 펼칠 수 있었습니다. 기록이 포함된 노트에서는 내용과 템플릿 코드를 확인하고, 복사하여 시도한 후에 작업합니다. 이는 이번 조건에 따른 결과입니다. 시작 시 Daily note를 여는 설정 등, 다른 경로로 일반화하고 있지 않습니다.

추가된 노트가 없습니다·다릅니다날짜, 저장 폴더, 파일을 만드는 경로기존의 데일리 노트 추가 문제로. Templater의 전개와는 별도로 확인하겠습니다

Templater 설정만으로는 외부 입력 접수, 다른 앱에서의 추가, 기기 간 동기화까지 완료되는 것은 아닙니다. 이 기사에서는 Obsidian 내에서 템플릿 처리를 확인했습니다.

자주 묻는 질문

Templater 템플릿을 저장하면 자동으로 실행됩니까?
저장만 해서 모든 노트에 자동으로 적용되는 것은 아닙니다. 저장한 템플릿을 현재 노트에 넣을 때는 “Templater: Open insert template modal”을 사용합니다. 새 파일을 생성할 때의 처리는 “Trigger Templater on new file creation”이라는 별도의 설정입니다.
데일리 노트에서는 Folder 템플릿도 필요합니까?
이번 확인에서는 core Daily notes에 Templates/Daily.md을 지정하고, Templater의 Trigger를 ON으로, Template matching mode를 None으로 설정하여, 새로운 날짜 노트 내의 명령이 전개되었습니다. None은 템플릿을 자동으로 할당하지 않는 설정이지만, 새로운 본문에 이미 있는 Templater 명령은 처리합니다.
트리거를 켜면 기존 데일리 노트도 고쳐지나요?
이번에 OFF로 만든 노트를 ON 후에 Daily notes 명령으로 다시 열어도 저장 내용은 변하지 않았습니다. 미전개 명령을 포함하는 동일한 노트에서는 “Templater: Replace templates in the active file”으로 확장할 수 있었습니다. 이는 이번 설정의 결과이며, 시작 시 Daily note를 여는 설정이나 일괄 처리는 검증하지 않았습니다.
iPhone에서도 같은 절차를 사용할 수 있습니까?
Templater 2.25.1의 공식 매니페스트는 데스크톱 전용이 아닌 설정이지만, 이번 실제 조작 확인은 Linux 버전 Obsidian 1.13.7에만 해당됩니다. iPhone의 화면 및 템플릿 전개, 단말 간 동기화, SimpleMemo에서의 입력은 검증하지 않았습니다. Trigger 설정 화면에도 기기별로 활성화하는 설정이 표시되어 있습니다.

검증 환경과, 이 기사를 사용할 수 있는 범위

  • 실작：Linux 격리 Vault, Obsidian 1.13.7, Templater 2.25.1. 설정 화면을 조작하고, 앱에 등록된 명령으로 노트 생성 및 전개를 확인합니다. 수동 삽입에서는 GUI 목록에서 템플릿을 선택했습니다.
  • 데일리 노트 대조：2026년9월30일10:49〜10:50 UTC（19:49〜19:50 JST）。 동일한 템플릿·저장 대상·날짜 형식으로 OFF와 ON+None 저장 Markdown을 비교합니다. 기존 OFF 노트의 재개방과 명시적인 Replace에 의한 복구도 확인했습니다.
  • 공식 원본：2.25.1의 배포 파일·manifest·공식 docs/source를 확인하십시오. Manifest의 최소 Obsidian 버전은 1.13.0입니다. 이는 모든 버전 및 단말기의 작동 보증이 아닙니다.
  • 미검증：iPhone/Android/Mac, Obsidian을 닫은 상태 및 외부에서 파일 생성, 시작 시 Daily note, 동기화, SimpleMemo 연동, 속도·음성 품질·Siri·Watch.

이 Linux 데스크톱 작업은 iOS 시뮬레이터나 iPhone 실제 기기에서의 확인이 아닙니다. 이미지에 보이는 가상 메모와 저장 Markdown이 표시하는 범위에 한해 실제 작업의 결과로 기재하고 있습니다.
