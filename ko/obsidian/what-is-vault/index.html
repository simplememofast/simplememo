Obsidian의보관함（Vault）란

「보관함」라는 이름 때문에, 독자적인 용기나 전용 형식을 상상하기 쉽습니다. 실제로는 당신이 선택한 일반 폴더 그대로에서, 노트와 첨부 파일, Obsidian의 설정을 한 번에 정리합니다. 이 페이지에서는 빈 폴더를 실제로 보관함으로 열어, 무엇이·몇 바이트가 생성되었는지 파일 시스템에서 계산했습니다.

Obsidian의 보관함(Vault)은 무엇입니까?

당신이 선택한 일반 폴더 자체입니다. 노트는 Markdown의 텍스트 파일이며, 첨부 파일 및 기본 설정 폴더인 .obsidian도 포함됩니다. 노트를 읽기 위한 자체 데이터베이스로의 변환은 필요하지 않습니다.

2026년8월20일에 빈 폴더를 Linux 버전 1.13.7으로 열어 셌더니, 생성된 것은 .obsidian/ 바로 아래의 JSON 파일4개·총 5,543바이트뿐이며, Markdown 파일은 0건였습니다.

iPhone에서음성으로 말하고 Obsidian에 남기는최단 방법은 4 방식의 비교(플러인 없이 절차 포함)에 정리했습니다.

보관함의 위치는 어디인가요? 이름을 바꿀 수 있나요?

보관함은 생성 시 선택한 장소에 있습니다. 이름은 그 폴더 이름입니다.「 'Obsidian'이라는 이름의 공통 폴더를 찾는다고 해서 목적의 보관함이 반드시 보장된 것은 아닙니다.

  • PC：저장 대상을 잊어버렸다면, Finder나 Explorer에서 보관함 이름을 검색하고, 내부의 .md 파일을 열어 자신의 노트인지 확인합니다. .obsidian은 보관함 안의 설정 폴더이며, 노트를 보관하는 보관함 자체가 아닙니다.
  • iPhone에서 iCloud를 사용합니다:「파일」→「브라우즈」→「iCloud Drive」→Obsidian 아이콘이 있는 폴더→자신의 보관함 이름 순서대로 확인합니다. 로컬 저장 및 Obsidian Sync는 별도의 저장 방법입니다.

PC에서 이름을 변경할 때는 보관함 관리 화면에서 대상 메뉴에서 “Rename vault”를 사용할 수 있습니다. 폴더 이름도 변경되므로, 연동 앱의 저장 대상도 확인해 주세요. 공식 보관함 관리 가이드와 iCloud의 보관처 가이드를 참조하고 있습니다.

기존 폴더를 보관함으로 열려면 어떻게 해야 합니까?

PC 버전 Obsidian의 왼쪽 하단에서 보관함 관리 화면을 열고, “Open folder as vault”의 “Open”을 선택하여 노트가 들어 있는 폴더를 지정합니다. .obsidian이나 개별 노트가 아니라, 한 번에 열고 싶은 폴더를 선택합니다. 화면 예시는 보관함 생성·초기 설정 가이드로 이동합니다.

실측 — 빈 폴더를 보관함으로 만들면 무엇이 만들어지는지

빈 디렉터리를 1개 준비하고, Obsidian 1.13.7(Linux 버전)에서 이를 보관함으로 열게 한 뒤, 직후의 내용을 find으로 열거했습니다. 결과가 이것입니다. 

vault-demo/
└── .obsidian/
    ├── app.json
    ├── appearance.json
    ├── core-plugins.json
    └── workspace.json
파일 크기 무엇이 들어 있는지
app.json2내용은 {}입니다. 기본값에서 변경한 설정만 기록됩니다
appearance.json2동일한 {}. 테마와 폰트를 바꾸면 증가합니다
core-plugins.json696코어 기능 31개의 ON/OFF(기본값은 ON 21·OFF 10)
workspace.json4,843 열려 있던 페인의 배치. 4 중 이것만이 큽니다
총합5,543 단위는 바이트입니다. 노트 본체는 1바이트도 포함되지 않습니다

이 5,543 바이트는 이번 빈 보관함의 초기 설정값만입니다. 보통 사용하는 보관함의 총 용량이 아닙니다. Obsidian은 노트와 별도로 IndexedDB와 메타데이터 캐시도 사용합니다. 'Markdown으로 저장한다'와 '앱이 데이터베이스를 전혀 사용하지 않는다'는 별개의 이야기입니다.

여기서 말할 수 있는 것 — 삭제·이동·동기어

.obsidian 와 노트의 저장 대상을 구분합니다

일반적인 Markdown 노트는 설정 폴더 외부에 있습니다. 단, .obsidian에는 테마·핫키·커뮤니티 플러그인 등도 포함됩니다. 삭제를 정리 방법으로 사용하지 말고, 설정을 포함한 보관함의 복사본을 남긴 후에 변경해 주세요. 이번 4 파일은 빈 검증 환경에 한정된 내역입니다.

복사 후에 노트와 설정을 확인합니다

데스크톱에서는 설정 및 첨부 파일을 포함한 보관함의 복사본을 남기고, 복사 대상을 “폴더 열기”에서 지정하여 노트 본문을 확인합니다. 복사만으로는 기기 간 동기화가 설정되지 않습니다. iPhone에서 iCloud를 사용하는 경우, Obsidian용 저장 위치도 확인해 주세요.

단말기를 넘으면 workspace.json 만 성격이 다릅니다

이번 4,843 바이트는 검증 시 화면 배치를 포함하는 설정이었습니다. 공식 자료는 Git에서 관리할 경우 workspace.json과 workspaces.json를 추적 대상에서 제외하는 옵션을 안내하고 있습니다. 사용 중인 동기화 방식 설정과 수동 복사 시 남겨두는 설정을 각각 확인합니다.

「새로 만들기」와「기존 폴더 열기」는 결과가 다릅니다

기존의 빈 폴더를 열었을 때 이번에는 Markdown이 0건이었습니다. 한편, “새로운 보관함을 만들”을 만들면 초기 노트가 1건 배치됩니다(실제 화면 기록). 이미 파일이 있는 폴더라면 후자를 선택하지 마십시오.

core-plugins.json 의 내용 — 기본적으로 OFF인 10개

696바이트의 정체는 Obsidian에 처음부터 들어 있는 핵심 기능의 ON/OFF 표입니다. 2026년 8월 20일의 Linux 버전 1.13.7에서는 31개가 나열되고, 기본값으로 ON 21개·OFF 10개였습니다. 추가 설치 없이 설정에서 전환할 수 있으므로, “해당 기능을 찾아 플러그인을 삽입”하기 전에 여기를 살펴볼 가치가 있습니다. OFF였던 것은 다음 10개입니다. 

footnotes          slash-command      markdown-importer
zk-prefixer        random-note        slides
audio-recorder     workspaces         publish
webviewer

이것은 커뮤니티 플러그인(2026년 8월 21일 기준 6,812개)과는 별개의 것입니다. 총수의 추이와 다운로드 수 상위 10의 실측은 플러인 입문 페이지에 정리했습니다.

폴더임을 알게 된 다음 문제 — 거기에 넣는 속도

iPhone에서 짧은 메모를 추가하려면, 입력 경로와 저장 대상을 먼저 결정합니다. SimpleMemo에서는 연동을 켜고, 파일 앱에서 접근할 수 있는 보관함 폴더에 대한 권한과 날짜 노트 또는 고정 Inbox를 설정하여 이메일을 보내지 않는 쓰기 테스트를 확인합니다. Siri 및 Apple Watch에서의 입력도, 자신의 기기에서 지정한 본문이 남아 있는지 시험해 보시기 바랍니다. 메일 도착, 보관함에 저장, 다른 단말기로의 동기화는 각각 확인합니다. 앱 내 기록 표시만으로는 보관함에 도착을 확인할 수 없습니다.

Obsidian을 선택한 사람의 입구를 가장 짧게 만들다

연동·접근 권한·추가 대상을 설정하고, 짧은 메모가 선택한 노트에 남아 있는지 확인해 주세요. 다운로드는 무료입니다.

보관함을 다른 컴퓨터로 옮기려면 어떻게 해야 하나요?
원본 보관함의 복사본을 확보하고, 노트·첨부·설정을 복사 대상에서 확인합니다. 데스크톱에서는 Obsidian의 “폴더 열기”에서 복사 대상을 지정할 수 있습니다. 복사와 기기 간 동기화는 별개의 작업입니다. 설정을 변경하기 전에 원본을 남겨두고, 화면 배치와 플러그인이 이전 대상에서 사용 가능한지도 확인해 주세요.
기존 폴더를 보관함으로 하면, 내용물이 추가됩니까?
이번 Linux 버전 1.13.7의 빈 폴더에서는,.obsidian와 초기 설정 파일이 생성되고, 직후의 Markdown은0건였습니다. 한편, “새 보관함을 생성”에서 만든 경우 초기 노트가 1건 배치됩니다(실화면 기록）。 이미 파일이 들어 있는 폴더라면 반드시 “폴더 열기” 측을 선택하십시오.
core-plugins.json에는 무엇이 적혀 있습니까?
Obsidian에 처음부터 들어 있는 핵심 기능의 ON/OFF입니다. 2026년8월20일의 Linux 버전 1.13.7에서는31개가 나열되어 있으며, 기본적으로 ON 21개·OFF 10개였습니다. 꺼져 있었던 것은 footnotes / slash-command / markdown-importer / zk-prefixer / random-note / slides / audio-recorder / workspaces / publish / webviewer의 10개입니다. 추가 설치가 필요 없으며 설정에서 전환할 수 있습니다.
검증 환경 및 검증 범위

검증일: 2026년8월20일 / 대상: Obsidian 1.13.7(공식 Linux AppImage·X-AppImage-Version에서 확인)/ 환경: Linux(Ubuntu 24.04·Xvfb 상의 헤드리스). 빈 디렉터리를 1개 준비하여 Obsidian에 보관함으로 열게 하고, 직후의 내용을 find와 ls -l으로 열거·측정한 값을 그대로 올려두고 있습니다. Windows 버전·macOS 버전·iOS 버전에서는 실행하고 있지 않습니다(보관함의 구조는 플랫폼에 의존하지 않는 것으로 간주되지만, 이 페이지에서 확인한 것은 Linux 버전입니다). 「새로운 보관함을 생성」 경우의 동작은 별 페이지에서 2026년 8월 11일에 Obsidian 1.13.6에서 확인한 것이며, 이번 재검증에는 포함되지 않습니다. 버전에 따라 기본값이 변경될 수 있습니다. 2026년 9월 30일은 Obsidian의 저장·이동·동기화 설명을 공식 자료와, SimpleMemo의 입력 연동 조건을 앱의 소스 코드와 대조했습니다. 위의 Linux 실측을 재실행한 것이 아니며, 현재 App Store 배포판 및 iPhone에서의 쓰기·동기는 검증되지 않았습니다.
