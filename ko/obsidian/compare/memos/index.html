Obsidian과 memos의 비교
셀프 호스트 파의 갈림길

두 경우 모두 “직접 가질 수 있는” 노트이지만, 가지고 있는 것이 다릅니다. Obsidian에서는 Markdown 파일을, memos에서는 웹 애플리케이션과 데이터베이스를 직접 관리합니다. Memos 0.30.0를 Mac에서 실제로 실행하고, 짧은 메모를 저장하여 차이를 확인했습니다.

결론: 파일을 보유할지, 서비스를 실행할지

노트의 원본을 일반 파일로 직접 다루고 싶다면 Obsidian. 브라우저에서 짧게 작성하고 타임라인, 태그, 공개 범위를 하나의 웹 애플리케이션으로 다루고 싶다면 memos가 후보입니다.

memos를 셀프호스팅하더라도, 원본이 Obsidian과 동일한 Markdown 폴더가 되는 것은 아닙니다. 이번 실행에서는 Memos가 지정한 데이터 디렉터리에 SQLite를 초기화했습니다. 자유도 대신, 백업 및 업데이트까지 포함하는 서비스 운영을 맡습니다.

memos의 구성 및 운영 책임은 공식 Binary 가이드, 편집·태그·Relations·공개 범위는 공식 Usage 가이드에서 확인했습니다.

Memos 0.30.0을 로컬로 실행하여 저장까지 시도했습니다

공식 GitHub 릴리스의 Apple 실리콘용 아카이브를 가져와, 공개 체크섬과 SHA-256가 일치함을 확인한 후, 외부에 공개하지 않는 로컬 환경에서 실행했습니다.

  1. 새로운 데이터 영역에서 시작합니다.
    작업 전용 임시 디렉터리를 지정하면 SQLite가 초기화되고 private access로 실행되었습니다.
  2. 첫 번째 관리자를 생성합니다.
    초기 화면에서 로컬 검증용 관리자를 만들었습니다. 홈에는 검색, 캘린더, 태그, 공개 범위, 입력란이 나열됩니다.
  3. 일본어의 짧은 메모를 저장합니다.
    태그, 미완료 체크 항목, 항목, 본문을 하나의 메모에 입력했습니다.
  4. 타임라인에 반영을 확인합니다.
    저장 직후에 메모가 표시되고, 태그가 왼쪽에 추가되었으며, 당일 캘린더에 1건으로 표시되었습니다.

셀프 호스트라도 “Markdown을 직접 보유한다”는 보장은 없습니다

Obsidian에서는 보관함을 파일 관리 앱으로 열면 노트의 실체를 확인할 수 있습니다. 다른 편집기에서 동일한 Markdown을 읽을 수 있다는 것은 도구를 교체할 때 탈출구가 됩니다.

memos는 서버가 데이터베이스를 읽고 쓰는 화면을 제공합니다. 공식 문서에서는 표준이 SQLite이며, MySQL과 PostgreSQL도 선택할 수 있습니다. 이는 데이터를 자신의 관리 하에 둘 수 있다는 의미에서는 강하지만, Obsidian의 보관함을 그대로 열어 함께 사용하는 형태는 아닙니다. 마이그레이션을 전제로 한다면, 본판 투입 전에 백업 및 복원, 필요한 형식으로의 내보내기를 소량으로 시도해야 합니다. 이번에는 그것들이 아직 검증되지 않았습니다.

memos를 선택하면 증가하는 것은 노트 기능보다 운영 책임입니다

집이나 사내에서만 사용하는 경우에도 업데이트와 백업이 필요합니다. 인터넷에 공개한다면, 도메인, 리버스 프록시, HTTPS, 접근 제어, 장애 시 복구를 추가로 다룹니다. 공식 가이드에서도 바이너리 사용자가 업그레이드, 롤백, 프로세스 모니터링, 데이터 권한, HTTPS을 관리한다고 설명하고 있습니다.

서버 운영 자체를 즐길 수 있거나 이미 운영 기반이 있다면, memos의 셀프 호스트는 자연스러운 선택입니다. 노트에만 집중하고 싶다면, 로컬 파일을 다루는 Obsidian이 책임 범위를 좁히기 쉽습니다.

어느 쪽을 선택하든, 이동 중인 입구는 별도로 고려합니다

Obsidian은 지식을 보관하고 연결하는 도구이며, memos는 짧은 기록을 타임라인에 흐르게 하는 도구로 설계되었습니다. 다만, Apple Watch이나 Siri에서 한 마디를 남기는 속도는 별개의 과제입니다. SimpleMemo는 Obsidian 연동을 켜두면, 메일을 보류하면서 Obsidian의 데일리 노트 등에 추가합니다. memos에 직접 게시하는 기능은 없습니다. 배송지가 Obsidian이라면 보조 입구로 사용할 수 있습니다.

역할을 섞지 않음: memos의 셀프 호스트와 SimpleMemo는 직접 연동되지 않습니다. 연동할 수 있도록 읽을 수 있는 표현은 피하고, 실제 저장 위치를 먼저 결정해 주세요.

자주 묻는 질문

Obsidian과 memos는 어느 것을 선택해야 합니까?
Markdown 파일을 직접 관리하고 싶다면 Obsidian, 직접 구동하는 웹 애플리케이션에 짧게 기록하고 타임라인에 되돌아보고 싶다면 memos가 후보입니다.
memos는 Obsidian의 보관함을 그대로 사용할 수 있습니까?
사용할 수 없습니다. 이번 표준 시작에서는 SQLite가 초기화되었습니다. Obsidian의 Markdown 폴더를 직접 편집하는 메커니즘이 아닙니다.
memos는 무료인가요?
본체는 오픈소스입니다. 다만, 공개 운영 서버나 도메인 등의 비용과 업데이트·백업·보안을 관리하는 시간은 별도로 필요합니다.

검증 환경 및 범위

실기 확인: 2026년 9월 8일, Apple Silicon Mac/macOS 26.4.1/Memos 0.30.0. 공식 darwin arm64 아카이브를 공개하고 SHA‐256과 대조하여 로컬 전용으로 실행합니다. SQLite 초기화, private access, 관리자 생성, 일본어 메모·태그·작업 저장을 확인했습니다.

미검증: 외부 공개, HTTPS, 다중 사용자, Spaces, SSO, 별도 기기와의 사용, 백업 복원, 업그레이드, 가져오기/내보내기, 모바일, Obsidian 이전, SimpleMemo와 직접 연동. 검증되지 않은 동작은 보증하지 않습니다.
