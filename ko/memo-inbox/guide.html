시작하기

짧은 메모를 위한 공간.

계정이 필요하지 않습니다. 메모는 이 브라우저에 저장됩니다.

기록하고 찾기

본문 입력란에 메모를 쓰고, 필요하면 제목과 쉼표로 구분한 태그를 추가한 뒤 메모 저장을 선택하세요. 저장은 직접 해야 하며, 작성 중인 내용은 자동 저장되지 않습니다. 검색으로 제목·본문·태그에 포함된 단어를 찾을 수 있습니다. 태그를 선택하면 목록을 좁힐 수 있습니다.

삭제와 복원

휴지통으로 이동을 선택해도 메모는 복원할 수 있습니다. 휴지통 탭에서 해당 메모를 선택하고 메모 복원을 누르세요. 영구 삭제 버튼은 없습니다.

텍스트 가져오기

텍스트 파일 가져오기는 UTF-8 .txt 및 .md 파일을 지원하며, 파일 하나를 메모 하나로 가져옵니다. 원본 파일은 수정하지 않습니다. Markdown은 front matter를 포함해 일반 텍스트로 가져옵니다.

메모를 Obsidian으로 옮기기

Markdown ZIP 내보내기에는 현재 필터와 관계없이 받은편지함에 저장된 모든 메모가 포함됩니다. ZIP 파일의 압축을 보관함이나 다른 Markdown 폴더에 풀어 주세요. 제목·날짜·태그는 YAML 메타데이터로 포함됩니다. 휴지통의 메모와 저장하지 않은 변경 사항은 제외됩니다.

백업 보관하기

백업 다운로드는 휴지통을 포함한 모든 저장된 메모를 저장합니다. JSON 파일을 안전한 곳에 보관하십시오. 백업에서 복원은 현재 메모와 병합합니다. 동일한 메모는 건너뛰고, 충돌하는 버전은 별도의 사본으로 보관됩니다. 잘못된 백업은 저장된 메모를 변경하지 않고 거부됩니다.

브라우저 저장 방식 이해하기

메모를 보려면 같은 브라우저 프로필과 사이트 주소를 사용하세요. 사이트 데이터 삭제, 비공개 탐색, 브라우저의 저장 데이터 자동 정리, 기기 분실로 로컬 메모가 사라질 수 있습니다. 정기적으로 백업을 내보내세요. 이 앱은 로컬 데이터를 암호화하지 않으며 보안 저장소가 아닙니다. 클라우드 동기화나 계정이 없고, Simple Memo iPhone 앱과도 연결되지 않습니다. 다른 탭에서 메모가 바뀌었다면 저장하지 않은 텍스트를 복사해 두고 페이지를 새로 고친 뒤 저장하세요.

앱은 서버에 메모를 전송하지 않으며 분석이나 외부 스크립트도 없습니다. 그 호스트는 일반 페이지 요청을 받습니다. 프로젝트 링크는 선택된 경우에만 외부 사이트를 엽니다.

제한

직렬화한 데이터 4 MB, 메모 5,000개, 제목당 200자, 메모당 200,000자, 태그 30개에 각 50자까지입니다. 브라우저의 저장 한도는 이보다 낮을 수 있습니다. 저장에 실패해도 편집기의 텍스트는 복사할 수 있도록 남아 있습니다.
