음성 입력 · iOS 26 이후

말만 하면, 메모.

해당 iOS 26 이후의 iPhone에서 마이크를 탭하여 말한 내용을 문자로 변환할 수 있습니다. 음성 텍스트 변환은 기기 내에서 처리하며, 외부 음성 인식 서버에는 전송하지 않습니다. 첫 번째에는 권한과 음성 모델 준비가 필요합니다. 완성된 메모의 이메일 전송 및 Obsidian 저장은 각각의 설정 및 동작 조건에 따릅니다.

한 마디로 말하면

SimpleMemo의 음성 입력은 말한 내용을 기기 안에서 텍스트로 바꾸는 기능입니다. iOS 26 이상의 지원 기기와 언어에서 메모 입력란의 마이크를 누르고, 음성 입력이 준비된 것을 확인한 뒤 말하세요. 설정에서 ‘앱 실행 시 음성 입력 자동 켜기’를 켜면 일반적인 앱 실행 시에도 음성 입력 시작을 시도합니다. 처음 사용하는 경우의 권한 확인이나 모델 준비가 생략되는 것은 아닙니다.

이 기능으로 달라지는 점

🙌 두 손이 바쁠 때도
요리 중에, 아이를 안고, 걸으면서. 키보드를 입력할 수 없는 상황에서도, 목소리로 그대로 남길 수 있습니다.
🔒 기기 안에서 처리해 개인정보 보호
음성 텍스트 변환은 단말기 내에서 완료됩니다. 음성도 텍스트도 외부 음성 인식 서버에 전송하지 않습니다.프라이버시 퍼스트의 설계입니다.
💸 종량 과금 API 불필요
음성을 텍스트로 바꿀 때 사용량에 따라 요금이 붙는 외부 음성 인식 API를 사용하지 않습니다. 메모 전송 한도와 Premium 조건, 모델 다운로드에 필요한 통신과 기기 용량은 별도입니다.

작동 방식

오른쪽 아래 마이크를 누르면 녹음이 시작되고, 말한 내용이 실시간으로 텍스트가 되어 커서 위치에 삽입됩니다. 녹음 중에는 목소리 크기에 반응하는 실제 파형이 표시됩니다. 설명을 읽지 않아도 ‘지금 듣고 있다’는 상태와 ‘다시 누르면 끝난다’는 조작을 알 수 있습니다.

🎙️ 마이크를 탭하십시오 → 🗣️ 말하다 → ✍️ 실시간으로 텍스트 변환 → 📤 원터치 전송
음성 및 수동 입력을 병용할 수 있습니다
녹음 중에도 키보드는 계속 표시됩니다. 주요 내용을 말로 입력하고, 고유명사나 숫자만 손으로 고칠 수 있습니다.
전송 시 자동 정지
녹음 중에 전송하면 자동으로 중지되고 본문은 삭제됩니다. Captio의 “쓰기→보내기→즉시 클리어” 리듬은 그대로입니다.
기술 메모

음성 텍스트 변환에는 Apple의 SpeechAnalyzer / SpeechTranscriber(iOS 26)를 사용합니다. 음성 모델은 앱 번들에 포함되지 않고, 필요한 언어를 시스템 영역에 다운로드합니다. 앱 본체의 다운로드 용량과는 별개이지만, 단말기의 여유 용량과 최초 획득 시 통신이 필요합니다. 모델이 아직 도입되지 않았다면 준비를 기다리시고, 음성 텍스트 변환이 가능한지 확인한 후에 말씀해 주세요. 시스템에 의한 모델 업데이트도 있습니다.

‘음성 자동 입력’ — 앱을 열 때 시작하도록 설정하기

앱 설정에서 “시작 시 음성 입력 자동 켜기”를 활성화하면, 일반적인 앱 실행 시 음성 입력을 시작하려고 시도합니다. 지원 기종·언어, 마이크와 음성 인식 허가, 음성 모델 준비가 필요합니다. 화면 상태를 확인한 후에 말씀해 주세요. 액션 버튼 등에 할당하는 “음성 메모” 단축키는 다른 호출 방법입니다.

함께 활용하기

홈 화면이나 잠금 화면의 해당 입구에서 앱을 열고, 음성 텍스트 변환을 확인한 후 전송합니다. 잠금 해제나 인증이 요구될 수 있으며, 실행부터 배포·저장까지의 소요 시간은 조건에 따라 달라집니다. Obsidian에 추가하려면 iPhone 측의 연동 및 보관함·저장처 설정이 필요합니다.

사용 방법

  • iPhone（iOS 26 이후·음성 입력 지원 기종）
  • SimpleMemo를 App Store에서 설치
  • 처음 사용할 때 마이크와 음성 인식 권한 허용(텍스트 변환은 기기 내 처리)
  1. 오른쪽 하단의 마이크를 탭합니다
    메모 입력 화면 오른쪽 하단에 있는 마이크 아이콘을 탭합니다. 첫 번째에는 마이크 음성 인식 허가와 미도입 언어의 음성 모델 준비가 필요합니다. 준비에 시간이 걸릴 수 있으니, 음성 텍스트 변환이 가능한지 확인한 후에 말씀해 주세요.
  2. 말하기
    음성을 텍스트로 바꿀 준비가 된 것을 확인하고 말하세요. 말하는 중간 결과도 실시간으로 표시되며, 확정된 텍스트는 커서 위치에 들어갑니다. 키보드 입력도 함께 사용할 수 있습니다.
  3. 다시 탭하여 정지합니다
    파형(정지 버튼)을 다시 탭하면 음성 입력이 멈춥니다.
  4. 전송
    언제나처럼 원탭 전송. 전송 시 녹음 중이면 자동으로 중지되며, 본문은 초기화됩니다.
자동으로 시작하고 싶으시면

설정에서 “시작 시 음성 입력을 자동으로 켜기”를 활성화합니다. 지원 기종·언어에 따라 권한과 음성 모델이 준비되어 있는지 확인해 주세요. 일반적인 앱 실행 시 자동 시작과 “음성 메모” 단축키 설정은 별도입니다.

활용 아이디어

가사·육아 사이에
손을 놓을 수 없을 때일수록 말로. 쇼핑 추가와 “저거 해야 해”를 순식간에 남길 수 있습니다.
긴 글을 한 번에
생각하고 있는 것을 말하고 대충 적어 두고, 나중에 정리합니다. 타이핑보다 더 빨리 내뱉을 수 있습니다.
아이디어의 순간 포착
아이디어 메모는 신선도가 생명입니다. 자동 시작과 음성이라면, 잊어버리기 전에 음성으로 남길 수 있습니다.
일본어 입력이 번거로운 경우
문자 변환이 잦은 일본어는 말로 입력하는 편이 더 빠를 때도 있습니다. 음성으로 쓰고 필요한 부분만 손으로 고칠 수 있습니다.

동작 조건 및 주의 사항

iOS 26 이후의 지원 기종 및 지원 언어가 필요합니다

음성 입력은 Apple의 새로운 온디바이스 음성 인식(iOS 26)을 사용합니다. iOS 26 미만에서는 이 기능의 마이크가 표시되지 않습니다. 지원하지 않는 기기나 언어를 사용하거나 모델 준비에 문제가 생기면 키보드로 입력하세요.

첫 번째는 음성 모델 다운로드가 필요할 수 있습니다

미도입된 음성 모델은 통신을 사용하여 시스템 영역으로 가져옵니다. 남은 용량과 연결을 확인하시고, 처음에는 준비가 될 때까지 기다린 후에 음성 텍스트 변환을 시도해 주세요.

마이크와 음성 인식에 대한 허가가 필요합니다

첫 탭 시(자동 시작이 켜질 경우 시작 직후)에 허가 대화 상자가 표시됩니다. 거부한 경우에는 알림의 “설정 열기”에서 나중에 허용할 수 있습니다.

자주 묻는 질문

음성 입력에 추가 요금이 부과됩니까?

음성을 텍스트로 바꿀 때 사용량에 따라 요금이 붙는 외부 음성 인식 API를 사용하지 않습니다. 메모 전송 한도와 Premium 조건은 별도입니다. 처음 음성 모델을 받을 때 등에는 통신이 필요하며, 통신 요금은 사용 환경에 따라 달라집니다.

말한 음성은 어디에 전송됩니까?

이 기능의 음성 텍스트 변환은 기기 내에서 수행되며, 외부 음성 인식 서버로 음성이나 텍스트를 전송하지 않습니다. 완성된 메모의 이메일 전송에서는 본문을 메일 중계 서비스와 수신자에게 보냅니다. Obsidian 저장 및 기타 연동은 선택한 설정과 각 연동의 동작 조건에 따릅니다.

사용 가능한 조건은 무엇인가요? 지원되지 않는 단말기에서는 어떻게 됩니까?

iOS 26 이후의 대응 기종·지원 언어, 마이크와 음성 인식 허가, 음성 모델 준비가 필요합니다. iOS 26 미만에서는 이 기능의 마이크가 표시되지 않습니다. 지원되지 않는 기종·언어나 준비 오류가 있는 경우에는 키보드 입력을 사용할 수 있습니다.

음성 모델은 단말기의 용량을 사용합니까?

예. 모델은 앱 본체의 다운로드 용량에 포함되지 않으며 시스템 영역에 저장됩니다. 단말기의 여유 용량과 미도입 모델을 획득하기 위한 통신이 필요합니다. 시스템에 의한 업데이트도 있기 때문에, 최초에 한 번만 통신한다고 보장할 수 없습니다.

「음성 자동 입력」이란 무엇입니까?

설정에서 ‘앱 실행 시 음성 입력 자동 켜기’를 켜면, 일반적인 앱 실행 시 음성 입력 시작을 시도하는 기능입니다. 지원 기기와 언어, 권한, 음성 모델 준비가 필요합니다. 시작 상태를 확인한 뒤 말하세요. ‘음성 메모’ 단축어는 별도의 실행 방법입니다.

음성 입력 중에도 키보드로 입력할 수 있나요?

예. 음성 입력과 수동 입력을 동시에 사용할 수 있습니다. 인식된 문자를 확인하시고, 말실수나 고유명사를 키보드로 수정한 후 전송해 주세요.

음성으로 작성한 메모도 Obsidian에 추가됩니까?

음성 입력과 Obsidian 연동은 별개의 기능입니다. 추가하려면 iPhone 측의 연동을 켜고, 보관함·저장처에 대한 접근을 설정해야 합니다. 사용하는 저장 방법의 동작 조건을 확인해 주세요. 해당 Obsidian 전용 모드가 활성화된 동안에는 이메일을 발송하지 않습니다. 전송 작업만으로 전송·저장 성공이 확정되는 것은 아니니, 저장 대상에서 확인해 주세요.

말만 하면 바로 메모합니다.
다운로드는 무료입니다. 음성 입력은 iOS 26 이상의 지원 기기에서 사용할 수 있습니다.
