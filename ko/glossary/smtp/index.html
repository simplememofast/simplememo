SMTP/IMAP이란

SMTP(Simple Mail Transfer Protocol)은 메일을 전송하는 프로토콜이며, IMAP(Internet Message Access Protocol)은 메일을 수신·열람하는 프로토콜입니다. SimpleMemo는 이러한 프로토콜을 직접 사용하지 않고, Cloudflare Workers + Resend API에 의한 릴레이 방식으로 메모를 전송하므로 SMTP 설정은 전혀 필요하지 않습니다.

정의

SMTP(Simple Mail Transfer Protocol)는 1982년에 RFC 821로 표준화된 이메일 전송 프로토콜입니다. 이메일 클라이언트에서 이메일 서버로, 또는 이메일 서버 사이에서 메시지를 전달합니다. IMAP(Internet Message Access Protocol)은 서버의 이메일을 열람·관리하는 프로토콜로, 메일을 서버에 둔 채 여러 기기에서 접근할 수 있습니다. 구형 POP3와 달리 IMAP은 폴더 관리와 부분 다운로드를 지원합니다.

SMTP vs IMAP vs POP3

SMTP（전송）
메일을 전송하는 전용 프로토콜. 메일 클라이언트→송신 서버→수신 서버로 메시지를 전달합니다. 포트 587(STARTTLS) 또는 465(SSL/TLS)를 사용합니다. 인증에는 사용자 이름과 비밀번호가 필요합니다.
IMAP(수신·동기)
메일을 서버에 남긴 채로 열람하는 프로토콜. iPhone, PC, 태블릿 등 여러 기기에서 동일한 메일을 볼 수 있습니다. 폴더 관리, 검색, 플래그 지정을 지원합니다. 현재 이메일 열람의 주류입니다.
POP3（다운로드형）
서버에서 디바이스로 메일을 다운로드하는 프로토콜. 다운로드 후에는 서버에서 삭제되므로 다른 기기에서는 볼 수 없습니다. 현재는 IMAP에 의해 대체되고 있습니다.

SimpleMemo가 SMTP 설정이 필요 없는 이유

자신의 메일 계정에서 전송하는 방식의 앱에서는 해당 계정의 SMTP 서버에 연결하기 위해 SMTP 서버명(예: smtp.gmail.com), 포트 번호(587), 앱 비밀번호 등의 설정이 필요할 수 있습니다. SimpleMemo는 이 방식을 사용하지 않습니다. 메모는 Cloudflare Workers에 전송되며, Resend API를 경유하여 이메일로 전달됩니다. 사용자가 설정하는 것은 이메일 주소뿐입니다. 6자리 확인 코드로 인증하면 설정이 완료됩니다.

자주 묻는 질문（SMTP/IMAP）

SMTP이(가) 무엇입니까?

메일을 전송하기 위한 인터넷 표준 프로토콜입니다. 메일 클라이언트에서 메일 서버로, 서버 간에 메일을 전달합니다.

SMTP와 IMAP의 차이점은 무엇인가요?

SMTP은 “전송”, IMAP은 “수신·열람” 프로토콜입니다. IMAP은 메일을 서버에 남겨 둔 채로 여러 기기에서 열람할 수 있습니다.

SimpleMemo는 왜 SMTP 설정이 필요 없나요?

Cloudflare Workers + Resend API를 사용한 릴레이 방식을 채택하고 있기 때문에 사용자의 SMTP 서버에 직접 연결하지 않습니다. 이메일 주소 입력과 6자리 코드 인증만으로 설정이 완료됩니다.
