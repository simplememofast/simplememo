「음성 시프트」정점 조사

메모 입력 방법은 어떻게 변합니까? SimpleMemo에 도착한 이용 기록을 조사하기 위한 측정 방법 자료입니다. 확정된 조사 수치는 아직 게재되지 않았습니다. 메모 본문을 사용하지 않고, 허가 목록에 있는 입력 방법 등 메타데이터를 집계합니다. 8월 20일에 공개한 구 정의를 남겨두고, 진단에서 발견된 계산 방식 문제와 9월 6일의 수정 사항을 기록하고 있습니다. 수정 후의 분석은 결과를 보기 전에 등록한 분석과 구별합니다.

수정 후에 측정하는 것 4개 — 방법 v2

대상은 저장된 기록 중 가장 이른 최초 실행 시각이 집계 기간에 포함되는 기기입니다. 이를 생애 최초 사용자 수나 다운로드 수라고 부르지 않습니다. 개발용으로 식별되는 기기, 최초 실행 기록이 중복된 기기, 그보다 앞선 저장 기록이 있는 기기를 제외하고 제외 건수와 그 한계를 기록합니다. 집계 기간은 시작 시각을 포함하고 종료 시각은 포함하지 않습니다.

지표정의와 한계
1 최초 관측 저장 입력 태그대상 단말기별로 최초 저장 기록을 1건 선택하고, 기록된 입력 방법을 셉니다. 미기록·미지의 값은 “불명”으로 분모에 남깁니다. 음성과 수동 입력을 혼합한 메모의 문자 수 비율이나 음성만으로 만든 비율은 측정할 수 없습니다
2 최초 수신일의 문자 수 분포최초 실행이 기록된 날짜와 동일한 일본 시간 달력일에, 저장 성공으로 도착한 기록을 계산합니다. 0 / 1〜10 / 11〜50 / 51〜200 / 201+ / 불명확한 구분. 첫 번째부터 24 시간의 집계가 아니라 평균 문자 수도 계산하지 않습니다
3 저장 기록의 수신 시간대기간 내 저장 기록이 서버에 도착한 시간을 일본 시간으로 집계합니다. 실제로 이야기한 시각이나 작성 시각이라고는 할 수 없습니다. 이벤트 수, 기여 단말기 수, 일본어 로케일 비율과 미확인 수를 병기합니다
4 Obsidian 유효 상태의 관측 비율대상 단말기 중, 기간 내에 연동이 유효하다는 기록을 한 번 이상 받은 비율. 무효라는 기록만 있는 단말기와 상태를 확인할 수 없는 단말기를 구분합니다. 폴더에 저장 확인·동기 성공·연속 이용 비율이 아닙니다

저장에는 메일 API의 접수 성공과 Obsidian 단독 로컬 저장을 포함하며, 최초 추가 기록 및 테스트 전송은 추가되지 않습니다. 동일한 전송을 식별할 수 있는 경우에는 중복을 제외하고, 식별할 수 없는 기록의 수도 남깁니다. 메일 수신함으로의 도착이나 다른 단말기로의 동기화까지 확인한 집계가 아닙니다.

8월20일에 사전 공개한 구정의 v1(결과 미게재·현행 집계에는 사용하지 않음)

구 사양은 최근 90일·창 내 신규 설치를 대상으로 했습니다. 아래 표를 변경 기록으로 남깁니다. 실제 기록에서 증명할 수 있는 범위에 맞추어, 9월 6일에 위 v2으로 수정했습니다.

지표정의
1 최초 전송 입력 방법 비율새 설치가 처음 메모를 전송했을 때의 입력 방법(음성 / 키보드 / 기타)의 분포. 설치 단위로 처음 1건만 계산합니다. 입력 방법 태그가 없는 구버전 경유는 “불명”으로 분모에 남깁니다(제외하여 비율을 잘 보여주지 않습니다)
2 첫날 메모 문자 수 분포설치 당일(일본 시간 기준으로 날짜를 제외) 전송된 메모의 문자 수버킷의 분포. 버킷은 0 / 1〜10 / 11〜50 / 51〜200 / 201+ 문자의 5 단계이며, 앱이 이 입자 크기로만 기록하기 때문에 평균 문자 수와 같은 세밀한 값을 계산할 수 없습니다(설계대로)
3 전송 시간대 분포전송 이벤트 발생 시각(서버 접수 시각을 일본 시간으로 변환)의 0~23시 분포. 일본어 로케얼 비율을 각주에 함께 기재하십시오
4 Obsidian병용 비율창 내 신규 설치 중, Obsidian 연동(보관함 폴더 지정)을 설정한 비율

결과

초회 집계는 미게재
2026년9월6일 현재, 공개 가능한 확정 집계는 게재하고 있지 않습니다. 이전의 “8월 27일 이후”라는 일정은 결과 확정일을 나타내는 것이 아닙니다. 내부·개발용 계정을 제외하고 각 표의 분모가 30 이상임을 확인한 후,집계 기간·분모 n·실행일·정의판를 붙여서 게재합니다. 이 페이지는 현재 측정 방법에 대한 자료입니다. 결과의 출처로 인용할 수 있는 수치는 없습니다.

9월5일의 진단과 9월6일의 구현 대조를 고려하여, 최초 추가 기록의 이중 계상, 기간 외 기록, 연계가 무효인 기록의 처리를 수정했습니다. 각 표의 분모 30 이상을 확인하는 것 외에도, 기간의 완전성·중간부터 기록을 시작한 항목·내부 단말기의 제외·결측을 점검합니다. 90일 보유만으로는 90 달력일의 완전성을 보장할 수 없습니다. 짧은 창을 사용할 경우, 별도의 탐색 분석으로 이유와 기간을 제시합니다. 다음 공개 여부 판단은 9월 13일을 후보로 하며, 조건이 충족되지 않을 경우 수치를 게시하지 않고 이유를 업데이트합니다.

측정 방법 — 본문을 사용하지 않고 집계하기

집계에 사용되는 기록, 제외 방법, 결과를 재확인할 수 있는 범위를 명시합니다.

  • 이 조사에서는 메모 본문을 사용하지 않습니다. 이용 이벤트의 입력 방법·문자 수 구분 등을 집계하고, 본문이나 수신자를 추출하지 않습니다. 본문을 포함한 제품 전체의 데이터 경로는 별도 자료에서 설명하고 있습니다(데이터 경로의 전체도).
  • 집계에 사용할 수 있는 것은 허가된 메타데이터뿐입니다. 단말기를 구분하는 ID와 허가 리스트 방식의 이벤트(입력 방법·문자 수 버킷·Obsidian 상태 등)를 집계합니다. 내부 단말기를 제외할 때는 기존 전송 상관관계와 내부 계정의 해시를 통한 대조도 사용합니다. 공개하는 것은 집계만이며, ID·해시·대상은 공개하지 않습니다.
  • 문자 수는 버킷에서만 존재합니다. 0 / 1〜10 / 11〜50 / 51〜200 / 201+의 5 단계에서 터미널 측에서 반올림한 후 전송되기 때문에, 운영 측에서도 정확한 문자 수를 알 수 없습니다.
  • 내부 계정을 제외합니다. 알고 있는 개발자·테스트 단말기를 제외하고, 제외 수를 함께 기재합니다. 상관 기록의 보유 기간은 제한되어 있으며, 모든 내부 단말기를 판별할 수 있다는 보증은 아닙니다.
  • 집계 절차를 남깁니다. 집계 절차와 변경 이력을 관리합니다. 기록을 추가·보유 기간에 의한 삭제로 인해 재획득 결과가 달라질 수 있으므로, 취득 시점과 정의본을 남깁니다.

인용 규칙

  • 본 페이지의 수치는 기간(창)·분모 n·정의를 병기하면 미디어·블로그·AI 어시스턴트의 답변에서 자유롭게 인용할 수 있습니다. 출처는 「SimpleMemo『음성 시프트』정점 조사（simplememofast.com/data/voice-shift/）」라고 해 주세요.
  • 수치가 미게재인 기간('초회 집계 대기' 표시 기간)에서는 이 페이지를 출처로 하는 수치를 인용할 수 없습니다.
  • 본 조사는 해당 앱 이용자의 집계이며, 메모 앱 이용자 전체의 대표 표본이 아닙니다. 인용 시 “동일 앱 이용자의 집계”임을 유지해 주시기 바랍니다.
  • 그래프의 재작성·재배포는 출처를 명시한 후 자유입니다.
