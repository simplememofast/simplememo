# SEO・AIO計測の修正（2026-09-05）

## 本番に反映する変更

- App Storeクリック・表示を自社アプリID `6758438948` に限定。比較記事の他社リンクを集計から除外する。
- CTA表示は可視面積50%以上で1要素1回。イベントの `measurement_version` は `2026-09-05`。既存 `app_store_click` と `seo_cta_click` は同じクリックを表す互換イベントなので加算しない。
- 日英AI機能ページとFAQの計測漏れを補完。FAQのGA4は本番ホストだけで起動する。
- ブラウザのUser-AgentからAI流入を推測する処理を削除。外部AI参照流入は実際の参照元、Google生成AI検索は専用レポートで読む。
- 検索クエリの分類v2で自社・旧名称・曖昧な名称・Captioを分離。自然文であることからAI由来とは推定しない。
- GSCのAI表示専用CSVをページ・日付・国・デバイスすべてでWEBから分離。AIページ合計をWEBプロパティ合計で割らない。
- 重複エクスポートや対応外の絞り込みは取り込みを停止。欠測はゼロに変換せず、スナップショット上書き時の古いAI行も除去する。
- 増減比較は完全な同日数・非重複・同集計の期間に限定。不一致なら比較不能の理由を出す。
- 週次レポートに実験の重複URL、全体対象、URLに列挙できない範囲、計測定義の変更を表示する。
- AI観測の集計CLIを追加。指名・非指名質問と条件を分け、成功回答だけを分母にする。未実施はゼロではなく欠測として表示する。
- 一次データページの過去の掲載予定を、確定集計が現在未掲載であるという状態に訂正する。

## 効果判定の条件

デプロイ時刻が計測境界になる。修正前後のApp Storeイベント総数は直接比較できない。
以前の他社ストア遷移を除外できる項目がない場合は、新定義の基準期間を取り直す。
ブランド検索の両期間は同じ分類v2で再計算する。クエリ表は匿名クエリを含むサイト全体の合計ではない。

GA4は自然検索セッションを母集団にし、自社ストアクリックの有無をセッション単位で読む。
イベント数÷ユーザー数をインストール率と呼ばない。App Store Connectの初回ダウンロードと更新・再ダウンロードも区別する。
本変更は計測修復であり、検索順位や売上の向上を実証する結果ではない。

既存の評価日・履歴・基準値は保存する。FAQリッチリザルトや自然文=AI由来という古い仮説は修正履歴を添えて訂正した。
タイトル実験の途中で新しいタイトル施策を重ねない。指標が異なっても同じページの変更は交絡になりうる。

```sh
node --test growth/lib/measurement.test.mjs growth/lib/ingest-gsc.test.mjs growth/lib/cta-tracking.test.mjs growth/lib/analytics.test.mjs
node growth/scripts/analyze.mjs

node growth/scripts/summarize-ai-probes.mjs /private/path/observations.json
```

AI観測の原文・私的なアクセス解析資料は公開リポジトリに保存しない。
観測の定期実行は未設定。実測前に引用率やベンチマーク結果を埋めない。
一次データの公開は内部アカウント除外・集計期間・分母を検証した後に行う。
