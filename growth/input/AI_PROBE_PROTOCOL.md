# AI Visibility Probe — 月1回・取得範囲を記録・APIキー不要の定点観測

**目的:** 「AIアシスタントに聞いたとき、SimpleMemoは名前が出るか・引用されるか・
競合の誰が引用されているか」を毎月同じ条件で記録する。
APIは使わない。**オーナーが各AIの通常アプリ/Webで質問し、回答を貼るだけ**。
記録後に集計CLIを実行する。条件が一致しない月の率は直接比較しない。

**設計原則:**
- 質問は**固定**（変えると時系列が壊れる。追加は末尾にのみ、削除はしない）
- 質問文はGSCで実測された会話型クエリ（自然文であることはAI由来の証拠ではない）と
  ブランド確認から採っている。**架空のキーワードではない**
- 各AIとも**新規会話・ログイン状態は普段のまま**で聞く（パーソナライズ込みの
  現実の答えを記録する。クリーンルーム計測は目的ではない）
- 回答は要約せず**そのまま**貼る（解釈はオートパイロット側の仕事）

---

## 手順（月初の任意の日・所要時間は回答数による）

1. このファイルを公開リポジトリ外の作業フォルダにコピー
2. ChatGPT / Gemini / Perplexity の3つで、下の質問を上から順に聞く
   （時間がなければ Q1〜Q5 だけでも成立。やった範囲を正直に記録）
3. 各回答をテンプレの該当欄に貼り付け、「SimpleMemo/シンプルメモへの言及」
   「simplememofast.com の引用有無」だけ ○/× を手で付ける
4. 回答原文は公開サイト・公開リポジトリの外へ保存する。集計だけを共有する場合も、Codex/ブランチのPRと検証を経由する。
5. 下のJSON形式で観測を記録し、`node growth/scripts/summarize-ai-probes.mjs /private/path/observations.json` を実行する。標準出力は集計のみ。原文と証跡のパスは出力しない。定期実行・日報への接続は未設定。

## 計測条件（2026-09-05追記）

実行日・サービス・表示モデル名・検索の有無・言語・ログイン状態・反復番号を残す。
成功した回答だけを率の分母にする。未実施・検索失敗・利用不可は欠測であり、言及なしのゼロと混ぜない。
言及・リンク付き引用・誤記を別の指標にし、ブランド確認質問と非指名質問も分ける。
同じ質問は新しい会話で3回。初週は主要5問×2サービスから始め、全体は月次にする。
下のv1質問は過去データの再現のため維持し、新しい質問セットは別のversionで記録する。

## 記録テンプレ（AIごと×質問ごと×反復ごと）

回答原文を私的な証跡ファイルに保存し、次のJSONで観測を記録する。
以下は**未実施の記入例**であり、観測データではない。`model` は実際の画面表示に置き換える。
成功時は `status: "ok"` とし、`mentioned`・`linked_citation`・`wrong_claim` を確認して真偽値で記録する。
`evidence_ref` には保存した回答のパスを入れる。リンク付き引用は対象URLを開いて確認する。

```json
{
  "schema_version": 2,
  "observations": [{
    "date": "2026-09-05",
    "question_set": "v1",
    "question_id": "Q2",
    "question_type": "nonbrand",
    "service": "chatgpt",
    "model": "未確認",
    "search_enabled": true,
    "language": "ja",
    "login_state": "signed-in",
    "repetition": 1,
    "status": "missing"
  }]
}
```

Q5は `question_type: "brand"`、その他のv1質問は `nonbrand`。
利用できなかった回答は `status: "error"`、実行しなかった回答は `missing` として予定した全枠を残す。
集計は日付・質問セット・質問種別・サービス・モデル・検索・言語・ログイン状態ごとに分かれる。
分母は完了回答数。未実施とエラーも件数を表示し、完了が0件なら率は `null` にする。
反復回答は独立したユーザー標本ではなく、この質問集合・条件での観測結果に限る。

誤記があれば、該当ページの可視本文・一次資料の改善に使う。
llms.txt の更新だけをGoogle検索の掲載改善策として扱わない。
