# AI Visibility Probe — 月1回・10分・APIキー不要の定点観測

**目的:** 「AIアシスタントに聞いたとき、SimpleMemoは名前が出るか・引用されるか・
競合の誰が引用されているか」を毎月同じ条件で記録する。
APIは使わない。**オーナーが各AIの通常アプリ/Webで質問し、回答を貼るだけ**。
集計・前月比・日報への反映はオートパイロットが行う。

**設計原則:**
- 質問は**固定**（変えると時系列が壊れる。追加は末尾にのみ、削除はしない）
- 質問文はGSCで実測された会話型クエリ（fan-out痕跡・27件）と
  ブランド確認から採っている。**架空のキーワードではない**
- 各AIとも**新規会話・ログイン状態は普段のまま**で聞く（パーソナライズ込みの
  現実の答えを記録する。クリーンルーム計測は目的ではない）
- 回答は要約せず**そのまま**貼る（解釈はオートパイロット側の仕事）

---

## 手順（月初の任意の日・計10分）

1. このファイルを `growth/input/ai-probe/YYYY-MM.md` にコピー
2. ChatGPT / Gemini / Perplexity の3つで、下の質問を上から順に聞く
   （時間がなければ Q1〜Q5 だけでも成立。やった範囲を正直に記録）
3. 各回答をテンプレの該当欄に貼り付け、「SimpleMemo/シンプルメモへの言及」
   「simplememofast.com の引用有無」だけ ○/× を手で付ける
4. コミットしてpush（ブランチ不要・mainに直接でもclaude/ブランチ経由でも可）
5. 以降はオートパイロットが集計し、`growth/data/ai-probes/YYYY-MM.json` に
   機械可読化して日報・週次に反映する

## オートパイロット側の集計仕様

`growth/data/ai-probes/YYYY-MM.json`:

```json
{
  "month": "2026-08",
  "assistants": ["chatgpt", "gemini", "perplexity"],
  "questions_asked": 10,
  "mention_rate": {"chatgpt": 0.2, "gemini": 0.1, "perplexity": 0.3},
  "citation_rate": {"chatgpt": 0.1, "gemini": 0.0, "perplexity": 0.2},
  "top_cited_competitors": ["notion.so", "obsidian.md"],
  "wrong_claims": ["ChatGPTがE2EEと誤答(Q5)"],
  "notes": "..."
}
```

`wrong_claims` に載った誤りは llms.txt の誤り訂正リストと該当ページの
回答ブロック更新の**根拠データ**になる（ここがこのプローブの一番の実用価値）。
