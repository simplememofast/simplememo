远程工作 笔记管理术
提高在家办公生产力的5的方法

远程工作，办公室的“小对话”消失了。 因此，通过备忘录进行信息管理比办公室工作更重要。 异步沟通、在线会议、自我管理、工作的界限。 介绍用备忘录解决居家办公特有的课题的5种方法。

TL;DR

解说远程办公、在家办公时的备忘录管理术。 非同步沟通备忘录、Zoom会议笔记、自我问责制日志、工作和私人的界限备忘录等5个实践技巧。

在远程工作中，由于不能在旁边的座位上重新确认，所以把决定的事情留在原地的价值会变大。 会议结束后马上把要点发到自己身上，以后就可以成为确认“说过或不说”的材料。

为什么远程工作中备忘录很重要

Slack、Zoom、Teams、邮件、Google Docs——信息流入渠道多的话，重要信息容易被埋没。

在办公室里对旁边的人说“那个怎么了？” 虽然可以问，但如果远程没有记录的话，可能需要几个小时才能确认。 备忘录是远程工作者的“外部大脑”。

远程工作特有的课题：

  • 随着异步交流的增加，容易发生“说、不说”
  • Zoom太累了，会议后的记录被忽略了
  • 如果不把自己的进度可视化的话，很难被评价
  • 工作和私人的界限容易变得模糊
  • 从孤独感开始，容易堂堂正正地思考

技术1：异步交流・备忘录

1写在Slack之前用备忘录整理沟通

远程工作以Slack和邮件的异步交流为主。 但是，如果随心所欲地写在Slack上的话，信息就会变得零碎，无法传达给对方。

非同步备忘录的规则：

  • 在Slack上投稿之前，先用备忘录软件整理要点
  • 用“背景”“要求”“期待的动作”的3点套装来写
  • 意识到对方的时区，问题集中到1信息
  • 在开头注明是“FYI（参考信息）”还是“需要行动”
例：“[需要行动] @佐藤 / 背景：Q2 LP的原稿是3/10〆 / 要求：英雄部分的副本案3个 / 期待：3/8中请在Slack上分享 / 参考：附加的竞争分析文件”

技术2：Zoom会议30秒总结

2会议结束后马上30秒备忘录会议效率化

在远程工作中，在1日进行5~8的Zoom会议的情况并不罕见。 会议连续的话，上一个会议的内容会被下一个会议覆盖。

Zoom会议总结的写法：

  • 关闭Zoom的之后的30秒写笔记（下次会议之前）
  • 写的内容只有3点：决定事项・行动项目・下次预定
  • 通过邮件发送给自己，稍后用Gmail的标签列表化
  • 如果有Zoom录像的话，录像URL也附在备忘录里

SimpleMemo的话0.4秒（iPhone 16e・warm启动的实测）启动，一键发送邮件即可。 关闭Zoom后，马上就可以发送摘要。

例：“[Zoom] 设计评论 3/6 / 决定：将标题改为深色模式 / @田中：模拟3/8 / @佐藤：字体大小调查 / 下次：3/10 15:00”

技术3：自我问责制日志

3把自己的工作“可视化”自我管理

在远程工作中，上司和同事看不到你的工作状态。“ 需要自己记录“在做什么”并定期共享的机制。

自我问责制日志的写法：

  • 早上9时：今天的TODO3给自己发邮件
  • 白天12时：上午的进度1行备忘录
  • 傍晚17时：用Done/Doing/Blocked记录今天的成果
  • 周末作为每周报告总结，分享给上司

积累这个日志后，可以在评价面谈中将“这半年做了什么”作为具体数据提出来。

例（傍晚备忘录）：“3/6 17:00 / Done: LP原稿v2完成，客户提案书草稿 / Doing: SEO关键词调查（70%完成） / Blocked: 等待设计资产的素材 / 明天: SEO调查完成，广告文草稿”

技术4：工作的“开始笔记”和“结束笔记”

4划定工作和私人的界限工作与生活的平衡

在家办公的最大课题1是“工作没有结束”的感觉。 因为没有通勤的物理界限，所以晚上10时也会确认Slack。

解决这个问题的是“开始备忘录”和“结束备忘录”：

  • 开始备忘录（早上）：“开始今天的工作。 今天的TOP是〇〇”→给自己发邮件
  • 结束备忘录（傍晚）：“今天的工作结束。 完成: 〇〇 / 结转: 〇〇 / 明天的首要任务: 〇〇”→ 给自己发邮件

这个2邮件可以代替“上班”和“下班”。 发送结束备忘录后，关闭Slack的通知，有意识地关闭工作模式。

结束备忘录示例：“17:30 工作结束 / 完成：LP公开、提交SEO报告、1on1 / 结转：广告创意（预计明天上午完成） / 明天的首要任务：客户演示准备”

技术5：Inbox Zero备忘录管理法

5通过邮件基础的备忘录管理将信息集中化信息整理

远程工作的信息散布在Slack、Zoom、邮件、Google Docs、Notion等多个工具中。 解决这个问题的是“将邮件作为备忘录的集中点”的战略。

Inbox Zero备忘录管理步骤：

  1. 所有备忘录用SimpleMemo发送到自己的邮件
  2. 通过Gmail的过滤器自动将“from: simplememo”分配到“备忘录”标签
  3. 每天早上的15分钟，处理备忘录标签的未处理邮件：动作化、转移、存档
  4. 需要行动的带有星号，参考信息在存档中
  5. “备忘录”标签空了就达成Inbox Zero

这个方法的话，通过Slack、Zoom、1on1获得的信息全部汇总到邮件中，可以在1处进行管理。

此外，在远程工作中很难共享“隐性知识”，因此在整个团队中推进备忘录文化也很有效。 虽然也有引进Obsidian这样的知识库工具的团队，但首先要巩固个人的笔记习惯。 每天下班时，在1行也引入共享频道上发布“今天的学习”的习惯，整个团队的知识库自然会建立起来。 将个人备忘录转化为团队资产的机制是消除远程组织信息差距的关键。

积分：SimpleMemo专门用于“捕捉”，“整理”交给Gmail。 这种分离使远程工作者的信息管理变得最简单。

常见问题

为什么远程工作很难管理备忘录？

远程工作中信息流入渠道很多（Slack、Zoom、邮件、Teams等），所以容易分散笔记。 另外，由于不能像办公室那样在旁边的座位上轻松确认，所以笔记的准确性和完整性更加重要。

有高效记下Zoom会议笔记的诀窍吗？

会议前准备3个问题，在屏幕的侧面常驻备忘录应用程序。 不想全部写下来，而是把重点放在决定事项、行动项目、下次预定的3点上进行记录。 会议结束后，在30秒内向自己发送摘要是最有效的。

在家办公有保持工作和私人界限的笔记技巧吗？

早上的“开始备忘录”和傍晚的“结束备忘录”明确工作的开始和结束的方法很有效。 在开始的备忘录中写下今天的TODO，在结束的备忘录中写下完成报告和第二天的优先事项，然后用邮件发送给自己并划定界限。
