提高工作效率 笔记术 7选
为商务人士准备的实践指南

“虽然在记笔记，但工作却无法完成”。 那是因为记笔记的方法没有融入到工作流程中。 从会议准备到决定日志、跟进，解说与工作成果直接相关的记事术7。

TL;DR

彻底解说与工作效率化直接相关的记事术7选。 会议准备备忘录、决定日志、后续行动项目、项目进度备忘录等，在商务现场也能使用的实用笔记术。

从开始有意识地实践记事术开始，大约1年，最能体会到效果的是“会议后30秒记事”的习惯化。 通过SimpleMemo将决定事项和下一步行动立即发送给自己，每周评论的精度明显提高。

记事术1：会议前“3个问题”记事

1事先决定会议的成果会议效率化

很多商务人士“被动”地参加会议。 只要提前准备3个问题，会议的密度就会急剧变化。

会议前写的3个问题：

  1. 这个会议需要决定什么？ （目的明确化）
  2. 自己能提供的信息是什么？ （贡献的准备）
  3. 会议结束后自己应该采取什么行动？ （出口的假设）

这个3在会议的5分钟前写在备忘录上，用邮件发给自己。 会议中将集中精力填写这个3个问题的答案。

实践例：“Q2企划会议/决定：市场预算的分配/提供：过去的ROI数据/行动：批准后开始活动设计”

记事术2：会议后30秒记事

2会议结束后的30秒决定一切最重要的技术

会议结束后的30秒，是信息新鲜度最高的瞬间。 在这个30秒内只记下以下3点：

  1. 决定事项（决定了什么）
  2. 动作道具（谁・做什么・到什么时候）
  3. 下次的预定（下次会议是什么时候）

没有必要写完美的会议记录。 按住这个3点的话，会议结束后可以留下行动的信息。

实践例：“[Q2企划会议] 决定：市场预算比上年增加20% / @田中：LP改造方案到3/10 / @佐藤：广告创意3方案到3/12 / 下次：3/15 14:00”

笔记术3：决定日志（Decision Log）

3记录“为什么做出那个判断”判断的透明化

工作中最后悔的是“想不起来为什么当时做出那个判断”的场景。 决定日志不仅是记录重要判断的“结果”，也是记录“理由”和“替代方案”的方法。

决定日志的记录项目：

  • 日期：什么时候决定的
  • 决定内容：决定了什么
  • 理由：为什么做出那个选择
  • 拒绝的替代方案：还有什么选择
  • 相关人员：谁参与了
  • 评论日：什么时候回顾结果
实践例：“3/6 决定：将邮件发送工具从 SendGrid 迁移到 Resend / 理由：API 响应快 3 倍，成本降低 30% / 否决方案：Mailgun（价格不合适）、AWS SES（配置繁琐） / 相关人员：田中及工程团队 / 复盘：在 4/6 评估效果”

笔记术4：后续行动笔记

4减少“遗漏”的机制任务管理

工作的信任是通过“遵守约定”建立起来的。 后续行动备忘录是在1处管理所有承诺的方法。

后续备忘录的写法：

  • 以动词开始（“发送”“确认”“制作”“联系”）
  • 注明负责人（@记法）
  • 一定要输入期限
  • 完成后，取消星号（Outlook的话是标志）

发送邮件后，可以在Gmail的“星星”和Outlook的“标志”中列出未完成的动作。 工作任务管理的活用事例也请参考。

实践例：“TODO @自己: 1. 向客户发送报价（3/7）2. 向设计团队分享反馈（3/7）3. 下周的1on1议程制作（3/8）”

记事术5：1日5分的“进度总结”

5时刻把握项目的“现在”项目管理

多个项目在运行时，“那个项目，现在怎么样了？” 频繁发生。 每天下班前的5分钟写的“进度总结”解决了这个问题。

进度摘要模板：

  • Done（完成）：今天完成的事情
  • Doing（进行中）：目前正在进行的事情
  • Blocked（阻挡）：停止的、障碍
  • Next（下一个）：明天要做的事情

把这个用邮件发给自己的话，第二天早上就能马上确认“昨天做到什么程度”，开始冲刺结束。

实践例：“3/6 进度 / Done: LP原稿v2完成，SEO关键词调查 / Doing: 设计评论（等待佐藤） / Blocked: 等待服务器转移的批准 / Next: LP公开准备，广告文制作”

备忘录术6：1on1会议备忘录

6与上司、下属的对话成为资产人际关系

1on1有很多人没有记录会议内容，这是非常可惜的事情。 上司的反馈、下属的烦恼、事业的方向，如果不记录的话，就会从细枝末节开始忘记。

1on1备忘录的要点：

  • 直接写对方说的重要发言（“〇〇先生说~”）
  • 写下自己感受到的违和感、觉察
  • 约定的事情明文说明（双向）
  • 写下下次1on1要确认的事情

会议备忘录的活用事例页面介绍了1on1备忘录的模板。

实践例：“1on1 @田中部长 3/6 / 田中:“Q3致力于新事业的方针。 期待你担任领导角色”/ 注意到：虽然有压力，但有成长机会 / 承诺：下周之前新事业的研究3个 / 下次确认：研究结果的方向”

笔记术7：每周评论笔记

71周在15分盘点回顾

以备忘录的形式进行GTD的“每周评论”。 每周五下班前15分钟，或者周日晚上进行是最理想的。

每周回顾备忘录的模板：

  • 本周的成果 3个：具体取得了什么成就
  • 本周的学习 1个：最重要的觉悟
  • 未完成的任务：结转的东西（也写理由）
  • 下周最重要的任务 3个：有优先顺序
  • 想要改善的事情 1个：流程的改善点

积累这个每周的备忘录的话，每月、季度的回顾会轻松很多。 也可以直接用于评价面谈的准备。

实践例：“W10 评论 / 成果: 1. LP公开 2. 广告ROI 15%改善 3. 新客户提案完成 / 学习：早期反馈委托提高质量 / 未完成：服务器转移（等待批准） / 下周：1. 客户演示 2. Q2预算确定 3. 招聘面试/改善：将会议时间缩短到30分钟”

常见问题

工作笔记术中最有效的是什么？

最有效的是“会议后30秒备忘录”。 会议结束后，在30秒内写下决定事项和下一步行动，然后用邮件发送给自己。 仅凭这一点，会议的生产力就会大大提高。

有会议备忘录的诀窍吗？

会议前准备“3个问题”，会议中只专注于决定事项和行动项目做笔记。 诀窍是不要全部写下来，只记录以后与行动相关的信息。

通过备忘录工作效率能提高多少？

提高多少取决于工作内容，不能显示统一的数字。 容易感受到效果的是，把会议的决定事项和后续行动写下来，甚至做了回顾的机制。
