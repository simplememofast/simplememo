备忘录应用程序比较

SimpleMemo vs UpNote
应该选哪个

UpNote是想在应用程序内编辑、整理笔记，在多个终端上同步的人的候选人。 SimpleMemo，在想在自己的邮件或已经设置好的Obsidian上留下简短的记录时，可以考虑。 用同样的1件确认输入的入口、保存地址、取出方法后再选择吧。

SimpleMemo的费用和免费额度

UpNote也直接进入新笔记本

UpNote的移动版可以从列表下方的蓝色新笔记按钮写。 因为本文的1行是标题，所以不需要在另外的栏里输入标题。 在PC上用Cmd/Ctrl + N，从其他应用程序在Mac上用Cmd + Option + N，Windows/Linux用Ctrl + Alt + N打开新窗口。

不能以每次必须选择笔记本为前提来计算速度差。 从自己使用的入口开始写1件简短的备忘录，确认以后能不能找到。 如果想用收件箱处理的话，可以比较从SimpleMemo到的正文阅读。

UpNote官方：新笔记和标题

50笔记本，买断，确认解约后

免费版最大50笔记本。 附件、锁定、导入、PDF・Markdown的导出等请确认Premium的条件。 无论是购买月费还是Lifetime，都会优先考虑当地商店显示的金额。 没有直接从Windows/Linux购买的功能，在Mac・iOS・Android购买后，登录同一个UpNote账户进行反映。

即使解约月费也可以浏览现有的笔记，但是如果超过50件的话，就不能新建，部分导出功能也无法使用。 如果计划转移的话，在合同有效期间会以必要的形式尝试写出来。

UpNote官方：Premium和解约后的限制

Evernote转移，少量确认链接和附件

PC版可以导入Evernote的ENEX文件。 以原来的笔记本为单位划分ENEX，启用“Use file name as notebook”就可以进行分类。 分层化在导入后进行。 将标签转换为标签后，特殊文字可能会变成连字符。

Evernote内部链接没有转换为UpNote内的链接，打开原来的Evernote。 超过20MB的附件和超过300000字的笔记可能无法导入。 请确认颜色和布局，并留下原来的ENEX。 超过20000笔记或附加10GB的一次性导入，有1次50件的限制。

UpNote官方：ENEX导入和限制

将同步和可以恢复的副本分开考虑

UpNote的自动备份在Mac、Windows、Linux上保存在终端内。 默认为1天1次・最大50天分，可以从设置中确认间隔、保存地址、附加的处理。 以智能手机为中心使用时，在同步到PC后确认是否备份。 不编辑备份用文件夹的管理文件。

UpNote官方：自动备份

要转移到其他应用程序，将少量导出到Markdown或HTML等，实际打开正文、图像、链接。 拥有备份和在其他应用程序上可以重现相同的状态是不同的。 SimpleMemo的接收邮件也遵循邮件方的容量、保留设置、备份。

UpNote官方：导出格式和操作

UpNote，如果不登录的话，笔记会保留在终端内，使用同步的话也会保存在美国的Firebase服务器上。 请不要将通信、保存时的加密和应用程序锁定等同于运营者无法解密内容的E2EE。

UpNote官方：数据保存和隐私

从免费范围到正式过渡的5步骤

  1. 决定经常写的短笔记1件，从平时使用的终端和入口输入。
  2. 以第二天为目的进行搜索，补充正文确认保存地址。
  3. 打开必要的笔记后，在信号范围外读写，重新连接后确认其他终端的内容。
  4. 如果需要导入的话，请先确认Premium的功能和购买条件。 处于可用状态后，导入包括图像、附件、内部链接在内的少量内容，与原始数据进行比较。
  5. 以合同中可以使用的格式导出，确认文件和备份的保存位置后，判断正式转移。

如果在应用内继续写的话，单独尝试UpNote是出发点。 如果每天处理邮件的话，SimpleMemo也是候选人。 同时将接收邮件转移到UpNote时，需要另外复制或对应格式的导入，不一定已经设置了自动连接。

常见问题

UpNote现在的费用是多少？
官方网站介绍的是每月US$1.99，Lifetime是US$39.99。 因为地区和税不同，所以在日本购买时请确认应用程序内的最终金额。
超过免费版的50笔记本会怎么样？
增加新的笔记本需要Premium。 即使月度合同结束，也可以浏览现有的笔记本，但是如果超过50件的话，就不能新建，部分Premium功能也无法使用。
在新笔记本之前必须选择笔记本吗？
不是必须的。 可以从手机的新笔记按钮和PC的快捷键写。 因为1行是标题，所以不需要另外输入标题。
UpNote可以离线使用吗？
会读写。 登录后使用同步时，重新连接后变更会反映在其他终端上。 必要的笔记和附件请在移动前用实机打开确认。
笔记本锁是E2EE吗？
不。 UpNote说明了通信中和保存时的加密，但明确说明不支持E2EE。 应用程序和笔记的锁定，不会改变其区别。
Evernote的内部链接也可以移动吗？
UpNote内的链接没有转换，而是作为打开原来的Evernote的链接保留。 附加尺寸、长笔记、标签转换和格式也有限制，所以少量尝试后再转移。
致想在收件箱中处理备忘录的人
首先1件，写好后发送，确认收到的正文。 免费名额是每天3条。
