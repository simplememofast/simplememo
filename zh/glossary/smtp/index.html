SMTP/IMAP是指

SMTP（Simple Mail Transfer Protocol）是发送邮件的协议，IMAP（Internet Message Access Protocol）是接收、浏览邮件的协议。 SimpleMemo不直接使用这些协议，而是通过Cloudflare Workers + Resend API的中继方式发送备忘录，所以完全不需要SMTP设置。

定义

SMTP（Simple Mail Transfer Protocol）是1982年RFC 821标准化的邮件发送协议。 从邮件客户端到邮件服务器，或者在邮件服务器之间转发信息。 IMAP（Internet Message Access Protocol）是阅览、管理邮件服务器上的邮件的协议，邮件留在服务器上可以从多个设备访问。 与旧式的POP3不同，IMAP支持文件夹管理和部分下载。

SMTP vs IMAP vs POP3

SMTP（发送）
发送邮件的专用协议。 将信息转发到邮件客户端→发送服务器→接收服务器。 使用端口587（STARTTLS）或465（SSL/TLS）。 认证需要用户名和密码。
IMAP（接收、同步）
将邮件留在服务器上进行阅览的协议。 可以在iPhone、PC、平板电脑等多个设备上看到相同的邮件。 支持文件夹管理、搜索、标记。 是现在邮件阅览的主流。
POP3（下载型）
将邮件从服务器下载到设备的协议。 因为下载后会从服务器中删除，所以在其他设备上看不到。 现在正被IMAP取代。

SimpleMemo不需要SMTP设置的理由

从自己的邮件账户发送方式的应用程序，为了连接到该账户的SMTP服务器，可能需要设置SMTP服务器名称（例：smtp.gmail.com）、端口号（587）、应用程序密码等。 SimpleMemo不使用这种方式。 备忘录发送至Cloudflare Workers，通过Resend API以邮件形式发送。 用户设置的只有邮箱地址。 用6位数的确认码认证后，设置就完成了。

常见问题（SMTP/IMAP）

SMTP是什么？

是发送邮件的互联网标准协议。 从邮件客户端到邮件服务器，在服务器之间转发邮件。

SMTP和IMAP的区别是什么？

SMTP是“发送”，IMAP是“接收、阅览”的协议。 IMAP可以将邮件留在服务器上，在多个设备上浏览。

SimpleMemo为什么不需要SMTP设置？

因为采用了使用Cloudflare Workers + Resend API的中继方式，所以不会直接连接到用户的SMTP服务器。 只需输入邮箱地址和6位代码认证即可完成设置。
