什么是艾森哈瓦矩阵

艾森豪威尔矩阵（Eisenhower Matrix）是基于第34代美国总统德怀特·D·艾森豪威尔的决策法，任务优先级框架。 所有任务在“紧急度”和“重要度”的2轴上分类为4象限，不仅明确“做什么”，还明确“不做什么”这一点是最大的特点。

定义

艾森哈瓦矩阵是“紧急与否”和“重要与否”的2轴将任务分类为4象限的框架。 第1象限（紧急x重要）立即执行，第2象限（重要x非紧急）是日程，第3象限（紧急x非重要）委托，第4象限（非紧急x非重要）排除。 Stephen Covey在《7个习惯》中传播，至今仍是最实用的任务管理方法之一。

4象限的解说

Q1：紧急x重要→立即执行
截止日期前的项目，来自客户的紧急应对，健康上的问题。 不能推迟，现在应该马上应对的任务。
Q2：重要 x 非紧急 → 日程
战略立案、技能开发、人际关系构建、预防措施。 最应该投入时间的象限。 在这里花时间的人最有成效。
Q3：紧急 x 非重要 → 委托
他人的委托、部分会议、电话对应。 看似紧急但与自己的目标没有直接关系的任务。 尽可能委托给他人。
Q4：非紧急 x 非重要 → 排除
SNS的无目的浏览、八卦、过度的电视。 时间的浪费。 通过有意识地排除，将时间转向其他象限。

用SimpleMemo运用矩阵

发生任务后用SimpleMemo立即捕获，在备忘录的开头加上【Q1】〜【Q4】的象限编号。 收到邮件后，用Gmail的过滤器按象限自动对标签进行分类，收件箱会自动变成艾森霍瓦矩阵。 不是在捕捉的瞬间考虑分类，而是在之后冷静地做出判断也是优点。

常见问题（艾森豪瓦矩阵）

什么是艾森豪瓦矩阵？

将任务按“紧急度”和“重要度”的2轴分类为4象限的框架。 根据第34代美国总统艾森豪威尔的决策法。

最应该花费时间的象限是什么？

第2象限（重要但不紧急）。 战略立案、技能开发、预防措施等。 在这里投入时间的人最有成效，Q1的“灭火”也会减少。

SimpleMemo的运用方法是什么？

在备忘录的开头加上【Q1】~【Q4】的象限标签发送。 用Gmail过滤器自动标签分类的话，收件箱会变成矩阵。
