工作任务管理
备忘录→通过邮件解决

会议中的行动项目、突然的委托、截止日期——有没有想过“稍后再输入”而忘记这些的经历？ 如果是SimpleMemo的话，启动0.4秒（iPhone 16e・warm启动的实测）・一键发送，想到的瞬间就可以发送邮件。

常见的工作笔记问题

工作中想到“必须要做这个”的瞬间，你是怎么做的？ 写在笔记本上吗？ 贴在便条上吗？ 打开任务管理应用程序？——都需要“打开、输入、保存”的多个步骤，在会议中或移动中是不现实的。 结果，想着“以后再做”就忘了。

问题1：输入的步骤很多
打开任务应用程序，选择项目，输入标题保存——步骤很多，会停止会议的流程。
问题2:没有确认其他应用程序的习惯
任务应用程序必须有意识地打开才能确认。 结果，任务只是堆积起来，没有执行就被搁置了。
问题3：与邮件分离
很多商务人士在1天多次确认邮件。 如果用邮件和其他工具管理任务的话，就会发生确认遗漏。

解决方法：备忘录→通过邮件将收件箱添加到ToDo列表中

SimpleMemo以“将备忘录发送到邮件”的简单方法，将任务纳入现有的邮件工作流程中。 不需要养成新工具的习惯。 每天确认的邮件收件箱会直接变成ToDo列表。

使用方法步骤（5步骤）

  1. 启动应用程序 — 点击主页的图标。 0.4秒（iPhone 16e・暖启动的实际测量）进入可以输入的状态。 即使在会议中也能立即启动。
  2. 输入任务、行动项目 — 输入会议确定的行动项目、截止日期、负责人姓名。 例：“〇〇的资料在周五之前发给田中先生”
  3. 一键发送邮件 — 只需点击1次发送按钮，就可以发送到自己的邮箱地址。 在1行的开头写上“[TODO]”的话，它就会成为标题，所以也可以自动分配。
  4. 通过邮件管理任务 — 在收件箱中确认任务、完成处理。 可以直接整合到现有的邮件工作流程中。 不需要打开其他应用程序。
  5. 将已完成的任务存档 — 任务完成后将邮件存档或删除。 收件箱可以一直保持干净的状态。

常见问题

适合在会议中记笔记吗？

是的。 启动0.4秒（iPhone 16e・暖启动的实际测量）可以立即输入，所以不会停止会议的流程，可以快速记下动作项目。 因为一键发送会到达自己的邮件，所以会议后可以确认。

可以管理多个项目的任务吗？

是的。 因为1行就是邮件的标题，所以在1行的开头加上“[项目A]”“[项目B]”等，可以在邮件中进行过滤，按项目进行管理。

和任务应用程序的区别是什么？

专用任务应用程序必须打开应用程序才能确认，但SimpleMemo会发送邮件，所以每天使用的收件箱会自然而然地看到任务。 不需要增加工具的习惯化。

可以发送截止日期的提醒吗？

是的。“ 〇〇 截止日期：3/15”这样记下并发送邮件的话，可以结合邮件客户端的提醒功能加以利用。 如果是Gmail的话，可以通过“打盹”功能在指定日期重新显示。

可以和团队成员共享任务吗？

通过邮件收到备忘录后，只需将该邮件转发给团队成员即可共享。 因为收件人只有1个，所以不能同时发送到多个地址。
