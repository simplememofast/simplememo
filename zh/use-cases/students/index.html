没有这样的烦恼吗？

上课时觉得“这个很重要”的瞬间，打开笔记软件的时候错过了教授的话。 写在Slack上的想法被其他信息埋没了。 手写笔记忘在家里了——。 学生的笔记问题，比起“记录”，更集中于“可以立即记录”和“以后可以肯定地找到”。

比备忘录说话更快的教授
在启动笔记应用程序期间，重要的补充已经结束了。 捕捉的速度是生命。
分散的备忘录，迷路的信息
课堂笔记，LINE，Notion，手写和多个分散。“ 那个纸条在哪里？” 考试前频繁发生。
截止日期提醒遗漏
虽然口头上说“下周一之前报告”，但打开应用程序后，接下来的说明就开始了。

SimpleMemo解决学生笔记问题的理由

SimpleMemo的核心是“启动后可以立即输入的状态”和“一键发送到收件箱”的2点。 因为备忘录是以邮件形式发送的，所以课后在PC上打开的话，所有的截图都会按时间顺序排列。 Notion和电子表格的整理也可以按照自己的节奏进行。

面向学生的4步骤活用法

  1. 上课中：立即捕捉重要要点 — 启动应用程序（0.4秒、iPhone 16e・warm启动的实测），用短文记下教授的发言和板书的精华。“ ◯◯的定义：~~”“下周一提交报告”等。
  2. 一键发送到自己的邮件 — 只需点击发送按钮。 应用程序的画面被清除，回到可以马上写下一个备忘录的状态。
  3. 课后通过邮件确认、复习内容 — 下课后在PC上打开收件箱。 发送的备忘录按时间顺序列出。 在这里把重要度高的东西放在星星上。
  4. 考试前整理成总结笔记 — 在邮件搜索中搜索科目标签（例：“【统计学】”），将考试范围的笔记汇总起来，粘贴到笔记软件或Google Docs中整理。

真实的场景例子

场景 1 — 大学讲座
统计学课上，教授说“中心极限定理在n=30以上可以近似正态分布”。 没有时间打开笔记本。 启动SimpleMemo：
【统计学】中心极限定理n≥30正态分布近似OK ← 考试频繁出现
点击发送按钮。 几秒钟就结束了。 因为收件箱里收到了邮件，所以回家后对照课本加深理解。
场景 2 — 作业・截止日期提醒
英语老师说“下次上课（周四）之前提交500字的论文”。 没有时间打开日历。 即时备忘录：
【英语】周四之前提交500单词随笔 ← 不要忘记
发送后，将收件箱中的邮件作为提醒设置打盹。 之后可以添加到日历上。
场景 3 — 小组研究的调整
在图书馆的小组会议中，决定“下次的角色分担：A是文献调查，B是数据整理”。 想全员共享：
【毕业论文G】角色：A→文献调查、B→数据整理、C→发表资料。 下次：下周二15时 图书馆3F
如果将群组的邮件列表设置为收件人，备忘录就会到达所有成员（列表设置为接受来自成员以外的邮件的情况。 收件人是1，所以不再是自己的地址了）。 可以代替会议记录使用。

常见问题

上课时用手机记笔记不显眼吗？

从应用程序的启动到发送只需要几秒钟，所以不需要长时间操作智能手机。 因为只是写笔记然后点击，所以比看LINE更自然地使用。

离线环境（地下或信号较弱的地方）也可以使用吗？

是的。 离线时用Outbox架构对备忘录进行AES-GCM加密保存，在信号恢复的时机自动发送。 图书馆的地下楼层也放心。

可以分开管理多个科目的笔记吗？

如果养成在备忘录的开头写“【数学】”“【英语】”等科目标签的习惯，通过邮件的搜索功能可以立即按科目进行筛选。 也可以用Gmail的过滤器自动分类文件夹和标签。

如何通过小组学习共享备忘录？

组的邮件列表和Google组的地址设置为收件人后，备忘录就会发送给全体成员。 因为备忘录会从noreply@mail.simplememofast.com收到，所以列表必须设置为接受来自成员以外的邮件（在Google组中由“可以投稿的用户”的设置决定）。 收件人是1，所以不再是自己的地址，需要用那个地址接收收件人的验证码。 也可以代替会议中的会议记录。

可以继续免费使用吗？

是的。 Free套餐的话每天最多3条，没有使用期限限制，可以免费使用。 如果只关注课程的重要要点的话，每天3条就足够了。 Premium套餐（每月500日元）可以无限制发送。
