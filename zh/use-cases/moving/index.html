面向搬家准备的活用指南

搬家准备备忘录
待办事项清单・手续・打包

迁出申报的期限、搬家公司的报价、网络线路的转移手续、纸箱里的东西清单。 搬家的任务非常庞大，如果不在想到的瞬间记录的话，很容易漏掉。 SimpleMemo的话，一键记录在邮件中。 在搬家完成之前，可以减少要做的事情的遗漏。

没有这样的烦恼吗？

搬家是人生中任务最多的事件之一。 役所的手续、生命线的转移、不用品的处理、新家的准备——即使每次想到都想记下来，在工作或外出时也不能马上记录下来。 结果会出现手续遗漏或遗忘物品的情况。

任务太多无法掌握
迁出申报、迁入申报、电力、煤气、自来水、网络、邮件转发、钥匙交接......有100以上的任务。
想到的瞬间无法记录
上班途中虽然觉得“要量一下窗帘的尺寸”，但回家的时候却忘了。
搬家当天找不到行李
“充电器放在哪个箱子里？”“ 餐具是哪个纸箱？” 在新家左右逢源。

SimpleMemo改变搬家准备的理由

SimpleMemo的话，在想“啊，必须要做那个”的瞬间，马上用邮件记录下来。 只需在周末用电脑列出积累的备忘录邮件，整理清单即可。 不需要新引进任务管理软件。 搬家完成后也会在邮件中留下记录，下次搬家时也可以使用。

搬家准备4步骤活用法

  1. 一想到就马上记下 — 上下班中、工作中、睡觉前——一想到“啊，电气合同变更”就立即发送记下。“【 搬家】电力合同变更 ← 2周前”。
  2. 商家、报价的比较记录 — 给搬家公司打电话后马上记下。“【 商家A】45,000日元 纸箱20附赠3/20上午OK”。 3家公司并排比较。
  3. 打包时：记录纸箱里的东西 — 在箱子上摇了编号，把里面的东西记下来发送。“ 盒子7：客厅 书20册，遥控器，充电器类”。 在新家搜索一下。
  4. 搬家后：检查剩余任务 — 在“搬家”中搜索邮件，已完成。 确认未完成的任务（迁入申报、驾照地址变更等）。

真实的场景例子

场景 1 — 任务的随时捕获
在通勤电车上突然想起来了。 马上记下：
【搬家/手续】迁出申报（3月15日为止）、邮政转发申报（网上可、国民健康保险的转换、银行地址变更、信用卡地址变更 ← 全部做
场景 2 — 商家报价比较
3公司的报价电话结束。 立即记录：
【搬家/商家C】38,000日元。 条件：仅限工作日，不可指定时间。 纸箱15个+胶带2个。 拆下空调另付8,000日元。 ←虽然是最便宜的，但是不能指定时间是瓶颈
场景 3 — 打包内容列表
每次装完纸箱的笔记：
【搬家/箱子12】卧室：冬装（外套2，毛衣5件，围巾）。 不马上使用→在衣柜里面OK

常见问题

如何管理搬家的庞大任务？

想到的任务当场发送备忘录。 因为会累积到邮件中，所以以后可以在PC上列出并整理成检查清单。

可以用来管理政府机关的手续清单吗？

是的。“【 役所】迁出申报 3月15日”一样带有标签的备忘录。“ 在“政府机关”中搜索的话，会显示手续一览表。

也可以用于搬家公司的报价比较吗？

是的。 报价电话结束后马上记下。 可以把3公司的邮件排列起来进行比较。

可以作为打包中的检查清单使用吗？

在纸箱上打号码，把里面的东西发送。 在搬家的地方搜索“箱子”的话，一眼就能知道哪个箱子里装了什么。

搬家后数据也会保留吗？

是的。 发送的备忘录，除非删除，否则会以邮件的形式保留。 下次搬家的时候也可以参考。
