会议的动作项目
当场发送邮件

有没有在会议中想着“以后再整理”就忘记确定的动作项目的经历？ 如果是SimpleMemo的话，启动0.4秒（iPhone 16e・warm启动的实测）・一键发送，可以在不停止会议流程的情况下将动作项目记录在邮件中。

会议备忘录的理想工作流程
会议中：输入决定事项 → 一键发送 → 通过邮件接收 → 会议后跟进 → 完成后存档

会议备忘录的3大问题

问题1：后面看会议记录很麻烦
即使仔细地整理在会议记录工具中，后面打开确认也很麻烦。 结果，在行动项目没有执行的情况下迎来了下一个会议。
问题2：会议中很难操作备忘录工具
Notion和Google文档适合在PC上操作，但在智能手机上快速记下的话启动需要时间。 切断了会议的对话。
问题3：任务和邮件分离
即使动作项目进入任务工具，在日常邮件检查中也看不到。 收到邮件的话，自然会映入眼帘。

会议备忘录和会议记录是两回事 — 本页面处理的是“会议中的30秒”

会议记录是会议结束后将“决定的事情、要做的事情、结转”结构化共享的文件。 这里所说的会议备忘录是会议中留在自己手边的1行的截图，目的只是“不漏掉自己的行动”。 如果用1个工具同时做这个2的话，会议中的输入会变得很重，结果都是半途而废。

会议记录本身的写法和可以复制粘贴的样式总结在会议备忘录·议事备忘录模板5选中。 这个页面只处理会议中从打开应用程序到发送为止的30秒。

3行格式“谁・什么・什么时候”

会议中要写的量，这个3行就足够了。 写作需要10秒以上的形式，在会议中不会持续下去。

型
[会议名称]谁→什么→到什么时候
例
[定例 9/2] 田中 → 重新制作报价单 → 9/5（周五） 自己 → 向对方发送日程候选人 → 今天之内
  • 标题为会议名称后，可以在收件箱中搜索会议单位。
  • 自己的动作写成“自己”。 以他人的动作稍后传送为前提，将负责人名放在首位。
  • 期限到星期写。“ 下周”的话，回到收件箱的时候就动不了了。
  • 犹豫的话1件1通。 换行合并多个也可以，但如果要转发的话，分开比较方便。

会议种类的使用方法

1on1
不总结对方的话，直接用1行留下。“ 只把“下次之前要确认什么”作为自己的行动，不写评价和感想。 会议结束后，收件箱的1on1邮件是每个对方的履历。
常规・每周评论
行动分散到多个负责人的会议。 如果给每个负责人发送1，会议结束后可以直接转发给每个负责人，不需要说“请看会议记录”。
客户、商谈
只写对方的委托事项和期限。 谈话内容和温度感在会议结束后立即单独总结比较准确。 商谈固有的写法商谈备忘录技巧中进行解说。
在线会议（Zoom・Teams）
PC保持会议画面不变，用智能手机发送。 即使在画面共享中，对方也看不到备忘录的操作，也不需要从会议软件切换到备忘录软件。

会议后 — 从收件箱到哪里留下

会议期间发送的备忘录已经送到了收件箱，所以会议结束后要做的只有“将自己的动作作为任务”“转发他人的动作”的2。 如果使用Obsidian的话，只要通过邮件发送就会在保管库中追加，所以之后可以通过会议名称进行搜索。 这个使用方法的要点是，在会议中不用考虑整理什么，在哪里。

使用方法步骤（5步骤）

  1. 会议前准备应用程序 — 会议开始前打开SimpleMemo。 在1行写上“[会议名称]”的话，它就会成为标题，以后更容易搜索邮件。
  2. 决定行动项目后立即输入 — 会议中担当、期限、内容确定的瞬间输入应用程序。“ 田中先生→制作资料→到周五为止”等简洁的形式输入。
  3. 一键发送邮件 — 输入后一键发送。 一边继续会议，一边每次出现动作项目时都会重复。 发送只需点击一下即可完成。
  4. 会议结束后用邮件跟进 — 会议结束后确认收件箱。 在列表中查看发送的行动项目，通过邮件委托负责人，在日历上设定期限。
  5. 与团队共享、转发 — 只需转发收到的邮件，就可以与团队成员共享行动项目。 转写到会议记录工具也很简单。

客户提案MTG 行动 →日程详情 下周一之前发送 →负责人：自己
场景 2
公司内部的每周审查会议
每周评论中出现了多个动作项目。 按成员发送，会议后转发给各成员。“ 没有必要说“请看会议记录”，因为行动项目会直接发送到各自的邮件中，所以执行率大大提高。

常见问题

在会议中使用也不会失礼吗？

启动、输入、发送只需几秒钟，所以不会停止会议的流程。 只需操作智能手机几秒钟，就可以一边专注于会议一边记录行动项目。

可以把多个动作道具一起发送吗？

是的。 用换行分隔符将多个动作项目汇总输入，可以一次性发送。 或者也可以一个一个地发送，分成多个邮件。

与会议记录工具的区别是什么？

SimpleMemo最适合快速捕捉动作道具。 整个会议的会议记录稍后整理在Notion或专用工具中，只留下动作项目即时邮件的组合很有效。

在线会议（Zoom等）也可以使用吗？

是的。 可以在PC上使用Zoom的同时，用智能手机操作SimpleMemo。 PC画面保持会议状态，可以用智能手机记下并发送。

通过邮件管理动作项目的优点是什么？

因为会到达每天使用的收件箱，所以即使不自觉也能自然而然地看到动作项目。“ 不需要打开专用工具”的习惯化，可以直接纳入现有的工作流程中。

会议记录有什么不同？

会议记录是会议后将决定事项、任务、结转结构化共享的文件。 这里所说的会议备忘录是会议中用1行留下自己的动作的截图，共享和结构化会推迟。 会议记录的写法在“会议备忘录、会议备忘录模板5选”中进行了解说。

会议中写的最小格式是什么？

“谁→什么→到什么时候”的3行。 如果把主题作为会议名称的话，可以在收件箱中按会议进行搜索，如果把期限写到星期的话，回到收件箱时就可以直接操作了。

1on1的备忘录应该怎么做？

将对方的话原封不动地留在1行，只将自己在下次之前确认的事情作为行动。 不写评价和感想，使用收件箱的1on1邮件作为每个对方的履历。
