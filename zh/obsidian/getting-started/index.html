Obsidian的下载和安装

首先从官方网站下载您使用的OS用的Obsidian。 下面总结了Windows、Mac的导入步骤。 启动后选择日语，制作保管库，进入第一个笔记本。 之后的实画面6张是2026年8月12日操作Linux版1.13.6的记录。

官方下载地址和OS不同的步骤

打开Obsidian官方下载页面 → 选择您使用的OS。

  • Windows：从“Windows”的“Universal”获取安装程序，打开并按照屏幕上的指示进行安装。
  • Mac：获取“macOS”的“Universal”并打开，将Obsidian拖到“Applications”文件夹。
  • Linux：在官方页面选择分发形式。 每种形式的操作请参考官方安装步骤。 本报道的实际画面是AppImage版。
  • iPhone・iPad / Android：可以从官方下载页面内的App Store / Google Play的链接获得。 以下的实画面指南以桌面版为对象。

上面的指南是基于2026年9月22日确认的官方资料。 Windows、Mac、移动版不是这次实机验证的记录。

安装好后日语设置和首次启动。 如果已经有笔记本的文件夹的话，可以确认打开现有保管库的步骤。

Obsidian怎么开始好呢？

从官方网站免费安装自己的OS用Obsidian，在首次启动画面中制作1个保管库（Vault），就可以当场开始写笔记了。 不需要注册账号。 在实机验证中，从安装到显示第一个笔记、链接、图表视图不到15分钟，在此期间一次也没有要求输入邮箱地址。

以下，通过这个验证拍摄的实画面截图，按照1一步一步地遵循相同的步骤。

开始之前：是新建还是打开现有的保管库

第一次使用的话，按照接下来的步骤可以制作新的保管库。 如果有现有的Markdown文件夹，在保管库的管理画面中选择“作为保管库打开文件夹”，指定该文件夹。 如果在保管库中设置另一个保管库的话，链接的处理会出现问题，所以不要嵌套。

保存地址，稍后在文件管理画面中选择可以打开的地方，保留文件夹名和位置。 如果想在其他终端上使用同样的保管库，请先确认同步方法和对应终端。 仅仅在本地制作备忘录和设置同步是不同的工作。

这个补充和下面的保存、复印确认，是基于2026年9月9日确认的保管库的官方管理指南等的指南。 刊登的实画面是2026年8月12日的Linux版1.13.6的记录，与现在的画面细节可能有所不同。

Step 1: 安装 — 对应OS和分发形式

Obsidian可以从官方网站的下载页面免费获得。 2026年8月12日直接确认了官方发布（v1.13.6）的分发文件，提供了以下格式。

操作系统 分发形式（在v1.13.6上确认） 本报道的验证
Windows 安装器（.exe） 只确认分发的存在（执行未验证）
macOS 磁盘映像（.dmg） 只确认分发的存在（执行未验证）
Linux AppImage（x64/arm64）・.deb・.tar.gz 实际安装、启动AppImage（本报道的全部截图）
iOS/安卓 App Store / Google Play的官方应用程序 未验证（仅官方信息）

※ 分发形式是当天确认官方GitHub发布（obsidianmd/obsidian-releases v1.13.6）的分发文件的实测。 下载后，Windows运行.exe，Mac打开.dmg，将应用程序拖到Applications，按照OS标准步骤进行安装。

Step 2: 首次启动 — 选择日语，进入制作保管库的画面

第一次启动时，不是笔记画面而是决定“保管库（Vault）怎么办”的画面。 虽然有很多人在这里感到困惑，但要做的就是1——按下“新建保管库”的创建。 在画面下方的语言菜单中选择日语，整个UI都会变成日语（本报道的验证也全部是日语UI）。 也有登录按钮，这是付费官方同步（Obsidian Sync）用的，开始不需要账号。

Step 3: 制作保管库（Vault） — 只需决定名字和地点

决定的只有名称和位置（制作地点）的2。 验证中名称为“备忘录”，地点为主页内的Vaults文件夹。 名称可以直接使用日语。 这里制作的保管库的实体是在指定的地方制作的普通文件夹——这件事之后，打开文件夹的内容，用实物进行确认。

按下“创建”，在打开日语的“欢迎”笔记本的状态下，保管库就启动了。 右边已经能看到图表视图了。

保管库的实体只是文件夹

制作后用文件管理器（终端）打开保管库文件夹，里面只有设置用的隐藏文件夹.obsidian和“ようこそ.md”的2个。 笔记的正文是.md文件，Obsidian以外的文本编辑器也可以阅读。 另一方面，应用程序为了同步状态和元数据也使用IndexedDB。 请区分本文的保存形式和应用程序内部的保存处理。 官方数据保存说明。 

# 作成直後の保管庫の中身（実測・2026-08-12）
Vaults/メモ/
├─ .obsidian/     ← 設定フォルダ（app.json, appearance.json など5ファイル）
└─ ようこそ.md    ← 最初から入っている案内ノート（普通のMarkdown）

Step 4: 写第一个笔记 — Ctrl+N（Mac是⌘N）

Ctrl+N（Mac是⌘N）制作了新的笔记，在标题中输入“第一次的笔记”，写了正文。 用- 开头的行会自动变成项目符号，所谓的Markdown记法可以直接使用，即使不记得记法，只要写普通的文章就没问题。

没有保存按钮。 写的内容会自动保存在.md文件中。 实际上，用文本编辑器打开这个笔记的话，里面是这样的。 是画面上看到的Markdown。 

# はじめてのノート.md の実際の中身（テキストエディタで開いた実物）

今日からObsidianを使い始めた。

このノートは普通のMarkdownファイルとして保存されている。

- 覚えたいこと
- 思いついたこと
- あとで調べたいこと

をここに書いていく。

Step 5: 链接 — [[ ]]是Obsidian的核心

在笔记本中输入[[，选择链接的候选人就会出现在现场。 这是Obsidian的最大特点，链接的笔记还不存在也没关系。 在验证中，还没有的“购物清单”这个名字写成了[[買い物リスト]]。 候选者会显示“找不到匹配的”，这样就正常了。

一边按Ctrl一边点击写的链接（Mac是⌘+点击），在那一瞬间“買い物リスト.md”被打开了。 写下内容后，在右侧的图表视图中，“第一次笔记→购物清单”的连接以线的形式出现，画面下方是“1 反向链接”——也就是说“这个笔记是从第一次笔记开始链接的”的相反方向信息也被自动记录下来。

到此为止学到的东西

1保管库=只是制作文件夹 2笔记本=只是写Markdown文件 3用[[リンク]]连接笔记本（先贴，后制作）。 Obsidian的入门用这个3就完成了。 标签、插件、同步等都是在这个基础上需要后添加的，不需要在第一天设置。

确认第一个笔记本是否处于可用状态，5点

写好正文后，进行下一次确认后，明天也可以从同一个地方继续。 这是读者在自己的环境中尝试的检查清单。

  1. 名字：“第一次的笔记本”等，取个容易找到的名字。
  2. 重新显示：打开另一个笔记本后返回，确认是否还有写的一句话。
  3. 实际文件：在保管库文件夹内找到对应的.md，用文本编辑器打开副本阅读正文。
  4. 链接：打开创建的链接，确认是否移动到预期的笔记。
  5. 重启：关闭应用程序重新打开，确认是否能找到同一个保管库和笔记本。

在应用程序上找不到备忘录时，首先确认当前开放的保管库的名称和位置。 如果只是打开另一个空的保管库的话，可以通过打开原来的文件夹继续。 查询地点的方法请参考保管库的实体和保存地点。

如果图表上没有线，先确认链接是否打开，查看图表的显示范围和过滤器。 没有必要为了出线而增加插件。 比起画面的外观，首先确认打开必要的笔记。

与同步分开，测试是否可以从复制读取

同步是将变更反映到其他终端的机制，也有误删的情况。 Obsidian官方的备份指南建议使用与同期不同的副本。 不仅要恢复笔记，还想恢复附件和保管库设置的话，请确认包括.obsidian在内的文件夹内容。

  1. 编辑完毕，将保存的保管库文件夹复制到其他备份地址。
  2. 从副本中取出必要的笔记和附件到验证用的其他文件夹。 不覆盖原来的保管库。
  3. 用文本编辑器或图像查看器打开，确认是否可以阅读正文和必要的附件。

即使复制了1次，之后的更新部分也不包括在内。 选择适合自己使用频率的备份方法。 .obsidian是包含设置的隐藏文件夹，请不要断定为不需要的文件而删除。

常见问题

Obsidian在哪里可以下载？
官方网站（黑曜石.md/下载）可以免费下载。 2026年8月12日确认时Windows用安装器（.exe）、macOS用磁盘映像（.dmg）、Linux用AppImage/.deb/.tar.gz，正在分发面向iOS/Android的官方应用程序，本报道实际下载、安装并验证了Linux版AppImage。
Obsidian可以免费使用吗？
应用程序本体个人使用、商业使用都是免费的。 收费的只有官方同期的Obsidian Sync（Standard 月4美元・年付）和公开服务的Obsidian Publish等附加服务。 这篇报道的验证（安装~笔记制作~链接~图表视图）也全部在免费范围内完成。
需要注册账号吗？
不需要。 在2026年8月12日的实机验证中，从安装到保管库的制作、笔记的制作、链接、图表视图的显示，一次也没有要求输入邮箱地址和账户注册。 只有在使用付费官方同步（Obsidian Sync）等情况下才需要账户。
可以用日语吗？
可以使用。 在首次启动画面的语言菜单中可以选择日语，菜单和设置也会显示日语。 这篇报道的验证（Obsidian 1.13.6）也全部用日语UI进行。 确认保管库名和笔记本名称也可以像“备忘录”、“第一次的笔记本”这样的日语原样使用。
保管库（Vault）是什么？
是保存笔记的文件夹。 实体是普通的文件夹，通过验证创建之后的保管库的内容是设置用的.obsidian文件夹和“ようこそ.md”的2。 笔记本都是普通的Markdown文件（.md），所以即使不使用Obsidian也可以用文本编辑器打开。
Windows和Mac也是同样的步骤吗？
官方发布Windows用安装器（.exe）和macOS用磁盘映像（.dmg）在2026年8月12日确认有（Linux用是AppImage・deb・tar.gz）。 本报道的截图是Linux版的，虽然没有验证Windows版、Mac版的画面，但是安装后从制作保管库开始的流程是同一个Obsidian应用程序的操作。
只用iPhone就可以开始吗？
Obsidian有iOS版应用程序，可以从App Store免费获得（本报道中没有验证iOS版的动作）。 在iPhone中想到的1行留在Obsidian的方法在每日笔记中补充的方法和从iPhone发送到Obsidian的方法6选中详细解说。
可以使用现有的Markdown文件夹吗？
在保管库的管理画面中选择“作为保管库打开文件夹”，可以指定现有的文件夹。 避免在另一个保管库内部建造新的保管库，请确认打开的地方和笔记本的内容。
使用Obsidian Sync不需要备份吗？
同步和备份是分开的。 因为错误删除和覆盖可能会反映在同步对象上，所以请准备另外的副本，确认是否打开必要的笔记和附件。
验证环境和验证范围

验证日期：2026年8月12日 / 对象：Obsidian 1.13.6（官方AppImage・日语UI）/ 环境：Linux桌面（Ubuntu 24.04）。 刊登的截图是在上述环境下安装~制作保管库~制作笔记~链接~实际操作图表视图后拍摄的。 分发形式（.exe/.dmg/AppImage/deb/tar.gz）是当天直接确认官方GitHub发布的实测。 Windows版・macOS版・iOS版的执行没有验证（关于它们的描述是基于官方分发物・官方信息的确认）。 规格、费用可能会发生变化，请在官方网站上确认最新信息。
