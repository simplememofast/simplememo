Dataview是做什么的插件？

是能够像数据库一样搜索保管库（Vault）的插件。 写在笔记的frontmatter和内联字段的元数据，可以用DQL・内联式・DataviewJS・内联JS式的4种书写方法处理。 DQL的输出格式是LIST・TABLE・TASK・CALENDAR，与DataviewJS不相同的分类。 官方下载数数据（2026年8月22日获取）中4805635件，3位居第（注册表的注册总数是6,840个，但排名是与此不同的文件下载数数据中的排名）。

4个查询模式 — 来自官方README的样本

官方README区分了DQL、内联式、DataviewJS、内联JS式4的写法。 DQL内的输出格式是LIST（列表）、TABLE（表）、TASK（任务）、CALENDAR（日期日历）。 下面的README例子这次也没有在实机上执行。

1. DQL（数据视图查询语言）

类似于SQL的专用记法。 适合基本用途。 

```dataview
TABLE file.name AS "File", rating AS "Rating" FROM #book
```
2. 内联式

嵌入正文中，通过预览进行评价。 

We are on page `= this.file.name`.
3。 数据视图JS

可以充分利用JavaScript API，最强大的模式。 

```dataviewjs
dv.taskList(dv.pages().file.tasks.where(t => !t.completed));
```
4. 内联JS式

内联式JavaScript版。 可以当场执行任意的JS。 

This page was last modified at `$= dv.current().file.mtime`.

数据的输入方是2种。 笔记开头的YAML frontmatter（用---包围）或正文中写フィールド名:: 値的内联字段，两者都是Dataview读取并作为查询的对象。 从输入UI和保存YAML连接实际查询的例子，可以通过属性变更，Dataview列表变更的实例进行确认。 

---
alias: "document"
last-reviewed: 2021-08-17
thoughts:
  rating: 8
  reviewable: false
---
Basic Field:: Value
**Bold Field**:: Nice!
You can also write [field:: inline fields]; multiple [field2:: on the same line].

关于DataviewJS安全的注意事项

来自官方README

DataviewJS功能强大，与其他Obsidian插件具有相同的权限。 也就是说，也可以改写、制作、删除文件，也可以进行网络通信。 官方推荐使用自己编写的代码或理解内容、可靠的分发来源的脚本。 另一方面，普通的Dataview查询（DQL）是沙盒化的，不能对存储库进行更改（因此能做的事情有限）。

在写查询之前，首先决定留下1行的地方

Dataview搜索、统计保管库中的笔记和元数据。 从SimpleMemo留下输入的备忘录时，打开连接，设置可以访问的文件夹和保存地址，确认写入测试。 可以选择日期笔记或固定的Inbox。 请分别确认邮件的到达和笔记的保存，与自动生成Dataview用的字段的功能区分开来。

常见问题

Dataview是做什么的插件？
是能够像数据库一样搜索保管库（Vault）的插件。 笔记的frontmatter和内联字段中写的元数据，可以用DQL、内联式、DataviewJS、内联JS式4的写法来处理。 DQL的输出格式是LIST・TABLE・TASK・CALENDAR，与DataviewJS不相同的分类。
Dataview用了多久？
Obsidian官方下载数数据在2026年8月22日直接获取，4805635件，其中数据中3位（1位Excalidraw・2位Templater）。 另外，“注册插件6,840个”是注册表一览的件数，与计算排名的下载数数据是分开的文件。
Dataview现在还在开发吗？
仅凭本页2026年8月22日的统计・版的获取记录，无法判断目前的开发情况。 统计的更新日期和时间与代码的更新日期不同。 请确认官方发布和变更记录，使用Obsidian的版本进行尝试。 在这次的更正中，没有安装现行版来确认动作。
Dataview的基本写法是什么？
在笔记的frontmatter（YAML）或正文中以“字段名::值”的形式书写的内联字段添加元数据。 在那上面dataview在代码块上写显示形式和条件。 例如，LIST・TABLE可以显示笔记，TASK可以显示笔记内的任务。
DataviewJS可以安全使用吗？
根据官方README，DataviewJS与其他Obsidian插件的权限相同，因此可以改写、删除文件和进行网络通信。 建议只使用自己编写的代码或可靠的分发来源的脚本。 普通的DQL查询是沙盒化的，不能写入保管库。
