提高工作效率

提高工作效率 筆記術 7選
為商務人士準備的實踐指南

“雖然在記筆記，但工作卻無法完成”。 那是因為記筆記的方法沒有融入到工作流程中。 從會議準備到決定日誌、跟進，解說與工作成果直接相關的記事術7。

作者: AI ATAKA · 公開日: 2026年03月06日

本頁內容

TL;DR

徹底解說與工作效率化直接相關的記事術7選。 會議準備備忘錄、決定日誌、後續行動專案、專案進度備忘錄等，在商務現場也能使用的實用筆記術。

從開始有意識地實踐記事術開始，大約1年，最能體會到效果的是“會議後30秒記事”的習慣化。 透過SimpleMemo將決定事項和下一步行動立即傳送給自己，每週評論的精度明顯提高。

記事術1：會議前“3個問題”記事

1事先決定會議的成果會議效率化

很多商務人士“被動”地參加會議。 只要提前準備3個問題，會議的密度就會急劇變化。

會議前寫的3個問題：

  1. 這個會議需要決定什麼？ （目的明確化）
  2. 自己能提供的資訊是什麼？ （貢獻的準備）
  3. 會議結束後自己應該採取什麼行動？ （出口的假設）

這個3在會議的5分鐘前寫在備忘錄上，用郵件發給自己。 會議中將集中精力填寫這個3個問題的答案。

實踐例：“Q2企劃會議/決定：市場預算的分配/提供：過去的ROI資料/行動：批准後開始活動設計”

記事術2：會議後30秒記事

2會議結束後的30秒決定一切最重要的技術

會議結束後的30秒，是資訊新鮮度最高的瞬間。 在這個30秒內只記下以下3點：

  1. 決定事項（決定了什麼）
  2. 動作道具（誰・做什麼・到什麼時候）
  3. 下次的預定（下次會議是什麼時候）

沒有必要寫完美的會議記錄。 按住這個3點的話，會議結束後可以留下行動的資訊。

實踐例：“[Q2企劃會議] 決定：市場預算比上年增加20% / @田中：LP改造方案到3/10 / @佐藤：廣告創意3方案到3/12 / 下次：3/15 14:00”

筆記術3：決定日誌（Decision Log）

3記錄“為什麼做出那個判斷”判斷的透明化

工作中最後悔的是“想不起來為什麼當時做出那個判斷”的場景。 決定日誌不僅是記錄重要判斷的“結果”，也是記錄“理由”和“替代方案”的方法。

決定日誌的記錄專案：

  • 日期：什麼時候決定的
  • 決定內容：決定了什麼
  • 理由：為什麼做出那個選擇
  • 拒絕的替代方案：還有什麼選擇
  • 相關人員：誰參與了
  • 評論日：什麼時候回顧結果
實踐例：“3/6 決定：將郵件傳送工具從 SendGrid 遷移到 Resend / 理由：API 響應快 3 倍，成本降低 30% / 否決方案：Mailgun（價格不合適）、AWS SES（配置繁瑣） / 相關人員：田中及工程團隊 / 覆盤：在 4/6 評估效果”

筆記術4：後續行動筆記

4減少“遺漏”的機制任務管理

工作的信任是透過“遵守約定”建立起來的。 後續行動備忘錄是在1處管理所有承諾的方法。

後續備忘錄的寫法：

  • 以動詞開始（“傳送”“確認”“製作”“聯絡”）
  • 註明負責人（@記法）
  • 一定要輸入期限
  • 完成後，取消星號（Outlook的話是標誌）

傳送郵件後，可以在Gmail的“星星”和Outlook的“標誌”中列出未完成的動作。 工作任務管理的活用事例也請參考。

實踐例：“TODO @自己: 1. 向客戶傳送報價（3/7）2. 向設計團隊分享反饋（3/7）3. 下週的1on1議程製作（3/8）”

記事術5：1日5分的“進度總結”

5時刻把握專案的“現在”專案管理

多個專案在執行時，“那個專案，現在怎麼樣了？” 頻繁發生。 每天下班前的5分鐘寫的“進度總結”解決了這個問題。

進度摘要模板：

  • Done（完成）：今天完成的事情
  • Doing（進行中）：目前正在進行的事情
  • Blocked（阻擋）：停止的、障礙
  • Next（下一個）：明天要做的事情

把這個用郵件發給自己的話，第二天早上就能馬上確認“昨天做到什麼程度”，開始衝刺結束。

實踐例：“3/6 進度 / Done: LP原稿v2完成，SEO關鍵詞調查 / Doing: 設計評論（等待佐藤） / Blocked: 等待伺服器轉移的批准 / Next: LP公開準備，廣告文製作”

備忘錄術6：1on1會議備忘錄

6與上司、下屬的對話成為資產人際關係

1on1有很多人沒有記錄會議內容，這是非常可惜的事情。 上司的反饋、下屬的煩惱、事業的方向，如果不記錄的話，就會從細枝末節開始忘記。

1on1備忘錄的要點：

  • 直接寫對方說的重要發言（“〇〇先生說~”）
  • 寫下自己感受到的違和感、覺察
  • 約定的事情明文說明（雙向）
  • 寫下下次1on1要確認的事情

會議備忘錄的活用事例頁面介紹了1on1備忘錄的模板。

實踐例：“1on1 @田中部長 3/6 / 田中:“Q3致力於新事業的方針。 期待你擔任領導角色”/ 注意到：雖然有壓力，但有成長機會 / 承諾：下週之前新事業的研究3個 / 下次確認：研究結果的方向”

筆記術7：每週評論筆記

71周在15分盤點回顧

以備忘錄的形式進行GTD的“每週評論”。 每週五下班前15分鐘，或者週日晚上進行是最理想的。

每週回顧備忘錄的模板：

  • 本週的成果 3個：具體取得了什麼成就
  • 本週的學習 1個：最重要的覺悟
  • 未完成的任務：結轉的東西（也寫理由）
  • 下週最重要的任務 3個：有優先順序
  • 想要改善的事情 1個：流程的改善點

積累這個每週的備忘錄的話，每月、季度的回顧會輕鬆很多。 也可以直接用於評價面談的準備。

實踐例：“W10 評論 / 成果: 1. LP公開 2. 廣告ROI 15%改善 3. 新客戶提案完成 / 學習：早期反饋委託提高質量 / 未完成：伺服器轉移（等待批准） / 下週：1. 客戶演示 2. Q2預算確定 3. 招聘面試/改善：將會議時間縮短到30分鐘”

常見問題

工作筆記術中最有效的是什麼？

最有效的是“會議後30秒備忘錄”。 會議結束後，在30秒內寫下決定事項和下一步行動，然後用郵件傳送給自己。 僅憑這一點，會議的生產力就會大大提高。

有會議備忘錄的訣竅嗎？

會議前準備“3個問題”，會議中只專注於決定事項和行動專案做筆記。 訣竅是不要全部寫下來，只記錄以後與行動相關的資訊。

透過備忘錄工作效率能提高多少？

提高多少取決於工作內容，不能顯示統一的數字。 容易感受到效果的是，把會議的決定事項和後續行動寫下來，甚至做了回顧的機制。
