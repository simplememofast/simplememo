會議的動作專案
當場傳送郵件

有沒有在會議中想著“以後再整理”就忘記確定的動作專案的經歷？ 如果是SimpleMemo的話，啟動0.4秒（iPhone 16e・warm啟動的實測）・一鍵傳送，可以在不停止會議流程的情況下將動作專案記錄在郵件中。

會議備忘錄的理想工作流程
會議中：輸入決定事項 → 一鍵傳送 → 透過郵件接收 → 會議後跟進 → 完成後存檔

會議備忘錄的3大問題

問題1：後面看會議記錄很麻煩
即使仔細地整理在會議記錄工具中，後面開啟確認也很麻煩。 結果，在行動專案沒有執行的情況下迎來了下一個會議。
問題2：會議中很難操作備忘錄工具
Notion和Google文件適合在PC上操作，但在智慧手機上快速記下的話啟動需要時間。 切斷了會議的對話。
問題3：任務和郵件分離
即使動作專案進入任務工具，在日常郵件檢查中也看不到。 收到郵件的話，自然會映入眼簾。

會議備忘錄和會議記錄是兩回事 — 本頁面處理的是“會議中的30秒”

會議記錄是會議結束後將“決定的事情、要做的事情、結轉”結構化共享的檔案。 這裡所說的會議備忘錄是會議中留在自己手邊的1行的截圖，目的只是“不漏掉自己的行動”。 如果用1個工具同時做這個2的話，會議中的輸入會變得很重，結果都是半途而廢。

會議記錄本身的寫法和可以複製貼上的樣式總結在會議備忘錄·議事備忘錄模板5選中。 這個頁面只處理會議中從開啟應用程式到傳送為止的30秒。

3行格式“誰・什麼・什麼時候”

會議中要寫的量，這個3行就足夠了。 寫作需要10秒以上的形式，在會議中不會持續下去。

型
[會議名稱]誰→什麼→到什麼時候
例
[定例 9/2] 田中 → 重新制作報價單 → 9/5（週五） 自己 → 向對方傳送日程候選人 → 今天之內
  • 標題為會議名稱後，可以在收件箱中搜尋會議單位。
  • 自己的動作寫成“自己”。 以他人的動作稍後傳送為前提，將負責人名放在首位。
  • 期限到星期寫。“ 下週”的話，回到收件箱的時候就動不了了。
  • 猶豫的話1件1通。 換行合併多個也可以，但如果要轉發的話，分開比較方便。

會議種類的使用方法

1on1
不總結對方的話，直接用1行留下。“ 只把“下次之前要確認什麼”作為自己的行動，不寫評價和感想。 會議結束後，收件箱的1on1郵件是每個對方的履歷。
常規・每週評論
行動分散到多個負責人的會議。 如果給每個負責人傳送1，會議結束後可以直接轉發給每個負責人，不需要說“請看會議記錄”。
客戶、商談
只寫對方的委託事項和期限。 談話內容和溫度感在會議結束後立即單獨總結比較準確。 商談固有的寫法商談備忘錄技巧中進行解說。
線上會議（Zoom・Teams）
PC保持會議畫面不變，用智慧手機傳送。 即使在畫面共享中，對方也看不到備忘錄的操作，也不需要從會議軟體切換到備忘錄軟體。

會議後 — 從收件箱到哪裡留下

會議期間傳送的備忘錄已經送到了收件箱，所以會議結束後要做的只有“將自己的動作作為任務”“轉發他人的動作”的2。 如果使用Obsidian的話，只要透過郵件傳送就會在保管庫中追加，所以之後可以透過會議名稱進行搜尋。 這個使用方法的要點是，在會議中不用考慮整理什麼，在哪裡。

使用方法步驟（5步驟）

  1. 會議前準備應用程式 — 會議開始前開啟SimpleMemo。 在1行寫上“[會議名稱]”的話，它就會成為標題，以後更容易搜尋郵件。
  2. 決定行動專案後立即輸入 — 會議中擔當、期限、內容確定的瞬間輸入應用程式。“ 田中先生→製作資料→到週五為止”等簡潔的形式輸入。
  3. 一鍵傳送郵件 — 輸入後一鍵傳送。 一邊繼續會議，一邊每次出現動作專案時都會重複。 傳送只需點選一下即可完成。
  4. 會議結束後用郵件跟進 — 會議結束後確認收件箱。 在列表中檢視傳送的行動專案，透過郵件委託負責人，在日曆上設定期限。
  5. 與團隊共享、轉發 — 只需轉發收到的郵件，就可以與團隊成員共享行動專案。 轉寫到會議記錄工具也很簡單。

實際場景示例

場景 1
與客戶的提案會議
在與客戶的提案會議上被委託“希望在下週一之前傳送詳細的日程表”。 在想寫在筆記本上的瞬間用SimpleMemo立即輸入→傳送。 會議結束後確認了郵件，馬上就可以著手製定日程了。
客戶提案MTG 行動 →日程詳情 下週一之前傳送 →負責人：自己
場景 2
公司內部的每週審查會議
每週評論中出現了多個動作專案。 按成員傳送，會議後轉發給各成員。“ 沒有必要說“請看會議記錄”，因為行動專案會直接傳送到各自的郵件中，所以執行率大大提高。
每週評論 2026/3/5 [田中] 修正bug → 週四之前 [佐藤] 設計評論 → 週三之前 [自己] 進度報告郵件 → 明天之內

常見問題

在會議中使用也不會失禮嗎？

啟動、輸入、傳送只需幾秒鐘，所以不會停止會議的流程。 只需操作智慧手機幾秒鐘，就可以一邊專注於會議一邊記錄行動專案。

可以把多個動作道具一起傳送嗎？

是的。 用換行分隔符將多個動作專案彙總輸入，可以一次性傳送。 或者也可以一個一個地傳送，分成多個郵件。

與會議記錄工具的區別是什麼？

SimpleMemo最適合快速捕捉動作道具。 整個會議的會議記錄稍後整理在Notion或專用工具中，只留下動作專案即時郵件的組合很有效。

線上會議（Zoom等）也可以使用嗎？

是的。 可以在PC上使用Zoom的同時，用智慧手機操作SimpleMemo。 PC畫面保持會議狀態，可以用智慧手機記下併傳送。

透過郵件管理動作專案的優點是什麼？

因為會到達每天使用的收件箱，所以即使不自覺也能自然而然地看到動作專案。“ 不需要開啟專用工具”的習慣化，可以直接納入現有的工作流程中。

會議記錄有什麼不同？

會議記錄是會議後將決定事項、任務、結轉結構化共享的檔案。 這裡所說的會議備忘錄是會議中用1行留下自己的動作的截圖，共享和結構化會推遲。 會議記錄的寫法在“會議備忘錄、會議備忘錄模板5選”中進行了解說。

會議中寫的最小格式是什麼？

“誰→什麼→到什麼時候”的3行。 如果把主題作為會議名稱的話，可以在收件箱中按會議進行搜尋，如果把期限寫到星期的話，回到收件箱時就可以直接操作了。

1on1的備忘錄應該怎麼做？

將對方的話原封不動地留在1行，只將自己在下次之前確認的事情作為行動。 不寫評價和感想，使用收件箱的1on1郵件作為每個對方的履歷。

從下次會議開始，當場寫下行動專案吧
下載免費。 設定馬上就結束了。
