SimpleMemo vs UpNote
應該選哪個

UpNote是想在應用程式內編輯、整理筆記，在多個終端上同步的人的候選人。 SimpleMemo，在想在自己的郵件或已經設定好的Obsidian上留下簡短的記錄時，可以考慮。 用同樣的1件確認輸入的入口、儲存地址、取出方法後再選擇吧。

SimpleMemo的費用和免費額度

UpNote也直接進入新筆記本

UpNote的移動版可以從列表下方的藍色新筆記按鈕寫。 因為本文的1行是標題，所以不需要在另外的欄裡輸入標題。 在PC上用Cmd/Ctrl + N，從其他應用程式在Mac上用Cmd + Option + N，Windows/Linux用Ctrl + Alt + N開啟新視窗。

不能以每次必須選擇筆記本為前提來計算速度差。 從自己使用的入口開始寫1件簡短的備忘錄，確認以後能不能找到。 如果想用收件箱處理的話，可以比較從SimpleMemo到的正文閱讀。

UpNote官方：新筆記和標題

50筆記本，買斷，確認解約後

免費版最大50筆記本。 附件、鎖定、匯入、PDF・Markdown的匯出等請確認Premium的條件。 無論是購買月費還是Lifetime，都會優先考慮當地商店顯示的金額。 沒有直接從Windows/Linux購買的功能，在Mac・iOS・Android購買後，登入同一個UpNote賬戶進行反映。

即使解約月費也可以瀏覽現有的筆記，但是如果超過50件的話，就不能新建，部分匯出功能也無法使用。 如果計劃轉移的話，在合同有效期間會以必要的形式嘗試寫出來。

UpNote官方：Premium和解約後的限制

Evernote轉移，少量確認連結和附件

PC版可以匯入Evernote的ENEX檔案。 以原來的筆記本為單位劃分ENEX，啟用“Use file name as notebook”就可以進行分類。 分層化在匯入後進行。 將標籤轉換為標籤後，特殊文字可能會變成連字元。

Evernote內部連結沒有轉換為UpNote內的連結，開啟原來的Evernote。 超過20MB的附件和超過300000字的筆記可能無法匯入。 請確認顏色和佈局，並留下原來的ENEX。 超過20000筆記或附加10GB的一次性匯入，有1次50件的限制。

UpNote官方：ENEX匯入和限制

將同步和可以恢復的副本分開考慮

UpNote的自動備份在Mac、Windows、Linux上儲存在終端內。 預設為1天1次・最大50天分，可以從設定中確認間隔、儲存地址、附加的處理。 以智慧手機為中心使用時，在同步到PC後確認是否備份。 不編輯備份用資料夾的管理檔案。

UpNote官方：自動備份

要轉移到其他應用程式，將少量匯出到Markdown或HTML等，實際開啟正文、影象、連結。 擁有備份和在其他應用程式上可以重現相同的狀態是不同的。 SimpleMemo的接收郵件也遵循郵件方的容量、保留設定、備份。

UpNote官方：匯出格式和操作

UpNote，如果不登入的話，筆記會保留在終端內，使用同步的話也會儲存在美國的Firebase伺服器上。 請不要將通訊、儲存時的加密和應用程式鎖定等同於運營者無法解密內容的E2EE。

UpNote官方：資料儲存和隱私

從免費範圍到正式過渡的5步驟

  1. 決定經常寫的短筆記1件，從平時使用的終端和入口輸入。
  2. 以第二天為目的進行搜尋，補充正文確認儲存地址。
  3. 開啟必要的筆記後，在訊號範圍外讀寫，重新連線後確認其他終端的內容。
  4. 如果需要匯入的話，請先確認Premium的功能和購買條件。 處於可用狀態後，匯入包括影象、附件、內部連結在內的少量內容，與原始資料進行比較。
  5. 以合同中可以使用的格式匯出，確認檔案和備份的儲存位置後，判斷正式轉移。

如果在應用內繼續寫的話，單獨嘗試UpNote是出發點。 如果每天處理郵件的話，SimpleMemo也是候選人。 同時將接收郵件轉移到UpNote時，需要另外複製或對應格式的匯入，不一定已經設定了自動連線。

常見問題

UpNote現在的費用是多少？
官方網站介紹的是每月US$1.99，Lifetime是US$39.99。 因為地區和稅不同，所以在日本購買時請確認應用程式內的最終金額。
超過免費版的50筆記本會怎麼樣？
增加新的筆記本需要Premium。 即使月度合同結束，也可以瀏覽現有的筆記本，但是如果超過50件的話，就不能新建，部分Premium功能也無法使用。
在新筆記本之前必須選擇筆記本嗎？
不是必須的。 可以從手機的新筆記按鈕和PC的快捷鍵寫。 因為1行是標題，所以不需要另外輸入標題。
UpNote可以離線使用嗎？
會讀寫。 登入後使用同步時，重新連線後變更會反映在其他終端上。 必要的筆記和附件請在移動前用實機開啟確認。
筆記本鎖是E2EE嗎？
不。 UpNote說明了通訊中和儲存時的加密，但明確說明不支援E2EE。 應用程式和筆記的鎖定，不會改變其區別。
Evernote的內部連結也可以移動嗎？
UpNote內的連結沒有轉換，而是作為開啟原來的Evernote的連結保留。 附加尺寸、長筆記、標籤轉換和格式也有限制，所以少量嘗試後再轉移。
致想在收件箱中處理備忘錄的人
首先1件，寫好後傳送，確認收到的正文。 免費名額是每天3則。
