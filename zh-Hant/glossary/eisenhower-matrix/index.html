術語集 — 任務管理

什麼是艾森哈瓦矩陣

艾森豪威爾矩陣（Eisenhower Matrix）是基於第34代美國總統德懷特·D·艾森豪威爾的決策法，任務優先順序框架。 所有任務在“緊急度”和“重要度”的2軸上分類為4象限，不僅明確“做什麼”，還明確“不做什麼”這一點是最大的特點。

定義

艾森哈瓦矩陣是“緊急與否”和“重要與否”的2軸將任務分類為4象限的框架。 第1象限（緊急x重要）立即執行，第2象限（重要x非緊急）是日程，第3象限（緊急x非重要）委託，第4象限（非緊急x非重要）排除。 Stephen Covey在《7個習慣》中傳播，至今仍是最實用的任務管理方法之一。

4象限的解說

Q1：緊急x重要→立即執行
截止日期前的專案，來自客戶的緊急應對，健康上的問題。 不能推遲，現在應該馬上應對的任務。
Q2：重要 x 非緊急 → 日程
戰略立案、技能開發、人際關係構建、預防措施。 最應該投入時間的象限。 在這裡花時間的人最有成效。
Q3：緊急 x 非重要 → 委託
他人的委託、部分會議、電話對應。 看似緊急但與自己的目標沒有直接關係的任務。 儘可能委託給他人。
Q4：非緊急 x 非重要 → 排除
SNS的無目的瀏覽、八卦、過度的電視。 時間的浪費。 透過有意識地排除，將時間轉向其他象限。

用SimpleMemo運用矩陣

發生任務後用SimpleMemo立即捕獲，在備忘錄的開頭加上【Q1】〜【Q4】的象限編號。 收到郵件後，用Gmail的過濾器按象限自動對標籤進行分類，收件箱會自動變成艾森霍瓦矩陣。 不是在捕捉的瞬間考慮分類，而是在之後冷靜地做出判斷也是優點。

常見問題（艾森豪瓦矩陣）

什麼是艾森豪瓦矩陣？

將任務按“緊急度”和“重要度”的2軸分類為4象限的框架。 根據第34代美國總統艾森豪威爾的決策法。

最應該花費時間的象限是什麼？

第2象限（重要但不緊急）。 戰略立案、技能開發、預防措施等。 在這裡投入時間的人最有成效，Q1的“滅火”也會減少。

SimpleMemo的運用方法是什麼？

在備忘錄的開頭加上【Q1】~【Q4】的象限標籤傳送。 用Gmail過濾器自動標籤分類的話，收件箱會變成矩陣。
