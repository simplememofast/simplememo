Obsidian的保管庫（Vault）是什麼？

就是你選擇的普通資料夾本身。 筆記是Markdown的文字檔案，附件和預設的設定資料夾.obsidian也可以放進去。 不需要為了閱讀筆記而轉換為獨立資料庫。

2026年8月20日用Linux版1.13.7開啟空資料夾數了一下，建立的只有.obsidian/直下的JSON檔案4個・合計5,543位元組，Markdown檔案是0件。

從iPhone用聲音說話留給Obsidian最短的方法，總結為4方式的比較（附帶不需要外掛的步驟）。

保管庫在哪裡？ 名字可以改嗎？

保管庫在製作時選擇的地方。 名字是那個資料夾名。“ 僅僅尋找名為“Obsidian”的共同資料夾，不一定是目標的保管庫。

  • PC：忘記儲存位置後，在Finder或資源管理器中搜尋保管庫名稱，開啟裡面的.md檔案，確認是否是自己的筆記本。 .obsidian是保管庫中的設定資料夾，不是放置筆記本的保管庫本身。
  • 在iPhone中使用iCloud：按照“檔案”→“瀏覽”→“iCloud Drive”→帶有Obsidian圖示的資料夾→自己的保管庫名稱的順序進行確認。 本地儲存和Obsidian Sync是另外的儲存方法。

在PC上更改名稱時，可以在保管庫的管理畫面中從目標選單中使用“Rename vault”。 資料夾名也會改變，請確認合作應用程式的儲存地址。 參考官方保管庫管理指南和iCloud的儲存地址指南。

如何開啟現有的資料夾作為保管庫？

從PC版Obsidian的左下方開啟保管庫的管理畫面，選擇“Open folder as vault”的“Open”，指定包含筆記的資料夾。 不是.obsidian或單獨的筆記，而是選擇想要一起開啟的資料夾。 畫面示例保管庫的製作・首次設定指南。

實測 — 如果把空資料夾作為保管庫的話，會製作出什麼

準備了1個空目錄，在Obsidian 1.13.7（Linux版）中將其作為保管庫開啟，在find中列舉了緊接著的內容。 結果就是這個。 

vault-demo/
└── .obsidian/
    ├── app.json
    ├── appearance.json
    ├── core-plugins.json
    └── workspace.json
檔案 尺寸 裡面裝了什麼
app.json2裡面是{}。 只寫從預設更改的設定
appearance.json2同樣{}。 改變主題和字型會增加
core-plugins.json696核心功能31個ON/OFF（預設ON 21・OFF 10）
workspace.json4,843開啟的窗格的配置。 4中只有這個大
合計5,543單位是位元組。 筆記本本體連1位元組都不包含

這個5,543位元組，只是這次空的保管庫的初始設定值。 不是平時使用的保管庫的總容量。 Obsidian除了筆記本以外，還使用IndexedDB和後設資料快取。“ 用Markdown儲存”和“應用程式完全不使用資料庫”是兩回事。

從這裡可以說的話 — 刪除、移動、同步

.obsidian 和筆記的儲存地址

普通的Markdown筆記本在設定資料夾外面。 但是，.obsidian中包含主題、熱鍵、社群外掛等。 請不要將刪除作為整理方法，請留下包括設定在內的保管庫的副本後再進行更改。 這次的4檔案僅限於空的驗證環境。

複製後確認筆記和設定

在桌面上，留下包括設定和附件在內的保管庫的副本，在“開啟資料夾”中指定複製目的地，確認筆記正文。 僅僅複製就無法設定終端之間的同步。 在iPhone中使用iCloud時，也請確認Obsidian用的儲存位置。

跨在終端上 workspace.json 只是性格不同

這次的4,843位元組是包含驗證時的畫面配置的設定。 官方資料介紹了在Git管理時將workspace.json和workspaces.json從追蹤物件中除名的選項。 分別確認使用中的同步方式的設定和手動複製時留下的設定。

“新建”和“開啟現有資料夾”的結果不同

這次開啟現有的空資料夾，Markdown是0件。 另一方面，在“建立新的保管庫”中製作時，會放置1個初始筆記（實際畫面的記錄）。 如果已經有檔案的資料夾的話，不要選擇後者。

core-plugins.json的內容 — 預設關閉的10個

696位元組的正體是Obsidian從一開始就包含的核心功能的ON/OFF表。 2026年8月20日的Linux版1.13.7中31個排列，預設ON 21個・OFF 10個。 因為無需追加安裝就可以從設定中切換，所以在“找到那個功能並插入外掛”之前，值得看看這裡。 關閉的是下一個10個。 

footnotes          slash-command      markdown-importer
zk-prefixer        random-note        slides
audio-recorder     workspaces         publish
webviewer

這與社群外掛（2026年8月21日時6,812個）是不同的。 總數的推移和下載數前10的實測總結在外掛入門頁面中。

知道是資料夾的下一個問題 — 進入那裡的速度

iPhone要新增簡短的備忘錄，首先要決定輸入路徑和儲存地址。 在SimpleMemo中，開啟聯動，設定從檔案App可以訪問的保管庫資料夾的許可權和日期筆記或固定Inbox，確認不傳送郵件的寫入測試。 從Siri和Apple Watch輸入，也請嘗試自己的終端指定的正文是否保留。 郵件到達、儲存到保管庫、同步到其他終端分別確認。 僅透過應用內記錄的顯示，無法確認到達保管庫。

選擇Obsidian的人，將入口縮短

請設定連線、訪問權、追記地址，確認簡短的備忘錄是否保留在選擇的筆記中。 下載是免費的。

常見問題

Obsidian的保管庫（Vault）是什麼？
是放置筆記、附件、設定的資料夾。 筆記本本體是Markdown。 2026年8月20日的Linux版1.13.7的空資料夾驗證中，製作的是.obsidian和，其正下方的JSON 4（app.json・appearance.json・core-plugins.json・workspace.json）僅，合計5,543位元組。
刪除.obsidian資料夾後筆記會消失嗎？
普通的Markdown筆記本在設定資料夾外面。 但是，.obsidian中包含主題、熱鍵、社群外掛等。 請不要將刪除作為整理方法，請留下包括設定在內的保管庫的副本後再進行更改。 這次的4檔案僅限於空的驗證環境。
如何將保管庫轉移到其他電腦上？
確保原來的保管庫的影印件，在影印處確認筆記、附加、設定。 在桌面上，可以透過Obsidian的“開啟資料夾”指定複製地址。 影印和終端間同步是另外的操作。 在更改設定之前，請留下原件，確認畫面配置和外掛是否可以在轉移目的地使用。
如果把現有的資料夾變成保管庫的話，裡面會加點什麼嗎？
在這次Linux版1.13.7的空資料夾中，.obsidian和初始設定檔案被製作，緊接著的Markdown是0件。 另一方面，從“建立新的保管庫”開始建立時，初始筆記會放置1件（真實畫面的記錄）。 如果是已經包含檔案的資料夾，請務必選擇“開啟資料夾”的一側。
core-plugins.json上寫著什麼？
Obsidian從一開始就包含的核心功能的ON/OFF。 在2026年8月20日的Linux版1.13.7中31個排列，預設是ON 21個・OFF 10個。 OFF的是footnotes / slash-command / markdown-importer / zk-prefixer / random-note / slides / audio-recorder / workspaces / publish / webviewer的10個。 無需追加安裝，可以從設定中切換。
驗證環境和驗證範圍

驗證日期：2026年8月20日 / 物件：Obsidian 1.13.7（官方Linux AppImage・X-AppImage-Version確認）/ 環境：Linux（Ubuntu 24.04・Xvfb上的無頭）。 準備了1個空的目錄，在Obsidian中作為保管庫開啟，將緊接著的內容原封不動地放在find和ls -l中列舉、測量的數值。 Windows版・macOS版・iOS版沒有執行（保管庫的結構與平臺無關，但本頁面確認的是Linux版）。 “建立新的保管庫”時的行為是別頁2026年8月11日Obsidian 1.13.6確認的，不包含在這次的重新驗證中。 根據版本不同，預設值會發生變化。 2026年9月30日將Obsidian的儲存、轉移、同步的說明與官方資料，SimpleMemo的輸入配合條件與應用程式的原始碼進行了核對。 不是重新執行上述的Linux實測，而是現在的App Store分發版和iPhone的寫入、同步尚未驗證。
