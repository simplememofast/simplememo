Dataview是做什麼的外掛？

是能夠像資料庫一樣搜尋保管庫（Vault）的外掛。 寫在筆記的frontmatter和內聯欄位的後設資料，可以用DQL・內聯式・DataviewJS・內聯JS式的4種書寫方法處理。 DQL的輸出格式是LIST・TABLE・TASK・CALENDAR，與DataviewJS不相同的分類。 官方下載數資料（2026年8月22日獲取）中4805635件，3位居第（登錄檔的註冊總數是6,840個，但排名是與此不同的檔案下載數資料中的排名）。

僅憑下載統計的更新日期，無法判斷開發的繼續、停止和當前動作。 下面的數值和版本是2026年8月22日的獲取記錄，不是當前值。

4個查詢模式 — 來自官方README的樣本

官方README區分了DQL、內聯式、DataviewJS、內聯JS式4的寫法。 DQL內的輸出格式是LIST（列表）、TABLE（表）、TASK（任務）、CALENDAR（日期日曆）。 下面的README例子這次也沒有在實機上執行。

1. DQL（資料檢視查詢語言）

類似於SQL的專用記法。 適合基本用途。 

```dataview
TABLE file.name AS "File", rating AS "Rating" FROM #book
```
2. 內聯式

嵌入正文中，透過預覽進行評價。 

We are on page `= this.file.name`.
3。 資料檢視JS

可以充分利用JavaScript API，最強大的模式。 

```dataviewjs
dv.taskList(dv.pages().file.tasks.where(t => !t.completed));
```
4. 內聯JS式

內聯式JavaScript版。 可以當場執行任意的JS。 

This page was last modified at `$= dv.current().file.mtime`.

資料的輸入方是2種。 筆記開頭的YAML frontmatter（用---包圍）或正文中寫フィールド名:: 値的內聯欄位，兩者都是Dataview讀取並作為查詢的物件。 從輸入UI和儲存YAML連線實際查詢的例子，可以透過屬性變更，Dataview列表變更的例項進行確認。 

---
alias: "document"
last-reviewed: 2021-08-17
thoughts:
  rating: 8
  reviewable: false
---
Basic Field:: Value
**Bold Field**:: Nice!
You can also write [field:: inline fields]; multiple [field2:: on the same line].

關於DataviewJS安全的注意事項

來自官方README

DataviewJS功能強大，與其他Obsidian外掛具有相同的許可權。 也就是說，也可以改寫、製作、刪除檔案，也可以進行網路通訊。 官方推薦使用自己編寫的程式碼或理解內容、可靠的分發來源的指令碼。 另一方面，普通的Dataview查詢（DQL）是沙盒化的，不能對儲存庫進行更改（因此能做的事情有限）。

在寫查詢之前，首先決定留下1行的地方

Dataview搜尋、統計保管庫中的筆記和後設資料。 從SimpleMemo留下輸入的備忘錄時，開啟連線，設定可以訪問的資料夾和儲存地址，確認寫入測試。 可以選擇日期筆記或固定的Inbox。 請分別確認郵件的到達和筆記的儲存，與自動生成Dataview用的欄位的功能區分開來。

常見問題

Dataview是做什麼的外掛？
是能夠像資料庫一樣搜尋保管庫（Vault）的外掛。 筆記的frontmatter和內聯欄位中寫的後設資料，可以用DQL、內聯式、DataviewJS、內聯JS式4的寫法來處理。 DQL的輸出格式是LIST・TABLE・TASK・CALENDAR，與DataviewJS不相同的分類。
Dataview用了多久？
Obsidian官方下載數資料在2026年8月22日直接獲取，4805635件，其中資料中3位（1位Excalidraw・2位Templater）。 另外，“註冊外掛6,840個”是登錄檔一覽的件數，與計算排名的下載數資料是分開的檔案。
Dataview現在還在開發嗎？
僅憑本頁2026年8月22日的統計・版的獲取記錄，無法判斷目前的開發情況。 統計的更新日期和時間與程式碼的更新日期不同。 請確認官方釋出和變更記錄，使用Obsidian的版本進行嘗試。 在這次的更正中，沒有安裝現行版來確認動作。
Dataview的基本寫法是什麼？
在筆記的frontmatter（YAML）或正文中以“欄位名::值”的形式書寫的內聯欄位新增後設資料。 在那上面dataview在程式碼塊上寫顯示形式和條件。 例如，LIST・TABLE可以顯示筆記，TASK可以顯示筆記內的任務。
DataviewJS可以安全使用嗎？
根據官方README，DataviewJS與其他Obsidian外掛的許可權相同，因此可以改寫、刪除檔案和進行網路通訊。 建議只使用自己編寫的程式碼或可靠的分發來源的指令碼。 普通的DQL查詢是沙盒化的，不能寫入保管庫。
