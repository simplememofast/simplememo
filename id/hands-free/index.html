Pengaturan

  • iPhone (iOS 26 atau versi lebih baru, model yang kompatibel dengan input suara)
  • Penyimpanan Obsidian terletak di Drive iCloud atau "di iPhone ini" (digunakan untuk penyimpanan lokal)
  • Online hanya untuk pertama kalinya (mendapatkan model bahasa)
  1. Mengaktifkan input suara secara otomatis saat memulaiPengaturan
    → "Input suara dan suara" → "Mengaktifkan input suara secara otomatis saat memulai". Setelah itu, rekaman akan dimulai saat Anda membukanya.
  2. Pilih folder ObsidianNyalakan "Kolaborasi Obsidian" di kolom "Obsidian" pada pengaturan
    dan pilih folder penyimpanan (Drive iCloud atau "di iPhone ini"). Karena file ditulis secara langsung, itu disimpan secara lokal bahkan jika berada di luar jangkauan.
  3. Siapkan model suara (hanya pertama kali)
    Ketuk mikrofon secara online sekali untuk mendapatkan model bahasa. Setelah itu, pengenalan suara juga akan berfungsi secara offline.
  4. Ditempatkan di layar beranda/widget
    Tempatkan di posisi atau widget yang mudah ditekan sehingga dapat diaktifkan dalam waktu singkat.
  5. Buka → Bicara → Kirim
    Buka saja dan bicara dalam situasi yang aman. Ketika Anda mengirimkannya, memo akan memasukkan Outbox (jika tautan Obsidian dihidupkan, itu juga akan ditambahkan ke catatan lokal), dan draf akan hilang.

Berapa akurasi audionya? Apakah ada biaya tambahan?

Menggunakan pengenalan suara pada perangkat Apple (iOS 26 atau yang lebih baru), transkripsi dilakukan di terminal.
