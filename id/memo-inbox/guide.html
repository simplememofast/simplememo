MULAI MENGGUNAKAN

Tempat untuk catatan singkat.

Tidak perlu akun. Catatan Anda tetap tersimpan di browser ini.

Catat dan temukan

Tulis di kolom Catatan, tambahkan judul opsional dan tag yang dipisahkan koma, lalu pilih Simpan catatan. Penyimpanan harus dilakukan secara manual: perubahan yang belum selesai tidak disimpan otomatis. Gunakan pencarian untuk menemukan kata dalam judul, isi, atau tag. Pilih tag untuk mempersempit daftar.

Hapus dan pulihkan

Pindahkan ke Sampah membuat catatan tetap dapat dipulihkan. Buka tab Sampah, pilih catatannya, lalu pilih Pulihkan catatan. Tidak ada tombol hapus permanen.

Impor teks

Impor file teks menerima file .txt dan .md dengan pengodean UTF-8, satu catatan per file. File asli tidak diubah. Markdown, termasuk front matter, diimpor sebagai teks biasa.

Bawa catatan ke Obsidian

Ekspor ZIP Markdown mencakup semua catatan yang tersimpan di kotak masuk, terlepas dari filter saat ini. Ekstrak ZIP ke vault Anda atau folder Markdown lainnya. Judul, tanggal, dan tag disertakan sebagai metadata YAML. Catatan di Sampah dan perubahan yang belum disimpan tidak disertakan.

Simpan cadangan

Unduh cadangan menyimpan semua catatan tersimpan, termasuk Sampah. Simpan file JSON tersebut di tempat yang aman. Pulihkan dari cadangan menggabungkannya dengan catatan saat ini. Catatan identik dilewati; versi yang bertentangan disimpan sebagai salinan terpisah. Cadangan tidak valid ditolak tanpa mengubah catatan tersimpan.

Pahami penyimpanan lokal

Gunakan profil browser dan alamat situs yang sama untuk mengakses catatan. Menghapus data situs, menggunakan penjelajahan pribadi, penghapusan data oleh browser, atau kehilangan perangkat dapat menghapus catatan lokal. Ekspor cadangan secara rutin. Aplikasi ini tidak mengenkripsi data lokal dan bukan tempat penyimpanan yang aman untuk data rahasia. Tidak ada sinkronisasi cloud, akun, atau koneksi dengan aplikasi Simple Memo untuk iPhone. Jika tab lain mengubah catatan, salin teks yang belum disimpan lalu muat ulang halaman sebelum menyimpan.

Aplikasi tidak mengirim catatan ke server dan tidak memiliki analitik atau skrip eksternal. Penyedia hosting menerima permintaan halaman biasa. Tautan proyek membuka situs eksternal hanya saat dipilih.

Batas

Batasnya adalah 4 MB data terserialisasi, 5,000 catatan, 200 karakter per judul, 200,000 karakter per catatan, serta 30 tag dengan masing-masing 50 karakter. Kuota browser mungkin lebih rendah. Jika penyimpanan gagal, teks di editor tetap tersedia untuk disalin.
