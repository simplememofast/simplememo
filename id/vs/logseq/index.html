Siapkan sinkronisasi dan pencadangan secara terpisah

README resmi menjelaskan versi DB sebagai beta, versi seluler baru dan RTC sebagai alfa, dan memandu kemungkinan kehilangan data dan cadangan. Mengaktifkan sinkronisasi saja tidak mencegah penghapusan yang tidak disengaja dan kehilangan data. Pertama, cobalah dengan grafik kecil yang tidak menyertakan isi produksi.

Periksa instruksi untuk versi yang Anda gunakan tanpa mencampur pengaturan sinkronisasi versi file dan versi DB. Apakah catatan dapat ditemukan di tujuan sinkronisasi atau apakah salinan independen dapat dibaca kembali adalah konfirmasi lain.

Gunakan cadangan DB dan ekspor Markdown secara terpisah

Dalam versi DB dari grafik Ekspor, Anda dapat memilih "Ekspor SQLite DB dan aset" untuk meringkas DB dan lampiran. Ekspor standar Markdown digunakan untuk menghasilkan teks yang mudah dibaca, tetapi tidak mempertahankan semua atribut atau stempel waktu. Jangan hanya membuat Markdown untuk migrasi sebagai satu-satunya cadangan.

Coba Impor → SQLite + aset (.zip) dengan grafik terpisah baru sambil meninggalkan grafik asli dan periksa apakah Anda dapat membuka konten yang diperlukan. Saat mengubah grafik file lama ke DB, harap juga periksa Org non-dukungan, konversi status tugas, dan beberapa kueri dan penyematan pembatasan impor.

Pertanyaan yang Sering Diajukan

Apakah Anda ingin menyimpan semua Logseq dalam file Markdown?

Tidak. Versi file sebelumnya dibagi menjadi Logseq OG, dan versi DB menggunakan basis data SQLite. Ekspor Markdown dari versi DB tidak dalam format yang mempertahankan semua properti dan stempel waktu.

Apa yang Anda lakukan sebelum mencoba versi DB dengan grafik yang ada?

Tinggalkan salinan independen dari grafik asli dan coba dengan grafik uji kecil yang tidak penting. Jika Anda tidak hanya membutuhkan SQLite tetapi juga lampiran, pilih ekspor termasuk SQLite DB dan aset dan periksa impor ke dalam grafik terpisah.

Dapatkah saya menggunakan plug-in sebelumnya seperti dalam versi DB?

Periksa kompatibilitas satu per satu. Pasar Resmi "Mendukung DB?" Silakan periksa apakah plug-in yang Anda gunakan mendukung grafik DB dengan melihat tampilan yang kompatibel dengan DB.

Apakah plug-in diperlukan untuk input cepat Logseq?

Dokumen resmi versi DB memiliki "Penambahan cepat" bawaan yang mengirimkan catatan singkat ke jurnal saat ini. Pintu masuk berbeda untuk versi dan terminal, jadi silakan periksa dengan aplikasi saat ini sebelum mencari plug-in tambahan.

Apakah tidak akan ada kehilangan data jika saya menggunakan sinkronisasi resmi?

Sinkronisasi bukan pengganti cadangan. README resmi adalah versi beta untuk versi DB, dan alfa untuk versi seluler baru dan RTC, memandu kemungkinan kehilangan data dan cadangan independen. Periksa versi dan rute sinkronisasi yang akan digunakan.

Jika saya menggunakan SimpleMemo, apakah itu akan secara otomatis ditambahkan ke Logseq?

Contoh gabungan di halaman ini adalah cara mentransfer teks yang diterima ke kotak masuk email ke Logseq jika perlu. Itu tidak menunjukkan fungsi penulisan otomatis ke DB atau grafik Logseq, atau kemampuan untuk memigrasikan seluruh grafik.
