Apa itu Standard Notes

Standard Notes adalah aplikasi memo yang berorientasi pada privasi dengan enkripsi ujung ke ujung (XChaCha20-Poly1305) pada intinya. Ini berjalan di iOS, Android, Windows, Mac, dan Linux, dan menyinkronkan catatan ke cloud dalam keadaan terenkripsi. Ini dikembangkan sebagai proyek sumber terbuka dan memiliki editor yang diperluas (markdown, spreadsheet, dll.), tag, lampiran file, dan riwayat versi. Paket gratis hanya memiliki fungsi dasar, dan banyak fungsi lanjutan memerlukan paket berbayar. Ini disukai oleh pengguna yang menginginkan aplikasi catatan berfitur lengkap sambil memprioritaskan privasi.

Perbandingan aplikasi memo terenkripsi: Standard Notes vs SimpleMemo

Standard Notes dan SimpleMemo keduanya adalah aplikasi catatan yang menekankan privasi, tetapi pendekatan enkripsinya pada dasarnya berbeda. Standard Notes menggunakan enkripsi ujung ke ujung dengan XChaCha20-Poly1305. Catatan dienkripsi di perangkat dan disimpan serta disinkronkan ke server cloud Standard Notes dalam keadaan terenkripsi. Dapat dikatakan bahwa tingkat keamanannya sangat tinggi karena isi catatan tidak dapat dibaca bahkan di sisi server. Pertukarannya adalah hanya aplikasi Standard Notes yang dapat membaca catatan. SimpleMemo mengambil pendekatan yang berbeda. Outbox, yang sedang menunggu transmisi offline, dan riwayat transmisi dienkripsi dengan AES-GCM-256 di terminal, tetapi transmisi email itu sendiri bukan enkripsi E2E karena itu adalah standar SMTP (sehingga pengguna penerima dapat membacanya di aplikasi email harian). Sebaliknya, isi email tidak disimpan secara permanen di server kami (hanya lewat selama pemrosesan transmisi). Memo yang dikirim akan tetap berada di kotak masuk (server layanan email) sebagai email. " Perbedaan antara model adalah terenkripsi dan penyimpanan cloud (E2E) dan "jangan tinggalkan teks di server (minimalisasi data)". Di sisi lain, sebagai aplikasi catatan berfitur lengkap, Standard Notes memiliki banyak fungsi seperti manajemen tag, editor ekstensi, riwayat versi, dan lampiran file. SimpleMemo didedikasikan untuk menangkap dan tidak memiliki kemampuan untuk mengatur dan mengedit secara manual (jika Anda mengaktifkan "Tambahkan tag AI secara otomatis" di tautan Obsidian, AI di terminal akan menambahkan judul dan tag). Pilihan model keamanan tergantung pada model ancaman Anda. Tidak apa-apa untuk meninggalkan teks kriptografi di server, tetapi saya hanya ingin menggunakan Standard Notes untuk aplikasi yang dapat membaca teks" lalu Standard Notes. " Jika Anda ingin membaca memo di kotak masuk email biasa Anda, tetapi Anda tidak ingin meninggalkan teks di basis transmisi, maka SimpleMemo.

4 Perbedaan antara aplikasi yang berorientasi privasi

  • 1 Perbedaan dalam model enkripsi
    Standard Notes menyimpan data di cloud dengan enkripsi ujung ke ujung dengan XChaCha20-Poly1305 (server tidak dapat membaca teks). SimpleMemo mengenkripsi riwayat transmisi dengan Outbox dan AES-GCM-256 offline di terminal, tetapi transmisi email bukan E2E karena itu adalah SMTP standar. Sebaliknya, itu dirancang (minimalisasi data) yang tidak menyimpan teks secara permanen di server. Perbedaan mendasar dalam desain adalah "mengenkripsi dan menyimpan di cloud" dan "jangan tinggalkan teks di server".
  • 2 Penyimpanan server vs pengiriman emailCatatan
    Standard Notes disimpan di cloud terenkripsi dan hanya dapat dilihat dari dalam aplikasi. Memo SimpleMemo tiba di kotak masuk email Anda, sehingga Anda dapat melihatnya dari semua klien email seperti Gmail, Outlook, dan Apple Mail. Perbedaan antara ketergantungan aplikasi dan tujuan umum email.
  • 3 Ekspansi editor vs input tunggal
    Standard Notes adalah paket berbayar yang menawarkan berbagai editor ekstensi seperti editor Markdown, spreadsheet, dan editor kode. SimpleMemo hanya memiliki satu bidang input teks biasa, dan dengan berani mempersempit fungsinya, ia mencapai kecepatan aktivasi 0.4 detik (iPhone 16e, pengukuran aktual awal hangat) dan transmisi satu ketukan.
  • 4 Perbandingan model biaya
    Paket gratis Standard Notes hanya memiliki fungsi dasar, editor yang diperluas membutuhkan Produktivitas ($90) atau lebih tinggi, dan lampiran file membutuhkan Profesional ($120 per tahun). Paket gratis untuk SimpleMemo adalah maksimal 3 pesan per hari ("Simpan hanya ke Obsidian" adalah Premium). Premium juga terjangkau di 500 yen per bulan / 5,000 yen per tahun.

Pertanyaan yang Sering Diajukan

Apa perbedaan antara enkripsi E2E dari Standard Notes dan AES-GCM dari SimpleMemo?

Standard Notes mengenkripsi data dengan XChaCha20-Poly1305 dan menyimpannya di cloud (enkripsi E2E). SimpleMemo mengenkripsi riwayat transmisi offline Outbox dan AES-GCM-256 di terminal, tetapi transmisi email itu sendiri bukan E2E karena itu adalah SMTP standar. Sebaliknya, itu dirancang untuk tidak menyimpan isi email secara permanen di server kami (hanya lewat selama pemrosesan transmisi). Keduanya adalah pendekatan yang menekankan privasi karena perbedaan dalam filosofi desain "enkripsi dan simpan di cloud" dan "jangan tinggalkan teks di server".

Dapatkah saya menggunakan SimpleMemo tanpa membuat akun untuk Standard Notes?

Ya. SimpleMemo tidak memerlukan pembuatan akun, dan Anda dapat memulai hanya dengan mengatur alamat email yang ada. Tidak perlu mengatur kata sandi (alamat email tujuan akan dikonfirmasi dengan kode konfirmasi digit 6).

Apakah editor yang diperluas untuk Standard Notes terletak di SimpleMemo?

SimpleMemo tidak memiliki editor yang diperluas seperti Markdown, spreadsheet, dan editor kode. Dengan mengkhususkan diri dalam input tunggal teks biasa, itu menyadari kecepatan start-up 0.4 detik (iPhone 16e, pengukuran aktual awal hangat) dan transmisi satu ketukan. Perbedaan antara Standard Notes untuk buku catatan terstruktur dan SimpleMemo untuk pengambilan instan adalah efektif.

Jika Anda menghargai privasi, mana yang harus Anda pilih, Standard Notes atau SimpleMemo?

Itu bervariasi tergantung pada tujuannya. Jika Anda ingin menyimpan catatan terenkripsi di cloud untuk waktu yang lama, Standard Notes. Jika Anda tidak menyimpan isi memo secara permanen di server aplikasi dan ingin segera menerimanya melalui email, SimpleMemo. Ini juga efektif untuk berbagi pengambilan dan penyimpanan dengan menggabungkan keduanya.
