Gratis dan tidak perlu akun

Masukkan dan buat URL untuk Obsidian.

Anda dapat membuat URI obsidian:// untuk digunakan dengan pintasan iPhone, dll. Mendukung operasi membuka buku catatan, membuat yang baru, dan membuka buku catatan harian. Jika Anda hanya ingin membuat URL, Anda tidak perlu menginstal Obsidian.

Jika Anda hanya ingin menambah catatan harian Anda dengan iPhone, Anda juga dapat menggunakan pintasan standar Obsidian "Capture to Daily Note". Alat ini dimaksudkan untuk bekerja dengan aplikasi atau peluncur lain yang memerlukan URI. Obsidian Periksa fungsi standar dalam panduan resmi iOS.

append/silent dari new sebelumnya adalah bendera telanjang. Ini adalah masukan terpisah dari pengamatan tetap seperti append=benar, dan hanya sintaks yang diperlakukan. Karena efek tunggal harian append tidak dipisahkan, append dihilangkan dari generasi daily di layar ini. Output konvensional dari API murni dipertahankan.

Masukkan nama penyimpanan yang ditampilkan di Obsidian. Bahkan jika namanya kosong atau Jepang, itu akan dikodekan.

Jalur relatif dari rute lemari besi. Contoh: Inbox.md atau Ideas/Inbox.md.

Teks yang Anda masukkan di sini diperbaiki ke URI yang dihasilkan. Jika Anda membagikan URL, pihak lain juga akan dapat melihat teksnya, jadi mohon jangan sertakan konten rahasia.

Konten input akan dikonversi ke URL di peramban ini. Kami tidak menambahkan teks untuk menyimpan, mengirim, atau menganalisis acara.

    Pertanyaan umum
    Apakah Anda ingin menyandikan bahasa Jepang, kosong, #, & pertama?
    Silakan masuk apa adanya. Alat ini mengkodekan nilai input sekali, mengubah kosong menjadi %20, garis miring menjadi %2F, # menjadi %23, dll. String yang telah ditulis sebagai %20 menjadi %2520 untuk mengubah % sebagai karakter menjadi %25. Jeda baris dalam teks juga disimpan sebagai nilai.
    Jika konfirmasi sintaks OK, apakah Obsidian akan selalu berhasil?
    Konfirmasi sintaks adalah kecocokan antara pembacaan kembali query dan nilai input. Pendaftaran Vault, keberadaan file, folder penyimpanan, plugin Core, asosiasi URI OS tidak dicentang. Hanya jika cocok dengan nilai input Linux yang tetap, hasil aktual asli dan kegagalan/premis akan ditampilkan di kolom terpisah. Masukan sewenang-wenang tidak akan dipromosikan ke kesuksesan yang sebenarnya.
    Bagaimana jika Harian dan Unik tidak dibuat?
    Markdown tidak dapat dilakukan dalam input harian pertama dan unik yang asli. Dalam rencana lain yang telah menyiapkan folder penyimpanan, dll., penyimpanan diamati. Aktifkan catatan harian atau pembuat catatan unik dan periksa pengaturan tujuan yang ingin Anda gunakan. Bukan catatan bahwa ditentukan bahwa perubahan premis hanya disebabkan.
    Bagaimana jika Anda ingin menambahkan ke catatan yang sudah ada?
    Masukkan teks yang akan ditambahkan, atur tindakan ke new, target ke jalur relatif, dan tindakan ke append. Dalam contoh tetap asli, teks yang ada dipertahankan dan ditambahkan. overwrite sendiri diganti, dan ada catatan terpisah yang ditambahkan untuk penunjukan simultan append dan overwrite. Alat ini adalah formulir yang memilih satu tindakan.
    Dapatkah saya juga menghasilkan umpan absolut, panggilan balik, dan Hooks?
    Menangani jalur Linux absolut open yang membuka catatan yang ada. path absolut new tidak dapat dibuat setelah enam detik bahkan dengan input non-konflik asli, dan tidak termasuk dalam target yang sesuai. Pengembalian dan output dari panggilan balik dan Hook juga tidak tercapai. Spesifikasi name/file/path dari daily telah ditingkatkan ke file tanggal yang ditetapkan, sehingga tidak termasuk dalam bidang input.
    Apakah konten input akan ditransmisikan dan disimpan?
    Generasi dan tabrakan dilakukan di browser. API untuk mengirim input, menyimpan, dan pengukuran input tidak ditambahkan. Pengukuran tampilan halaman yang ada dan tautan App Store akan dipertahankan. Layar ini hanya salinan, dan URI tidak diaktifkan secara otomatis atau manual. URI bersama berisi teks.
