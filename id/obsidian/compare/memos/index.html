Obsidian × memo

Perbandingan Obsidian dan memo
Garpu faksi tuan rumah mandiri

Keduanya adalah buku catatan "sendiri", tetapi yang Anda pegang berbeda. Obsidian mengelola file Markdown, dan memo mengelola aplikasi web dan basis data dengan sendirinya. Saya benar-benar meluncurkan Memos 0.30.0 di Mac saya dan menyimpan catatan singkat untuk melihat perbedaannya.

Kesimpulan: Memiliki file atau menjalankan layanan

Jika Anda ingin memperlakukan buku catatan secara langsung sebagai file biasa, Obsidian. Jika Anda ingin menulis secara singkat dari browser dan memperlakukan garis waktu, tag, dan ruang lingkup publik sebagai satu aplikasi web, memo adalah kandidat.

Bahkan jika Anda memo host sendiri, buku utama tidak akan menjadi folder Markdown yang sama dengan Obsidian. Dalam startup ini, SQLite diinisialisasi dalam direktori data yang ditentukan oleh Memos. Alih-alih kebebasan, kami melakukan operasi layanan, termasuk cadangan dan pembaruan.

Konfigurasi dan tanggung jawab operasi memo dikonfirmasi dalam panduan Biner resmi, dan pengeditan, tag, hubungan, dan cakupan pengungkapan dikonfirmasi dalam panduan penggunaan resmi.

Saya mencoba memulai Memo 0.30.0 secara lokal dan menyimpannya

Kami mengunduh arsip resmi GitHub Releases untuk Apple Silicon, memastikan SHA-256 cocok dengan checksum yang dipublikasikan, lalu menjalankannya di lingkungan lokal yang tidak dibuka ke publik.

  1. Mulai di area data baru.
    Ketika Anda menentukan direktori sementara yang didedikasikan untuk tugas, SQLite diinisialisasi dan dimulai dengan akses pribadi.
  2. Buat administrator pertama.
    Saya membuat administrator untuk verifikasi lokal di layar pertama. Pencarian, kalender, tag, jangkauan publik, dan bidang input berbaris di halaman beranda.
  3. Simpan catatan singkat dalam bahasa Jepang. Tag
    , item cek yang belum selesai, poin-poin, dan badan dimasukkan ke dalam satu catatan.
  4. Periksa refleksi pada garis waktu. Sebuah catatan ditampilkan segera setelah menyimpan
    , sebuah tag ditambahkan ke kiri, dan 1 ditampilkan di kalender hari itu.

Self-hosting tidak selalu berarti "secara langsung memiliki Markdown"

Di Obsidian, Anda dapat memeriksa substansi buku catatan dengan membuka penyimpanan dengan aplikasi manajemen file. Mampu membaca Markdown yang sama di editor lain adalah pelarian saat mengganti alat.

memos menyediakan layar di mana server membaca dan menulis basis data. Dalam dokumen resmi, standarnya adalah SQLite, dan Anda juga dapat memilih MySQL dan PostgreSQL. Meskipun ini kuat dalam arti bahwa Anda dapat menempatkan data di bawah kendali Anda, ini bukan bentuk membuka ruang penyimpanan Obsidian dan menggunakannya bersama-sama. Jika Anda mengasumsikan migrasi, Anda harus mencoba mencadangkan, memulihkan, dan mengekspor ke format yang diperlukan dengan sedikit sebelum memasukkannya ke dalam produksi. Kali ini, mereka belum diverifikasi.

Memilih memo meningkatkan tanggung jawab operasional daripada fungsi catatan

Pembaruan dan cadangan diperlukan bahkan jika Anda hanya menggunakannya di rumah atau di rumah. Jika Anda mempublikasikannya ke Internet, itu juga akan berurusan dengan domain, proxy terbalik, HTTPS, kontrol akses, dan pemulihan jika terjadi kegagalan. Panduan resmi juga menjelaskan bahwa pengguna biner mengelola peningkatan, pengembalian, pemantauan proses, izin data, dan HTTPS.

Jika Anda dapat menikmati operasi server itu sendiri, atau jika Anda sudah memiliki infrastruktur operasi, hosting mandiri memos adalah pilihan alami. Jika Anda hanya ingin fokus pada catatan, Obsidian, yang menangani file lokal, memudahkan untuk mempersempit cakupan tanggung jawab.

Tidak peduli yang mana yang Anda pilih, pikirkan tentang pintu masuk yang bergerak secara terpisah

Obsidian adalah alat untuk menyimpan dan menghubungkan pengetahuan, dan memo dirancang sebagai alat untuk mengalirkan catatan singkat ke garis waktu. Namun, kecepatan meninggalkan kata dari Apple Watch dan Siri adalah masalah lain. Jika SimpleMemo mengaktifkan tautan Obsidian, itu akan ditambahkan ke catatan harian Obsidian, dll. sambil menyimpan email. Tidak ada fungsi untuk memposting langsung ke memo. Jika tujuannya adalah Obsidian, itu dapat digunakan sebagai pintu masuk tambahan.

Jangan mencampur peran: host sendiri memos dan SimpleMemo tidak berfungsi secara langsung. Hindari ekspresi yang dapat dibaca sehingga dapat ditautkan, dan tentukan tujuan penyimpanan yang sebenarnya terlebih dahulu.

Pertanyaan umum

Mana yang harus saya pilih, Obsidian atau memo?
Jika Anda ingin mengelola file Markdown secara langsung, Obsidian, dan jika Anda ingin merekamnya secara singkat dalam aplikasi web yang Anda jalankan sendiri dan melihat kembali pada garis waktu, memo adalah kandidat.
Bisakah memo menggunakan penyimpanan Obsidian apa adanya?
Saya tidak bisa menggunakannya. SQLite diinisialisasi dalam startup standar ini. Ini bukan mekanisme untuk secara langsung mengedit folder Markdown dari Obsidian.
Apakah memo gratis?
Badan utamanya adalah sumber terbuka. Namun, biaya server dan domain yang dioperasikan secara publik, dan waktu untuk mengelola pembaruan, cadangan, dan keamanan diperlukan secara terpisah.

Lingkungan dan cakupan verifikasi

Konfirmasi mesin aktual: 2026 tahun 9 bulan 8, Apple Silicon Mac/macOS 26.4.1/Memo 0.30.0. Arsip resmi darwin arm64 dirilis. Ini cocok dengan SHA-256 dan hanya diaktifkan secara lokal. Inisialisasi SQLite, akses pribadi, pembuatan administrator, dan penyimpanan catatan, tag, dan tugas bahasa Jepang telah dikonfirmasi.

Tidak terverifikasi: Publik eksternal, HTTPS, banyak pengguna, Spaces, SSO, gunakan dengan terminal lain, pemulihan cadangan, peningkatan, impor/ekspor, seluler, migrasi Obsidian, kolaborasi langsung dengan SimpleMemo. Operasi yang tidak terverifikasi tidak dijamin.
