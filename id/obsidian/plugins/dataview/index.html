Apa fungsi plugin Dataview?

Plugin ini memungkinkan Anda mencari isi Vault (tempat penyimpanan catatan) seperti basis data. Metadata yang ditulis di frontmatter atau bidang inline catatan dapat diolah dengan 4 cara penulisan: DQL, ekspresi inline, DataviewJS, dan ekspresi JS inline. Format keluaran DQL adalah LIST, TABLE, TASK, dan CALENDAR, dan klasifikasi ini tidak sama dengan DataviewJS. Dalam data jumlah unduhan resmi (diambil pada tanggal 22 Agustus 2026), Dataview tercatat 4805635 unduhan dan berada di peringkat ke-3 (jumlah total plugin terdaftar di registri adalah 6,840, tetapi peringkat ini dihitung dalam data jumlah unduhan, yaitu file yang terpisah dari registri).

Tanggal dan waktu pembaruan statistik unduhan saja tidak cukup untuk menilai apakah pengembangan masih berlanjut atau sudah berhenti, maupun bagaimana plugin ini berfungsi saat ini. Angka dan versi di bawah ini adalah data yang diambil pada tanggal 22 Agustus 2026, bukan nilai saat ini.

4 mode kueri — dari contoh di README resmi

README resmi membedakan 4 cara penulisan: DQL, ekspresi inline, DataviewJS, dan ekspresi JS inline. Format keluaran di dalam DQL adalah LIST (daftar), TABLE (tabel), TASK (tugas), dan CALENDAR (kalender tanggal). Kali ini pun, contoh README di bawah ini tidak kami jalankan di perangkat nyata.

1. DQL (Dataview Query Language)

Notasi khusus yang mirip dengan SQL. Cocok untuk penggunaan dasar. 

```dataview
TABLE file.name AS "File", rating AS "Rating" FROM #book
```
2. Ekspresi inline

Tertanam dalam teks dan dievaluasi dalam pratinjau. 

We are on page `= this.file.name`.
3. DataviewJS

Mode paling kuat yang dapat memanfaatkan JavaScript API sepenuhnya. 

```dataviewjs
dv.taskList(dv.pages().file.tasks.where(t => !t.completed));
```
4. Ekspresi JS inline

Versi JavaScript dari ekspresi inline. Anda dapat menjalankan JS apa pun langsung di tempat.

This page was last modified at `$= dv.current().file.mtime`.

Ada 2 cara memasukkan data: YAML frontmatter di awal catatan, diapit ---, atau bidang inline dengan menulis フィールド名:: 値 di dalam isi catatan. Dataview membaca keduanya sebagai data untuk kueri. Contoh yang menghubungkan UI input dan YAML tersimpan ke kueri nyata tersedia dalam demonstrasi perangkat: mengubah properti dan melihat daftar Dataview ikut berubah. 

---
alias: "document"
last-reviewed: 2021-08-17
thoughts:
  rating: 8
  reviewable: false
---
Basic Field:: Value
**Bold Field**:: Nice!
You can also write [field:: inline fields]; multiple [field2:: on the same line].

Tindakan keamanan DataviewJS

Dari README resmi

Seiring kemampuannya yang besar, DataviewJS berjalan dengan hak akses yang sama seperti plugin Obsidian lainnya. Artinya, DataviewJS dapat menulis ulang, membuat, dan menghapus file, serta melakukan komunikasi jaringan. Secara resmi, Anda disarankan hanya menggunakan kode yang Anda tulis sendiri, atau skrip dari sumber distribusi tepercaya yang isinya Anda pahami. Sebaliknya, kueri Dataview biasa (DQL) berjalan di dalam sandbox dan tidak dapat mengubah isi vault (karena itu, kemampuannya lebih terbatas).

Sebelum menulis kueri, tentukan dulu di mana catatan 1 baris akan disimpan

Dataview mencari dan merangkum catatan serta metadata di dalam vault. Jika Anda ingin menyimpan memo yang ditulis di SimpleMemo, aktifkan integrasi, atur folder yang dapat diakses dan lokasi penyimpanan, lalu periksa hasil uji penulisan. Anda dapat memilih catatan bertanggal atau Inbox tetap. Periksa kedatangan email dan penyimpanan catatan secara terpisah, dan bedakan hal ini dari fitur yang membuat bidang untuk Dataview secara otomatis.

Pertanyaan yang Sering Diajukan

Apa fungsi plugin Dataview?
Plugin ini memungkinkan Anda mencari isi Vault (tempat penyimpanan catatan) seperti basis data. Metadata yang ditulis di frontmatter atau bidang inline catatan dapat diolah dengan 4 cara penulisan: DQL, ekspresi inline, DataviewJS, dan ekspresi JS inline. Format keluaran DQL adalah LIST, TABLE, TASK, dan CALENDAR, dan klasifikasi ini tidak sama dengan DataviewJS.
Seberapa banyak Dataview digunakan?
Data jumlah unduhan resmi Obsidian yang diambil langsung pada tanggal 22 Agustus 2026 mencatat 4805635 unduhan; di dalam data tersebut, Dataview menempati peringkat ke-3 (peringkat ke-1 Excalidraw, ke-2 Templater). Sebagai catatan, angka "6,840 plugin terdaftar" adalah jumlah entri dalam daftar registri, yaitu file yang terpisah dari data jumlah unduhan yang digunakan untuk menghitung peringkat.
Apakah Dataview masih dalam pengembangan?
Status pengembangan saat ini tidak dapat dinilai hanya dari catatan statistik dan versi yang diambil pada tanggal 22 Agustus 2026 di halaman ini. Tanggal dan waktu pembaruan statistik berbeda dari tanggal dan waktu pembaruan kode. Periksa rilis resmi dan riwayat perubahan, lalu coba di versi Obsidian yang Anda gunakan. Dalam koreksi kali ini, kami tidak menginstal versi saat ini untuk memeriksa cara kerjanya.
Apa cara dasar untuk menulis Dataview?
Tambahkan metadata di frontmatter (YAML) catatan, atau di bidang inline yang ditulis dalam bentuk "nama bidang:: nilai" di dalam isi catatan. Setelah itu, tulis format tampilan dan kondisi di blok kode (dataview). Misalnya, LIST dan TABLE dapat menampilkan catatan, sedangkan TASK dapat menampilkan tugas di dalam catatan.
Dapatkah saya menggunakan DataviewJS dengan aman?
Menurut README resmi, DataviewJS berjalan dengan hak akses yang sama seperti plugin Obsidian lainnya, sehingga dapat menulis ulang dan menghapus file serta melakukan komunikasi jaringan. Anda disarankan hanya menggunakan kode yang Anda tulis sendiri atau skrip dari sumber distribusi tepercaya. Kueri DQL biasa berjalan di dalam sandbox dan tidak dapat menulis ke vault.
Lingkungan verifikasi dan jangkauan verifikasi

Pada tanggal 30 September 2026, kami membaca ulang README resmi dan penjelasan Query Types, lalu mengoreksi klasifikasi cara penulisan dan format keluaran. Jumlah unduhan, jumlah plugin terdaftar, dan versi saat itu tetap mengacu pada data yang diambil pada tanggal 22 Agustus 2026 dan tidak diambil ulang kali ini. Instalasi Dataview, eksekusi kueri, kompatibilitas dengan versi saat ini, input dari SimpleMemo, dan sinkronisasi ke perangkat lain tidak termasuk dalam verifikasi di perangkat nyata kali ini.
