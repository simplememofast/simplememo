Apa plug-in untuk Dataview?

Ini adalah plug-in yang memungkinkan Anda untuk mencari brankas (Vault) seperti basis data. Metadata yang ditulis di frontmatter dan bidang inline dari catatan dapat ditangani dalam metode penulisan 4 dari DQL, ekspresi inline, DataviewJS, dan ekspresi JS inline. Format keluaran DQL adalah LIST・TABLE・TASK・CALENDAR, yang bukan klasifikasi yang sama dengan DataviewJS. Dalam data unduhan resmi (2026 tahun 8 bulan 22), itu diberi peringkat 3 dengan kasus 4805635 (jumlah total pendaftaran dalam registri adalah 6,840, tetapi peringkatnya adalah peringkat dalam data nomor unduhan file yang berbeda dari ini).

Tidak mungkin untuk menentukan kelanjutan atau penangguhan pengembangan atau operasi saat ini hanya dengan tanggal dan waktu pembaruan statistik unduhan. Nomor dan versi di bawah ini adalah catatan akuisisi 2026 tahun 8 bulan 22, bukan nilai saat ini.

Mode kueri 4 — dari sampel README resmi

README resmi membedakan antara metode penulisan 4: DQL, inline, DataviewJS, dan inline JS. Format keluaran di DQL adalah DAFTAR, TABEL, TUGAS, dan KALENDER. Contoh README berikut juga tidak berjalan di mesin yang sebenarnya kali ini.

1. DQL（Bahasa Kueri Tampilan Data)

Notasi khusus yang mirip dengan SQL. Cocok untuk penggunaan dasar. 

```dataview
TABLE file.name AS "File", rating AS "Rating" FROM #book
```
2. Tipe sebaris

Tertanam dalam teks dan dievaluasi dalam pratinjau. 

We are on page `= this.file.name`.
3. DataviewJS

Mode paling kuat yang dapat memanfaatkan JavaScript API sepenuhnya. 

```dataviewjs
dv.taskList(dv.pages().file.tasks.where(t => !t.completed));
```
4. Tipe JS sebaris

Versi inline JavaScript. Anda dapat menjalankan JS apa pun di tempat. 

This page was last modified at `$= dv.current().file.mtime`.

Ada 2 cara memasukkan data: YAML frontmatter di awal catatan, diapit ---, atau bidang inline dengan menulis フィールド名:: 値 di dalam isi catatan. Dataview membaca keduanya sebagai data untuk kueri. Contoh yang menghubungkan UI input dan YAML tersimpan ke kueri nyata tersedia dalam demonstrasi perangkat: mengubah properti dan melihat daftar Dataview ikut berubah. 

---
alias: "document"
last-reviewed: 2021-08-17
thoughts:
  rating: 8
  reviewable: false
---
Basic Field:: Value
**Bold Field**:: Nice!
You can also write [field:: inline fields]; multiple [field2:: on the same line].

Tindakan keamanan DataviewJS

Dari README resmi

DataviewJS sangat kuat dan berjalan dengan otoritas yang sama dengan plug-in Obsidian lainnya. Dengan kata lain, dimungkinkan untuk menulis ulang, membuat, menghapus file, dan komunikasi jaringan. Secara resmi disarankan untuk hanya menggunakan kode yang Anda tulis sendiri atau skrip dari distributor tepercaya yang memahami kontennya. Di sisi lain, kueri Dataview (DQL) normal adalah kotak pasir dan tidak dapat diubah ke brankas (apa yang dapat dilakukan terbatas).

Sebelum menulis pertanyaan, pertama-tama tentukan di mana harus meninggalkan baris 1

Dataview mencari dan mengumpulkan catatan dan metadata di brankas. Jika Anda ingin meninggalkan catatan yang dimasukkan dari SimpleMemo, nyalakan tautan, atur folder yang dapat diakses dan tujuan penyimpanan, dan periksa tes tulis. Anda dapat memilih catatan tanggal atau Kotak Masuk tetap. Silakan periksa kedatangan email dan simpan catatan secara terpisah, dan bedakan dari fungsi yang secara otomatis menghasilkan bidang untuk Dataview.

Pertanyaan yang Sering Diajukan

Apa plug-in untuk Dataview?
Ini adalah plug-in yang memungkinkan Anda untuk mencari brankas (Vault) seperti basis data. Metadata yang ditulis di frontmatter dan bidang inline dari catatan dapat ditangani dalam dua metode penulisan 4: DQL, ekspresi inline, DataviewJS, dan ekspresi JS inline. Format keluaran DQL adalah LIST・TABLE・TASK・CALENDAR, yang bukan klasifikasi yang sama dengan DataviewJS.
Berapa banyak Dataview yang digunakan?
Data jumlah unduhan resmi Obsidian yang diambil langsung pada tanggal 22 bulan 8 tahun 2026 mencatat 4805635 unduhan; di dalam data tersebut,3th(1 Excalidraw, 2 Templater). Selain itu, "plug-in terdaftar 6,840" adalah jumlah kasus dalam daftar registri, dan itu adalah file terpisah dari data unduhan yang menghitung peringkat.
Apakah Dataview masih dalam pengembangan?
Status pengembangan saat ini tidak dapat ditentukan hanya dengan catatan akuisisi statistik dan versi 2026 tahun 8 bulan 22 di halaman ini. Tanggal dan waktu pembaruan statistik berbeda dari tanggal dan waktu pembaruan kode. Silakan periksa rilis resmi dan riwayat perubahan dan coba dengan versi Obsidian yang Anda gunakan. Dalam koreksi ini, versi saat ini belum diinstal dan operasinya telah dikonfirmasi.
Apa cara dasar untuk menulis Dataview?
Tambahkan metadata ke materi depan (YAML) dari catatan atau bidang sebaris yang ditulis dalam bentuk "nama bidang:: nilai" di badan. Di atas itudataviewTulis format tampilan dan kondisi di blok kode. Misalnya, Anda dapat menampilkan catatan di DAFTAR dan TABEL, dan tugas dalam catatan di TUGAS.
Dapatkah saya menggunakan DataviewJS dengan aman?
Menurut README resmi, DataviewJS berjalan dengan otoritas yang sama dengan plug-in Obsidian lainnya, sehingga dimungkinkan untuk menulis ulang dan menghapus file dan komunikasi jaringan. Disarankan untuk hanya menggunakan kode atau skrip Anda sendiri dari distributor tepercaya. Kueri DQL normal adalah kotak pasir dan tidak dapat ditulis ke brankas.
Lingkungan verifikasi dan jangkauan verifikasi

Saya membaca ulang penjelasan README resmi dan Jenis Pertanyaan pada 2026 tahun 9 bulan 30, dan mengoreksi klasifikasi format penulisan dan keluaran.
