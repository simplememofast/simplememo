Cara menggunakan · Penyimpanan draf secara otomatis

Catatan yang akan Anda tulis akan tetap ada di terminal.

Catatan dalam input secara otomatis disimpan saat input berhenti. Bahkan jika Anda mendapat panggilan di tengah, menutup aplikasi, atau secara tidak sengaja menjatuhkannya - saat berikutnya Anda membukanya, Anda dapat melanjutkan dari tempat terakhir yang Anda simpan. Simpan enkripsi AES-GCM di terminal, dan segera buang jika Anda mengirimkannya. Anda bahkan tidak perlu menyadari "pelestarian".

Dalam satu kalimat

Simpan draf secara otomatis adalah fungsi yang secara otomatis meninggalkan catatan tertulis di terminal. Tidak ada tombol simpan——Saat input berhenti, itu secara otomatis disimpan, dan bahkan setelah aplikasi ditutup atau macet, Anda dapat menulis dari tempat terakhir yang disimpan pada startup berikutnya. Drafnya AES-GCM terenkripsi dan disimpan di iPhone, dan akan segera dibuang setelah catatan dikirim.

Apakah Anda pernah memiliki pengalaman seperti ini?

Hal yang paling menjengkelkan tentang aplikasi memo adalah tulisannya menghilang. Saya mengetuk notifikasi di tengah mengetik kalimat yang panjang, baterai mati, aplikasi ditutup di latar belakang - setiap kali saya berkata, "Oh, apa yang Anda tulis?", Anda dapat mengakhirinya.

📞 Tahan terhadap gangguan
Bahkan jika Anda beralih panggilan, pemberitahuan, dan aplikasi saat mengetik, Anda dapat melanjutkan jika kembali.
💥 Tahan terhadap kerusakan
Bahkan jika aplikasi turun atau OS dihentikan, konten hingga titik terakhir yang disimpan akan kembali ke waktu berikutnya Anda memulai.
🧠 Jangan terganggu
Anda dapat berkonsentrasi untuk menulis tanpa khawatir tentang "Saya menyimpannya".

Karya - ketenangan pikiran 3

  1. Penyimpanan otomatis saat input berhenti
    Draf secara otomatis disimpan sekitar 0.4 detik setelah input karakter berhenti. Tidak perlu menyimpan pada interval yang juga memperhitungkan pemisahan konversi input Jepang (IME).
  2. Simpan untuk konfirmasi tepat sebelum menutup aplikasi
    Kembali ke beranda, beralih aplikasi, dll. Simpan lagi untuk terakhir kalinya ketika aplikasi beralih ke belakang. Akibatnya, bahkan jika OS keluar setelah berbelok ke belakang, konten hingga saat itu akan tetap ada.
  3. Pulihkan "hanya saat kosong" saat startup
    Saat berikutnya Anda membuka aplikasi, jika bidang input kosong, draf akan dipulihkan secara otomatis. Jika Anda sudah mulai menulis sesuatu, itu tidak akan ditimpa. Dan Saat Anda mengirimkannya, draf akan dibuang, dan Anda dapat memulai dengan selembar kertas kosong selanjutnya.

Privasi dan keamanan

Drafnya hanya ada di terminal dan dienkripsi

Draf disimpan di dalam iPhone Anda. Aplikasi tidak mengirim draf ke cloud atau server kami. Draf dienkripsi dengan AES-GCM saat disimpan, dan kuncinya dikelola di Keychain Apple. Perlindungan file juga memastikan file baru dapat dibaca setelah perangkat dibuka kuncinya. Cadangan iPhone (seperti cadangan iCloud) dapat menyertakan draf yang tetap terenkripsi, tetapi kuncinya tidak dipindahkan ke perangkat lain melalui cadangan, sehingga draf tidak dapat dibaca di perangkat lain. Ini mengikuti prinsip desain yang mengutamakan privasi, sama seperti antrean offline (Outbox) dan riwayat pengiriman.

Coba

  1. Pada layar input memo, masukkan beberapa karakter (belum dikirim).
  2. Tutup aplikasi dengan tombol beranda/gerakan beranda atau beralih ke aplikasi lain.
  3. Buka SimpleMemo lagi. Isi tulisan tetap seperti apa adanya.
  4. Ketika Anda mengetuk tombol kirim, draf akan dibuang dan waktu berikutnya akan dimulai dengan selembar kertas kosong.

Pertanyaan yang Sering Diajukan

Di mana tombol simpan untuk draf?

Tidak. Menyimpan itu otomatis. Ketika input berhenti, draf secara otomatis disimpan, jadi tidak perlu mengoperasikan tombol. Bahkan jika Anda menutup aplikasi, konten yang Anda tulis saat berikutnya Anda membukanya tetap ada.

Jika aplikasinya mati, apakah catatan yang akan saya tulis akan hilang?

Konten input secara otomatis disimpan di terminal sekitar 0.4 detik setelah input dihentikan, dan juga disimpan ketika aplikasi dihidupkan di belakang. Bahkan jika aplikasi mogok atau OS ditutup, konten hingga titik terakhir yang disimpan akan kembali ke waktu berikutnya Anda memulai (mungkin tidak ada beberapa karakter yang tersisa tepat sebelum mogok).

Di mana drafnya disimpan? Apakah itu dikirim ke cloud?

Draf akan dienkripsi dan disimpan di iPhone Anda dengan AES-GCM. Aplikasi tidak mengirim draf ke cloud atau server kami (cadangan iPhone (seperti cadangan iCloud) mungkin termasuk dalam enkripsi, tetapi kuncinya tidak berpindah dari cadangan ke terminal lain, sehingga tidak dapat dibaca di terminal lain). Kunci enkripsi dikelola oleh Apple Keychain.

Kapan itu akan dipulihkan? Apakah konten yang dimasukkan akan ditimpa?

Pemulihan selesai saat aplikasi dimulai. Draf dikembalikan hanya ketika bidang input kosong, jadi jika Anda sudah mulai menulis sesuatu, itu tidak akan ditimpa.

Apakah drafnya akan tetap ada setelah dikirim?

Tidak ada yang tersisa. Ketika Anda mengirimkan catatan, draf akan segera dibuang. Lain kali Anda menulis, Anda dapat memulai dengan selembar kertas kosong baru.

Tidakkah aplikasi menjadi berat dengan penyimpanan otomatis?

Saya membuatnya agar tidak menjadi berat. Menyimpan dilakukan dengan pemrosesan latar belakang khusus, dan tidak ditulis ke file selama proses startup, input, dan transmisi (penulisan sekitar 0.4 detik setelah input berhenti).
