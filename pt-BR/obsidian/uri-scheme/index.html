Perguntas frequentes

Qual é a diferença entre obsidian:// e Web comum URL?

obsidian:// é o URI exclusivo recebido por Obsidian. Não é URL para obter a página da web. Verifique a associação no lado do terminal e a operação da nota depois de ir para Obsidian separadamente. A medição real deste artigo é depois de receber o URI do aplicativo Linux.

Como você escreve em japonês, espaços em branco e #?

Codificação URI para cada valor. O espaço em branco é %20, # é %23, / é %2F. O número da especificação de cabeçalho e bloco também é codificado no valor file. No exemplo do autor que deixou o # bruto do texto, o # e o # subsequente não foram salvos.

Eu uso open para adicionar às notas existentes?

O exemplo confirmado do pós-escrito de texto é que file, content, append=true foi passado para new. Há também uma descrição de append/prepend na seção open, mas content não está listado na mesma seção, e o texto não mudou na entrada exploratória desta verificação.

Posso alterar o destino de armazenamento se eu der file ou name para daily?

O texto oficial fixo afirma que o daily recebe os mesmos parâmetros que o new. Por outro lado, nesta entrada do Linux, eu não especifiquei o destino de name, file e path, mas o adicionei à nota de data da configuração de notas diárias. Por favor, verifique as configurações e arquivos reais para o endereço salvo.

Se eu especificar x-success, você confirmou a devolução?

Não. Algumas entradas foram observadas como salvas em new, daily e unique, mas não houve recibo no destino de retorno HTTP. Os atalhos físicos iPhone, iOS e SimpleMemo não são executados neste artigo. Este é o resultado do Vault apenas para o autor do Linux Obsidian1.13.7. Para sintomas específicos do iPhone, consulte o guia de manuseio de atalho existente e verifique-o no terminal.
