Enfie hospedagem ou gerencie os produtos você mesmo

Publish é o serviço oficial de hospedagem que publica notas na web. Quartz é uma ferramenta que gera um site a partir do Markdown e seleciona o destino de entrega do produto separadamente. GitHub Pages é um dos destinos de entrega. Ao combinar Quartz e GitHub Pages, ele lida com duas funções: geração e entrega.

Se você quiser selecionar a nota que deseja publicar e deixar a hospedagem do site para o serviço, verifique as condições de publicação. Se você puder executar comandos, alterar as configurações e gerenciar o destino de entrega você mesmo, tente a geração estática, como Quartz, com uma pequena nota. Se você não precisar publicar apenas as notas salvas na web, decida sobre o propósito antes de escolher serviços adicionais para publicação.

Verifique a taxa separadamente do contrato, destino de entrega e operação

A quantidade atual de Publicação não foi reconfirmada neste ambiente. Por favor, verifique o valor mais recente e o período de cobrança anual e mensal na taxa oficial Obsidian. Com o sucesso dessa construção real, não obtemos o resultado de que o Publish seria gratuito.

A fonte fixa de Quartz foi licenciada pelo MIT. Esta é uma condição para o uso do software, e não é uma condição que o custo do destino de distribuição, domínio original e trabalho de atualização seja uniformemente zero. O custo dessa execução também é desconhecido.

O documento oficial fixo GitHub pode usar Páginas em repositórios públicos em GitHub Free e GitHub Free para organizações, e as condições de Pro/Equipe/Empresa correspondem a repositórios públicos e privados. Verifique o plano, a cobertura pública, as restrições e os termos e condições da conta que você realmente escolheu. Eu também não mudei minha conta ou configurações de hospedagem desta vez.

A lista de preços existente é um artigo que confirmou a indicação oficial sobre 2026 ano 9 mês 9. Desta vez, não será tratado como uma confirmação independente da taxa atual, e as últimas condições de compra serão divididas em informações que exigem confirmação oficial. A sincronização entre Publicar e a sincronização entre terminais também é um serviço separado.

Desenvolva uma fonte fixa, verifique dependências e configurações e construa

  1. Eu verifiquei a ramificação v4 do Quartz oficial e implantei o arquivo de origem do commit d25a6eabf96751ffca56f8a8139272def7a65041 no zero.
  2. Verificado o processo de compilação de README, licença MIT, package.json, package-lock.json e CLI. A versão do pacote é 4.5.2, e a versão necessária é Node 22 ou superior e npm 10.9.2 ou superior. O ambiente real era o Nó 24.19.0 e o npm 11.9.0.
  3. npm ci foi executado com um arquivo de bloqueio fixo. Os pacotes 491 são instalados e saem do 0. As entradas 597 do arquivo de bloqueio são registros que incluem dependências, como o sistema operacional compatível, e não significam o mesmo que o número de exibições de instalação. Os bytes do arquivo de bloqueio original não foram alterados.
  4. Mudei minhas configurações privadas e as criei com Quartz CLI para três notas. O seguinte explicará a mudança de configuração e a primeira falha.

O formato do comando executado é o seguinte. A pasta de entrada e saída no exemplo especifica o local que você preparou.

npm ci --no-audit --no-fund
node quartz/bootstrap-cli.mjs build   --directory /path/to/fixture   --output /path/to/generated   --concurrency 1

O log de execução deixa um caminho absoluto no zero e uma especificação de cache npm isolada. O caminho mostrado aqui é um substituto para a explicação. O comando que omitiu a Auditoria não significa que você passou na auditoria de segurança dependente. O artigo não é um registro do procedimento de implantação para um servidor público.

Perguntas frequentes

Preciso de um contrato de publicação para publicar notas Obsidian na web?
Se você quiser usar o Publish, precisará de uma conta Obsidian e de um contrato de publicação válido no guia oficial. Outro método é colocar o site gerado a partir do Markdown no Quartz para o destino de distribuição de sua própria escolha. Desta vez, verifiquei a geração local do Quartz e não tentei o contrato de publicação ou distribuição externa.
As Páginas Quartz e GitHub são o mesmo tipo de serviço?
Quartz é uma ferramenta que converte Markdown para HTML, CSS, JavaScript, etc., e GitHub Pages é um serviço que distribui sites estáticos do repositório. Está configurado para colocar produtos feitos com Quartzo em Páginas GitHub, etc. GitHub Nós não configuramos, implantamos ou realmente distribuímos para o Pages desta vez.
Onde posso verificar a taxa para Publicação e métodos alternativos?
Você pode verificar o último valor e o período de cobrança do Publish na página oficial de preços. Nesse ambiente, a página de taxa atual não pode ser readquirida e o valor atual não foi confirmado. A fonte fixa do Quartz era uma licença do MIT, mas o destino de entrega, o domínio e os custos operacionais serão confirmados separadamente. Consulte também o documento oficial para as condições do plano para os repositórios públicos e privados das Páginas GitHub.
Posso determinar a compatibilidade da publicação na web e de todas as funções apenas verificando o Quartz desta vez?
Eu não posso julgar. Para o Markdown criado por três autores e um SVG, verificamos a compilação local do commit fixo, a largura de quatro telas, o link interno e o arquivo gerado. Há mudanças de configuração, como desativar o Latex não utilizado e a geração arbitrária de OG. Fórmulas, grande armazenamento, todas as funções Obsidian, distribuição externa, sincronização, cooperação SimpleMemo, velocidade e produtividade não foram verificadas.
