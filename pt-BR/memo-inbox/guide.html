PRIMEIROS PASSOS

Um lugar para notas rápidas.

Sem necessidade de conta. Suas notas ficam neste navegador.

Registrar e encontrar

Escreva no campo Nota, adicione um título opcional e etiquetas separadas por vírgulas e escolha Salvar nota. Você precisa salvar manualmente: alterações ainda não concluídas não são salvas automaticamente. Use a busca para encontrar palavras nos títulos, textos ou etiquetas. Selecione uma etiqueta para filtrar a lista.

Remover e restaurar

Mover para a lixeira mantém a nota disponível para recuperação. Abra a aba Lixeira, selecione a nota e escolha Restaurar nota. Não há botão de exclusão permanente.

Importar texto

Importar arquivos de texto aceita arquivos .txt e .md em UTF-8, com uma nota por arquivo. Os arquivos originais não são modificados. O conteúdo Markdown, incluindo o front matter, é importado como texto simples.

Levar notas para o Obsidian

Exportar ZIP em Markdown inclui todas as notas salvas na caixa de entrada, independentemente do filtro atual. Extraia o ZIP para seu cofre ou outra pasta de Markdown. Títulos, datas e etiquetas são incluídos como metadados YAML. A lixeira e as alterações não salvas ficam de fora.

Manter um backup

Baixar backup salva todas as notas armazenadas, incluindo a lixeira. Guarde esse arquivo JSON em um local seguro. Restaurar backup mescla seu conteúdo com as notas atuais. Notas idênticas são ignoradas; versões conflitantes são mantidas como cópias separadas. Backups inválidos são rejeitados sem alterar as notas salvas.

Entender o armazenamento local

Use o mesmo perfil do navegador e endereço do site para acessar suas notas. Limpar os dados do site, usar navegação privada, a remoção de dados pelo navegador ou perder o dispositivo pode apagar notas locais. Exporte backups regularmente. O aplicativo não criptografa os dados locais e não é um cofre seguro. Não possui sincronização na nuvem, contas ou conexão com o aplicativo Simple Memo para iPhone. Se outra aba alterar suas notas, copie o texto não salvo e recarregue a página antes de salvar.

O aplicativo não envia notas a um servidor e não tem análises de uso nem scripts externos. O serviço de hospedagem recebe as solicitações normais de página. Os links do projeto só abrem sites externos quando selecionados.

Limites

4 MB de dados serializados, 5,000 notas, 200 caracteres por título, 200,000 caracteres por nota e 30 etiquetas de até 50 caracteres cada. As cotas do navegador podem ser menores. Se o salvamento falhar, o texto do editor continua disponível para copiar.
