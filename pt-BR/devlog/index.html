[Day1] Eu amo tanto Captio que quero fazer "essa experiência" novamente
Transmissão e design com um toque para evitar derramamentos - Um primeiro registro de desenvolvimento que desmonta a experiência Captio e registra todos os julgamentos técnicos do UIKit, arquitetura Outbox, Relay API e design de privacidade.
UIKit Outbox Cloudflare Trabalhadores Privacidade Swift

Tópico técnico de escavação profunda

UIKit vs SwiftUI: Seleção para velocidade de inicialização
A razão pela qual escolhi o UIKit no 2026. Projeto de arquitetura voltado para Time-to-Text 500ms ou menos.
Outbox Arquitetura: Design para evitar derramamentos
A interface do usuário é limpa assim que é enviada, mas a mensagem não enviada permanece no terminal e é reenviada. A imagem completa do padrão de criptografia AES-GCM Outbox.
Relay API: Construa uma plataforma de transmissão de e-mail com trabalhadores Cloudflare
Envie sem depender da integração OAuth da caixa de correio. Envie com Resend do relé API (Cloudflare Trabalhadores) que se move na borda.
Design de Privacidade em Primeiro Lugar: Compromisso Paranóico
O escopo da criptografia no terminal, cache de comunicação, registro e análise de uso. A especificação atual que não oculta notas com o switcher de aplicativos também é explicada.
