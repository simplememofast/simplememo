Gratis y sin necesidad de cuenta

Introduzca y cree URL para Obsidian.

Puedes crear un URI obsidian:// para usarlo con accesos directos iPhone, etc. Admite el funcionamiento de abrir cuadernos, crear otros nuevos y abrir cuadernos diarios. Si solo quieres hacer URL, no necesitas instalar Obsidian.

Si solo desea agregar a su nota diaria con iPhone, también puede usar el acceso directo estándar Obsidian "Capture to Daily Note". Esta herramienta está destinada a funcionar con otras aplicaciones o lanzadores que requieren un URI. Obsidian Comprueba las funciones estándar en la guía oficial iOS.

En la sintaxis anterior de new, append/silent son indicadores sin valor. Son entradas distintas de las observaciones fijadas con append=true y aquí solo se trata su sintaxis. Como no se ha aislado el efecto de append por sí solo en las notas diarias, el generador daily de esta pantalla omite append. Se conserva la salida anterior de la API pura.

Introduzca el nombre de almacenamiento que se muestra en Obsidian. Incluso si el nombre está en blanco o es japonés, estará codificado.

Ruta relativa desde la ruta del repositorio. Ejemplo: Inbox.md o Ideas/Inbox.md.

El texto que pones aquí está fijo en el URI generado. Si compartes URL, la otra parte también podrá ver el texto, así que por favor no incluyas contenido secreto.

El contenido de entrada se convertirá a URL en este navegador. No agregamos texto para guardar, enviar o analizar eventos.

    Esta herramienta crea el URI estándar oficial Obsidian. No hacemos obsidian://adv-uri dedicado al complemento de la comunidad Advanced URI. Los símbolos, el japonés y los saltos de línea están codificados para el URI. Si introduce el texto, será una oración fija URL. Para pasar una oración diferente cada vez con un acceso directo, se requiere una configuración separada para codificar el URI de la variable e incorporarlo en el parámetro content. La operación depende de la configuración y el terminal del Obsidian, así que pruébalo primero en una frase corta sin información personal. Fuente: Obsidian oficial "Obsidian URI".
    Para especificar cada acción y comprobar el manejo de japonés y símbolos, consulte también la  guía URI que admite la entrada oficial de elementos 38 y la observación 58 de Linux.
    

    Si no quieres hacer atajos cada vez
    

    Esta herramienta es para crear un URI una vez. Si desea dejar repetidamente oraciones cortas y audio de iPhone a Obsidian, puede ver cómo agregar a la carpeta de almacenamiento seleccionada en Archivos y cómo verificar el almacenamiento en Guía de configuración de SimpleMemo. Se requiere permiso de carpeta para escribir directamente en la aplicación, y por favor verifique el lugar guardado para ver si puede escribirlo correctamente.

    Preguntas frecuentes
    ¿Quieres codificar japonés, espacios en blanco, # y primero?
    Por favor, introdújalo tal como está. Esta herramienta codifica el valor de entrada una vez, convirtiendo el espacio en blanco a %20, la barra a %2F, el # a %23, etc. Una cadena que ya se ha escrito como %20 se convierte en %2520 para convertir % como un carácter a %25. Los saltos de línea en el texto también se mantienen como valores.
    Si la confirmación de la sintaxis está bien, ¿Obsidian siempre tendrá éxito?
    La comprobación de sintaxis consiste en volver a leer query y verificar que coincida con los valores introducidos. No comprueba el registro de la Vault, la existencia del archivo, la carpeta de destino, los complementos del núcleo ni la asociación del URI con el sistema operativo. Solo cuando los valores coinciden con las entradas fijas probadas en Linux se muestran, en un apartado separado, los resultados originales, los fallos y las condiciones previas. Una entrada arbitraria no se presenta como un éxito comprobado en un dispositivo real.
    ¿Qué pasa si no se crean Daily y Unique?
    En las primeras pruebas originales de daily y unique no se pudo realizar Markdown. En otro plan de prueba, con las carpetas de destino preparadas, se observó el guardado. Activa Daily notes o Unique note creator y revisa la configuración del destino que vas a utilizar. Este registro no demuestra que el cambio de condiciones previas fuera la única causa.
    ¿Qué pasa si quieres añadir a tus notas existentes?
    Selecciona new como acción, una ruta relativa como destino y append como comportamiento; después introduce el texto que quieres añadir. El ejemplo fijado original conservó el texto existente y añadió el nuevo. Otro registro muestra que overwrite por sí solo sustituye el texto, mientras que append y overwrite juntos lo añaden. Esta herramienta permite elegir un único comportamiento.
    ¿También puedes generar pases absolutos, devoluciones de llamada y ganchos?
    Se admiten rutas Linux absolutas con open para abrir notas existentes. El path absoluto de new no se incluye entre las opciones compatibles: incluso en la entrada original sin conflicto no se observó la creación tras seis segundos. Tampoco se lograron devoluciones ni salidas de callback o Hook. Los valores de name/file/path enviados a daily terminaron en el archivo fechado configurado, por lo que no se incluyen en los campos de entrada.
    ¿Se transmitirá y guardará el contenido de entrada?
    La generación y la colisionación se realizan dentro del navegador. API para enviar entrada, guardar y medición de entrada no se agregan. Se mantendrá la medición de las páginas vistas existentes y los enlaces App Store. Esta pantalla es solo una copia, y el URI no se activa de forma automática ni manual. El URI compartido contiene el texto.
