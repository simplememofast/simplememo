Qué es SMTP/IMAP

SMTP (Simple Mail Transfer Protocol) es un protocolo de envío de correo; IMAP (Internet Message Access Protocol) sirve para recibirlo y consultarlo. SimpleMemo no usa estos protocolos directamente: envía las notas mediante Cloudflare Workers y la API de Resend, por lo que no requiere configurar SMTP.

Definición

SMTP (Protocolo Simple de Transferencia de Correo) es un protocolo de transmisión de correo electrónico estandarizado en RFC 821 en 1982. Reenvía los mensajes del cliente de correo al servidor de correo o entre los servidores de correo. IMAP (Internet Message Access Protocol) es un protocolo que navega y gestiona los correos electrónicos en un servidor de correo electrónico al que se puede acceder desde varios dispositivos mientras se deja los correos electrónicos en el servidor. A diferencia del antiguo POP3, IMAP admite la gestión de carpetas y descargas parciales.

SMTP vs IMAP vs POP3

SMTP (transmisión)
Un protocolo dedicado para enviar correos electrónicos. Transmita el mensaje al cliente de correo → servidor de envío → servidor de recepción. Utilice el puerto 587 (STARTTLS) o 465 (SSL/TLS). Se requiere un nombre de usuario y una contraseña para la autenticación.
IMAP (recepción y sincronización)
Un protocolo que ve los correos electrónicos mientras los deja en el servidor. Puede ver el mismo correo electrónico en varios dispositivos como iPhone, PC y tableta. Admite la gestión de carpetas, la búsqueda y el marcado. Es la corriente principal de la navegación actual por correo electrónico.
POP3 (tipo de descarga)
Un protocolo para descargar correos electrónicos del servidor al dispositivo. Se eliminará del servidor después de la descarga, por lo que no se puede ver en otros dispositivos. Actualmente está siendo reemplazado por IMAP.

La razón por la que SimpleMemo no necesita establecer SMTP

Las aplicaciones que se envían desde su propia cuenta de correo electrónico pueden requerir configuraciones como el nombre del servidor SMTP (por ejemplo, smtp.gmail.com), el número de puerto (587) y la contraseña de la aplicación para conectarse al servidor SMTP de esa cuenta. SimpleMemo no utiliza este método. El memorando se enviará a los trabajadores de Cloudflare y se entregará por correo electrónico a través de Resend API. Lo único que el usuario puede establecer es una dirección de correo electrónico. Si se autentica con el código de confirmación de 6 dígitos, la configuración está completa.

Preguntas frecuentes (SMTP/IMAP)

¿Qué es SMTP?

Es un protocolo estándar de Internet para enviar correos electrónicos. Reenvía correos electrónicos desde el cliente de correo al servidor de correo y entre servidores.

¿Cuál es la diferencia entre SMTP e IMAP?

SMTP es un protocolo de "enviar", e IMAP es un protocolo de "recepción y visualización". IMAP se puede ver en varios dispositivos mientras se dejan los correos electrónicos en el servidor.

¿Por qué SimpleMemo no necesita configurar SMTP?

Usamos un sistema de retransmisión mediante Cloudflare Workers y la API de Resend, sin conectar directamente al servidor SMTP del usuario. Basta con introducir la dirección de correo y verificarla con un código de 6 dígitos.
