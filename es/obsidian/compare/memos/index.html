Comparación de Obsidian y memos
La bifurcación de la facción de autohost

Ambos son cuadernos "propios", pero lo que tienes es diferente. Obsidian gestiona los archivos Markdown, y memos gestiona las aplicaciones web y las bases de datos por sí misma. De hecho, lancé Memos 0.30.0 en mi Mac y guardé notas cortas para ver la diferencia.

Conclusión: Tener un archivo o ejecutar el servicio

Si desea tratar el cuaderno original directamente como un archivo normal, Obsidian. Si desea escribir brevemente desde el navegador y tratar la línea de tiempo, las etiquetas y el alcance público como una sola aplicación web, memos es un candidato.

Incluso si usted mismo aloja notas, el libro principal no será la misma carpeta Markdown que Obsidian. En este inicio, SQLite se inicializó en el directorio de datos especificado por Memos. En lugar de libertad, realizamos operaciones de servicio, incluyendo copias de seguridad y actualizaciones.

Incluso el autoalojamiento no significa necesariamente "tener Markdown directamente"

Obsidian, puede comprobar la sustancia de la nota abriendo el almacenamiento con la aplicación de gestión de archivos. Ser capaz de leer el mismo Markdown en otro editor es un escape al cambiar de herramientas.

memos proporciona una pantalla en la que el servidor lee y escribe la base de datos. En el documento oficial, el estándar es SQLite, y también puedes elegir MySQL y PostgreSQL. Si bien esto es fuerte en el sentido de que puedes poner los datos bajo tu control, no es una forma de abrir la sala de almacenamiento Obsidian y usarla juntos. Si asume la migración, debe intentar hacer una copia de seguridad, restaurar y exportar al formato requerido con una pequeña cantidad antes de ponerlo en producción. Lo que aumenta cuando eliges notas es la responsabilidad operativa en lugar de la función de nota

Se requieren actualizaciones y copias de seguridad, incluso si solo lo usas en casa o en casa. Si lo publicas en Internet, también se ocupará de dominios, proxy inverso, HTTPS, control de acceso y recuperación en caso de fallo. La guía oficial también explica que los usuarios binarios gestionan actualizaciones, reversos, monitoreo de procesos, permisos de datos y HTTPS.

Si puede disfrutar de la operación del servidor en sí, o si ya tiene una infraestructura operativa, el autoalojamiento de memos es una opción natural. Si desea centrarse solo en las notas, el Obsidian, que maneja archivos locales, facilita el alcance de la responsabilidad.

No importa cuál elijas, la entrada móvil se considerará por separado

Obsidian es una herramienta para almacenar y conectar el conocimiento, y memos está diseñado como una herramienta para transmitir registros cortos a la línea de tiempo. Sin embargo, la velocidad de dejar una palabra de Apple Watch y Siri es otro problema. Si SimpleMemo tiene el enlace Obsidian activado, se agregará a la nota diaria de Obsidian, etc. mientras se mantiene el correo electrónico. No hay ninguna función para publicar directamente en las notas. Si el destino es Obsidian, se puede utilizar como entrada auxiliar.

No mezclar roles: memos y SimpleMemo no funcionan directamente. Evite expresiones que se puedan leer para que puedan vincularse y decida primero el destino de almacenamiento real.

Preguntas frecuentes

¿Cuál debería elegir, Obsidian o notas?
Si desea administrar el archivo Markdown directamente, Obsidian, y si desea grabarlo brevemente en una aplicación web que ejecuta usted mismo y mira hacia atrás en la línea de tiempo, memos es un candidato.
¿Pueden las notas usar el almacenamiento Obsidian tal como está?
No se puede usar. SQLite se inicializó en este inicio estándar. No es un mecanismo para editar directamente la carpeta Markdown de Obsidian.
¿Las notas son gratuitas?
La unidad principal es de código abierto. Sin embargo, el costo de los servidores y dominios operados públicamente, y el tiempo para administrar las actualizaciones, las copias de seguridad y la seguridad se requieren por separado.
