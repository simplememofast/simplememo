Confíe el alojamiento o administre los productos usted mismo

Publish es el servicio oficial de alojamiento que publica notas en la web. Quartz es una herramienta que genera un sitio a partir de Markdown y selecciona el destino de entrega del producto por separado. GitHub Pages es uno de los destinos de entrega. Al combinar las páginas Quartz y GitHub, se trata de dos funciones: generación y entrega.

Si desea seleccionar la nota que desea publicar y dejar el alojamiento del sitio al servicio, compruebe las condiciones de publicación. Si puede ejecutar comandos, cambiar la configuración y administrar el destino de entrega usted mismo, pruebe la generación estática como Quartz con una pequeña nota. Si no necesita publicar solo las notas guardadas en la web, decida el propósito antes de elegir servicios adicionales para la publicación.

Compruebe la tarifa por separado del contrato, el destino de la entrega y la operación

La cantidad actual de publicación no se ha reconfirmado en este entorno. Por favor, compruebe la última cantidad y el período de facturación anual y mensual en Obsidian tarifa oficial. Del éxito de esta construcción real, no obtuimos el resultado de que Publish sería gratis.

La fuente fija de Quartz era una licencia del MIT. Esta es una condición para el uso del software, y no es una condición de que el costo del destino de distribución, el dominio original y el trabajo de actualización sea uniformemente cero. El costo de esta ejecución también es desconocido.

El documento oficial fijo GitHub puede usar Pages en el repositorio público en GitHub Free y GitHub Free para la organización, y las condiciones de Pro/Team/Enterprise corresponden a repositorios públicos y privados. Compruebe el plan, la cobertura pública, las restricciones y los términos y condiciones de la cuenta que realmente elija. Esta vez tampoco he cambiado la configuración de mi cuenta o de alojamiento.

Implemente la fuente fija, compruebe las dependencias y la configuración, y construya

  1. Revisé la rama v4 del Cuarzo oficial e implementé el archivo fuente del commit d25a6eabf96751ffca56f8a8139272def7a65041 en cero.
  2. Comprobó el proceso de construcción de README, licencia MIT, package.json, package-lock.json y CLI. La versión del paquete es 4.5.2, y la versión requerida es Node 22 o superior y npm 10.9.2 o superior. El entorno real era el nodo 24.19.0 y el npm 11.9.0.
  3. npm ci se ejecutó con un archivo de bloqueo fijo. Los paquetes 491 están instalados y salen de 0. Las entradas 597 del archivo de bloqueo son registros que incluyen dependencias como el sistema operativo compatible, y no significan lo mismo que el número de pantallas de instalación. Los bytes del archivo de bloqueo original no han cambiado.
  4. Cambié mi configuración privada y la creé en Quartz CLI para tres notas. Lo siguiente explicará el cambio de configuración y el primer fallo.

La forma del comando ejecutado es la siguiente. La carpeta de entrada y salida en el ejemplo especifica la ubicación que ha preparado.

npm ci --no-audit --no-fund
node quartz/bootstrap-cli.mjs build   --directory /path/to/fixture   --output /path/to/generated   --concurrency 1

La ruta absoluta en scratch y la especificación de caché npm aislada se dejan en el registro de ejecución. La ruta que se muestra aquí es un sustituto de la explicación. El comando que omitió la auditoría no significa que haya pasado la auditoría de seguridad dependiente. El artículo no es un registro del procedimiento de implementación en un servidor público.

Preguntas frecuentes

¿Necesito un contrato de publicación para publicar notas Obsidian en la web?
Para usar Publish, la guía oficial requiere una cuenta Obsidian y un contrato de Publish válido. Otro método es colocar el sitio generado a partir de Markdown en Quartz al destino de distribución de su propia elección. Esta vez, revisé la generación local de Quartz y no probé el contrato de publicación o la distribución externa.
¿Quarz y GitHub Pages son el mismo tipo de servicio?
Quartz es una herramienta que convierte Markdown a HTML, CSS, JavaScript, etc., y GitHub Pages es un servicio que distribuye sitios estáticos desde el repositorio. Está configurado para colocar productos hechos con cuarzo en páginas GitHub, etc. GitHub No hemos configurado, implementado o distribuido realmente a Pages esta vez.
¿Dónde puedo comprobar el precio de la publicación y los métodos alternativos?
Puede consultar la última cantidad y período de facturación de Publish en la página oficial de precios. En este entorno, la página de tarifas actual no se puede volver a adquirir, y la cantidad actual no se ha confirmado. La fuente fija de Quartz era una licencia del MIT, pero el destino de entrega, el dominio y los costos operativos se confirmarán por separado. Consulte también el documento oficial para conocer las condiciones del plan para los repositorios públicos y privados de GitHub Pages.
¿Puedo juzgar la compatibilidad de la publicación web y todas las funciones solo revisando Quartz esta vez?
No puedo juzgar. Para Markdown creado por tres autores y un SVG, comprobamos la compilación local de la confirmación fija, el ancho de cuatro pantallas, el enlace interno y el archivo generado. Hay cambios de configuración, como la desactivación de Latex no utilizado y la generación arbitraria de OG. No se han verificado fórmulas, almacenamiento grande, todas las funciones Obsidian, distribución externa, sincronización, cooperación SimpleMemo, velocidad y productividad.
