La palabra "soporte local" por sí sola no determina el destino de todo el complemento. Los extractos de notas pasadas al modelo, dónde hacer un índice, búsqueda web y servicios de conversión de documentos, y confirmación de diagnóstico y actualización se comprueban por separado.

Separar referencias de notas e índices Miyo

El material explica que el agente lee las notas y pone las partes necesarias en el aviso del modelo de selección. " El comportamiento de "subir todo el Vault solo abriendo el chat del agente" no se explica. Miyo tiene una conexión local y una conexión de servidor remoto, y el índice y el destino de búsqueda se seleccionan por separado. El extracto encontrado en la búsqueda también encaja en el contexto del modelo. Solo usando el índice local, no se puede decir que el extracto no pase al proveedor del modelo. Q03/Q05

El procesamiento de documentos no es uniforme. Según el documento, el procesamiento Miyo de Agent Chat se realiza mediante CLI local, Quick Chat utiliza el servicio Miyo de destino de conexión, y si es remoto, es procesado por ese servidor. El contexto de proyecto guardado que utiliza Web, YouTube y archivos binarios puede usar el servicio de proyecto alojado, y es una ruta diferente de la selección de Miyo. Q03

El modo Self-Host no garantiza el bloqueo de la comunicación

La guía especifica que la nube no se desactiva ni siquiera en el modo Self-Host. La ruta enviada al Claude seleccionado, Codex, modelo de nube, proveedor de búsqueda, etc. seleccionado permanecerá. Esta es una configuración para cada función para comprobar si la función que desea utilizar y el destino de procesamiento aceptable coinciden. Q04

La configuración que puede recuperar el portapapeles y el mensaje real es diferente

La configuración inicial de la versión fija tiene includeClipboard=true, y el generador de contexto tiene una rama que le permite obtener el portapapeles si el valor es verdadero. Por otro lado, los title, starredBlocks y tg_selection en la plantilla inicial citada no son marcadores de posición en portapapeles. Q15/ Q17

El valor resuelto cambia dependiendo de la plantilla, la materia principal, las opciones de contexto y el rango de selección. No trate la lista de valores disponibles como los valores de la solicitud real como los mismos. Esta confirmación del código no da como resultado que "el portapapeles siempre se envía" o "todos los Vault siempre se envían". Q17/Q18

Los caracteres en el campo de clave simple no son evidencia de cifrado

El valor inicial es encrypt_keys=false. Hay un proceso de vaciado de la columna clave simple al guardar, y un proceso de preparación de otro campo relacionado con el secreto. Cuando el cifrado no está disponible o encrypt_keys está desactivado, getEncryptedKey devuelve un valor que conecta el prefijo fijo y la clave de entrada. Incluso si el nombre del campo contiene cifrado/hashed, no se puede determinar que son bytes cifrados por sí mismo. Q15 / Q19 / Q20 / Q21 / Q22

Como no se introdujo ninguna clave, no se verificaron el contenido realmente guardado ni el funcionamiento de safeStorage en este dispositivo. Antes de compartir archivos de configuración o registros de diagnóstico que contengan claves, revisa tanto el campo plain como los demás valores almacenados.

El proveedor inicial de la fuente es OpenAI Chat (Langchain), y el punto final es https://api.openai.com/v1. El proveedor de Ollama tiene una implementación que recibe el conjunto basePath. Preguntas frecuentes

Si selecciono un modelo local, ¿el plug-in no se comunicará en absoluto?
El destino de procesamiento del modelo y el índice, la búsqueda web, la conversión de documentos y la confirmación de actualización son rutas diferentes. Los documentos del copiloto distinguen la ruta de funciones adicionales, y el propio código de Smart Connections tiene la confirmación de actualización GitHub GET. En esta confirmación de documento, no hemos confirmado que todas las funciones no se comuniquen o el contenido real de la transmisión.
¿Smart Connections envía notas al exterior?
La versión fija de README explica cómo crear incrustación e indexación con un modelo local incorporado. Esta es la explicación del proveedor. Hay un URL para la confirmación de la actualización y la orientación inicial en su propia fuente, y algunos modelos y configuraciones dependen externamente. La presencia o ausencia de transmisión real de notas y comunicación completa no se mide en esta comparación.
¿IncluyeClipboard=true En Text Generator Significa Que El Portapapeles Debe Enviarse?
En el código fuente hay una rama que permite al context builder leer el portapapeles cuando ese ajuste es true. Sin embargo, la plantilla inicial mostrada utiliza title, starredBlocks y tg_selection y no incluye clipboard. Un valor disponible y el contenido de una solicitud realmente construida son cosas distintas. No se midió el payload real.
Si la clave API de los datos guardados está vacía, ¿está encriptada la clave?
No es posible juzgar solo por campos clave vacíos. En Text Generator 0.8.7, hay un proceso de guardado que vacía el campo de clave simple y otro campo de guardado, y si el cifrado no está disponible o si encrypt_keys está desactivado, hay una rama que devuelve un prefijo fijo y una clave de entrada. No he probado el almacenamiento real de claves o el comportamiento de cifrado de la plataforma.
¿Este artículo compara la calidad de la respuesta de IA, las tarifas y la operación iPhone?
El objetivo de comparación es la ruta de datos y la configuración que se muestran en los materiales oficiales y el código de la versión fija 3. No hemos confirmado la instalación de plug-ins, el funcionamiento real de la pantalla de configuración, la generación de modelos, la facturación, la comunicación real, el funcionamiento de terminales, incluido iPhone, y el cumplimiento de las políticas de almacenamiento y no aprendizaje del proveedor.
