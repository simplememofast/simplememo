PRIMEROS PASOS

Un lugar para tus notas breves.

No necesitas una cuenta. Tus notas se quedan en este navegador.

Guarda y encuentra tus notas

Escribe en el campo Nota, añade un título opcional y etiquetas separadas por comas, y elige Guardar nota. Debes guardar los cambios de forma explícita: las ediciones sin terminar no se guardan automáticamente. Usa la búsqueda para encontrar palabras en los títulos, el texto o las etiquetas. Selecciona una etiqueta para filtrar la lista.

Eliminar y restaurar

Mover a la papelera permite recuperar la nota después. Abre la pestaña Papelera, selecciónala y elige Restaurar nota. No hay un botón para eliminar de forma permanente.

Importar texto

Importar archivos de texto admite archivos .txt y .md con codificación UTF-8, con una nota por archivo. No modifica los originales. El contenido Markdown, incluidos los metadatos iniciales, se importa como texto sin formato.

Llevar las notas a Obsidian

Exportar ZIP de Markdown incluye todas las notas guardadas de la bandeja de entrada, independientemente del filtro actual. Extrae el ZIP en tu bóveda o en otra carpeta de Markdown. Los títulos, las fechas y las etiquetas se incluyen como metadatos YAML. Se excluyen la papelera y los cambios sin guardar.

Conservar una copia de seguridad

Descargar copia de seguridad guarda todas las notas almacenadas, incluida la papelera. Conserva ese archivo JSON en un lugar seguro. Restaurar desde una copia lo combina con tus notas actuales. Se omiten las notas idénticas y se conservan las versiones en conflicto como copias separadas. Las copias no válidas se rechazan sin modificar las notas guardadas.

Entender el almacenamiento local

Usa el mismo perfil del navegador y la misma dirección del sitio para acceder a tus notas. Borrar los datos del sitio, usar navegación privada, la eliminación de datos por parte del navegador o perder el dispositivo pueden hacer que desaparezcan las notas locales. Exporta copias de seguridad con regularidad. La aplicación no cifra los datos locales y no es una bóveda segura. No tiene sincronización en la nube, cuentas ni conexión con la aplicación Simple Memo para iPhone. Si otra pestaña modifica tus notas, copia el texto sin guardar y recarga la página antes de guardar.

La aplicación no envía notas a ningún servidor y no tiene analítica ni scripts externos. El alojamiento recibe las solicitudes normales de las páginas. Los enlaces del proyecto solo abren sitios externos cuando los seleccionas.

Límites

Los límites son 4 MB de datos serializados, 5,000 notas, 200 caracteres por título, 200,000 caracteres por nota y 30 etiquetas de 50 caracteres cada una. La cuota del navegador puede ser menor. Si falla el guardado, el texto del editor sigue disponible para copiarlo.
