Apple Watch support

Apple Watch voice memo, straight to your email.

Enter a short note on your wrist and pass it through the paired iPhone to your configured email address. Verify the recipient on iPhone, choose the input method on Watch, and confirm arrival in your inbox. Additional Obsidian saving needs its own setup on iPhone.

Read about input and dictation

How do I dictate a memo on Apple Watch?

Apple Watch can turn speech into text in supported input screens. You can also capture into the built-in Notes app on watchOS 26. If your destination is your own email inbox, start with the Simple Memo setup below. This workflow sends confirmed text, not an attached audio recording.

Reviewed September 9, 2026. The author develops Simple Memo. This guide checks Apple’s instructions and the app’s input and send paths; it is not a measured tap-count or delivery-time benchmark across all Watch models.

Set up the receiving address on iPhone first

  1. Open Simple Memo on the paired iPhone. Configure and verify your receiving email address, then send a small test message from iPhone using the first-send guide.
  2. Check that Simple Memo is installed on the Watch. In the iPhone Watch app, look under My Watch and Available Apps if you need to add it. See Apple’s installation guide.
  3. Open Simple Memo on Watch and wait for setup to sync. If it shows setup or sync is pending, check the iPhone app and recipient configuration first.

Free use allows 3 sends per day; see the pricing FAQ. Keep the iPhone and Watch near each other for the first test so you can check both setup and connectivity.

Enter text, submit it, and check the result

  1. Open the app. Use the app list, a Smart Stack widget you added, or a supported watch-face complication.
  2. Choose an input method and speak. The standard input screen opens. If you see a keyboard, choose Dictation using the input-method control. If no input screen appears, tap the app’s central microphone button.
  3. Review the text and press Done. Confirming non-empty text starts the send request. Check names and numbers first; dismiss without confirming if you do not want to send.
  4. Check the receiving inbox. Read the waiting, sent or failed state on Watch, and confirm the same text arrived. If you use Obsidian, open the configured target note as well.

Opening an input screen is different from starting dictation

This page previously said automatic input could not be implemented, and later described dictation as always opening directly. The distinction is now explicit: the app can present the standard input screen; the input method shown can vary. Automatic presentation is intended for a configured app that is ready for input, not every setup or sending state.

WatchKit’s public text-input API can present this system interface. Model, language and screen state affect the available input path. “Open” and “Done” are a shortest-case example only when dictation is already usable and no additional interaction is needed.

If a keyboard appears, the language is wrong, or dictation is missing

Open a text-entry screen and inspect its current input method. Apple’s text-entry guide describes switching among Dictation, the keyboard and Scribble using the input control. Availability depends on model and language. Check the selected input language if the transcript does not match what you said.

If this happens only in Simple Memo, try a text field in another app such as Messages to see whether Dictation is available there. With the paired iPhone nearby, you can also use its Apple Watch Keyboard Input notification to continue entering text. For a longer note, iPhone may be easier to use.

If the app is waiting, fails, or the email does not arrive

Simple Memo passes Watch send requests to the paired iPhone. Its mail workflow does not operate entirely on the Watch’s own Wi-Fi or cellular connection. If the handoff does not progress, open the iPhone app and check the recipient setup, connection and pending items.

A waiting or queued state is not proof of receipt. Check the receiving inbox and spam folder before retrying; use the retry action if the app offers it. Test with a short note first, and preserve unconfirmed text before deleting data or reinstalling an app. See the delivery checks.

Additional Obsidian saving needs vault access and a target configured on iPhone. Follow the integration guide and find the same text in the target note rather than assuming that email arrival confirms the append.

Open the app from the Smart Stack

From the watch face, turn the Digital Crown upward or swipe up from the bottom of the screen. Add Simple Memo’s widget and tap it to open the app. Use Apple’s Smart Stack guide for the editing and rearranging controls available in your watchOS version.

Frequently asked questions

Does dictation automatically start when the Watch app opens?

When setup is complete and the app is ready for input, Simple Memo is designed to open the standard watchOS text-input screen. The input method shown can vary with the model, language and screen state. Switch to Dictation if a keyboard appears; use the app’s central microphone button if the input screen does not open.

Can I send in two taps?

If dictation is already available after launch and no additional choice or confirmation is needed, opening the app and pressing Done can start the send in two taps. Initial setup, unlocking and changing the input method are separate. This does not guarantee a tap count or email arrival time in every configuration.

Can the Watch send email using only its own Wi-Fi or cellular connection?

Simple Memo passes the Watch send request to the paired iPhone. Its email workflow does not run entirely on the Watch’s own connection. If the app shows a waiting or failed state, check the paired iPhone connection and app status, then confirm arrival in the receiving inbox.

Do Watch memos also reach Obsidian?

Additional saving requires the Obsidian integration, vault access and target to be configured on iPhone. An email arriving does not by itself confirm that a note was appended. For your first test, find the same text in the configured note too.

Is this an official Obsidian app for Apple Watch?

No. Simple Memo is an independent app developed by YURIKA, K.K. It is not an official Obsidian app, and you can use it for email to yourself without Obsidian. Free use allows 3 sends per day; check the in-app purchase screen for plans with more sending.

How do I open the Smart Stack?

From the watch face, turn the Digital Crown upward or swipe up from the bottom of the screen. Tap the Simple Memo widget you added to open the app. The editing screen and widget setup labels can vary by watchOS version.
