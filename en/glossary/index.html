Memo App Glossary

Essential terms for understanding memo apps and productivity tools. From encryption technology to productivity methodologies and email protocols — 10 key terms explained clearly and concisely.

Security & Technology Terms

🔐
AES-GCM Encryption
Galois/Counter Mode authenticated encryption — the same cipher family as TLS 1.3, used by Simple Memo for Outbox storage. Includes AES-CBC comparison.
Learn more →
🛡️
E2E Encryption
How end-to-end encryption works, and how Simple Memo's on-device AES-GCM approach compares.
Learn more →
📤
Outbox Architecture
Queue locally, send when connected. The core technical innovation behind Simple Memo.
Learn more →
📡
SMTP/IMAP
How email sending and receiving protocols work, and why Simple Memo needs no SMTP configuration.
Learn more →

Productivity Method Terms

📭
Inbox Zero
Merlin Mann's methodology for keeping your inbox empty. Treating email as a task queue.
Learn more →
📋
GTD
David Allen's Getting Things Done system. Five steps: Capture, Clarify, Organize, Reflect, Engage.
Learn more →
🗃️
Zettelkasten
Niklas Luhmann's slip-box note system. Fleeting notes, literature notes, and permanent notes.
Learn more →
🧠
Second Brain
Tiago Forte's Building a Second Brain and PARA method. A systematic approach to digital knowledge management.
Learn more →
🍅
Pomodoro Technique
Francesco Cirillo's time management technique. 25-minute focus + 5-minute break cycles for peak productivity.
Learn more →
✉️
Captio Method
The "send memo to yourself by email" concept. History and philosophy originating from the Captio app (around 2011).
Learn more →

Knowledge & Learning Terms

📝
Markdown
A lightweight markup language for formatting plain text. The de facto standard supported by most memo apps.
Learn more →
🧠
PKM (Personal Knowledge Management)
A systematic approach to collecting, organizing, and leveraging personal knowledge. The overarching concept behind Second Brain and Zettelkasten.
Learn more →
🔁
Spaced Repetition
A memorization technique using spaced review intervals. Based on the forgetting curve, it optimizes timing to maximize retention.
Learn more →
🗺️
Mind Map
A visual thinking tool that radiates ideas from a central theme. Systematized by Tony Buzan as a visual note-taking method.
Learn more →
📓
Cornell Notes
A note-taking system developed at Cornell University. Divides the page into notes, cues, and summary for effective learning.
Learn more →

Focus & Productivity Terms

📵
Digital Detox
Intentionally disconnecting from digital devices and social media. A practice to restore attention and reclaim deep thinking.
Learn more →
🎯
Deep Work
Cal Newport's concept of performing cognitively demanding work in focused concentration. Understood in contrast with shallow work.
Learn more →
📊
Eisenhower Matrix
A prioritization framework that classifies tasks into 4 quadrants by urgency and importance. Focus on Quadrant 2 (important but not urgent).
Learn more →
📌
Kanban
A visual workflow management method born from Toyota Production System. Visualize tasks on boards with "To Do," "Doing," and "Done" columns.
Learn more →
⏱️
Timeboxing
A time management technique that assigns fixed time blocks to tasks. Leverages deadline pressure to boost focus and completion rates.
Learn more →
Put These Terms into Practice
Simple Memo lets you instantly practice GTD, Inbox Zero, Second Brain, and more with an email-based workflow. Free to download.
