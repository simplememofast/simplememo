Email to Obsidian: iPhone Capture and Received-Mail Workflows

By AI Ataka · Updated: September 9, 2026

Start with the material you want to save

Saving a new iPhone note is different from importing a received email. Simple Memo’s integration writes from iPhone to a note in the folder you configure. It does not automatically collect forwarded messages from an email inbox.

Five steps for new iPhone notes

  1. Open your vault in Obsidian on the same iPhone. Check that Files can access the destination folder and that required iCloud files are downloaded.
  2. In Simple Memo settings, enable the Obsidian integration and choose the destination in Folder. If daily notes live in a subfolder, select that subfolder.
  3. Choose a Daily note destination or a fixed Custom note. A blank custom-note name uses Inbox.md.
  4. Run Test Obsidian write. This test sends no email. Note the filename in its result, then find the test text in Obsidian on iPhone.
  5. Send one short memo and check the same note. If the selected mode also sends email, check the inbox separately; verify another device’s sync as a further step.

The first-note guide includes setup screens and failure checks. Simple Memo and Obsidian Sync have separate costs.

Daily and fixed-note destinations

Direct writing uses yyyy-MM-dd.md in the selected folder for a daily note. It does not automatically read Obsidian’s chosen daily-note folder or date format. For a fixed note, match its name and folder and first verify one saved item.

If you want to save without email

The supported Obsidian-only mode makes Obsidian the memo destination. Enabling it requires Premium, the integration enabled, a selected folder and a successful write test. Read the conditions and confirmation in settings before switching. You do not need to accumulate unwanted copies in an unmonitored mailbox.

In this mode, an unsuccessful file write is handled as pending. If you choose email rescue, recognize it as a separate send. An already-enabled mode does not switch to email solely because Premium ends; the usage allowance changes to the free allowance. Pricing and free allowance

Four checks when the result is missing

  • The write test fails: open the folder in Files, confirm required downloads and select the destination again. Keep the original notes.
  • Email arrives but the note is absent: check the iPhone folder, destination type and filename. Treat inbox success and file saving as separate checks.
  • The note exists on iPhone but not Mac: confirm that both devices use the same vault and a working, supported sync method.
  • Pending items remain: reconnect, open Simple Memo, and inspect retry status and the target note. Keep the pending inventory until you have checked it.

Local writing can fail because of folder access or download state. In the normal email-plus-integration route, a failed direct write may fall back to an Obsidian URI that opens Obsidian. Remaining in the background and saving while offline are not unconditional guarantees.

Four steps for keeping received email as reference

  1. Choose one email and record its subject, sender, date and relevant text in a new Markdown note. Make clear whether the text is a copy or your summary.
  2. Save needed PDFs/images in supported formats and link or embed them in the note. Do not depend solely on remote image URLs used in the original email.
  3. Add a link back to the original when your mail app provides a usable one. It may require the same mail account; try it on the other device you intend to use.
  4. Verify the note’s text, attachments, date and searchability. Keep the original email until checks and any required retention period are complete.

Obsidian: attachments. Before automating a larger import, inspect mailbox permissions, attachments, duplicates, failure reporting and what will enter a shared vault. This page does not test or endorse a specific email-ingestion service.

URI, Watch and sync conditions

Obsidian URI is a built-in route for opening, creating and appending notes from another app. Its daily action requires the built-in Daily Notes feature; that is separate from direct folder writing. If you build a Shortcuts workflow, test it with a limited target note first. Official Obsidian URI specification

Apple Watch capture passes the memo to the paired iPhone, where writing is performed. Check the resulting iPhone note separately from the fact that input was captured on Watch.

Use a sync method that supports the devices involved; iCloud does not work identically across every OS. Neither sync nor self-email replaces a backup of the whole vault. Cross-device sync / Independent backup

Frequently asked questions

Will forwarding an email automatically put it in Obsidian?
The Simple Memo integration described here writes notes captured on iPhone to a configured destination. It is not an importer for received email and does not create an email-address inbox for your vault.
Can I save only to Obsidian without sending email?
A supported Obsidian-only mode is available. Enabling it requires Premium, the integration turned on, a selected folder and a successful write test. Check the conditions and confirmation shown in settings before switching.
Is offline saving guaranteed?
No. The folder and target file must be available on the device with valid write access. Distinguish pending from saved status and check the intended iPhone note after reconnecting.
Why is the email delivered but the Obsidian note missing?
Email arrival does not confirm the file write. Check the selected folder, destination type, note name and iCloud download status, then run the write test first.
Do I need an Obsidian plugin?
Direct folder writing needs no community plugin. A separate route using the Obsidian URI daily action requires Obsidian’s built-in Daily Notes feature to be enabled.
Can I read the same notes on Android or desktop?
Set up a separate sync method that supports your operating systems, then open the synced notes in Obsidian. Do not assume iCloud alone supports every OS; consult the official cross-device guide.
