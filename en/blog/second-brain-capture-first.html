Second Brain / PKM

A second brain starts with capture
Why recording comes before organizing

Find the recorded notes so that you can use them when you need them. Hold down the 4 stage of the CODE and connect the content to be written down, the timing of the look back, and the next action with a small operation example.

TL;DR

Second Brain is a mechanism that not only saves notes, but also uses them for work and study later. At first, decide on a familiar record destination, and leave the reasons and sources that you are interested in together. When looking back, separate the time-limited actions and reference materials, and connect the necessary notes to the actual work. The form of organization can be increased after using it.

1. CODE is the flow of utilization, PARA is the division of organization

Tiago Forte's CODE is a 4 stage method that absorbs information and thinks about how to use it. Capture refers to the recording of information of interest, Organize refers to the organization according to the purpose of use, Distill refers to the extraction of key points, and Express refers to the use of writing, proposals, production, etc. Forte's explanation of CODE emphasizes linking it to current interests and initiatives rather than the amount of acquisation.

PARA is an organization method that divides completed initiatives into Projects, areas to be continuously managed into Areas, reference information of interest into Resources, and those that are not currently used into Archives. CODE and PARA are not the same, and PARA can be used at the Organize stage. Please also refer to PARA's official commentary.

If you want to start now, first handle a small amount of notes that you actually use, and you will know the necessary classification. If you have already decided on a folder or sharing rule at work, you can use it. There is no need to move all notes or prepare a completed dashboard as an initiation requirement.

2 Add "why leave" and the source to the content

Leave a clue at the time of recording so that it doesn't become "what's going on" later. The following is a fictional example for explanation. It is not an actual meeting record or user's results.

Example of a short record

内容: 案内ページに、利用開始までの手順図を入れる案
残す理由: 初回設定の説明に使えそう
出典・日時: 9/9の社内打ち合わせ、自分の提案
次に確認: 9/10の作業開始時に、必要な画面を洗い出す

If you are reading, add the book title and page, and if you are on the Web, add URL, confirmation date, and applicable part. Please separate the quotation from your own interpretation and leave the necessary scope. If it is difficult to search with images alone, add a short explanation of the words you are likely to use when looking for it.

You don't have to fill in all the fields every time. When you are in a hurry, start with the text and add only the background that you are likely to forget. However, requests with a deadline will not be filled in the "Information to be organized later", and the confirmation destination will be determined in time for the deadline.

3. When looking back, decide on the next treatment

Before increasing the number of entries, reserve time to check the current notes. The following table is a simple sorting suggested in this guide. There is no need to transfer all the notes to another app.

Found contentWhat to do nextStatus that can be confirmed
Requests and work with a deadlineReging specific actions, deadlines, and, if necessary, the person in charge in the task management and calendarWhen to check and know what can be done
Materials used for current workLink to related projects and documents and add short points that can be usedYou can return to the original basis from the place where you work
A plan that has not yet been decided on how to use itCheck the reason for leaving, and if necessary, decide on the place of hold and the date of reconfirmationCan be distinguished from unprocessed requests
Duplicate and unnecessary informationCheck and organize the need for storageYou have not mistakenly deleted records necessary for sharing and business

If it is a proposal for the procedure above, change it to the action of "select the required screen 3 and make a draft" to 9/10. Leave a link to the original memo in the draft and write down the reason why you used it in one sentence. This 1 can confirm whether it was connected from storage to use.

It doesn't mean that "if you write it, you can forget everything"

Masicampo and Baumeister’s 2011 study reports experiments in which making specific plans for unfinished goals reduced interference with other tasks. It does not conclude that simply writing something down removes the burden. In light of the paper’s abstract, this guide suggests adding a next step and a review time to notes that require action. The study does not demonstrate the effectiveness of a particular app or the same result for everyone.

4 In the first 1 week, try from recording to utilization

The following method is an example of the introduction. It does not guarantee the time required or the effect of habituation, but please adjust it according to the amount of work and the deadline.

  1. At the beginning: Decide the entrance and the place to look back. Select one inbox, note, email label, etc. of the familiar memo app. If it is necessary to separate work and personal, reserve it as a place to check both.
  2. Date of recording: Check the contents with a deadline. Close schedules and requests will be reflected in task management. For other records, check if there is enough background and source to look back later.
  3. Working day: Use 1 notes. Open the scheduled work and look for reference notes. It will be used for a paragraph of the proposal, the agenda of the meeting, the items to be examined, etc., so that you can return to the original materials.
  4. End of the week: Fix the blocked areas. Check the number of scenes you couldn't write, the notes you couldn't find, and the number of cases you couldn't process. Change one of the necessary points in the operation of the entrance, the explanation of the notes, and the frequency of looking back.

There are some contents that are not in time for weekly reviews alone. If the number of unconfirmed memos continues to increase, make adjustments such as increasing the number of confirmations, narrowing down the storage target, and separateing information from your current work. There is no need for the goal of how many percent to throw away.

5. The record destination is selected according to the usual usage and storage conditions

Start with a place you already open regularly, such as Apple Notes, Notion, Obsidian, or email. Along with input speed, check whether you can find the content later, whether people you share it with can read it, whether necessary information remains available offline, and whether you can export it to another format. A launch time below a specific number of seconds cannot be declared a requirement for maintaining the habit.

  • Complete with the existing memo app:If you can record, search, and use in the same place, you can use it as it is. There is no need to add another capture app.
  • Aggregated to Notion and Obsidian: First, try to save, search, share necessary, and export with a few notes. For offline use, we will also check the pre-acquisition and terminal conditions. You can refer to app comparison by purpose and condition and preparing for offline use.
  • Make an email addressed to you as an entrance:It is a candidate for viewing emails on a daily basis. First, send the 1 and confirm the actual receipt. Please set the search and label according to the sender and subject of the email you received.

For the automatic transfer of emails, if you try only labeling at first, you can check the operation and the habit of looking back. The setting to automatically delete from the inbox will be determined after you can reliably confirm the label and folder. Also check the reception capacity, storage period, account access, and sharing range, and do not think that emails will be stored permanently. Specific examples are summarized in How to use emails addressed to yourself.

6. Setting and confirmation when SimpleMemo is the entrance

SimpleMemo can be used as an entrance to leave short content written in iPhone to the email address, etc. First, please set and authenticate the destination and confirm the first reception. The speed of startup and input and the time of arrival in the other party's mailbox are different.

If you also want to save it to Obsidian, set the link and storage and storage destination in iPhone. Just sending an email does not automatically enter the vault. Follow the Obsidian Collaboration Guide to try a small amount and check the email reception and storage files separately. When using Notion, Notion linkage settings are also required.

Check whether the memo written out of range has been sent or is still waiting for transmission, and also check the recipient after reconnecting. For terms of use, please refer to Explanation of free and paid plans. In addition to "how many items you wrote", the first evaluation can be done by "found in the storage destination and used for the planned work".

Frequently Asked Questions

Where should I start with the second brain?

Decide on the familiar record destination and the timing to look back next. Please leave the content, the reason you are interested in, the source, and the date and time in the first memo, and connect it to the next action or the materials to be used when you look back. It is not necessary to migrate all data or purchase a dedicated template.

What is the difference between CODE and PARA?

CODE is a flow that utilizes information called Capture, Organize, Distill, and Express. PARA is a division of Projects, Areas, Resources, and Archives. PARA is one of the methods that can be used in the organization stage, and there is no need to create a full classification from the beginning.

Which do you need, Notion or Obsidian?

Specific apps are not required. If you can record, search, and reuse with the existing memo app, you can start. Please compare with a small sample whether you need to share or have a database, whether you want to keep a file that you can handle yourself, and how to use offline and export.

Is it enough to look back 1 times a week?

It depends on the content. Requests and schedules with a deadline will be transferred to the task management and calendar that will meet the deadline. Reference materials can be looked back at a set time, such as weekly, but if there are more unconfirmed notes, increase the number of times or narrow down the number of storage.

If I send it to an email addressed to me, will it be automatically saved to Obsidian?

It is not saved in Obsidian just by sending an email. To link the Obsidian of the SimpleMemo, it is necessary to set the link and save destination on the iPhone side. Please check the receipt of the email and the files in the storage separately.
