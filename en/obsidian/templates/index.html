10 practical Obsidian templates to copy and paste

You can copy the text by selecting the type you want to use, such as daily memos, meetings, reading, and surveys. All 10 types were inserted in the author's Linux version of Obsidian, and the title and date and time were replaced, saved, and reopened in the same app.

Verification date: 2026 year 10 month 1 (Japan time) · Obsidian 1.13.7

Choose one from your current use

It is the smallest frame to fill in the blanks. Please add the necessary items according to your work. The input Markdown distributed here and the applied example each maintain the original byte column.

Setting and inserting Core Templates

  1. Create the Templates folder in your practice Vault and place the selected input Markdown files inside it. You can also prepare the same input by pasting the code into a Markdown file.
  2. Enable Templates in Settings → Core plugins. Community plug-ins are not required.
  3. Specify Templates to the Template folder location of Templates. The original screen below is the English UI that was actually set.
  4. Create a new note, decide on a title, and then select the text. In this Linux operation, I created it with Ctrl+N.
  5. Open the command palette with Ctrl+P and search for the Insert template. Select a candidate for Templates and select one template you want to insert.
  6. Check the text and save it. This time, I matched the saved file and the editor's byte column after Ctrl+S, closed the target note, and reopened it from within the same app.

The input of this example is prepared in Source mode. The official description notes that when editing a template containing Properties in Live Preview, variables without quotation marks may be overwritten. Properties' YAML is not used for this 10 input.

The three variables are replaced when inserted

  • {{title}}: The title of the notebook that is actually open.
  • {{date:YYYY-MM-DD}}: This time 2026-10-01.
  • {{time:HH:mm}}: This time 04:29.

The input filenames identify each template type. Titles such as “適用01-日次メモ” in the saved examples are names assigned to notes created through the GUI. The execution environment used the Asia/Tokyo time zone. This does not test every combination of formatting tokens and time zones.

Frequently Asked Questions

What is the difference between Templates and Templater?
The Templates used in this article are the core plug-ins of Obsidian. The three variables used in the actual example are title, date, and time. Templater is another community plug-in and is not activated or executed here.
When will the date and time be?
This time, the clock of the app at the time of inserting the template was used. The Linux verification environment is Asia/Tokyo, and the saved values of all 10 cases were 2026-10-01 and 04:29. This reopening has not confirmed that the saved value will be recalculated when it is opened later.
Do I need to have the same name as the template file name and the note name to be created?
In this test, inputs included 01-日次メモ.md in the Templates folder, while created notes included 適用01-日次メモ.md. {{title}} was replaced with the title of the note actually open in the editor, not the input filename.
When the string {{date:YYYY-MM-DD}} remains as it is?
Simply copying and opening the Markdown leaves the variables as ordinary text. Set the Templates folder, place the cursor in the note body, and choose Templates → Insert template. The examples in this article confirm substitution through those actual GUI operations.
If I expand the ZIP as it is to Vault, will it have the same movement?
In the ZIP Templates, there are 10 inputs, and in the Applied, there are examples of saved results 10 separately. It is a configuration that specifies the folder where the input is placed in the Templates setting. The operation of importing ZIP into the reader's vault has not been verified, so please try one in your own practice vault first.
Have you also verified the cooperation with iPhone and SimpleMemo?
These 10 actual operations were performed only in an author-created Vault using Obsidian 1.13.7 for Linux. This record does not test iOS, Android, Windows, macOS, Obsidian Sync, SimpleMemo, cross-device synchronization, or effects on speed and productivity.

Actual confirmed range

  • Linux official Obsidian1.13.7, installer 1.13.7, English UI. A small Vault created by the author, no community plug-in.
  • Activation of Core Templates, specifying folders, inserting commands for fixed 10 input, replacing titles and dates and times, saving, and reopening notes in the same process.
  • Input is Markdown created directly by the author. Insertion and output notes were created from the GUI, and the auxiliary code was used to prepare the initial environment and read and copy evidence.
  • We retained the original screens and saved Markdown for all 10 cases. Published PNGs were not altered or regenerated. Restarting the entire app, importing into a reader’s Vault, other operating systems, iOS, Sync, SimpleMemo, and effects on speed, productivity, or traffic were not tested.

Startup failure in the preparation stage and script failure to select a command candidate are left. The application results of this article are not a successful treatment of them, but are based on the actual operation of another fixed 10. The original correspondence and progress will be summarized in verification record.
