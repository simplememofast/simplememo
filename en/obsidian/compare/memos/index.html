Obsidian and memos
Choosing a self-hosted approach

Both are "own" notebooks, but the ones you hold are different. Obsidian manages Markdown files, and memos manages web applications and databases by itself. I actually launched Memos 0.30.0 on my Mac and saved short notes to see the difference.

This page isComparison of storage and operation of Obsidian and memos. Do not assume that all self-hosted options are equivalent; consider what you actually need to manage in each case.

Conclusion: Do you have a file or run the service

If you want to treat the original notebook directly as a normal file, Obsidian. If you want to write briefly from the browser and treat the timeline, tags, and public scope as a single web app, memos is a candidate.

Self-hosting memos does not make the authoritative data the same Markdown folder used by Obsidian. During this launch, Memos initialized SQLite in its configured data directory. That flexibility comes with responsibility for operating the service, including backups and updates.

I tried to start Memos 0.30.0 locally and save it

Obtained the Apple Silicon archive of the official GitHub Releases, confirmed that the public checksums and SHA-256 matched, and then started it in a non-public local environment.

  1. Start in a new data area.
    When you specified a temporary directory dedicated to the task, SQLite was initialized and started with private access.
  2. Create the first administrator.
    I created an administrator for local verification on the first screen. Search, calendar, tag, public range, and input fields are lined up on the home page.
  3. Save a short note in Japanese.
    tags, uncompleted check items, bullets, and body were entered into one note.
  4. timeline. A note was displayed immediately after saving
    , a tag was added to the left, and 1 was displayed on the calendar of the day.

Even a self-host does not necessarily mean that you have "Markdown directly"

In Obsidian, you can check the substance of the notebook by opening the storage app with the file management app. Being able to read the same Markdown in another editor is an escape when changing tools.

memos provides a screen in which the server reads and writes the database. In the official document, the standard is SQLite, and you can also choose MySQL and PostgreSQL. While this is strong in the sense that you can put the data under your control, it is not a form of opening the Obsidian storage room and using it together. If you assume migration, you should try backing up, restoring, and exporting to the required format with a small amount before putting it into production. This time, they have not been verified.

Choosing memos increases the operational responsibility rather than the note function

Updates and backups are required even if you only use them at home or in-house. If you publish it to the Internet, it will also deal with domains, reverse proxy, HTTPS, access control, and recovery in the event of failure. The official guide also explains that binary users manage upgrades, rollbacks, process monitoring, data permissions, and HTTPS.

If you can enjoy the server operation itself, or if you already have an operating infrastructure, memos self-hosting is a natural choice. If you want to focus only on notes, the Obsidian, which handles local files, makes it easier to narrow the scope of responsibility.

No matter which one you choose, think about the moving entrance separately

Obsidian is a tool to store and connect knowledge, and memos is designed as a tool to stream short records to the timeline. However, the speed of leaving a word from Apple Watch and Siri is another issue. If SimpleMemo has the Obsidian link turned on, it will be added to the daily note of Obsidian, etc. while keeping the email. There is no function to post directly to memos. If the destination is Obsidian, it can be used as an auxiliary entrance.

Don't mix roles: Memos' self-host and SimpleMemo do not work directly. Avoid expressions that can be read so that they can be linked, and decide on the actual storage destination first.

Frequently Asked Questions

Which should I choose, Obsidian or memos?
If you want to manage the Markdown file directly, Obsidian, and if you want to record briefly in a web app that you run yourself and look back in the timeline, memos is a candidate.
Can memos use the Obsidian storage room as it is?
cannot be used. SQLite was initialized in this standard startup. It is not a mechanism to directly edit the Markdown folder of Obsidian.
Is memos free of charge?
The main body is open source. However, the cost of publicly operated servers and domains, and the time to manage updates, backups, and security are required separately.
