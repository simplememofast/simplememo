Before choosing, look at the model, context, index, and additional functions

The word "local support" alone does not determine the destination of the entire plug-in. Excerpts of notes passed to the model, where to make an index, web search and document conversion services, and diagnosis and update confirmation are checked separately.

  1. Modelprovider・endpoint・agent
  2. Context to refer toSelections, excerpts, templates
  3. Index and searchLocal or another server
  4. Additional functionsWeb, document conversion, diagnosis, update

This diagram organizes the official documentation; it is not a record of actual network traffic. The comparison examines pinned documents and source code. It does not include operating settings screens, making actual requests, or auditing providers’ operations.

First of all, check the path of the function you use in the table below. The "source" in the table represents the constants and branches read from the code, and "source description" represents the description of the README and guide.

Copilot: Even if you choose a model, the route of additional functions remains separately

The fixed version of the guide is divided into hosted, Cloud BYOK, Local BYOK, opencode, Claude, and Codex processing destinations. For example, even if the Local BYOK model is explained as a local endpoint, another service may be involved depending on the skill and project context used. Q03

Separe note references and Miyo indexes

The document explains that the agent reads the notes and puts the necessary parts into the prompt of the selection model. " The behavior of "uploading the entire Vault just by opening Agent Chat" is not explained. Miyo has a local connection and a remote server connection, and the index and search destination are selected separately. The excerpt found in the search also fits into the context of the model. Just by using the local index, it cannot be said that the excerpt does not pass to the model provider. Q03/Q05

Document processing is not uniform. According to the document, Agent Chat's Miyo processing is done by local CLI, Quick Chat uses the connection destination Miyo service, and if it is remote, it is processed by that server. Saved project context that uses Web, YouTube, and binary files may use hosted project service, and it is a different route from Miyo's selection. Q03

Self-Host Mode is not guaranteed to block communication

guide specifies that cloud does not disable even in Self-Host Mode. The route sent to the selected Claude, Codex, cloud model, search provider, etc. will remain. This is a setting for each function to check whether the function you want to use and the acceptable processing destination match. Q04

Text Generator: Check context candidates and key storage branches

The settings that can get the clipboard and the actual prompt are different

The initial setting of the fixed version has includeClipboard=true, and the context builder has a branch that can get the clipboard if the value is true. On the other hand, the title, starredBlocks, and tg_selection in the initial template quoted are not clipboard placeholders. Q15/Q17

The value to be resolved changes depending on the template, frontmatter, context options, and selection range. Do not treat the list of available values as the values in the actual request as the same. This code confirmation does not result that "clipboard is always sent" or "all Vault is always sent". Q17/Q18

Empty characters in the plain key field are not evidence of encryption

The initial value is encrypt_keys=false. There is a process of emptying the plain key column when saving, and a process of preparing another secret-related field. When encryption is unavailable or encrypt_keys is disabled, getEncryptedKey returns a value that connects the fixed prefix and the input key. Even if the field name contains encrypted/hashed, it cannot be determined that it is encrypted bytes by itself. Q15 / Q19 / Q20 / Q21 / Q22

key has not been entered, so the contents of the actual storage and the safeStorage operation of this terminal have not been confirmed. Before sharing configuration files and diagnostic records containing keys, you need to look not only at the plain column but also to other values that are saved.

Select the initial provider and local correspondence separately

The existence of a local provider alone does not establish where other features process data or prove that no network communication occurs. Q15 / Q23 / Q24

Frequently Asked Questions

If I select a local model, won't the plug-in communicate at all?
Model processing, indexing, web search, document conversion, and update checks use separate routes. Copilot’s documentation distinguishes routes for additional features; Smart Connections’ own code includes a GitHub update-check GET request. This document review did not establish that every feature avoids network communication or verify what is actually transmitted.
Does Smart Connections send notes to the outside?
The pinned README states that a built-in local model creates embeddings and an index. This is the provider’s description. The project’s own source includes URL for update checks and initial guidance, while some model and settings code relies on external dependencies. This comparison did not measure whether notes were actually transmitted or whether any other network communication occurred.
Does includeClipboard=true in Text Generator mean that the clipboard must be sent?
source, there is a branch that the context builder can retrieve the clipboard when the setting is true. On the other hand, the initial template posted uses title, starredBlocks, and tg_selection, and does not specify the clipboard. The available value is different from the content of the request that is actually assembled. The actual payload is unmeasured.
If the api_key of the saved data is empty, is the key encrypted?
You can't judge from an empty key field alone. In Text Generator 0.8.7, there is a save process that emptys the plain key field and another save field, and if encryption is not available or if encrypt_keys is disabled, there is a branch that returns a fixed prefix and input key. I haven't tried the actual key storage or platform encryption behavior.
Does this article compare the quality of AI responses, fees, and iPhone operation?
The comparison target is the data path and settings indicated in the official materials and code of the fixed 3 version. We have not confirmed the installation of plug-ins, the actual operation of the setting screen, model generation, billing, actual communication, the operation of terminals including iPhone, and compliance with the provider's storage and non-learning policies.
