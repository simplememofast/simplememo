Entrust hosting or manage the products yourself

Publish is the official hosting service that publishes notes on the web. Quartz is a tool that generates a site from Markdown, and selects the delivery destination of the product separately. GitHub Pages is one of the delivery destinations. When combining Quartz and GitHub Pages, it deals with two roles: generation and delivery.

Select the notes you want to publish and check the Publish conditions if you want to leave the hosting of the site to the service. If you can execute commands, change settings, and manage the delivery destination yourself, try static generation such as Quartz with a small note. If you don't need to publish only the saved notes on the web, decide on the purpose before choosing additional services for publication.

Deploy the fixed source, check the dependencies and settings, and build

  1. I checked the v4 branch of the official Quartz and deployed the source archive of commit d25a6eabf96751ffca56f8a8139272def7a65041 in scratch.
  2. Checked the build process of README, MIT license, package.json, package-lock.json, and CLI. The package version is 4.5.2, and the required version is Node 22 or higher and npm 10.9.2 or higher. The actual environment was Node 24.19.0 and npm 11.9.0.
  3. npm ci was executed with a fixed lockfile. 491 packages are installed and exit 0. The 597 entries of lockfile are records that include dependencies such as compatible OS, and do not mean the same as the number of installation displays. The bytes of the original lockfile have not changed.
  4. I changed my private settings and created it with Quartz CLI for three notes. The following will explain the setting change and the first failure.

The form of the executed command is as follows. The input and output folder in the example specifies the location you have prepared.

npm ci --no-audit --no-fund
node quartz/bootstrap-cli.mjs build   --directory /path/to/fixture   --output /path/to/generated   --concurrency 1

The execution log leaves the absolute path in scratch and the isolated npm cache designation. The path shown here is a replacement for explanation. A command that omits audit does not mean that it has passed a dependent security audit. The article is not a record of the deployment procedure to a public server.

Frequently Asked Questions

Do I need a Publish contract to publish Obsidian notes on the web?
If you want to use Publish, you will need a Obsidian account and a valid Publish contract in the official guide. Another method is to place the site generated from Markdown in Quartz to the distribution destination of your own choice. This time, I checked the local generation of Quartz and did not try the Publish contract or external distribution.
Are Quartz and GitHub Pages the same type of service?
Quartz is a tool that converts Markdown to HTML, CSS, JavaScript, etc., and GitHub Pages is a service that distributes static sites from the repository. It is configured to place products made with Quartz on GitHub Pages, etc. GitHub We have not set up, deployed, or actually distributed to Pages this time.
Where can I check the fees for Publish and alternative methods?
You can check the latest amount and billing period of Publish on the official price page. In this environment, the current fee page cannot be re-acquired, and the current amount has not been confirmed. The fixed source of Quartz was a MIT license, but the delivery destination, domain, and operating costs will be confirmed separately. Please also refer to the official document for the plan conditions for the public and private repositories of GitHub Pages.
Can I judge the compatibility of web publishing and all functions just by checking Quartz this time?
We cannot determine that. For three author-created Markdown files and one SVG, we checked a local build of a pinned commit, four viewport widths, internal links, and generated files. The configuration includes changes such as disabling unused Latex and optional OG image generation. Formulas, large vaults, all Obsidian features, external hosting, synchronization, integration with SimpleMemo, and effects on speed or productivity were not tested.
