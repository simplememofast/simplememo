Daily-note plugins: Calendar and Periodic Notes

Open the note you want to revisit by its date or week number. This example combines Calendar and Periodic Notes to create, save, and reopen daily and weekly notes in the same app.

Tested: 2026-9-30 (UTC) · Obsidian 1.13.7 on Linux

Two distinct roles make setup easier

Calendar lets you choose which date’s note to open. Periodic Notes defines its folder, filename, and initial content. In this test, we created the daily note 2026-09-30 and the weekly note 2026-W40, added an author-written confirmation line to the template content, and saved both.

The main daily-notes guide covers the built-in Daily notes feature in Obsidian and appending notes from iPhone. This article focuses on desktop calendar operations and daily and weekly settings.

Prepare and enable the tested versions

For this example, we manually placed official release files in an isolated, author-created Vault, then enabled and operated the plugins through the GUI. We did not test installation through Community plugins → Browse → Install.

  1. In your practice Vault, create empty folders named 日誌, 週誌, and テンプレート. This example uses the Markdown provided below.
  2. The files used in this example are available in the official Calendar 1.5.10 release and the official Periodic Notes 0.0.17 release. The manual file layout is shown below.
  3. Turn on Daily notes in Settings → Core plugins. In this test, Command palette was also on, and we confirmed that Quick switcher was on.
  4. After confirming trust for the Vault you prepared yourself, enable Periodic Notes and Calendar in Settings → Community plugins. The original screenshot below shows both plugins enabled.
  5. Open the right sidebar and select the Calendar tab. If another tab, such as Backlinks, remains selected, the calendar will not be visible.

Troubleshooting and FAQ

Do I need both Calendar and Periodic Notes?
Use both when you want to combine a calendar entry point with daily and weekly note settings. Calendar provides the date selector; Periodic Notes controls the Daily/Weekly folders, formats, and templates. For the built-in daily-only setup, start with the main daily-notes guide.
What if week numbers are not visible?
In Calendar 1.5.10, enabling Show week number in Settings → Calendar displayed a week-number column on the left. Opening the right sidebar alone may leave another tab, such as Backlinks, selected. Make sure you select the Calendar tab.
What if clicking a date does not open the note?
In this test, New Daily Note and New Weekly Note confirmations appeared in a separate Settings window that was already open, not in the main window. Check both windows, verify the target filename, and select Create in the confirmation. We did not test repeatedly clicking the same date before confirming.
Should the weekly format use YYYY or gggg?
This fixed example used gggg-[W]ww and created 2026-W40 in the environment dated 2026-09-30. The week-based year and calendar year can differ near a year boundary. Keep their formats distinct and check the app’s week-start and locale settings. We did not test all year boundaries, locales, or time zones.
Does this example use template variables or Templater?
The daily input uses the native Obsidian variable {{date:YYYY-MM-DD}}, which we confirmed was replaced with 2026-09-30 during creation. The weekly content is a static author-written template. This example does not cover Templater, JavaScript, arbitrary variables, or every format token.
Does this also work with iPhone, SimpleMemo, and synchronization?
We tested actual operations only in an author-created Vault using Obsidian 1.13.7 on Linux. This record does not test iOS, Android, other operating systems, Obsidian Sync, integration with SimpleMemo, cross-device synchronization, or effects on speed, productivity, or traffic. See the separate daily-notes guide for appending from iPhone.

Verified scope and official sources

  • Official Obsidian 1.13.7 for Linux, Installer 1.13.7, and the English UI. Actual version displays for Calendar 1.5.10 and Periodic Notes 0.0.17.
  • Actual GUI settings in an author-created Vault; one daily note and one weekly note, covering creation confirmation, content, saving, and reopening in the same app. Month navigation was checked in a separate fixed trial.
  • Official plugin release assets were placed manually. Helper code prepared the initial environment, read state and saved files, and copied originals. API calls did not replace creating, editing, saving, or reopening notes.
  • The published PNG and Markdown files retain their original bytes. iOS, other operating systems, SimpleMemo, Sync, every date/week/month/time/time zone, and effects on productivity or traffic were not tested.
