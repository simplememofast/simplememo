Prepare QuickAdd and select Capture

The procedure for introducing the official README is to search for QuickAdd in Obsidian's Settings → Community plugins, install and enable it. In this verification, the distribution file of the official 2.29.0 was placed in a separate repository and the plug-in was enabled. This is not a record of trying all the operations to be installed from the normal list.

If you are concerned about the startup time after enabling it, please also refer to the results and the cutting procedure comparing 0, Templater, Templater+QuickAdd for each 3 in the same Linux repository.

The minimum version of the Obsidian specified by the official manifest of QuickAdd 2.29.0 is 1.13.0. Check the version you are using first. At first, if you make Inbox.md 1 in the same storage without combining automatic date designation and scripts, it will be easier to check the storage destination.

Set the storage location, format, and additional location of Capture

  1. Settings → QuickAdd → New choice → Capture and name the option to Inbox capture.
  2. Capture to active file OFF and enter Inbox.md to Capture to. This is a relative pass from the open vault.
  3. Select Bottom of file under Write position. This setting adds text after the existing body.
  4. Capture format ON and specify - {{VALUE}}. The text written on the input screen will be included in the {{VALUE}}.
  5. Check the input and display settings according to the table below, and close the setting screen with Done.

Frequently Asked Questions

What is the difference between QuickAdd's Capture and Template?
Capture is an option to add text to the notebook you have decided on. Template is an option for creating a new note from a template. The only thing that confirmed the actual operation in this article was Capture, which was added to the end of the existing Inbox.md.
How to add it to the Inbox instead of the open note?
Capture to active file is turned off, Inbox.md is specified for Capture to, and Bottom of file is specified for Write position. In the example of this article, I created Inbox.md first and turned off Create file if it doesn't exist. After entering, open the saved note and check it.
Can QuickAdd be called from outside the Obsidian?
In the official document, there is a way to call up options from obsidian://quickadd URI, Apple Shortcuts, launcher, and desktop Obsidian CLI. It doesn't mean you can't call from outside. What I tried in this article was to run from the command palette in Obsidian, and the external startup has not been verified.
Can iPhone be used in the same way as this setting?
The official manifest of QuickAdd 2.29.0 is not a desktop-only setting, but the actual operation this time is only the Linux version of Obsidian 1.13.7. iPhone, Android setting screen, execution, inter-terminal synchronization, input from SimpleMemo have not been confirmed. Please check the storage destination and the actual addition on your own device.
