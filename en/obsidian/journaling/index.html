What should I prepare to write a diary with Obsidian?

You can prepare 1 dates in the storage room and leave the events of the day in bullet points in the form. There is no need to add tags and plug-ins from the beginning. If you haven't created a vault yet, see How to get started with Obsidian first.

The official Daily notes documentation describes opening today’s note and creating it if it does not exist. The default filename uses the YYYY-MM-DD format. This confirms the documented behavior; it is not a record of operating the settings screen on this Mac.

The following is a fictional completed example for the daily note dated 2026-9-14. You can add times only to entries whose sequence you want to check later.

# 2026-09-14

## 記録
- 09:15 散歩の途中で、来週の発表の導入を思いついた。
- 18:40 下書きを開いた。最初の一段落だけ直した。

## 1日の終わりに
- 明日やることを1つ：導入を声に出して読み直す。
- 覚えておきたいことを1つ：短く始めると下書きに戻りやすかった。

You are free to write long on the day you can write. However, if it is a burden to promise to fill in all the columns every time, reduce it to "record" only. This is an operational option, and it is not a guarantee that everyone will continue.

Try the existing manual template as it is

Save Japanese manual template (Markdown). The original text distributed on this site is the following short text. If you can't save the link, you can copy this content and use it.

# YYYY-MM-DD

## 記録

- HH:mm この例を、残したいことに置き換える。

## 1日の終わりに

- 明日やることを1つ：
- 覚えておきたいことを1つ：

If you want to start by hand, Create a new notebook with the date name in the storage room you want to use, and paste the template text above. Even if you don't know how to transfer the downloaded file, you can try this method to fill in the example.

You can check how to write headings, bullet points, check fields, and internal links in the standard Markdown and Obsidian extended notation real-screen correspondence table.

  1. Prepare a copy of the template for the day's record. Leave the original shape.
  2. Replace the file name and the date of the heading, for example, with 2026-09-14.
  3. Replace the example sentence with HH:mm with your own time and record. If you don't need a time, cut that part.
  4. After saving, open the note in your own Obsidian and check the destination vault, date and text.

YYYY-MM-DD and HH:mm are just characters in this file. It will not change to today's date or automatically enter the vault just by downloading it. The procedure here is a guide for readers to check, and this time, the import into the storage is not performed.

If you want an example of changing the date or check field, you can also use the existing Markdown template tool. I will check separately whether I can save the file there and whether I can import it into my storage. Before trying your personal record, check the flow with a short fictional example.

3 If you look back on the day, separate the event from the next action

If the number of diaries increases, instead of rewriting everything, there is a way to open the most recent notebook and pick up the same topic. The following table is also a fictional entry example. 3 days is a length for description and does not indicate the duration of effectiveness.

DateResidual recordsHandling when looking back
9 month 14 dayI came up with the idea of introducing the presentationLeave it as a plan that has not yet been tried
9 month 15 dayThe beginning was long when I said it out loudDistinguish as actually trying
9 month 16 dayThe introduction has come to an endNext, make sure it will be conveyed to the other party

In this example, by dividing "I came up with" and "I tried", you can choose 1 to do what to do next. If you leave the original text in the notebook of the day and summarize it briefly at the end of the day you look back, you can return to the original record when you change your interpretation later.

If the same topic comes up many times and you want to think about it in another note, you have the option to create a summary at that time. Even if you don't classify everything from the beginning, you can go back to the date first.

Days when you can't write, days when it gets longer, days when you can't find it

  • The day you couldn't write: You can choose to fill in the blank or resume it from the next day. If you write it later, it will be difficult to read it by separating the date of the event and the date of entry, such as "9 month 16 date".
  • The day the diary becomes longer: There is a way to put "what you want to remember" at the end of a long text 1 line. There is no need to shorten the full text.
  • Day when the note cannot be found: Check the open vault, the date of the file name, and the destination folder in order. External additions and date deviations are handled in daily note addition problems.
  • The day it does not appear on another terminal: Check the saving and synchronization separately. For operation on multiple terminals, go to comparison of synchronization methods. The synchronization setting does not complete only with the template in this article.

On days when you don't want to look back, you can just use a record of events. If you want to continue using Obsidian as a place to keep records, please decide according to your own burden.

When proceeding to the automatic template, distinguish the variables

The manual template and the Obsidian insert value template are different. In the formula Templates description, variables with curly braces such as {{date}} and {{time}} are guided.

The template specification for Daily notes is a setting for the body when creating a new date note. Don't think that it will be applied uniformly to the diary that already exists later. At the stage when you want to automate it, please read the official documents above and try it with your own settings.

If you proceed with Templater's <% … %> notation, Templater's execution example and daily note settings are covered in a separate article.
