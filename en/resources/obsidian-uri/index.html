Build a URL for Obsidian.

You can create a obsidian:// URI to use with iPhone shortcuts, etc. Supports the operation of opening notebooks, creating new ones, and opening daily notebooks. If you just want to make URL, you don't need to install Obsidian.

If you only want to add to your daily note with iPhone, you can also use the Obsidian standard "Capture to Daily Note" shortcut. This tool is intended to work with other apps or launchers that require a URI. Obsidian Check the standard functions in the official iOS guide.

The conventional new append/silent is a naked flag. It is a separate input from fixed observations such as append=true, and only syntax is treated. Since the daily append single effect is not separated, the append is omitted in the daily generation of this screen. The conventional output of the pure API is retained.

Enter the vault name shown in Obsidian. Names containing spaces or Japanese characters are encoded.

Relative path from the route of the vault. Example: Inbox.md or Ideas/Inbox.md.

The text you put here is fixed to the generated URI. If you share URL, the other party will also be able to see the text, so please do not include secret content.

Your input is converted to a URL in this browser. It is not saved, sent, or included in analytics events.

    Frequently Asked Questions
    Do you want to encode Japanese, spaces, #, & first?
    Please enter it as it is. This tool encodes the input value once, converting the blank to %20, the slash to %2F, the # to %23, etc. A string that has already been written as %20 becomes %2520 to convert % as a character to %25. Line breaks in the text are also kept as values.
    If the syntax confirmation is OK, will Obsidian always succeed?
    The syntax check reads the query back and compares it with the input values. It does not inspect Vault registration, file existence, destination folders, core plugins, or OS URI associations. Only inputs matching the fixed Linux examples show the original actual results, failures, and prerequisites in a separate field. Arbitrary inputs are not labeled as successful device tests.
    What if Daily and Unique are not created?
    The original first daily/unique inputs did not create Markdown. Saving was observed in a separate trial that prepared the destination folder and other prerequisites. Enable Daily notes or Unique note creator and check the intended destination settings. The record does not establish that the changed prerequisites alone caused the different outcome.
    What if you want to add it to your existing notes?
    Choose new as the action, a relative path as the target and append as the behavior, then enter the text to add. The original fixed example preserved the existing text and appended the new text. A separate record shows replacement with overwrite alone and appending when append and overwrite are both supplied. This tool lets you select one behavior.
    Can you also generate absolute paths, callbacks, and Hooks?
    The absolute Linux path of open to open an existing note will be handled. The absolute path of new cannot be observed after six seconds even with the original non-conflict input, and is not included in the corresponding target. The return and output of callback and Hook were also not reached. The daily name/file/path specification has been advanced to the set date file, so it is not included in the input field.
    Will the input content be sent and saved?
    Generation and comparison take place in your browser. We added no API that sends your input, no input storage, and no input measurement. Existing page-view and App Store-link analytics remain. This interface only copies the URI; it does not launch it automatically or manually. A URI you share contains its note body.
