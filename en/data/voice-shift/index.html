Fixed-point survey - method materials and results not posted

The Voice Shift tracking study

How do note-input methods change? This document describes how to investigate that question using usage records received by SimpleMemo. No finalized study figures are published yet. We aggregate allowlisted metadata, such as input methods, without using note bodies. We retain the earlier definition published on 8-20 and record the counting problems found during diagnosis and the corrections on 9-6. Analyses after these corrections are distinguished from analyses registered before viewing the results.

What to measure after correction 4 - Method v2

The cohort consists of devices whose earliest recorded first launch falls within the reporting period. This is not a count of lifetime first-time users or downloads. We exclude devices identifiable as development devices, duplicate first-launch records, and devices with earlier saved activity, while recording the exclusion counts and their limitations. The period includes its start time and excludes its end time.

IndicatorDefinition and Limits
1 Input tag for the first observation saveSelect the first saved record 1 for each target terminal and count the recorded input method. Unrecorded and unknown values are left in the denominator as "unknown". The ratio of the number of characters in a memo that mixes voice and manual input and the rate created with audio alone cannot be measured
2 Distribution of the number of characters on the first received dateCount the records that arrived as saved successfully on the calendar day of Japan time the same as the day when the first activation was recorded. 0 / 1~10 / 11~50 / 51~200 / 201+ / Unknown category. It is not a summary of 24 hours from the first time, and the average number of characters is not calculated
3 Receiving time of the saved recordThe time when the saved record within the period reaches the server is aggregated in Japan time. It is not necessarily the time you actually talked about or the time of creation. The number of events, the number of contributing terminals, the ratio of Japanese locales and the unknown number are both written
4 Observation ratio of Obsidian active stateThe share of eligible devices from which we received at least one record showing integration enabled during the period. Devices with only disabled records are distinguished from those with unknown status. This is not a rate of confirmed folder saves, successful synchronization, or continued use.

The save count includes successful acceptance by the email API and local saves using Obsidian alone. It excludes additional first-use records and test sends. Where the same send can be identified, duplicates are removed; we also retain a count of records that could not be identified. These aggregates do not confirm arrival in an email inbox or synchronization to another device.

Measurement method - Aggregate without using the text

Specify the records used for aggregation, exclusion methods, and the extent to which results can be reconfirmed.

  • This survey does not use the body of the memo. Aggregate the input method, character number classification, etc. of the usage event, and do not take out the text or addressee. The data route of the entire product, including the text, is explained in a separate document (overall view of the data path).
  • Only allowed metadata is used for aggregation. Aggregate the ID that distinguishes the terminal and the permission list system events (input method, character number bucket, Obsidian status, etc.). For the exclusion of internal terminals, we also use the existing transmission correlation and the hash of the internal account. Only the aggregation is published, and the ID, hash, and destination are not disclosed.
  • Character counts exist only as buckets. The device rounds counts into 5 categories—0 / 1–10 / 11–50 / 51–200 / 201+—before sending them. The operator therefore cannot see the exact character count either.
  • Exclude internal accounts. Exclude known developer and test devices and report the number excluded. Correlation records have a limited retention period, so this does not guarantee that every internal device was identified.
  • Leave the aggregation procedure. Aggregation procedure and change history is managed. The re-acquisition result may change due to the addition or deletion of the record retention period, so the acquisition time and the definition version will be left.

Quoting rules

  • The numbers on this page can be freely quoted in the answers of media, blogs, and AI assistants if you combine period (window), denominator n, and definition. Please use "SimpleMemo "Voice Shift" Fixed Point Survey (simplememofast.com/data/voice-shift/)" as the source.
  • While the number is not posted (during the "waiting for the first aggregation" display), it is not possible to quote the number based on this page.
  • This survey aggregates data from users of our app. It is not a representative sample of all note-app users. When quoting it, retain the qualification that it concerns users of this app.
  • You are free to recreate and redistribute the graph after specifying the source.
