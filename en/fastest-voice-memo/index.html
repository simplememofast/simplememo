In brief

Assign Voice Memo to the Action button or Back Tap. This shortcut requests voice input itself; the setting for auto-starting on a normal app launch is optional. You need a supported device and language on iOS 26 or later, completed initial setup, microphone and speech permission, and a ready language model.

Fewer repeated steps, with preparation first

This entry avoids finding the app icon and microphone each time. Launching, speaking, correcting text, network conditions and destination availability still take time.

👆 Launch without finding the icon
Press and hold the assigned Action button. If the phone asks you to unlock or authenticate, follow its instructions.
🎙️ Request voice input
Voice Memo opens the editor and starts voice input when the conditions are met. Permission prompts and model preparation can add a wait.
📂 Set destinations beforehand
Verify your email recipient. If you also use Obsidian, configure the integration and destination. Routes include direct folder saving and opening Obsidian to pass the text. Check settings before sending and the target note afterward.
✍️ Check the text before sending
Review names and numbers, correct them with the keyboard if needed, then send. The free plan allows three sends a day.

Set up and check the first memo

  • A device and language supported for voice input on iOS 26 or later. Back Tap support by itself does not establish voice input support.
  • Completed app setup and a verified recipient when using email.
  • Microphone and speech permission, and any required language-model preparation.
  1. Assign the trigger
    iPhone Settings → Action Button → Shortcut → Choose a Shortcut → Voice Memo. On a supported phone without an Action button, assign it under Settings → Accessibility → Touch → Back Tap.
  2. Prepare voice input once
    Open the app, complete initial setup, then tap the microphone to grant permission and prepare the model. First use can take longer than a few seconds.
  3. Try one short memo
    Hold the button, check that recording has started, and say a short sentence. Review the text before sending, then check email receipt or the configured vault note.
  4. Optional: auto-start on a normal launch
    To start recording when opening the app from its icon too, enable Auto-start voice input on launch under Settings → Voice Input & Sound. It is not required just to use the Voice Memo shortcut.
If it does not work

If Voice Memo is missing from the list, open the app, complete initial setup and reopen the shortcut picker. If the editor opens without recording, check iOS and language support, microphone and speech permission, and model preparation. If the memo is missing at its destination, check history, connectivity, email verification and the vault folder.

⚠ If you use it on the move

Holding your phone or watching the screen while driving or riding is illegal and dangerous in Japan (distracted cycling has been penalized since Nov 2024). Stop somewhere safe first. See hands-free voice memo for how to use it on the move.

FAQ

Does it always take five seconds?

No. The earlier five-second wording was based on one short voice-entry example. It does not guarantee setup, permissions, model preparation, authentication, longer speech, editing, email receipt or cross-device sync times. This update does not newly benchmark every route on the current app.

What if my iPhone has no Action button?

Assign Voice Memo to Back Tap, or use a supported widget or Siri entry. Voice input still needs a supported device and language on iOS 26 or later. Back Tap on an older iPhone does not by itself make voice input available.

Do I need to build my own shortcut?

No, when the app-provided Voice Memo shortcut is available. Complete initial app setup, then assign it in iPhone settings.

Is auto-start voice on launch required?

Not for the Voice Memo shortcut: this entry requests voice input itself. Use Auto-start voice input on launch (Settings → Voice Input & Sound) if you also want voice to start when opening the app normally. Both routes still need support, permissions and a prepared model.

Where does the text go?

Voice transcription happens on device. Review the text and send it through your configured email or Obsidian route. Email receipt and vault saving are separate results. Obsidian-only mode suppresses email while active, but disabling integration, losing the folder setting or an unavailable mode can return sending to the email route. Check the current destination and mode before sending, then confirm the actual text at the destination.

What if I misspeak?

Read the text and correct it with the keyboard before sending. Repeating a sentence does not necessarily replace the earlier text. After an interruption, reopen the app and check whether the draft is present.
