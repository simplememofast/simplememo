iCloudメールでObsidian連携シンプルメモを使う

iCloudメールアドレスをObsidian連携シンプルメモの送信先に設定する手順を解説します。iCloudのおかげで、iPhone・iPad・MacのすべてのAppleデバイスで送信したメモを受信できます。

著者: AI ATAKA

このページの内容

始める前に確認すること

  • iPhone（iOS 16.0以降）を用意する
  • iCloudメールアドレス（@icloud.com、@me.com、@mac.com）を手元に用意する
  • iPhoneの「設定 → 自分の名前 → iCloud → メール」で「このiPhoneで使用」がオンになっているか確認する
  • Obsidian連携シンプルメモをApp Storeからダウンロードする

設定手順（5ステップ）

  1. アプリをダウンロードする
    App Storeで「Obsidian連携シンプルメモ」を検索してダウンロードします。またはこちらのリンクから直接ダウンロードできます。
  2. アプリを起動して設定画面を開く
    アプリを起動するとメモ入力画面が表示されます。画面左上の設定アイコン（歯車マーク）をタップして設定画面を開きます。
  3. iCloudメールアドレスを入力する
    「メール設定」の「宛先」をタップし、メモを受け取りたいiCloudアドレス（例：yourname@icloud.com）を入力して「認証」をタップします。「メール認証」の画面が開き、確認コードが送られます（初めてメモを送るときに出る「このメモを自分のメールへ」の画面で入れた場合は、「確認コードを送る」をタップします）。
  4. iCloudメールに届いた6桁の確認コードを入力する
    iPhoneのメールアプリを開き、受信トレイを確認します。シンプルメモ（noreply@mail.simplememofast.com）から確認コードのメールが届いているので、6桁の数字をアプリに入力して「認証」をタップします。届いていない場合は迷惑メールフォルダも確認してください。
  5. 設定完了 — メモを送り始める
    設定が完了しました。メモ入力画面でテキストを書いて送信ボタンをタップすると、iCloudメールの受信トレイにすぐにメモが届きます。iPhone・iPad・MacのすべてのAppleデバイスに同期されます。Freeプランは1日3通まで、利用期間の制限なく無料で使えます。

iCloudメールでメモを活用するコツ

ヒント 1 — Appleエコシステムで全デバイス受信

iCloudメールに届いたメモは、iCloud経由でiPhone・iPad・Macのすべてに自動同期されます。iPhoneで書いたメモをMacのMailアプリで確認する、といった使い方が自然にできます。

ヒント 2 — Mailアプリのフィルタリング機能で整理

Mac版のMailアプリでは「スマートメールボックス」機能を使って、送信元（noreply@mail.simplememofast.com）から届いたメモを自動的に専用フォルダに整理できます。メニューバーの「メールボックス → 新規スマートメールボックス」から設定できます。

ヒント 3 — iCloud.comでどこからでもアクセス

iCloudメールにはiCloud.com（Webブラウザ）からもアクセスできます。PCからメモを確認したいときはiCloud.comにサインインするだけで、すべてのメモをWebブラウザで閲覧できます。

トラブルシューティング

確認コードがiCloudメールに届かない

まず迷惑メールフォルダを確認してください。次に、「設定 → 自分の名前 → iCloud → メール」で「このiPhoneで使用」がオンになっているかを確認してください。オフだと、このiPhoneのメールAppでは届いたメールを見られません。オンにした後、アプリで確認コードを再送してください。

iCloudメールアドレスを持っていない場合はどうすればいいですか？

iCloudメールアドレスは「設定 → 自分の名前 → iCloud → iCloudメール（またはメール）」から、画面の案内に沿って作成できます。作った@icloud.comのアドレスは、あとから変更できません（Apple Accountのメールアドレスとは別物です）。

メモが届いているのに通知が来ない

iPhoneの「設定 → 通知 → メール」でメールの通知が有効になっているか確認してください。また、メールアカウントごとの通知設定で、iCloudのアカウントが有効になっているかも確認してください。

@me.comや@mac.comのアドレスでも設定できますか？

はい。@me.comと@mac.comはAppleの旧iCloudメールアドレスで、@icloud.comと同じシステムで管理されているため、同様に設定できます。

よくある質問

iCloudメールが届かないのですが？

迷惑メールフォルダを確認し、「設定 → 自分の名前 → iCloud → メール」で「このiPhoneで使用」がオンになっているか確認してください。オフだと、このiPhoneのメールAppでは届いたメールを見られません。

@me.comや@mac.comでも使えますか？

はい。これらはAppleの旧iCloudメールドメインで、@icloud.comと同じシステムです。

メモは1日何通まで送れますか？

Freeプランは1日3通まで（利用期間の制限なし）。Premiumプラン（月額500円/年額5,000円）で無制限になります。

iPhoneで書いたメモをMacでも見られますか？

はい。iCloudメールに届いたメモはiCloud経由でMacのMailアプリに自動同期されます。MacでもiPadでもすぐに確認できます。

オフライン時に書いたメモはどうなりますか？

オフラインのときに送信ボタンを押したメモは、送信待ち（Outbox）としてAES-GCMで暗号化して端末に保存され、オンラインに戻ると自動で送信されます。まだ送っていない書きかけのメモも、下書きとして暗号化して端末に保存されます。

iCloudメールにメモを送り始める
ダウンロードは無料。設定はすぐに終わります。
