Appleショートカットで作る5つの設定例

iPhoneで自分にメールを送る
5つのショートカットと送信前の確認画面

テキストメモ、音声の文字起こし、スクリーンショットの文字、日記、到着時の入力を、自分の受信トレイへ送る仕組みを作ります。最初は送信前の確認画面を表示し、宛先と内容を確認しましょう。

このガイドについて著者はSimple Memoを開発しています。このページはAppleのショートカットとメールを使って手動で作成する手順を紹介します。作成済みのiCloudファイルのダウンロードはありません。アクション名や確認画面はiOSのバージョンにより異なります。手順はAppleの文書と照合していますが、作成したショートカットは自分の端末でテストしてください。

ショートカットの「Show Compose Sheet」とは？

Appleメールの「Send Email」アクションで「Show Compose Sheet」を有効にすると、送信をタップする前にメールの確認画面が表示されます。アクションのオプションを展開すると見つかります。オフにすると、その画面を表示せずに送信を試みます。ただし、権限やアカウントの設定、端末のロック、オートメーション自体の確認設定によっては、実行が中断される場合があります。

最初のテストではオンにしてください。送信者、宛先のメールアドレス、件名、本文を確認します。差し支えのないテストメモを1通送ったら、宛先の受信トレイを確認してください。ショートカットが完了しても、メールの到着を証明するものではありません。後から確認画面を無効にした場合は、実際に使う起動方法でも再テストしてください。

Apple は、いくつかのアクションはショートカットアプリを開く必要があること、そしてトリガー確認と個々のアクション設定は別々であることと説明しています。 1つの設定を無効にしても、無人のワークフローが保証されるわけではありません。

開始する前に

Appleメールを開き、送信用アカウントが設定され、動作することを確認してください。宛先のGmailやOutlookのアドレスが分かるだけでは不十分です。ここで使う「Send Email」はAppleメールのアクションです。宛先には自分のメールアドレスを指定してください。

ショートカットの「＋」から新しいショートカットを作成し、名前を付けて、アクションを検索しながら順番に追加します。作成とテストの手順は、Appleのカスタムショートカットのガイドで確認できます。以下の例では、最初の設定を簡単にするため件名を固定します。日付の取得・書式設定アクションは後から追加できます。

失いたくないメモは、メール送信の前にコピーを保存してください。例えばApple NotesのCreate Note（メモを作成）アクションを挿入し、同じテキストを渡します。この手順を頼りにする前に、保存したメモを開けることを確認してください。ここで紹介する設定例には、独自の再試行キューはありません。

受信トレイを保存先にすると便利な場面

普段から受信トレイを確認する習慣があるなら、自分宛てのメールが役立ちます。件名を「メモ」などにそろえると、書き留めた内容を見つけやすくなります。知識をまとめる用途なら、Apple Notes、Notion、Obsidianを整理先にする方法もあります。実際に見返す場所を選んでください。

設定例1：テキストメモをメールで送る

  1. 「メモをメールで送る」という名前のショートカットを作ります。Ask for Input（入力を要求）を追加し、入力の種類をテキストに設定します。入力を促す文には「何を覚えておきたいですか？」を指定します。
  2. その下にAppleメールのSend Email（メールを送信）アクションを追加します。宛先に自分のメールアドレス、件名に「メモ」を入力します。
  3. 変数の選択画面から、本文にAsk for Inputの出力を指定します。「Provided Input」という文字列をそのまま本文に入力しないでください。
  4. Send Emailの設定を展開し、Show Compose Sheetをオンにしておきます。ショートカットを実行して短いテストメモを入力し、送信前に下書きを確認します。送信後は受信トレイへの到着も確認してください。
  5. 動作を確認できたら、必要に応じてショートカットのメニューからホーム画面に追加します。ワンタップで起動できても、テキストの入力や確認操作は必要です。

入力した値が次のアクションに渡される仕組みは、AppleのAsk for Inputのガイドで説明されています。

設定例2：音声の文字起こしをメールで送る

  1. テキスト用の設定例を複製して「音声メモをメールで送る」と名付けます。Ask for InputをDictate Text（音声入力）に置き換えます。
  2. 端末で選べる言語と音声入力の停止方法を設定します。アクションが求めるマイクや音声認識の権限を許可してください。
  3. Send Emailの本文に設定していた変数を、Dictate Textの出力に置き換えます。件名は「音声メモ」とし、送信前の確認画面をオンにしておきます。
  4. 静止状態で実行し、短い文を話し、送信する前に文字起こしを確認してください。 名前、数字、句読点は修正が必要になる場合があります。

この設定例で送るのは音声録音ではなく、文字起こしです。特定の世代のiPhoneでオフライン動作すると決めつけないでください。Appleは、音声入力で利用できる機能は言語と地域によって異なると説明しています。ただし、この一般的な説明は、すべての設定でショートカットのアクションをテストした結果ではありません。メール配信にも通信接続が必要です。

設定例3：スクリーンショットの文字をメールで送る

  1. Select Photos（写真を選択）を使ってショートカットを作ります。実行時にスクリーンショットを1枚選び、どの画像を処理するのかを明確にします。
  2. Extract Text from Image（画像からテキストを抽出）を追加し、選択した写真を渡します。端末でこのアクションを検索してください。利用できるかどうかや認識言語は、インストールされているシステムにより異なります。
  3. Send Emailを追加します。宛先を自分のメールアドレス、件名を「スクリーンショットの文字」、本文をExtract Text from Imageの出力に設定します。
  4. Show Compose Sheetをオンにしておきます。数行の文字がはっきり写ったスクリーンショットを選び、送信前に下書きと画像を照合します。抽出した文字が空だったり不正確だったりした場合は、送信をキャンセルして元の内容を修正してください。

この設定例はスクリーンショットを添付せず、抽出した文字だけをメールに渡します。画像を自分で選ぶため、無関係な「最新のスクリーンショット」を誤って使うことも防げます。抽出アクションが使えない場合は、端末で利用できる機能で画像内の文字をコピーし、設定例1を使ってください。

設定例4：毎日の日記の入力を促す

  1. 設定例1を複製します。入力を促す文を「今日のことで覚えておきたいことを1つ挙げると？」、件名を「日記」に変更します。
  2. スケジュールを追加する前に、ショートカットを手動でテストしてください。
  3. ショートカットのオートメーションを開き、時刻を指定するオートメーションを作成します。時刻と繰り返す曜日を選び、日記用のショートカットを選択するか、Run Shortcutで呼び出します。
  4. 実行前の確認を求める設定がある場合は、有効にします。「Run After Confirmation」があるバージョンではそれを選び、ほかのバージョンでは「Ask Before Running」を使います。メールの確認画面もオンのままにしてください。
  5. 次の予定時刻に通知を開いて日記を入力し、内容を確認してから送信します。予定どおり動くと判断する前に、メールの到着を確認してください。

Appleは、イベントトリガーの文書で時刻の指定方法を説明しています。予定時刻に起動しても、日記が自動で書かれるわけではありません。Ask for Inputには自分で入力する必要があります。

設定例5：到着時に入力を促す

  1. 設定例1を複製します。入力を促す文を「ここで覚えておきたいことは？」、件名を「職場のメモ」などの固定文にして、手動でテストします。
  2. Arrive（到着）をきっかけにするオートメーションを作ります。場所を選び、地図上で範囲を調整してください。
  3. ショートカットを選択するか、Run Shortcutを追加して呼び出します。トリガーの実行確認を設定できる場合は、メールの確認画面とともに有効にしておきます。
  4. 実際に到着したとき、立ち止まって入力できる状態で画面を確認します。入力した内容が受信トレイに届くことも確認してください。

Appleの移動に関するトリガーのガイドに、場所の範囲や時間帯の指定方法があります。この設定例は位置情報をきっかけに入力を促しますが、メールにGPS座標を追加しません。検知のタイミングは変わることがあるので、到着時の動作が不安定なら、時刻指定か手動実行のショートカットを使ってください。

記録の保存先を選ぶ

自作のショートカットは、自分で使い方を調整し、維持したい人に向いています。トリガーの追加や確認画面の省略をする前に、まずはシンプルな構成で動作を確認してください。

Simple Memoも、iPhoneで入力したテキストを設定済みのメール受信トレイへ送る方法の1つです。任意でObsidian連携も使えます。Freeは1日3通まで（利用期間の制限なし）。送信待ちのメモは端末内のOutboxに保持され、実際のメール配信には接続と送信の成功が必要です。保存できたことを配信完了とみなさず、送信待ちや失敗したメモを確認してください。

Outboxと送信履歴は端末内で暗号化されますが、メールは配信システムを経由します。メールのエンドツーエンド暗号化ではありません。プライバシーポリシーをご確認ください。ここで述べているのは使い方の違いであり、Simple Memoとショートカットの速度を実測して順位付けしたものではありません。

メールが届かない場合

  • まずメール単体で切り分ける：同じ送信用アカウントから短いメールを手動で送ってください。失敗する場合は、先にアカウントや接続の問題を解決します。
  • アクションを確認する：Show Compose Sheetをオンにして、送信者、宛先、実際の出力変数を確認します。本文が空だったり変数名の文字列がそのまま入っていたりする場合は、入力の受け渡しに問題があります。
  • 起動のきっかけと処理内容を切り分ける：ショートカットアプリから直接実行します。そこで動くなら、オートメーションが有効になっているか、確認設定がどうなっているかを調べてください。
  • 再試行の前に到着を確認する：宛先の受信トレイと迷惑メールフォルダを確認し、利用できる場合はメールアプリの送信済みフォルダとOutboxも確認します。送信済みの記録は送信操作の証拠であり、到着の確認先は宛先の受信トレイです。状態が分からないまま何度も再送しないでください。
  • 未送信の文章を残す：エラー画面を閉じる前に、文章をコピーするかメモに保存します。メールのオフライン時の動作はアカウントやアクションによって異なります。この設定例には、送信待ちを保存して再試行する独自の仕組みはありません。
  • 変更後の再確認: アカウント、権限、または iOS の変更は既存のショートカットに影響を与える可能性があります。 通常の起動方法で短いテストを繰り返してください。
いつも見返す受信トレイへ書き留める
Simple MemoはiPhoneでテキストを記録するアプリです。Freeは1日3通まで（利用期間の制限なし）で、送信待ちのメッセージにはOutboxを使います。上記のAppleショートカットの設定例は、Simple Memoをインストールせずに作ることもできます。
